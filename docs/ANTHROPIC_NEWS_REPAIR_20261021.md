# Anthropic News 日期解析修復（2026-10-21）

官方新聞索引仍回傳 HTTP 200，但新版將日期放在文章卡片／列表列中，
不再放在標題連結內，原解析器因而回報 `invalid_page_fields`；公開健康
狀態將此錯誤統一標示為 `invalid_source`。

解析器保留舊版連結內日期，新增同一 `article` 或 TableView summary 列的
日期配對。僅接受一個日期與同一文章網址，不跨列借日期；成功解析日期後
才去重，避免無日期的同網址連結遮蔽有效列。既有 45 日來源窗口、出版者、
權重與健康零則判定不變，沒有新增請求、依賴、全文抓取或日報政策。

新增 8 項回歸案例，涵蓋新版兩種版型、舊版、去重、缺日期、歧義日期、
不同文章隔離與過期有效文章。完整本機回歸 1482 passed（含本機既有、
尚未部署的台灣來源觀察測試）；正式 CI 只涵蓋已追蹤並提交的測試。
實際頁面離線回放取得 13 個不重複、符合 45 日窗口的文章，
不是當日 24 小時新增 13 則。正式來源健康需待部署後的既有自然刷新確認。

## Free LLM APIs 移除影響評估（本輪不移除）

目前免費額度來源因退役 provider 的說明文字被當成模型名稱而整批拒收。
其失敗不影響獨立 LLM Price Tracker；後者本次公開資料截至 2026-10-20，
涵蓋 17 家 provider、64 個模型。這是第三方目錄覆蓋，不是完整市場清單。

若完整移除 Free LLM APIs：

- 保留模型輸入／輸出、Batch 輸入／輸出、快取讀／寫的六種單價差異。
  本次非空欄位依序為 64、59、29、26、24、7 個模型，缺欄位不補造價格。
- 保留價格目錄新增／移除與欄位出現／消失提醒、既有 old/new 值及證據連結。
  目錄移除不等於官方模型下架。
- 失去免費方案 provider、免費模型清單、RPM／RPD、註冊與可用狀態異動。
- Usage4Claude、Claude Usage Monitor 仍是「額度與政策速報」的候選線索；
  它們不是價格來源，也不能補上被移除的免費額度結構化比較。
- 價格區會剩一個價格資料來源，無價格差異時按既有規則隱藏；目前
  `market-signals.json` 零則不代表價格感測器失敗。

就現況而言，移除不會降低目前已正常運作的價格差異功能，會放棄修復
免費額度監測的能力。若獲准完整移除，需一併清理來源健康、舊 free_tier
比較基準及其留存訊號，避免產生假移除事件；區塊名稱宜改為「模型價格變更」。
本輪沒有執行上述移除或更名。

詳細 HTTP 證據與數值評估位於 Downloads 的
`ai-news-radar-source-incidents-20261021/`、
`ai-news-radar-anthropic-fix-20261021/`，不覆寫正式資料快照。
