# C06 本機私人日報預覽操作與邊界

狀態：2026-10-09 已完成本機**合成資料**預覽；未部署，也沒有 iPhone 遠端實測。
此頁使用 [C05 校稿服務](../scripts/digest_cloud_editorial.py) 的同一套 revision、
request 去重及原稿選版規則。它不接入真實私人日報、正式帳號或雲端保存。

## 在 Mac 上查看

於本專案根目錄執行：

```bash
.venv/bin/python -m scripts.digest_cloud_preview
```

程式只綁定 `127.0.0.1`，啟動後在終端機印出本機網址；於**同一部 Mac**
的瀏覽器打開該網址。預設建立當天期別的兩則合成新聞。可用
`--issue-date YYYY-MM-DD` 指定合成期別，或 `--port 8765` 固定本機埠。
輸入與驗證的暫存工作區預設位於 `~/Downloads/ai-news-radar-cloud-preview/`，
中間檔在生成流程結束後清理；原稿、控制紀錄、校稿歷史只在目前程序記憶體。
按 `Ctrl-C` 停止後，重開會回到 revision 0。

頁面顯示期別、交付狀態、預設原稿、正在校稿的原稿、revision、來源，
以及每則明確的「題號 → story ID」。可用大按鈕保留/排除、調整順序、
在標題及摘要欄位使用系統聽寫、儲存、讀回、還原歷史內容、明確選版、
匯出指定版本的 JSON。每次保存都帶 `expected_revision` 與新的 `request_id`；
伺服器成功後，頁面還會以 `applied_revision` 讀回比對內容雜湊。若另一頁
先修改，舊頁面會顯示目前版本與重新讀取入口，並保留尚未套用的輸入，
不會自動合併。切換或重新讀取前如有未儲存改動，會先提醒。

伺服器只向本機提供合成資料、限制 Host/Origin、使用每次啟動的隨機
預覽 token、拒絕超限請求，並標示無快取與限制內容安全政策。這些是
本機預覽邊界，**不構成正式登入、跨裝置私人存取或雲端權限驗證**。
來源網址均為 `.invalid` 合成樣本，頁面只以文字顯示，不會自動連外。

## 已驗證與待驗證

- `tests/test_digest_cloud_preview.py` 的五個案例涵蓋合成資料與題號映射、
  HTTP 邊界、修改/讀回/衝突/還原/匯出、選版控制版本、無網路/殼層呼叫。
- 已在本機瀏覽器以手機寬度檢查可讀排版；實際操作過標題編輯→保存→讀回、
  revision 0 還原，以及兩頁同時編輯後的可見衝突提示。
- **尚未**在 iPhone ChatGPT App、Safari、語音控制或 Mac 關機情境測試；
  `127.0.0.1` 只指向 Mac 自己，不能把本頁連結當成手機可用的雲端入口。
- C07 必須先依 C01 實測手機端工具/網頁可行性，再接正式服務；
  不可用本頁成功或模擬 owner 代替授權、持久交易及手機驗收。

回復方式：停止本機預覽程序即可；新檔案僅為
`scripts/digest_cloud_preview.py`、`private_preview/` 與測試、文件。
沒有修改公開首頁、Actions、Pages、既有私人稿、正式排程或憑證。
