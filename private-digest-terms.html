適用範圍

本工具供專案維護者本人使用，不提供對外帳號註冊、代管校稿或付費服務。Google OAuth 的發布狀態只是授權應用程式的設定，不是私人稿件的發布功能。

操作方式

日報由指定的 GitHub 工作產生，原稿與人工校稿分開保存。程式不覆寫已保存的原稿或人工校稿，但檔案擁有者仍可在 Drive 手動修改。

內容與發布

日報依既有公開來源快照選題，資料可能不足或過時。保存成功不代表新聞已查證、日報已達標或已發布；發布前由維護者人工校稿與決定。

帳號與憑證

請使用本人授權的 Google 帳號。不要將密鑰、權杖或私人稿件放進公開儲存庫、Issue 或日誌。需要停止存取時，可撤銷 Google 授權並移除 GitHub 中的相關 Secrets。
