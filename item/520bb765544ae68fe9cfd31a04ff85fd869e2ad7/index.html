Title
Amazon Bedrock 推出适用于 OpenAI GPT 模型的 Web Search
Source
AWS News
Published
2026-08-04T20:37:00Z
Summary
今天，我们宣布 Amazon Bedrock 的 Web Search 全面推出，这是一款内置的服务器端工具，完全在 AWS 内部执行 Web 搜索，支持 OpenAI 模型（GPT-5.4、GPT-5.5 和 GPT-5.6 Sol/Terra/Luna）利用最新 Web 知识对输出响应做事实锚定，同时保障数据驻留在受保护的 AWS 环境内，实现零数据外溢。以前，要实现 Web 事实锚定，需要接入第三方搜索提供商、管理单独的 API 密钥和账单、建立自定义编排，并对每家外部供应商开展额外合规审查。Web Search 通过在现有 API 调用中使用单个参数启用事实锚定，无需供应商接入，无需编排外部 API，也无需额外开展供应商安全审查，省去大量复杂工作。 Web Search 由 Amazon 基于多年在 Alexa+、Amazon Quick 和 Kiro 方面的经验构建而成。它将 Amazon 运营的 Web 索引与提供经过验证的事实的内置知识图谱相结合，该索引涵盖了持续更新的数百亿个文档。Web Search 不返回原始页面，而是执行语义片段提取，以低延迟提供针对模型上下文窗口进行优化、上下文利用率高的搜索结果。Web Search 通过标准工具使用接口进行集成，与 OpenAI Responses API 兼容。只需将 Web Search 工具添加到您的 API 调用中，Bedrock 即可在服务器端处理整个搜索生命周期；一次 API 调用即可返回附带引用出处、经过事实锚定的响应。 Amazon Bedrock 的 Web Search 现已在美国东部（弗吉尼亚州北部）、美国东部（俄亥俄州）和美国西部（俄勒冈州）正式推出。要开始使用，请阅读我们的博客文章 Introducing Web Search on Amazon Bedrock for foundation model grounding ，查看 《Amazon Bedrock 用户指南》中的“Web Search”部分 以获取技术文档，并访问 Amazon Bedrock 定价页面 了解费用详情。
