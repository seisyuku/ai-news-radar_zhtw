來源摘要（原文）
通过 Amazon Bedrock AgentCore 提供的 AWS 智能体注册表现已在 AWS GovCloud（美国西部）区域推出。 AWS 智能体注册表是一项完全托管式的发现服务，可为您的组织提供一个集中式目录，用于对资源进行组织、整理和发现。您可以将 MCP 服务器、工具、智能体、智能体技能和自定义资源发布到可搜索的注册表，并通过审批工作流控制哪些内容可发现。然后，人员和智能体可以通过混合搜索、目录浏览和原生 MCP 端点找到合适的工具和智能体。 借助 AWS GovCloud（美国西部）的智能体注册表，公共部门组织及其合作伙伴可以获得其环境中智能体和工具的单一受监管清单。审批工作流和 AWS CloudTrail 审计日志有助于满足其合规性和监督要求。 要开始使用，请参阅 AWS 智能体注册表文档 。
