Title
Amazon Bedrock 现已针对 OpenAI 模型支持推理摘要
Source
AWS News
Published
2026-10-09T17:44:00Z
Summary
Amazon Bedrock 现已通过响应 API 支持适用于 OpenAI 模型的 reasoning.summary 参数。借助该功能，您可以在获取模型响应的同时，请求一份通俗易懂的推理摘要，从而帮助您理解模型在处理编码、分析和多步骤问题解决等复杂任务时的思路。 推理摘要为开发人员提供了额外的上下文信息，有助于评估模型响应、调试应用程序以及向用户展示模型处理请求的过程。该摘要通过推理输出项中的 summary 数组返回，与模型的回答一同呈现。 该功能适用于 Amazon Bedrock 上的所有 OpenAI 模型，已在提供 OpenAI GPT 模型的所有 AWS 区域推出，并支持区域内推理、地理（GEO）跨区域推理和全球跨区域推理。 要了解更多信息，请参阅有关 Reasoning summaries 的 OpenAI 文档。要在 Amazon Bedrock 上开始使用 OpenAI GPT 模型，请参阅 此处 的文档。
