Title
Grok 4.7 现已在 Amazon Bedrock 上推出
Source
AWS News
Published
2026-09-28T18:29:00Z
Summary
Amazon Bedrock 现在支持 SpaceXAI Grok 4.7，这是一种专为编码、代理式任务和知识工作而构建的前沿模型，具有美国地理位置和全球跨区域推理功能。 Grok 4.7 在 Grok 4.6 的基础上进行了优化，具备更出色的混合文档处理能力、更可靠的存储库规模编程能力（包括规划和错误恢复功能），以及增强的浏览器代理功能，可用于表单填写和门户导航。 您可以在 Amazon Bedrock 控制台 中或通过受支持的 Amazon Bedrock API 以编程方式开始使用 Grok 4.7。有关支持的 AWS 区域 、端点、API、功能、推理配置文件和定价的信息，请参阅 Amazon Bedrock 文档 。要了解更多信息，请参阅发布 博客文章 。
