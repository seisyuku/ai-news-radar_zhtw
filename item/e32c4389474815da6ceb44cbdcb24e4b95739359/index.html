Title
用于迁移的 AWS Transform 扩大了对现有登录区的支持
Source
AWS News
Published
2026-10-20T08:00:00Z
Summary
现在，在为您的迁移构建登录区（包括 AWS Control Tower 登录区和使用 AWS Organizations 构建的登录区）时，AWS Transform 支持更多类型的现有 AWS 环境。AWS Transform 会对照 AWS 最佳实践对您当前的环境进行基础差距分析，并在目标账户中已有的登录区的基础上扩展您的登录区，让您的团队能够更快地开始迁移。 AWS Transform 现在还支持仅限基础设施即代码（IaC）模式，用于为您的迁移构建登录区。在此模式下，AWS Transform 会分析您的组织，生成建议，并以 AWS CDK、Terraform 或登录区加速器（LZA）形式生成为您的迁移计划量身定制的 IaC。仅限 IaC 模式专为不愿授予 AWS Transform 直接访问其管理账户的权限的组织而设计。AWS Transform 现在可以改为通过委派管理员（DA）账户进行连接。这对那些自行管理部署管道且不需要代理进行自动部署的客户来说也是有益的。 用于迁移的 AWS Transform 登录区代理可实现登录区的全程自动设计，包括基础设置、组织单元（OU）和账户结构、服务控制策略（SCP）以及与您的迁移计划和波次一致的工作负载账户。您可以直接部署或为自己的管道生成 IaC。 这些新功能已在 用于迁移的 AWS Transform 支持的所有目标 AWS 区域 推出。 要了解更多信息，请参阅 AWS Transform 用户指南 。
