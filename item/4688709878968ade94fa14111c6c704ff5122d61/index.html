Title
AWS Entity Resolution 数据匹配服务现已支持高级实时匹配
Source
AWS News
Published
2026-07-22T19:00:00Z
Summary
AWS Entity Resolution 数据匹配服务现已支持使用高级匹配流程进行实时匹配，可让客户通过 GenerateMatchId API 使用复杂规则集在数毫秒内匹配记录。以前，实时匹配仅限于简单的基于规则的工作流程，而高级规则集（支持 Exact 和 ExactManyToMany 等运算符并与 AND/OR 逻辑结合使用）只能用于批处理，耗时从数分钟到数小时不等。这对于需要利用复杂的匹配逻辑进行实时实体解析的客户而言，形成了一个关键能力缺口。 此次发布后，执行欺诈检测、实时账户查询或网站个性化的客户可以定义高级匹配规则并实时获得结果，而无需维护单独的匹配基础设施或重新构建应用程序。要启用高级实时匹配功能，客户可在匹配流程中将 enableRealTimeMatching 参数设置为 true，然后调用现有 GenerateMatchId API，不用新的端点或迁移。 高级实时匹配功能已在提供 AWS Entity Resolution 数据匹配服务的所有 AWS 区域 推出。 要开始使用，请参阅 AWS Entity Resolution 数据匹配服务用户指南中的 使用 GenerateMatchId 。 有关 AWS Entity Resolution 数据匹配服务的更多信息，请访问 产品页面 。
