Title
AgentCore 支付现已在 Amazon Bedrock AgentCore 中全面推出
Source
AWS News
Published
2026-08-18T19:15:00Z
Summary
今天，AWS 宣布全面推出 AgentCore 支付，这是 Amazon Bedrock AgentCore 中的一项功能，可让人工智能代理通过几行代码来自主发现、访问付费 API、MCP 和内容并支付相关费用。AgentCore 支付可提供企业在生产环境中大规模部署交易代理所需的安全性、护栏和可观测性。 AgentCore 支付与 Coinbase​ 和 Stripe Privy​ 钱包集成以支持微交易，提供跨协议的支付编排能力，在基础设施层强制实施可配置的支付限额，并通过 AgentCore 可观测性交付端到端可观测性。正式版本的 AgentCore 支付包含以下能力：快速创建能力，可直接在 AgentCore 控制台中预置 Coinbase 凭证；通过 AgentCore 网关接入精选的 Coinbase Bazar MCP 服务器，访问按使用量付费的 x402 端点；支持机器支付协议（MPP）；在 x402 协议中引入“最高限额”方案，适用于按推理付费与动态定价使用案例。 开发人员可以开始使用编码助手技能，例如 Claude Code、Kiro 和 Codex、AgentCore CLI 或 AWS 管理控制台，只需访问此 链接 。 AgentCore 支付功能已在 此处 列出的区域推出。要了解更多信息，请访问 AgentCore 支付文档 或 AWS 新闻博客 。 要了解定价，请访问 AgentCore 定价 。
