Title
AWS 弹性灾难恢复现支持基于 AWS Graviton 的源服务器
Source
AWS News
Published
2026-09-25T08:00:00Z
Summary
AWS 弹性灾难恢复（AWS DRS）现在支持对基于 AWS Graviton（arm64）的源服务器进行灾难恢复。现在，您可以借助与处理 x86 工作负载时使用的同样简单、可靠的 DRS 体验来保护和恢复您的 Graviton 工作负载。 随着越来越多的工作负载迁移至 Graviton 以享受其性价比优势，这些工作负载也需要与您环境中的其他部分享有同等水平的灾难恢复保障。DRS 现在可以自动检测 arm64 源服务器，并将其恢复到 Graviton 实例上，从而端到端地保留工作负载的架构。恢复过程与其他服务器的操作方式完全相同，无需进行任何额外配置。 此功能已在提供 AWS DRS 的所有 AWS 区域推出，无需额外费用。要了解更多信息，请参阅 AWS 弹性灾难恢复用户指南 。
