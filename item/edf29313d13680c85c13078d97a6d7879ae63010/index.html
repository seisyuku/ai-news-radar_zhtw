Title
Amazon Quick 现支持通过 Microsoft Purview 来实现数据丢失防护
Source
AWS News
Published
2026-08-14T21:04:00Z
Summary
Amazon Quick 现已与 Microsoft Purview 集成，可在 Quick 环境中实施数据丢失防护（DLP）策略。企业需要确保敏感文件不会在已批准的渠道之外共享。利用这一集成，IT 管理员和安全团队可以应用其现有的 Purview 敏感度标签，自动控制文件在 Quick 的各项功能（例如聊天、空间和知识库）中的处理方式。 管理员可以为每个敏感度标签配置强制性操作（阻止、警告或允许），使组织能够在 Quick 中对敏感文件共享实施精细管控。例如，金融服务公司可以阻止标有“高度机密”的文件上传到共享空间，同时允许“内部”文件并附带一条警告通知。利用这一集成，客户无需使用其他工具，即可将其现有的 Microsoft Purview 治理策略扩展到 Quick。 此功能已在 支持 Amazon Quick 代理式功能的所有 AWS 区域 推出。有关更多信息，请参阅 AWS 区域表 。要了解更多信息，请参阅《Amazon Quick 用户指南》 中的 数据丢失防护 。
