Title
Amazon CloudWatch Log Centralization 现在支持日志组标签传播功能
Source
AWS News
Published
2026-08-19T21:06:00Z
Summary
Amazon CloudWatch Centralization 现在可以将源账户中的日志组标签复制到根据集中化规则创建的目标日志组。CloudWatch Centralization 可以将来自多个账户和区域的日志数据聚合到一个目标账户中。借助标签传播功能，您在源位置维护的成本、所有权和合规性标签现在将应用到复制的日志组上。 通过此次发布，CloudWatch 可以将每个源日志组的标签复制到其目标日志组，并根据在设置集中化规则时选择的标签传播行为使它们保持同步。例如，平台团队可以在集中化日志组上保留“Application”和“CostCenter”标签，然后使用这些标签根据 IAM 条件限定访问范围，并在 AWS Cost Explorer 成本管理服务中按团队生成集中化日志支出报告。 标签传播功能已在提供 CloudWatch Centralization 的所有 AWS 区域推出。有关区域列表，请参阅 AWS 区域表 。 要开始使用，请在 Amazon CloudWatch 控制台中，或者使用 AWS CLI 或 AWS SDK，针对集中化规则启用标签传播功能。要了解有关在保留标签的同时集中管理日志的更多信息，请参阅 Log Centralization 用户指南 。有关 Centralization 定价，请参阅 Amazon CloudWatch 定价 。
