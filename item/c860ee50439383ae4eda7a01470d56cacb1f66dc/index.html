Title
Amazon DocumentDB 现在支持直接将主要版本升级到版本 8.0
Source
AWS News
Published
2026-08-31T22:30:00Z
Summary
Amazon DocumentDB（兼容 MongoDB）现在支持直接从引擎版本 3.6 和 4.0 到版本 8.0 的就地主要版本升级（MVU）。此升级功能不要求进行中间版本升级，允许您升级 3.6 或 4.0 版本的集群，同时保留现有数据、配置和集群设置。 升级到版本 8.0 即可获取最新的安全补丁、性能改进和新的开发人员功能。从 DocumentDB 3.6 和 4.0 到 8.0 的主要版本升级已在当前支持这些版本的所有 AWS 区域推出。 要了解有关升级到 Amazon DocumentDB 8.0 的更多信息，包括有关版本差异和升级路径的详细指南，请参阅 Amazon DocumentDB MVU 文档 ，查看 版本支持日期 ，以及在 Amazon DocumentDB 8.0 公告页面 上浏览新功能的完整列表。
