AWS Network Firewall 现支持在容器属性的筛选条件中使用通配符
收錄來源

發布時間（來源提供）
2026-10-08T16:00:00Z
來源摘要（原文）
AWS Network Firewall 现已支持在针对 Amazon Elastic Kubernetes Service（Amazon EKS）和 Amazon Elastic Container Service（Amazon ECS）的容器属性检测筛选条件中使用通配符匹配。通过此增强功能，您可以使用通配符模式定义属性筛选条件，从而在单条规则中匹配多个容器工作负载，无需再为每个变体单独创建容器关联。 借助通配符匹配，您可以使用诸如 app=payments-* 之类的模式来自动覆盖应用程序的所有变体，例如 payments-api、payments-worker 和 payments-cron。这简化了动态容器环境中的防火墙规则管理（在这些环境中，新应用程序变体会频繁部署），从而减少了运营开销，并确保容器化工作负载的持续安全保障。 容器属性筛选条件的通配符匹配现已在所有支持 AWS Network Firewall 容器属性检查的 AWS 区域推出。要查看受支持的区域的完整列表，请参阅 AWS 区域表 。 要开始使用，请访问 AWS Network Firewall 产品页面 和服务 文档 。
