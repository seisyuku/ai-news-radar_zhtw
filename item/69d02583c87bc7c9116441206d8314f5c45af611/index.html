Title
Amazon MSK 现已向客户提供 Kafka 授权者日志
Source
AWS News
Published
2026-08-06T14:00:00Z
Summary
Amazon Managed Streaming for Apache Kafka（MSK） 现已支持预置集群的授权者日志传输（包括标准代理和快速代理），不额外收取费用。有了授权者日志，您可以详细了解用户和应用程序访问，识别和解决客户端授权问题，以及满足组织的安全要求。每个被拒绝的授权请求均通过客户端的 IP 地址及其尝试调用的 API 来捕获，这可让您找到根本原因。您可以将日志传输到 Amazon CloudWatch Logs、Amazon S3 或 Amazon Data Firehose。授权者日志传输功能同时适用于新的和现有的预置集群。您可以通过 Amazon MSK 控制台或 AWS CLI 启用此功能。要了解如何设置授权者日志传输，请参阅 Amazon MSK 授权者日志文档 。 Amazon MSK 是一项针对 Apache Kafka 的完全托管服务，可用于轻松地实时摄取和处理流数据。授权者日志传输功能在提供 Amazon MSK 预置集群的所有 AWS 区域可用，但 AWS European Sovereign Cloud（eusc-de-east-1）区域除外。借助 Amazon MSK，您可以花更多时间对应用程序进行创新，花更少的时间管理集群。要开始使用，请参阅 Amazon MSK 开发人员指南 。
