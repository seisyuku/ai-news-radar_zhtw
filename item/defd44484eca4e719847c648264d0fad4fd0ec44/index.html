Title
AWS License Manager 现在支持通过 AWS Marketplace 购买的 Ubuntu Pro 的许可证类型转换
Source
AWS News
Published
2026-10-14T17:04:00Z
Summary
AWS License Manager 现在支持将 EC2 Ubuntu LTS（长期支持版）实例就地升级到 AWS Marketplace 上提供的 Ubuntu Pro。这使客户无需重建实例集或将工作负载迁移到新实例或 AMI，即可增强其安全态势并满足合规性要求。订阅 Ubuntu Pro 后，客户可获得长达 10 年的安全补丁支持，若购买 Legacy 附加组件，该支持期限可延长至 15 年。该支持范围不仅涵盖基础操作系统，还扩展至数千个附加软件包，其中包括 NGINX、PostgreSQL、MongoDB 和 Redis 等广泛使用的开源应用程序。Ubuntu Pro 还支持 Kernel Livepatch，它无需重启即可应用重要的内核安全补丁，以最大程度地减少停机时间。 通过此次发布，通过 AWS Marketplace 订阅了 Canonical Ubuntu Pro 的客户可以在转换工作流中直接升级。尚未订阅的客户可以在 AWS License Manager 控制台中订阅 Canonical Ubuntu Pro。这项新功能已在提供 AWS License Manager 的 所有商业区域 推出。 要开始使用，请导航到 AWS License Manager 控制台 和 AWS License Manager User Guide 。
