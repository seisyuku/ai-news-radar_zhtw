Amazon EC2 和 VPC 现可显示所有资源类型的相关资源
收錄來源
AWS News
發布時間（來源提供）
2026-11-04T08:00:00Z
來源摘要（原文）
Amazon Elastic Compute Cloud（Amazon EC2）、Amazon Virtual Private Cloud（Amazon VPC）和 AWS Global View 现在可以在各自的控制台中显示所有资源类型的相关资源。之前，仅安全组具有查看相关资源的选项。现在，您可以查看所有 EC2 和 VPC 资源类型的关系，包括 EC2 实例、Amazon Elastic Block Store（Amazon EBS）卷、启动模板、自动扩缩组、子网、路由表等。“相关资源”选项卡也已移至控制台工具栏中，更易于访问。 此功能可助您更好地了解基础设施依赖关系，并更高效地排查问题。例如，在调查 EC2 实例问题时，您可以快速查看其关联的 EBS 卷、安全组、子网和路由表，而无需在多个控制台页面之间来回切换。网络管理员现在可以跟踪从子网到其关联的路由表、网络 ACL 和实例的连接，从而简化网络配置审查与安全审计工作。 此功能现已在所有 AWS 商业区域推出。 要了解更多信息，请访问 AWS 管理控制台 中的 Amazon EC2 和 Amazon VPC。
