CloudFormation 现在支持采用快速配置的 Aurora PostgreSQL
收錄來源

發布時間（來源提供）

來源摘要（原文）
Aurora PostgreSQL 现在支持在 AWS CloudFormation 中使用快速配置，以实现基础设施即代码部署。此次发布使您能够通过 CloudFormation 模板自动部署 Aurora 集群的基础设施，同时享受快速配置带来的速度优势。 使用快速配置创建的 Aurora PostgreSQL 集群可让您在几秒钟内创建并查询 Aurora 无服务器数据库。AWS::RDS::DBCluster 资源新增的 withExpressConfiguration createOnly 属性只需一项属性声明即可创建集群及其主数据库实例。您无需在 CloudFormation 模板中单独为实例建模或管理实例。这简化了模板，使您能够更轻松地通过基础设施即代码管理采用快速配置的 Aurora 集群。 CloudFormation 支持已在提供采用快速配置的 Aurora PostgreSQL 的所有 AWS 区域推出。要了解更多信息，请参阅 Aurora 用户指南 以及 AWS CloudFormation 文档 中的 AWS::RDS::DBCluster 资源参考。
