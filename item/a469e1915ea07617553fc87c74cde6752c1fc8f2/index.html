Kimi K3.1 Pro（Highspeed）现已在 Amazon Bedrock 上推出
收錄來源

發布時間（來源提供）

來源摘要（原文）
如今，来自 Moonshot AI 的 Kimi K3.1 Pro 已在 Amazon Bedrock 上推出，以客户所信赖的安全性和治理能力扩展了我们的开放权重模型组合。使用 Amazon Bedrock 的客户现在可以在 Kimi K3.1 Pro（Highspeed）上运行编码和文档处理等智能体使用案例，该模型提供较高的每秒输出 Token 数（OTPS），可更快、更及时地生成结果。 根据 Moonshot AI 的说法，Kimi K3.1 Pro 是一款开放权重原生多模态智能体模型，具有 100 万个 Token 的上下文窗口，也是其迄今为止能力最强的 3 万亿参数级模型。Moonshot AI 报告称，该模型在编码、3D 创作、金融研究和其他智能体工作方面均有改进。在 Amazon Bedrock 上，它在与专有模型相同的安全边界内运行，并支持 显式提示缓存 ，可降低延迟和输入成本。 通过跨区域推理，Kimi K3.1 Pro 可在所有支持 Amazon Bedrock 的 AWS 区域 中使用。要开始使用，请访问 Amazon Bedrock 控制台 。要了解更多信息，请参阅 Amazon Bedrock 文档 。
