Title
Amazon Route 53 Resolver 现已在第二代 AWS Outposts 机架上全面推出
Source
AWS News
Published
2026-09-22T08:00:00Z
Summary
Amazon Route 53 Resolver 现已在第二代 AWS Outposts 上全面推出，可直接在 Outpost 上提供本地托管的递归 DNS 解析。Outpost 上运行的工作负载所发起的 DNS 查询将在本地完成解析，从而减少延迟，并且无需经由 Service Link 传输到父 AWS 区域。Route 53 Resolver 会在 Service Link 断开期间保留已缓存的 DNS 记录，从而确保即便在连接中断期间，也能持续进行 DNS 解析。Route 53 Resolver 完全运行于内置在所有第二代 Outpost 中的 AWS 托管基础设施之上，无需占用客户的计算资源。 默认情况下，Route 53 Resolver 在多机架第二代 Outpost 上处于启用状态。如果客户想自行管理 DNS 解析，可随时联系 AWS Support 来禁用该服务。 第二代 Outpost 上的 Route 53 Resolver 已在支持第二代 Outpost 的所有 AWS 区域推出。所有客户（包括当前的预览版客户）均可享受 91 天免费试用，截止日期为 2026 年 12 月 21 日。自 2026 年 12 月 22 日起，该服务按每个 Outpost 机架每小时 0.65 美元计费。要开始使用，请参阅 Outpost 上的 Route 53 Resolver 文档 。有关定价详情，请参阅 Amazon Route 53 定价 。
