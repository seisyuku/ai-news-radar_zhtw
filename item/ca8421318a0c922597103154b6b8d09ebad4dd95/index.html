AWS DataSync 增强模式现支持适用于 Windows File Server 的 Amazon FSx、适用于 NetApp ONTAP 的 FSx 以及 Red Hat OpenShift Virtualization
收錄來源
AWS News
發布時間（來源提供）
2026-10-29T08:00:00Z
來源摘要（原文）
AWS DataSync 增强模式现支持适用于 Windows File Server 的 Amazon FSx、适用于 NetApp ONTAP 的 Amazon FSx 作为源位置或目标位置。现在，您可以运行 Windows 到 Windows 的数据传输，例如从本地文件服务器传输到适用于 Windows File Server 的 FSx。此外，增强模式代理现在可以在 Red Hat OpenShift Virtualization 4.20 及更高版本上运行。 此次发布后，您可以在增强模式下使用与基本模式相同的位置选项。增强模式可通过并行处理数据来提升性能，取消了文件数量限制，并提供详细的数据传输指标。OpenShift Virtualization 扩展了您的代理部署选项，支持 VMware ESXi、KVM、Microsoft Hyper-V 和 Amazon EC2。 您可以通过在 AWS DataSync 控制台 中创建任务时选择“增强模式”来开始使用。这些功能在所有支持 DataSync 增强模式的 AWS 区域中均可用。要了解更多信息，请访问 AWS DataSync 文档 。
