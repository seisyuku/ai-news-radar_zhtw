Title
AWS Backup for Amazon S3 现在支持直接访问备份数据
Source
AWS News
Published
2026-08-06T10:00:00Z
Summary
AWS Backup for Amazon S3 现在支持创建 S3 接入点，并使用标准 S3 API 提供对备份数据的即时只读访问权限，而无需发起还原操作。这样一来，您便能在备份数据安全地存放在备份保管库中的前提下，进行针对性的文件恢复、数据验证、合规审计和取证调查。 您可以为 S3 恢复点创建接入点，并使用标准 S3 操作（例如 GetObject、HeadObject 和 ListObjectsV2）读取备份数据。接入点可使用存储在标准备份保管库或逻辑上受物理隔离的保管库中的快照和持续（时间点）恢复点，包括通过 AWS Resource Access Manager 或多方审批跨账户共享的恢复点。在接入点处于活动状态时，关联的恢复点将受到保护，而不会被删除。 通过使用 AWS Backup 控制台、API 或 CLI 为 S3 恢复点创建接入点，开始使用此功能。此功能已在 选定 AWS 区域 推出。 要了解更多信息，请参阅《AWS Backup 开发人员指南》中的 接入点 和 Amazon S3 备份 ，并参阅 发布博客 。有关定价信息，请参阅 AWS Backup 定价 。
