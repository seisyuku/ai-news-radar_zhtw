Haiku 5.5 现已在 AWS GovCloud（美国）的 Kiro 中推出

來源摘要（原文）
一款新的 Anthropic 模型现已在 AWS GovCloud（美国）区域的 Kiro IDE 和 CLI 中推出。随着 Haiku 5.5 的发布，所有三款 Claude 5.5 模型现已在 AWS GovCloud（美国）的 Kiro 中推出。 Claude Haiku 5.5 是 Claude 5.5 系列中速度最快的模型。与 Claude Haiku 4.5 相比，该模型有了明显的改进，非常适合处理海量任务且需要快速响应的工作。开发人员可以使用它来总结和压缩长的上下文、对请求进行分类和路由、批量处理文本，以及对许多文件进行小规模有针对性的编辑。它还非常适合作为并行运行的审查子智能体，而 Opus 5.5 和 Sonnet 5.5 则适合处理更复杂的规划和编码工作。Haiku 5.5 使用自适应思维，涵盖从低到最高的五个工作强度级别，默认级别为中等。它提供 100 万上下文窗口和 0.06 倍积分乘数。超过 10 万个 Token 的请求按照 0.3 倍的乘数计费。 确保您的 IDE 或 CLI 已更新到最新版本，然后重新启动它以从模型选择器访问新模型。如需了解更多详情，请访问 GovCloud 文档 、 监控和跟踪指南 ，或联系您的 AWS 账户团队。要了解有关 Kiro 的更多信息，请参阅 Kiro 产品页面 。
