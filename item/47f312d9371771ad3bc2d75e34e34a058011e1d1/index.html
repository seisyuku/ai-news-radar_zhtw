Title
AWS Deadline Cloud 现支持用户在 Deadline Cloud 监控界面中查找可访问资源
Source
AWS News
Published
2026-10-13T18:54:00Z
Summary
AWS Deadline Cloud 现在支持仅拥有特定实例集、集群或作业访问权限（而非整个计算农场）的用户直接从 Deadline Cloud 监控界面查找可以访问的资源。Deadline Cloud 是一项完全托管式服务，可帮助团队运行计算密集型工作负载，适用于视觉效果、动画、产品设计、仿真和游戏开发。 此前，仅拥有一个队列访问权限的用户必须先从管理员处获取农场 ID，才能访问其工作任务。此次发布后，Deadline Cloud 监控界面将向用户显示他们有权访问的队列、访问这些队列所需的父 ID 及其访问权限级别，涵盖直接权限和组继承权限。 此次发布后，监控界面将向这些用户显示他们有权访问的资源、访问这些资源所需的父 ID 及其访问权限级别，涵盖直接权限和组继承权限。管理员还可以在 Deadline Cloud 控制台中打开任意用户或组，通过“资源访问”选项卡查看该成员在各区域内可以访问的所有渲染农场、队列和渲染实例集，无论访问权限是直接授予的还是从组继承而来，并可在同一界面修改或撤销这些权限。 资源发现功能现已在所有提供 Deadline Cloud 的 AWS 区域推出。要了解更多信息，请访问 AWS Deadline Cloud 用户指南 。
