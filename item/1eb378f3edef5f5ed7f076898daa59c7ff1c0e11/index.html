Title
Amazon Nova 多模态嵌入模型现已在 AWS GovCloud（美国西部）区域推出
Source
AWS News
Published
2026-08-12T14:34:00Z
Summary
我们很高兴地宣布，Amazon Nova 多模态嵌入模型现已在 AWS GovCloud（美国西部）区域全面推出。该模型是一款面向代理式 RAG 和语义搜索的先进嵌入模型。作为首款统一支持文本、文档、图像、视频及音频的嵌入模型，它能以业界领先的准确率实现跨模态检索。 传统上，跨不同内容类型的管理与搜索需使用多个专用嵌入模型，从而导致系统复杂、成本攀升及数据孤岛问题。Amazon Nova 多模态嵌入模型以业界领先的准确率将多样内容类型映射至统一空间，有效解决数据孤岛问题。开发人员现可使用单一嵌入模型构建跨模态应用程序：既能通过复杂查询检索视频档案，也能根据客户问题匹配产品图像，还能在同时包含信息图表与文字说明的金融文档中实现精准搜索。 该模型支持输入长度高达 8K 的 Token 和长达 30 秒的视频/音频片段，并能够分割更大的文件。该模型提供多种输出嵌入维度，让组织能够在准确性和性能与存储和计算成本之间取得平衡。企业既可选用同步 API 满足近实时应用程序需求，也可采用异步 API 实现大文件高效处理，从而针对延迟敏感型工作负载与高吞吐量工作负载进行优化。 有关更多信息，请参阅 用户指南 。要开始在 Amazon Bedrock 中使用 Nova 多模态嵌入模型，请访问 AWS GovCloud（美国西部）区域的 Amazon Bedrock 控制台 。
