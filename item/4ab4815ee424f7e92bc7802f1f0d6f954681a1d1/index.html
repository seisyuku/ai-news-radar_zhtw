Amazon Aurora 和 RDS 现支持基于 AMD 的 R8a 实例
收錄來源
AWS News
發布時間（來源提供）
2026-09-30T17:00:00Z
來源摘要（原文）
Amazon Aurora 和 Amazon RDS 现在支持搭载第五代 AMD EPYC 处理器的 M8a 数据库实例，为您的数据库工作负载提供了更多选择。R8a 数据库实例中的每个 vCPU 均对应一个物理 CPU 核心，旨在提供稳定的单核性能。对于具有高 I/O 需求的工作负载，R8a 实例可提供高达 75Gbps 的网络带宽和高达 60Gbps 的 Amazon EBS 带宽。所有 R8a 实例都基于 AWS Nitro System 构建，并采用第六代 Nitro 卡。 R8a 数据库实例支持 Amazon Aurora PostgreSQL 兼容版、Amazon Aurora MySQL 兼容版，以及 RDS for PostgreSQL、RDS for MySQL 和 RDS for MariaDB。R8a 数据库实例已在以下区域提供：美国东部（弗吉尼亚州北部、俄亥俄州）、美国西部（俄勒冈州）、加拿大（中部）、亚太地区（东京、台北）和欧洲地区（爱尔兰、法兰克福、西班牙）。 您可以通过 Amazon RDS 管理控制台 或使用 AWS 命令行界面（CLI） 开始使用 R8a 数据库实例。有关支持这些实例类别的具体引擎版本，请参阅 Aurora 和 RDS 文档。有关定价，请参阅 Amazon Aurora 定价页面 和 Amazon RDS 定价页面 。
