來源摘要（原文）
Anthropic 11月9日發佈 Claude Fable5.2 與 Mythos5.2。Fable5.2 無傳統文生圖模型，卻能以代碼在虛擬畫布逐筆作畫，還原筆刷紋理、顏料溼度與畫布質感，並可修正錯誤。它不同於 Midjourney 等擴散模型從噪聲生成圖像，而是把繪畫拆解爲筆觸指令執行，每幅畫是一段約1000至2000行 Python 程序，不依賴圖像模型或預渲染底圖。員工 Jake Eaton 在 X 展示該能力。
