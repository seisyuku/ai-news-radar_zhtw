Title
Amazon EC2 C7a 实例现已在美国西部（北加利福尼亚）区域推出
Source
AWS News
Published
2026-07-22T21:42:00Z
Summary
即日起，计算优化型 Amazon EC2 C7a 实例已在 AWS 美国西部（北加利福尼亚）区域推出。C7a 实例由第四代 AMD EPYC 处理器（代号为 Genoa）提供支持，最大频率为 3.7GHz，与 C6a 实例相比，性能可提升高达 50%。 C7a 实例提供新的处理器功能，例如 AVX-512、VNNI 和 bfloat16。此类实例采用双数据速率 5 (DDR5) 内存，可实现对内存中数据的高速访问，与 C6a 实例相比，内存带宽提高了 2.25 倍，因此，即使是对延迟敏感的工作负载，此类实例也是理想之选。C7a 实例提供 12 种大小，从中等到 48xlarge，包括裸机大小。C7a 实例推出之后，客户可以将多达 128 个 EBS 卷附加到 EC2 实例，相比之下，C6a 实例只能将多达 28 个 EBS 卷附加到 EC2 实例。此类实例基于 AWS Nitro System 构建，非常适合高性能、计算密集型工作负载，例如批量处理、分布式分析、高性能计算 (HPC)、广告投放、高度可扩展多人游戏以及视频编码。 您可通过按需实例、竞价型实例和节省计划使用 C7a 实例。要开始使用，请访问 AWS 管理控制台 、 AWS 命令行界面 (CLI) 和 AWS SDK 。要了解更多信息，请参阅 C7a 实例 。
