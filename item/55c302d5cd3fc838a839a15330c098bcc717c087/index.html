Amazon Connect Customer 现在支持一次对最多 100 个工单执行批量操作
收錄來源

來源摘要（原文）
Amazon Connect Customer 中的案例功能现可让座席和主管一次分配、评论和更新最多 100 个案例的状态，从而减少团队在重复案例更新上花费的时间。当一问题影响到许多客户时（例如发货延迟或服务中断），团队无需再逐个更新案例。具有适当权限的座席和主管可以选择相关案例，一次操作即可更改负责人、添加评论或关闭案例。开发人员还可以使用批处理 API 以编程方式进行相同的更新。 案例功能已在以下 AWS 区域推出：美国东部（弗吉尼亚州北部）、美国西部（俄勒冈州）、加拿大（中部）、欧洲地区（法兰克福）、欧洲地区（伦敦）、亚太地区（首尔）、亚太地区（新加坡）、亚太地区（悉尼）、亚太地区（东京）和非洲（开普敦）。要了解更多信息并开始使用，请访问案例 网页 和 文档 。
