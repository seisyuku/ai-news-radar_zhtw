适用于 Amazon FSx 的 Amazon S3 接入点现已在其他 AWS 区域推出

來源摘要（原文）
现在，您可以将 Amazon S3 接入点连接到另外 4 个 AWS 区域中的适用于 NetApp ONTAP 的 Amazon FSx 文件系统，以及另外 20 个 AWS 区域中的适用于 OpenZFS 的 Amazon FSx 文件系统。借助这项功能，您可以访问 Amazon FSx 中的文件数据，以便将其用于与 S3 配合使用的各种人工智能、机器学习、分析服务和应用程序，而您的数据会继续驻留在 FSx 文件系统上。 适用于 Amazon FSx 的 S3 接入点是一个 S3 端点，它可让基于 S3 的应用程序和服务通过 Amazon S3 API 访问 FSx 文件系统上的数据，而无需复制或移动该数据。例如，您可以使用 Amazon Bedrock 知识库将生成式人工智能应用程序和代理关联到您的文件数据，以便它们提供相关的上下文响应。用户可以使用 Amazon Athena 就地查询相同的数据，或使用 AWS Glue 转换该数据，并且还可以使用 AWS Transfer Family 通过 SFTP、FTPS 和 FTP 与合作伙伴共享文件。您还可以通过无服务器计算服务（例如 Amazon ECS 和 AWS Fargate）或您自己的基于 S3 的应用程序来访问您的文件。 面向适用于 ONTAP 的 FSx 的 Amazon S3 接入点，以及面向适用于 OpenZFS 的 FSx 的 Amazon S3 接入点现已在北美、南美、欧洲、亚太地区和非洲的其他 AWS 区域推出。有关每种文件系统支持的 AWS 区域的完整列表，请参阅 适用于 ONTAP 的 FSx 用户指南和 适用于 OpenZFS 的 FSx 用户指南。要开始使用，请使用 Amazon FSx 控制台、AWS 命令​​行界面（AWS CLI）或 AWS 软件开发工具包（AWS SDK）创建并附加 S3 接入点。要了解更多信息，请访问 适用于 NetApp ONTAP 的 Amazon FSx 和 适用于 OpenZFS 的 Amazon FSx 产品页面、 Amazon S3 接入点页面 ，以及适用于 ONTAP 的 FSx 用户指南与适用于 OpenZFS 的 FSx 用户指南。
