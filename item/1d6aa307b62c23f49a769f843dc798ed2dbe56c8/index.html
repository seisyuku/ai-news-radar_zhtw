Title
PostgreSQL 19 测试版 3 现已在 Amazon RDS 数据库预览环境中推出
Source
AWS News
Published
2026-08-18T16:00:00Z
Summary
即日起， Amazon RDS for PostgreSQL 19 测试版 3 已在 Amazon RDS 数据库预览环境 中推出，使您能够在 Amazon RDS for PostgreSQL 上评估 PostgreSQL 19 的预发布版本。 PostgreSQL 19 测试版 3 新增用于查询性能和 autovacuum 管理的功能。新的 pg_stat_autovacuum_scores 视图有助于监控和调整 autovacuum 优先级。并行 autovacuum 现在可以使用多个工作进程来加速对大型表的维护操作。新的 pg_plan_advice 模块可让您锁定高效查询计划，以避免性能意外降低。早期聚合通过提前对数据分组来优化分析型查询，减少查询要处理的行数，加快查询完成速度。测试版 3 还包含测试版 2 测试期间的错误修复和稳定性改进。有关更多详情，请参阅 PostgreSQL 社区公告 。 Amazon RDS 数据库预览环境数据库实例最长保留 60 天，保留期过后将自动删除。在 Preview Environment 中创建的 Amazon RDS 数据库快照只能用于在 Preview Environment 内创建或恢复数据库实例。您可以使用 PostgreSQL 转储和加载功能向预览环境导入或从中导出数据库。Amazon RDS 数据库预览环境数据库实例的定价与美国东部（俄亥俄州）区域的 定价 一致。
