Title
Amazon RDS for Oracle 现在为 R8i 和 M8i 实例提供预留实例
Source
AWS News
Published
2026-07-31T15:00:00Z
Summary
Amazon RDS for Oracle 现在为 R8i 和 M8i 实例提供 1 年期和 3 年期预留实例，与按需价格相比，成本可节省高达 53%。这些实例由定制英特尔至强 6 处理器提供支持，仅在 AWS 上可用，在云中的同类英特尔处理器中性能最高，内存带宽最快。与上一代基于英特尔的实例相比，R8i 和 M8i 实例的性价比可提升高达 15%，内存带宽可增加 2.5 倍。 预留实例优势同时适用于多可用区和单可用区配置。这意味着客户可以在相同类型的数据库实例类的不同配置之间自由切换，从而更从容地应对各种生产工作负载。在自带许可 (BYOL) 许可模式下，Amazon RDS for Oracle 预留实例可以为 Oracle 数据库引擎提供大小灵活性。借助大小灵活性，预留实例的折扣费率会自动应用于同一实例系列中任意大小的使用量。 客户现在可以在提供 R8i 和 M8i 实例的所有 AWS 区域购买 Amazon RDS for Oracle 的预留实例，南美洲（圣保罗）区域除外。有关支持这些数据库实例类型的 Oracle 数据库版本和许可选项的具体信息，请参阅 Amazon RDS 用户指南 。 要开始使用，请通过 AWS 管理控制台、AWS CLI 或 AWS SDK 购买预留实例。有关详细的定价信息和购买选项，请访问 Amazon RDS for Oracle 定价页面 。
