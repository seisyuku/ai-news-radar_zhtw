Claude Fable 5.2 现已在 AWS GovCloud（美国）推出

來源摘要（原文）
Claude Fable 5.2 现已在 AWS GovCloud（美国）推出，为受监管客户带来 Anthropic 功能最强大、正式可用的技术工作模型。Fable 5.2 在编码、数学和科学领域的高难度项目中设立了新标准，Anthropic 建议将其用于软件工程、科学研究和金融等需要判断力、迭代和精确性的领域。Claude Mythos 5.2 与 Claude Fable 5.2 基于同一底层模型，完整保留了其网络安全和生物学研究所需的全部网络与生物学能力，目前可通过 Anthropic 的验证计划获取。 Claude Fable 5.2 可无人值守运行数小时乃至数天，推进自主工作，并处理规模更大、难度更高的项目。它能够处理跨多个存储库和单存储库的大型、边界模糊的工程问题，在工作过程中自行进行测试，并更主动地质疑既有结论，从而查明旧 Claude 模型遗漏的根本原因。在 Anthropic 的测试中，它作为主智能体协调了数百个子智能体，并标记了无法复现的结果。除了编码之外，它还能开发用于科学研究的新分析方法，并将前沿推理能力引入量化金融领域。 Anthropic 已将 Fable 5.2 和 Mythos 5.2 指定为涵盖的模型，这需要数据留存以进行安全监控。在企业前沿保障措施推出之前，符合条件的客户可使用具备零数据留存功能的 Fable 5.2。参阅 Amazon Bedrock 滥用检测 页面，了解有关这些模型的数据留存的详细信息。 要了解更多信息，请参阅 Amazon Bedrock 文档 和 区域可用性 。
