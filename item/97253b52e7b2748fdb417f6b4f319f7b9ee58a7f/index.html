AWS 合作伙伴中心现在提供更好的商业计划体验
收錄來源

發布時間（來源提供）

來源摘要（原文）
AWS 合作伙伴中心现在在 AWS 管理控制台中提供全新的商业计划体验。AWS 合作伙伴可以制定计划以拓展其 AWS 业务，或就 AWS 团队提出的计划开展合作。 合作伙伴可以与 AWS 合作伙伴发展、技术、营销和专家团队合作，共同制定计划纲要、目标和举措。人工智能辅助的计划准备情况分数可帮助合作伙伴确定需要改进的领域，而实时跟踪功能则能显示目标的达成进度。合作伙伴还可以添加附件和导出计划，为业务审查做准备。 合作伙伴可以使用应用程序编程接口（API）和软件开发工具包（SDK）将商业计划集成到其工作流程中。程序化通知也可以使用。 商业计划服务面向积极与 AWS 合作伙伴管理团队开展合作的 AWS 合作伙伴提供。AWS 合作伙伴中心在美国东部（弗吉尼亚州北部）区域可用。要开始使用，请登录 AWS 合作伙伴中心 并选择“商业计划”。
