Title
Web Search on Amazon Bedrock AgentCore 扩展到 AWS GovCloud 和 3 个区域
Source
AWS News
Published
2026-10-15T20:40:00Z
Summary
Web Search on Amazon Bedrock AgentCore 现已在另外四个 AWS 区域推出：美国东部（俄亥俄州）、美国西部（俄勒冈州）、亚太地区（悉尼）和 AWS GovCloud（美国西部）。Web Search 是一种完全托管式工具，可为智能体提供来自网络的实时背景信息，从而为研究、总结和问答等任务提供更准确、更具时效性的响应。 通过此次扩展，客户可以构建智能体，以更低的延迟在更靠近应用程序和终端用户的位置检索网络信息。具有政府工作负载的客户现在可以在 AWS GovCloud（美国西部）区域使用 Web Search 来满足合规性和数据驻留要求。 要了解有关 Web Search on Amazon Bedrock AgentCore 的更多信息，请参阅 Web Search 工具文档 。要了解定价，请访问 Amazon Bedrock AgentCore 定价。有关区域可用性，请访问 支持的 AWS 区域 。
