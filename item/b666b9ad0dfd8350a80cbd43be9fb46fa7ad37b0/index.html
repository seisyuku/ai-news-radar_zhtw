适用于 Lustre 的 Amazon FSx 在智能分层文件系统上提供的元数据 IOPS 提高了 16 倍
收錄來源

發布時間（來源提供）
2026-11-05T15:39:00Z
來源摘要（原文）
适用于 Lustre 的 Amazon FSx 现已在使用智能分层存储类别的文件系统上支持多达每秒 192,000 次的元数据 I/O 操作（IOPS），比之前的 12,000 次 IOPS 上限高出 16 倍。 适用于 Lustre 的 FSx 智能分层存储类别提供了云中成本最低且唯一具有完全弹性的 Lustre 文件存储。它针对混合了冷热数据且不需要持续 SSD 级别性能的工作负载进行了优化。文件系统的元数据 IOPS 决定了您每秒可以创建、列出、读取和删除的文件和目录的数量。今天的发布可让您扩展到更高的性能水平，缩短获得成效的时间，并优化元数据密集型机器学习研究和高性能计算（HPC）工作负载的存储成本。 在提供智能分层存储类别的所有 AWS 区域 中，更高的元数据 IOPS 已在新的适用于 Lustre 的 FSx 智能分层文件系统上推出。有关文件系统元数据性能的更多信息，请参阅适用于 Lustre 的 Amazon FSx 用户指南 。
