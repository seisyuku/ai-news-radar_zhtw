Title
Sierra、Meta推Personal Agent Protocol，規範AI代理人存取企業服務
Source
iThome
Published
2026-10-07T04:10:30Z
Summary
企業AI新創Sierra周二（10/6）宣布，正與Meta及Walmart、Shopify、Stripe等業者共同開發Personal Agent Protocol，建立個人AI代理人存取企業網站、API及服務的開放標準。 隨著個人AI代理人開始替使用者購物、訂票、預約及處理客服需求，企業也面臨新的存取問題。目前許多代理人仍像真人一樣操作網站或App，透過載入頁面、點擊按鈕及填寫表單完成任務，但企業往往無法清楚判斷來訪者是真人、受使用者授權的AI代理人，還是未經許可的自動化程式，也難以掌握代理人究竟獲得哪些權限。
