Title
Amazon EC2 未来日期容量预留共现支持推迟开始日期
Source
AWS News
Published
2026-09-28T21:17:00Z
Summary
Amazon EC2 未来日期容量预留功能可让您提前最多 120 天锁定容量，您只需指定所需容量、开始日期和承诺持续时间即可。如果您的计划在交付前发生变化，现在可以将开始日期推迟，以适应新的时间安排。 当您推迟开始日期时，EC2 会向您提供报价，其中显示新的开始日期和所需的承诺期限。根据您推迟开始日期的具体时间，承诺期限可能会相应延长。在您查看并接受报价后，EC2 会将新的开始日期更新到您的预留中。 此功能适用于所有未来日期容量预留客户。要了解提供这项功能的区域，请参阅 按区域探索 AWS 功能 网站。有关更多详细信息，请参阅 容量预留用户指南 。
