Title
AWS 管理控制台主页现已在 AWS European Sovereign Cloud（德国）区域支持“成本与使用情况”小部件
Source
AWS News
Published
2026-07-28T16:00:00Z
Summary
AWS 管理控制台主页现已在 AWS European Sovereign Cloud（德国）区域支持“成本与使用情况”小部件，让客户能够在其管理控制台主页控制面板上查看来自 Cost Explorer 成本管理服务和成本优化中心的洞察信息。 借助“成本与使用情况”小部件，客户可以跟踪本月迄今为止的成本和预测成本，发现节省机会，并查看其支出随时间的推移在各项服务中的分布情况。 要开始使用，请登录 AWS 管理控制台 ，选择 Add widgets（添加小部件），然后将“成本与使用情况”小部件拖动到您的管理控制台主页控制面板上。要了解更多信息，请参阅 在 AWS 管理控制台主页中使用小部件文档 。
