AWS Transfer Family 控制台支持 Web 应用程序使用 SVG 徽标和 ICO 网站图标
收錄來源
AWS News
發布時間（來源提供）
2026-10-14T08:00:00Z
來源摘要（原文）
AWS Transfer Family 控制台现已支持在 Web 应用程序中使用 SVG 文件作为徽标以及 ICO 文件作为网站图标，且上传限制已提高至 2 MB。这使您在自定义 Web 应用程序时，能够更灵活地使用现有的品牌资产。 此前，该控制台仅支持 JPG 和 PNG 格式文件，且将徽标上传大小限制为 50 KB，网站图标上传大小限制为 20 KB。该控制台会在保存图片前自动调整其大小，并将其转换为 JPG 或 PNG 格式。现有的 API 上传限制和格式要求保持不变。 这些功能在提供 Transfer Family Web 应用程序的所有 AWS 区域均可用。要了解更多信息，请参阅 Transfer Family Web 应用程序教程 。
