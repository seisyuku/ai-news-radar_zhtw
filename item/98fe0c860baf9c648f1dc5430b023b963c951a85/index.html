Title
Anthropic Claude Sonnet 5.5 和 Claude Opus 5.5 现已在 AWS GovCloud（美国）的 Kiro 中推出
Source
AWS News
Published
2026-10-09T17:13:00Z
Summary
两款新的 Anthropic 模型现已在 AWS GovCloud（美国）区域的 Kiro IDE 和 CLI 中推出。 Claude Opus 5.5 是 Anthropic 迄今为止功能最为强大的 Opus 模型，在长时间运行的智能体编程任务上较 Opus 5 有明显提升。Opus 5.5 会对每个请求进行自适应思考，判断每项任务需要多少投入；在 Kiro 的内部基准测试中，它完成任务所用的工具调用次数比 Opus 5 减少约 40%，使用的 Token 数量约为其一半。提供 100 万上下文窗口和 2.0 倍积分乘数，低于 Opus 5 的 2.2 倍。 Claude Sonnet 5.5 是 Anthropic 迄今为止速度最快的 Sonnet 模型，也是现有 Sonnet 5 使用团队的理想升级选择。输出速度提升超过 30%，在真实的编程和知识型工作场景中的表现已接近 Opus 5.5，此外写作表达更清晰，协作能力更强；这让开发人员能够在强大功能与更高吞吐量之间灵活调节，以平衡性能与成本效益。提供 100 万上下文窗口和 1.3 倍积分乘数。 确保您的 IDE 或 CLI 已更新到最新版本，然后重新启动它以从模型选择器访问新模型。如需了解更多详情，请访问 GovCloud 文档 、 监控和跟踪指南 ，或联系您的 AWS 账户团队。要了解有关 Kiro 的更多信息，请参阅 Kiro 产品页面 。
