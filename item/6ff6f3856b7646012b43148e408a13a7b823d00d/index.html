Title
Spot 置放评分功能现已支持 Local Zones
Source
AWS News
Published
2026-08-13T17:13:00Z
Summary
今天，AWS 宣布在 Spot 置放评分功能中支持 AWS Local Zones，助您识别 Spot 容量请求最可能成功的位置。Spot 置放评分功能会评估您的目标容量和计算需求，并返回 AWS 区域或可用区的评分。 以前，Spot 置放评分功能在报告可用区和区域评分时，不会包含本地区域容量信息。现在，您可以选择请求将本地区域纳入可用区和区域评分响应中，从而更深入地了解 Spot 容量选项。 您可以通过 EC2 Spot 控制台、AWS CLI 或开发工具包使用 Spot 置放评分。要了解有关 Spot 置放评分的更多信息，请参阅 Spot 置放评分文档 。
