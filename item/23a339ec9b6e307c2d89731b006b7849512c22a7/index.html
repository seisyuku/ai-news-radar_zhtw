Amazon RDS 现在支持按快照计费
收錄來源
AWS News
發布時間（來源提供）
2026-11-02T18:43:00Z
來源摘要（原文）
即日起，Amazon RDS 支持对 Amazon RDS 快照按快照计费。通过按快照计费，您可以查看每个快照的具体费用。 以前，在“成本与使用情况”报告以及“Cost Explorer 成本管理服务”中，RDS 快照费用均按数据库实例级别进行汇总。这意味着，虽然您可以了解快照费用，但只能查看数据库实例级别的汇总视图，而无法深入查看每个单独快照的费用。现在，您可以在快照上使用成本分配标签，准确了解每个快照的具体费用，从而更好地掌握备份支出和预算情况。默认情况下，所有 RDS 快照均启用按快照计费，不收取额外费用。 按快照计费已在所有 AWS 商业区域和 AWS GovCloud（美国）区域针对所有 Amazon RDS 引擎推出。要了解更多信息，请访问我们的 文档 。
