Amazon MWAA 现在支持 DuckDB 算子
收錄來源
AWS News
發布時間（來源提供）
2026-11-09T18:00:00Z
來源摘要（原文）
Amazon Managed Workflows for Apache Airflow（Amazon MWAA）现已支持 DuckDB 算子。DuckDB 是一个嵌入式分析数据库，允许客户对来自 DuckDB 支持的来源（包括 Amazon S3）的数据进行数据质量检查、汇总和转换。 在运行 Apache Airflow 3.3.1 的 Amazon MWAA 预配置环境中，DuckDB 可获得原生支持。在最新的 MWAA Airflow 3.3.1 更新中，DuckDB 已针对 AWS 连接进行了预安装和预配置。将 MWAA 环境更新至 Airflow 3.3.1 并为数据存储库授予执行角色访问权限后，客户无需进行额外配置，即可开始编写使用 DuckDBExecuteQueryOperator 的任务。 这项功能已在提供 Amazon MWAA 的所有 AWS 区域推出。有关更多信息，请参阅 AWS 区域表 。 要了解更多信息，请参阅“Amazon MWAA User Guide”中的 Using DuckDB with Amazon MWAA 。
