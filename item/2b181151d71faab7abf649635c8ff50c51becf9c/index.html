Title

Source

Published

Summary
OpenAI 宣布與 Google Cloud 合作，在 Model Garden 提供 GPT-6 Astra、GPT-6.1 Sol、GPT-6 Luna 與 Codex 的 Agent 工作流程。3 款模型 10 月 21 日起向部分企業客戶開放私有預覽，採購可折抵既有 GCP 承諾消費額度，為 OpenAI 模型再添 Azure 之外的銷售管道。
