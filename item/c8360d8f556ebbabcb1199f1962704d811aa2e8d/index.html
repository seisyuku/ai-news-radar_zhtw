Title
AWS Batch 现已支持 Amazon ECS 托管实例
Source
AWS News
Published
2026-08-25T19:36:00Z
Summary
AWS Batch 现已支持 Amazon ECS 托管实例（ECS MI）作为新的计算选项，使您能够在 AWS 托管的基础设施上运行 GPU 加速型和计算密集型批处理工作负载。借助 AWS Batch on ECS MI，您现在可以访问 GPU 加速型实例，AWS 会自动处理 AMI 更新、安全补丁和实例生命周期，从而消除客户管理的 Amazon EC2 基础设施的运营开销。 要开始使用，请使用 AWS Batch CreateComputeEnvironment API 或 AWS Batch 管理控制台创建 AWS Batch on ECS MI 计算环境。您可以在 managedInstancesProvider 块中指定允许的实例类型和联网配置，将计算环境与作业队列关联，并使用按需型容量、竞价型容量或预留容量提交作业。 提供 AWS Batch 的所有 AWS 区域 都支持 AWS Batch on ECS 托管实例。有关更多信息，请参阅 AWS Batch 用户指南 。
