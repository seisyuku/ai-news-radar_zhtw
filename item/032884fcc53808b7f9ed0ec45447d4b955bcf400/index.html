Title
Amazon S3 元数据和注释功能现已在 AWS GovCloud（美国）区域推出
Source
AWS News
Published
2026-08-18T04:00:00Z
Summary
Amazon S3 元数据和注释功能现已在 AWS GovCloud（美国东部）和 AWS GovCloud（美国西部）区域推出，可让您通过最简单、最快速的方式发现、理解和丰富您的 S3 数据。S3 元数据功能会自动捕获系统定义的详细信息（例如，对象大小和来源），并将其存储在 Amazon S3 表类数据存储服务中，该服务已针对近实时表格式查询进行优化，可简化业务分析与实时推理应用程序。 注释扩展了 S3 元数据功能，使您能够以 JSON、XML 或 YAML 格式将丰富的业务上下文直接附加到对象，每个对象最多支持 1 GB 的数据。这可为人工智能代理和分析工具提供查找和使用正确数据所需的上下文，而无需构建或维护单独的元数据系统。注释具有与对象相同的持久性和一致性属性，它会在复制操作期间随对象一起移动，并会在删除操作期间随对象一起删除。这样一来，在数据演进时，便可轻松保留最新的上下文。 注释功能已在所有 AWS 区域和 AWS GovCloud（美国）区域推出。有关已推出 Amazon S3 元数据功能的 AWS 区域的完整列表（包括注释表），请参阅 S3 元数据 AWS 区域 。要了解更多信息，请参阅 产品页面 、 文档 和 Amazon S3 定价页面 。
