Amazon Aurora MySQL 8.4.10 现已全面推出

來源摘要（原文）
即日起， Amazon Aurora MySQL 兼容版 8.4 将支持 MySQL 8.4.10。建议您升级到更新的次要版本，以修复早期 MySQL 版本中的常见漏洞和泄露（CVE），并享受漏洞修复、性能改进及 MySQL 社区增加的新功能带来的好处。有关更多详细信息，请参阅 Aurora MySQL 8.4 和 MySQL 8.4.10 发行说明。 Aurora MySQL 8.4.10 增加了对全局事务标识符（GTID）标签的支持，这使您可以为 GTID 分配用户定义的标签，从而帮助您在二进制日志复制中识别相关事务并将其分组。此版本还增加了对每个数据库实例最多 5 万个并发连接的支持，这使得连接密集型应用程序无需添加连接池层即可实现扩展。有关最大连接数最佳实践的更多信息，请参阅 Amazon Aurora MySQL 用户指南 。 您可以使用自动次要版本升级在计划维护时段内升级数据库。要大规模简化操作，请启用 自动次要版本升级 ，并使用 AWS Organizations 升级部署策略 分阶段编排各个集群的多次升级，先在低优先级环境中完成验证，然后再升级最重要的环境。您可以就地或通过快照还原执行次要版本升级。有关执行版本升级的更多信息，请参阅 Amazon Aurora 用户指南 。提供 Aurora MySQL 的所有 AWS 区域 均支持此版本。 Amazon Aurora 设计具有全球规模的高性能和可用性，与 MySQL 完全兼容。它提供可缩减至零的无服务器计算、支持多区域韧性的 Aurora Global Database、用于提升 I/O 密集型工作负载性价比的 Aurora I/O 优化版，以及内置的安全功能和持续备份。要开始使用，请查看 Aurora 的 入门页面 。
