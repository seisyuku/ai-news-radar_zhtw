Title
Amazon EC2 Auto Scaling 现已在 CloudFormation 中支持实例刷新
Source
AWS News
Published
2026-07-29T21:00:00Z
Summary
Amazon EC2 Auto Scaling 现在支持将实例刷新作为一项新的 AWS CloudFormation 更新策略。当您配置新的 AutoScalingInstanceRefresh 更新策略并更新需要替换实例的属性时，CloudFormation 会自动触发实例刷新。 通过此集成，您现在可以使用实例刷新的各项功能，包括用于就地更新的根卷替换、先启动后终止、基于警报的监控，以及带有烘焙时间的检查点，以实现可控部署。Auto Scaling 功能（如扩缩策略和运行状况检查）在整个更新过程中始终保持活跃，因此部署期间您的服务运行状况不会受到影响。回滚操作则通过 CloudFormation 堆栈回滚来处理。 此功能已在所有 AWS 区域提供，无需额外付费。要了解更多信息，请参阅“AWS CloudFormation 模板参考”中的 AutoScalingInstanceRefresh 更新策略 。
