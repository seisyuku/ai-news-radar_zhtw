Amazon Bedrock 为 Daybreak 模型新增 bedrock-runtime 端点支持

來源摘要（原文）
符合条件的客户现在可通过 Amazon Bedrock 上的 bedrock-runtime 端点访问 OpenAI 的专业网络安全模型 Daybreak Red: GPT-5.6 Cyber 和 Daybreak Blue: GPT-5.6 Sol。 Daybreak Blue 是大多数安全团队在防御性工作流（包括漏洞发现、检测工程和事件响应）中开展工作的起点。Daybreak Red 适用于经授权的高级任务，例如漏洞研究、漏洞利用复现和缓解措施开发。针对这些任务，模型采用更低的拒绝阈值，同时配合更严格的身份验证、监控与访问控制，从而提升调查的速度与深度。您的推理数据不会用于模型训练，这两款模型都不要求您选择与 OpenAI 共享数据。 在 bedrock-runtime 端点上，可通过美国和全球跨区域推理（CRIS）配置文件使用这两款模型。需先申请获得 OpenAI 的 Daybreak 访问权限 ，之后才能访问这两款模型。如需申请，请联系 OpenAI 或您的 AWS 账户团队以获取资格要求方面的指导。获得批准后，请与您的账户团队合作，在 AWS 上申请访问权限。有关通过 bedrock-mantle 端点提供的区域可用性及更多信息，请查看 文档 。
