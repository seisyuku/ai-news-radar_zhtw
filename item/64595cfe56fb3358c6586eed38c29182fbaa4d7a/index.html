Title
AWS Glue 数据质量自动监测功能现支持异常检测，并支持将结果写入 AWS Glue Data Catalog
Source
AWS News
Published
2026-07-27T20:45:00Z
Summary
AWS Glue 数据质量自动监测功能现在支持对基于 Catalog 的数据质量评估进行异常检测，并支持将评估结果写入 AWS Glue Data Catalog（GDC）表。这些功能在 ETL 作业和 Catalog 评估中均可使用，无论工作流类型如何，都能为您提供一致的数据质量体验。 借助对 GDC 的异常检测支持，您可以使用机器学习驱动的时序预测功能来识别数据统计中的意外变化（例如 GDC 表中唯一值的突然下降或行数的激增），而无需编写包含显式阈值的规则。对于需要在 GDC 中监控数百张表并自动发现问题的数据工程师而言，这一功能尤为有价值。 借助 GDC 中的结果存储 功能，数据质量规则的结果、剖析指标以及异常预测（含置信区间）将被写回 GDC 表，从而为所有质量评估创建可查询的记录。无论评估是在 ETL 作业中运行，还是直接在 Catalog 表上运行，均支持随时使用标准 SQL 查询评估结果。 AWS Glue 数据质量自动监测功能的异常检测和 Catalog 结果存储已在所有 AWS 商业区域和 AWS GovCloud（美国）区域提供。 要开始使用，请访问 AWS Glue 数据质量自动监测功能文档 。
