Title
Amazon SageMaker 融通式合作开发工作室现已支持自定义工具蓝图
Source
AWS News
Published
2026-10-09T08:00:00Z
Summary
Amazon SageMaker 融通式合作开发工作室现在支持自定义工具蓝图，使域管理员能够使用自己的 AWS CloudFormation 模板定义每个项目的基础。管理员可以定制项目环境以满足组织特定的需求，例如使用符合公司命名规范的 IAM 角色名称，或使用自定义权限边界而非 AWS 托管策略。 Amazon SageMaker 融通式合作开发工作室管理员需要先编写描述所需项目环境的 CloudFormation 模板，然后将其注册为自定义工具蓝图。该服务会在注册时以及每次项目部署后验证模板，确保在任何团队成员使用该项目之前，所需的资源均已就绪。模板可以包含任何 CloudFormation 支持的资源（例如 AWS Lake Formation 授权、Amazon Athena 工作组或 VPC 安全组），还可以跨多个 AWS 账户和区域使用，无需针对每个项目进行编辑。在部署时，该服务会自动填充预留的模板参数（例如项目 ID 和域 ID），因此管理员只需定义一次模板，即可将其应用于所有场景。 该功能已在提供 Amazon SageMaker 融通式合作开发工作室的所有 AWS 区域 推出。要了解更多信息，请访问 “Custom blueprints as Tooling”文档 。
