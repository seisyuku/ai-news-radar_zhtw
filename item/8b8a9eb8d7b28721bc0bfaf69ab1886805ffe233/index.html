Amazon EC2 R8gd 实例现已在更多区域推出

來源摘要（原文）
Amazon Elastic Compute Cloud（Amazon EC2）R8gd 实例现已在 AWS European Sovereign Cloud（德国）区域推出。这些实例配备了高达 11.4TB 的基于 NVMe 的本地 SSD 块级存储，并由 AWS Graviton4 处理器提供支持，与基于 Graviton3 的实例相比，性能可提升高达 30%。这些实例基于 AWS Nitro System 构建，非常适合需要访问高速、低延迟本地存储的应用程序。 R8gd 实例有 12 种不同的大小可供选择。这种实例可提供高达 50Gbps 的网络带宽和高达 40Gbps 的 Amazon Elastic Block Store (Amazon EBS) 带宽。此外，客户现在可以使用 EC2 实例带宽权重配置将这些实例的网络和 Amazon EBS 带宽调整 25%，以便更灵活地分配带宽资源，从而更好地优化工作负载。这些实例就 24xlarge、48xlarge、metal-24xl 和 metal-48xl 大小提供 Elastic Fabric Adapter (EFA) 网络。 要了解更多信息，请参阅 R8gd 实例 。要了解如何将工作负载迁移到基于 Graviton 的实例，请参阅 AWS Graviton Fast Start 迅速开启程序 。要开始使用，请参阅 AWS 管理控制台 。
