AWS 服务参考信息现在支持全局条件键、服务名称和数据面板分类

來源摘要（原文）
AWS 正在扩展编程式服务参考信息，以帮助您自动执行 IAM 策略管理，并使您的策略与最新的服务更新保持一致。服务参考现在在一个机器可读文件中包含所有以 aws: 为前缀的全局条件键、一个将服务标识符映射到人类可读名称的 ServiceName 字段，以及一个标识哪些操作属于数据面板操作的 IsDataPlane 属性。 您可以实现这些信息的自动化检索以消除手动工作，并将其直接整合到您现有的策略管理工具和流程中。此功能不额外收费。要开始使用，请参阅有关 编程式服务参考信息 的文档。
