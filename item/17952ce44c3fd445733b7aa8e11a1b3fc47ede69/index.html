Title
Amazon Location Service 推出集地点、路线和地图 API 于一体的交互式 API 演练场
Source
AWS News
Published
2026-10-13T18:46:00Z
Summary
Amazon Location Service 现在提供一个功能齐全的交互式 API 演练场，开发人员无需编写代码，即可直观地探索和测试所有地点、路线和地图 API。此次发布后，Amazon Location Service 的全部 14 个地点、地图和路线 API 均可在这一交互式 API 演练场中使用。开发人员可在其中进行真实的 API 调用，在交互式地图上查看渲染结果，调整参数，并将可直接用于应用程序的请求代码片段复制到自己的应用程序中。 该 API 演练场涵盖了 Amazon Location Service 的地点、路线和地图 API：搜索与地理编码（Geocode、ReverseGeocode、Autocomplete、Suggest、SearchText、SearchNearby 和 GetPlace）、路线规划与优化（CalculateRoutes、CalculateRouteMatrix、CalculateIsolines、OptimizeWaypoints 和 SnapToRoads），以及地图（Dynamic Map 和 GetStaticMap）。客户无需配置 SDK 或编写测试脚本，即可模拟配送地址验证、规划适合卡车行驶的多点停靠路线、可视化驾车时间服务区域，或将地图嵌入其应用程序中。 API 演练场现已在以下AWS 区域推出：美国东部（俄亥俄州）、美国东部（弗吉尼亚州北部）、美国西部（俄勒冈州）、亚太地区（孟买）、亚太地区（新加坡）、亚太地区（悉尼）、亚太地区（马来西亚）、亚太地区（东京）、加拿大（中部）、欧洲地区（法兰克福）、欧洲地区（爱尔兰）、欧洲地区（伦敦）、欧洲（西班牙）、欧洲地区（斯德哥尔摩）和南美洲（圣保罗）。 要开始使用，请访问 AWS 管理控制台中的 Amazon Location Service API 演练场 ，或查阅 开发人员指南 了解更多信息。
