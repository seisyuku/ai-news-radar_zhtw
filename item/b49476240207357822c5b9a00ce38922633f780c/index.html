來源摘要（原文）
AWS 合作伙伴中心现在可让 AWS 合作伙伴更清楚地了解，解决方案匹配引擎（SME）对其协同销售渠道的贡献。合作伙伴分析中的解决方案匹配引擎性能部分可帮助合作伙伴了解 SME 针对其公司和 AWS Marketplace 列表的匹配效果。 合作伙伴可以查看推荐、SME 带来的商机、自身在 AWS 发起商机中的占比、停滞率以及归因于 SME 的商机管道。他们可以按推荐类型或 AWS Marketplace 列表进行筛选，并按区域、行业和细分市场浏览高匹配客户画像。这些见解可帮助合作伙伴评估其曝光度并确定改进其列表和商机信息的方向。 所有具备 AWS 合作伙伴网络客户参与计划（ACE） 参与资格的合作伙伴，均可在 AWS 合作伙伴中心 的“合作伙伴分析”下的“商机管道分析”页面中找到相关部分。 要了解有关 SME 的更多信息以及如何提升您在 AWS 卖家中的曝光度，请阅读 解决方案匹配引擎：通往 AWS 卖家的门户 。
