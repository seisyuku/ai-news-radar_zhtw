AWS Transform 现在可以建立新网络并对安全组进行现代化改造
收錄來源
AWS News
發布時間（來源提供）
2026-10-21T08:00:00Z
來源摘要（原文）
用于迁移的 AWS Transform 现在为您提供了三种将您的网络迁移到 AWS 的方法。除了迁移现有网络并对其进行现代化改造外，您还可以从头开始构建新网络，或者将本地访问规则转换为优化的安全组并将其部署到现有 VPC 中。无论您选择哪种路径，最终都可以在 AWS 上搭建起安全且可扩展的网络基础。 本地网络积累了多年的定义和访问规则，您可能不想将它们原封不动照搬到 AWS。为了实现干净的起步，AWS Transform 会构建符合 AWS 最佳实践的新网络。为了让您沿用自己的访问规则，AWS Transform 会将其转换为安全组并在转换过程中对其进行现代化改造（检测过时的规则并提出优化建议），然后将这些组部署到您现有的 VPC 中，而无需重新部署网络堆栈。 借助这些功能，您可以迁移到任何 AWS 商业区域或 GovCloud 区域 。 要开始使用，请参阅 迁移网络 。要了解更多信息，请访问 用于迁移的 AWS Transform 。
