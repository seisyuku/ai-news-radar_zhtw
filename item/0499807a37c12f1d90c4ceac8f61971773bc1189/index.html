Title
Amazon DynamoDB 全局表现已支持取消关联副本
Source
AWS News
Published
2026-10-20T23:00:00Z
Summary
Amazon DynamoDB 全局表现已支持取消关联副本，且无需删除该副本对应的表和数据。全局表提供完全托管式多区域、多活动复制。现在，您可以停止向副本复制和从副本复制，并继续将同一个表用作单区域表。 账户可以退出共享的多账户全局表，继续独立使用自身的表。您还可以停止向某个区域复制，同时保留该区域的表用于本地工作负载、验证或审计，无需创建替换表或复制数据。 对于使用多区域最终一致性（MREC）的同账户和多账户全局表，DynamoDB 支持在所有 AWS 区域取消关联副本。 要开始使用，请使用 AWS 管理控制台、AWS CLI、DynamoDB API 或 AWS CloudFormation。有关更多信息，请参阅 Amazon DynamoDB 开发人员指南中的 取消关联副本 。
