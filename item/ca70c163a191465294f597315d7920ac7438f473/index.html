Amazon MWAA 现已支持成本分配标签
收錄來源
AWS News
發布時間（來源提供）
2026-11-04T23:00:00Z
來源摘要（原文）
Amazon Managed Workflows for Apache Airflow（Amazon MWAA）现已支持 成本分配标签 。您应用于 Amazon MWAA 环境的标签现在会传播到运行该环境的计算资源，包括工作进程、调度器和 Web 服务器。随后，您可以在 AWS Cost Explorer 成本管理服务以及 AWS 成本与使用情况报告中按标签跟踪 Amazon MWAA 支出。 通过此次发布，平台团队可以将 Airflow 成本以成本展示或成本分摊的方式，归属到拥有每个环境的团队、项目或成本中心。您可以在创建新环境或更新现有环境时使用成本分配标签。要开始使用，请使用 Amazon MWAA 控制台、AWS CLI 或 Amazon MWAA API 为环境添加标签，然后在 AWS 账单与成本管理控制台中将该标签键作为成本分配标签激活。 这项功能已在提供 Amazon MWAA 的所有 AWS 区域推出。有关更多信息，请参阅 AWS 区域表 。要了解更多信息，请参阅《Amazon MWAA User Guide》中的 Cost allocation tags in Amazon MWAA 。
