宣布推出 Amazon Textract 的更新版文本检测模型

來源摘要（原文）
Amazon Textract 现已提供更新版文本检测模型，该模型提高了准确率，扩展了语言支持范围，并增强了多语言表提取功能。更新版模型适用于 DetectDocumentText API 和 AnalyzeDocument API，无需更改您的 Amazon Textract API 请求或响应架构。更新版模型会自动为您的应用程序提供服务，因此您可以像以前一样继续调用 Amazon Textract。 更新版模型将语言覆盖范围扩展到 40 多种语言，包括阿尔巴尼亚语、阿拉伯语、巴斯克语、白俄罗斯语、波斯尼亚语、保加利亚语、中文（简体和繁体）、克罗地亚语、捷克语、丹麦语、荷兰语、英语、爱沙尼亚语、芬兰语、法语、德语、希伯来语、印地语、匈牙利语、冰岛语、意大利语、日语、韩语、拉脱维亚语、立陶宛语、卢森堡语、挪威语、波兰语、葡萄牙语、罗马尼亚语、俄语、塞尔维亚语（西里尔字母）、塞尔维亚语（拉丁字母）、斯洛伐克语、斯洛文尼亚语、西班牙语、瑞典语、土耳其语、土库曼语和乌克兰语，从而能够可靠地处理此前不支持的脚本。准确率方面的改进包括增强了长词识别和手写检测功能。此外，多语言表提取功能在处理合并单元格、倾斜或旋转的表以及不完整或损坏的表时，表现更为稳健。这些改进可帮助您准确地大规模处理发票、表单、身份证件和其他多语言或复杂的文档，包括带有表的文档。 更新版 Amazon Textract 模型已在提供 Amazon Textract 的所有 AWS 区域推出。要了解更多信息，请参阅 Amazon Textract 产品页面 和 Amazon Textract Developer Guide 。
