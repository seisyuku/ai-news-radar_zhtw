Title
Amazon WorkSpaces Applications 现已提供控制台内监控功能
Source
AWS News
Published
2026-08-19T15:00:00Z
Summary
Amazon WorkSpaces Applications 现已提供直接嵌入在服务控制台内的原生监控体验。管理员现在无需第三方监控工具或 Amazon CloudWatch 专业知识，即可访问实时会话级指标、实例级资源数据和网络性能指标。 以前，管理大型 WorkSpaces Applications 部署的企业客户需要依赖外部解决方案，或构建复杂的自定义 CloudWatch 控制面板。现在，无需进行任何配置即可全面监控。WorkSpaces Applications 控制台内监控功能提供实例集级别的容量可见性，显示活跃会话和资源利用率；可自定义的会话表，支持按用户 ID、性能指标和实例 ID 进行筛选；以及关联的图形视图，在共享时间轴上显示帧速率、输入延迟、带宽和 CPU/内存/GPU 使用情况等会话指标。所有这些指标也可在 Amazon CloudWatch 中找到，让客户可以灵活地选择合适的体验来监控其 WorkSpaces Applications 资源。 此功能现已在提供 Amazon WorkSpaces Applications 的所有 AWS 区域 推出。 要了解更多信息，请参阅 Amazon WorkSpaces Applications 文档 ，或者登录 Amazon WorkSpaces Applications 控制台 ，导航到实例集菜单，然后选择一个实例集来监控活跃会话指标。
