Title
AWS HealthOmics 现在支持共享 VPC
Source
AWS News
Published
2026-10-15T17:42:00Z
Summary
AWS HealthOmics 现在支持跨账户共享 VPC，使您的工作流程能够通过 AWS Resource Access Manager（RAM）访问其他 AWS 账户管理的 Amazon Virtual Private Cloud（VPC）中的资源。 AWS HealthOmics 是一项符合 HIPAA 标准的服务，能够通过完全托管式生物信息学工作流，帮助医疗保健与生命科学客户大规模加速取得科学突破。 有了共享 VPC，客户可以通过在组织内的多个账户之间共享来自单个 VPC 的子网和安全组来集中联网管理，HealthOmics 随后会将每个账户的工作流程直接放入这些共享子网。利用跨账户 VPC 共享，多个账户可以在一个集中管理的 VPC 内运行，而不是在 VPC 之间复制端点。参与账户中的工作流程可以私下访问数据，无需单独的 VPC 对等连接或重复的 VPC 端点。以前，使用集中式联网的客户必须在每个 VPC 中创建单独的 AWS PrivateLink VPC 端点，并使用 VPC 对等连接来维护各个路由表。跨账户 VPC 共享可减少基础设施开销，简化具有集中联网的组织的网络管理，同时支持研究人员和开发人员在自己的账户中运行生物信息学工作流程。 共享 VPC 已在提供 AWS HealthOmics 的所有区域推出：美国东部（弗吉尼亚州北部、俄亥俄州）、美国西部（俄勒冈州）、欧洲地区（法兰克福、爱尔兰、伦敦）、以色列（特拉维夫）和亚太地区（新加坡、首尔、东京）。要开始使用，请参阅 AWS HealthOmics 用户指南 。
