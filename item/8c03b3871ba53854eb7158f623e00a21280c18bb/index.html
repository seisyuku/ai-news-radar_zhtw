Amazon Quick 现已更名为 AWS Quick

來源摘要（原文）
专为工作场景打造的人工智能工作区 Amazon Quick 现已更名为 AWS Quick，这一新名称体现了 Quick 自作为一项 AWS 服务推出之初便内置的企业级安全与治理能力。Quick 网站、Web 端、桌面端和移动端应用程序以及 AWS 文档中现已采用新名称。现有客户无需执行任何操作，Quick 的使用方式保持不变。 Amazon Quick Sight（Quick 中的商业智能功能）现已更名为 AWS Quick Sight。Quick Sight 客户可继续照常使用控制面板、数据集和分析内容，其数据、设置或定价保持不变。 借助 Quick，团队可使用智能体对他们已使用的数据和应用程序进行研究、分析并执行操作，不受供应商限制。Quick 能够理解您的角色、团队以及各项工作之间的关联；任何人都可以使用自然语言构建代理、应用程序和自动化流程，这些成果将成为整个团队的共享资产。Quick 符合 HIPAA 资格，并持有 FedRAMP、SOC 2 和 ISO 27001 等合规认证。您的数据始终保留在您的环境中，绝不会用于训练他人的模型。 AWS Quick 现已在多个 AWS 区域推出。有关更多信息，请参阅 AWS 区域表 。 要了解更多信息，请参阅 AWS Quick 。
