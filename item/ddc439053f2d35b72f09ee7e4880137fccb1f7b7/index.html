托管式 Prometheus 收集器现在支持 Amazon MSK 消费者组指标
收錄來源
AWS News
發布時間（來源提供）
2026-10-30T08:00:00Z
來源摘要（原文）
托管式 Prometheus 收集器现已支持 Amazon Managed Service for Prometheus 和 Amazon CloudWatch 的 Amazon MSK 消费者组指标。该集成可从您的 Amazon MSK 集群中收集 Kafka 导出器指标和消费者组延迟指标。 托管式 Prometheus 收集器会从您的工作负载中发现并收集 Prometheus 指标，因此您无需自己运行和操作收集智能体。您可以将收集到的指标导入 Amazon Managed Service for Prometheus 工作区或 Amazon CloudWatch，在那里查询和分析这些指标。您可以使用消费者组指标监控 Kafka 流的运行状况和消费者性能。这可以帮助您检测流式处理应用程序中的处理瓶颈。 此功能已在正式发布托管式 Prometheus 收集器的所有 AWS 区域 推出。要了解更多信息，请参阅 Amazon Managed Service for Prometheus 和 Amazon CloudWatch 的文档。
