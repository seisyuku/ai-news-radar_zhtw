來源摘要（原文）
与 Equinix 联合推出 AWS 互连 – 最后一英里预览版。您只需点击几下，即可通过 Equinix 遍布全球的 282 个数据中心所构成的全球网络将您的基础设施连接到 AWS。 互连 – 最后一英里为您提供了 AWS 托管私有弹性连接，使您无需订购交叉连接或配置路由器。要在 AWS 管理控制台中进行设置，请选择 AWS 区域、带宽速度、Direct Connect 网关和您的 Equinix Fabric One 项目 ID。AWS 会生成一个激活密钥，您需要在 Equinix Fabric One 门户中输入该密钥以完成设置。您也可以从 Equinix Fabric One 门户发起连接。AWS 和 Equinix 会预先跨两个位置和四条独立链路配置四重冗余容量，并为您配置 BGP 对等连接、VLAN 和 ASN。每个连接均为实现最大韧性而构建，并附带可用性为 99.99% 的 SLA。默认情况下，AWS 和 Equinix 边缘设备之间的流量通过 MACsec 进行加密。 在预览版期间，您可以免费订购 1 Gbps 的互连 – 最后一英里连接，分别经由圣何塞城域网接入美国西部（北加利福尼亚）区域，经由北弗吉尼亚城域网接入美国东部（弗吉尼亚州北部）区域。在与 Equinix 联合推出互连 – 最后一英里正式版后，您可在控制台中将带宽从 1 Gbps 扩展到 100 Gbps。您可以使用控制台、AWS CLI 或 API 创建连接。合作伙伴可以使用 GitHub 上的开放 API 包进行集成。要了解更多信息，请参阅 AWS Interconnect - last mile 文档 。
