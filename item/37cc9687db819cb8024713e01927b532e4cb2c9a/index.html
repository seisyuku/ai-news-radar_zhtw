AgentCore 运行时实例现已在另外六个 AWS 区域推出
收錄來源
AWS News
發布時間（來源提供）
2026-11-16T07:30:00Z
來源摘要（原文）
Amazon Bedrock AgentCore 运行时实例 现已在另外六个 AWS 区域使用：美国西部（北加利福尼亚）、加拿大（中部）、欧洲地区（伦敦）、欧洲地区（巴黎）、欧洲地区（斯德哥尔摩）和亚太地区（首尔）。运行时实例在 Amazon EC2 实例上运行您的智能体，而 AgentCore 则负责配置、修补、扩展和生命周期管理。 通过扩展到这些 AWS 区域，更多团队可以使用 运行时实例功能 ，例如 GPU 加速、内存优化型或计算优化型实例类型，以及长达 14 天的长时间运行智能体会话。您可以在离用户更近的地方运行智能体，以减少调用延迟，并将智能体实例、存储卷和会话数据保留在您的数据驻留要求所要求的区域。 通过此扩展，您可以在以下 AWS 区域使用运行时实例：美国东部（弗吉尼亚州北部）、美国东部（俄亥俄州）、美国西部（北加利福尼亚）、美国西部（俄勒冈州）、加拿大（中部）、欧洲地区（法兰克福）、欧洲地区（爱尔兰）、欧洲地区（伦敦）、欧洲地区（巴黎）、欧洲地区（斯德哥尔摩）、亚太地区（孟买）、亚太地区（首尔）、亚太地区（新加坡）、亚太地区（悉尼）和亚太地区（东京）。除了您的 Amazon EC2 费用外，您还需要为管理预置计算付费。 要开始使用，请参阅以下资源： 《Amazon Bedrock AgentCore 开发人员指南》中的 支持的 AWS 区域 AgentCore 定价 《Amazon Bedrock AgentCore 开发者指南》中的 运行时实例和容量提供者
