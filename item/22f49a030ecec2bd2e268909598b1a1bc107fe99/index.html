适用于智能体的 Amazon WorkSpaces 现已支持 Linux 和 Windows 11 云桌面
收錄來源
AWS News
發布時間（來源提供）
2026-11-03T18:00:00Z
來源摘要（原文）
除 Windows Server 之外，适用于智能体的 Amazon WorkSpaces 现在还支持 Linux 和 Windows 11 云桌面。您可以在每款智能体的工作流和应用程序所要求的操作系统上运行该智能体。之后，您的智能体便能在员工已使用的环境中工作，而无需更换平台。 Linux 桌面向智能体授予操作系统的完全根访问权限，而许多开发人员已在此操作系统中构建、测试和自动执行代理式工作流。智能体可以在您已依赖的企业级安全和治理控制措施范围内执行开发人员任务，例如运行构建、测试和脚本。Windows 11 桌面可让智能体在团队日常依赖的企业应用程序中工作。 Linux 和 Windows 11 桌面采用与 Windows Server 桌面相同的安全和治理控制措施，其中包括网络隔离、基于 IAM 的访问以及您的组织已确立的合规边界。 要开始在 WorkSpaces 上运行智能体，请访问： https://docs.aws.amazon.com/appstream2/latest/developerguide/agent-access.html 。
