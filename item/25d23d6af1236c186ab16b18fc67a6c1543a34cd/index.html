Amazon Bedrock AgentCore 身份现在支持 OAuth 2.0 发现 URL
收錄來源
AWS News
發布時間（來源提供）
2026-11-13T08:00:00Z
來源摘要（原文）
Amazon Bedrock AgentCore 身份现在对入站 JWT 授权和出站 OAuth 凭证提供程序支持 OAuth 2.0 授权服务器发现 URL。此更新使开发人员能够使用不采用 OpenID Connect（OIDC）的 OAuth 2.0 授权服务器来配置 AgentCore。 此前，AgentCore 身份仅接受 OIDC 发现 URL。仅实施 OAuth 2.0 而未实施 OIDC 的授权服务器会在另一个知名路径发布其元数据，此前无法与 AgentCore 配合使用。通过此次发布，在 AgentCore 上配置 JWT 授权方或自定义 OAuth 凭证提供程序时，您可以使用 OIDC 或 OAuth 2.0 授权服务器发现 URL。 此功能已在提供 Amazon Bedrock AgentCore 的所有 AWS 区域推出，无需额外付费。要了解更多信息，请参阅《Amazon Bedrock AgentCore 开发人员指南》 中的 配置入站 JWT 授权器 和 使用自定义提供商添加 OAuth 客户端 。
