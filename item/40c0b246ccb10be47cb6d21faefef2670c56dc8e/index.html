Title
Amazon SageMaker AI 批量转换现已支持 G6e 实例
Source
AWS News
Published
2026-09-04T08:00:00Z
Summary
Amazon SageMaker AI 现已支持在 Amazon EC2 G6e 实例 上进行批量转换。批量转换使您能够对存储在 Amazon S3 中的数据集运行预测，适用于不需要持久性推理端点的大型数据集。 Amazon EC2 G6e 实例配备了多达八个 NVIDIA L40S Tensor Core GPU（每个 GPU 具有 48 GB 内存），并搭载第三代 AMD EPYC 处理器。G6e 实例为 GPU 密集型工作负载提供了更高的性能。此次发布后，您可以将 G6e 实例用于 GPU 密集型离线推理工作负载，包括可生成图像、视频和音频的大型语言模型与扩散模型。要开始使用，请在通过 AWS SDK、AWS CLI 或 CreateTransformJob API 创建批量转换作业时，选择支持的 ml.g6e 实例类型。 G6e 对批量转换的支持已在以下区域推出：美国东部（弗吉尼亚州北部）、美国东部（俄亥俄州）、美国西部（俄勒冈州）、亚太地区（孟买）和亚太地区（海得拉巴）。要了解更多信息，请访问 Amazon SageMaker AI 产品页面并查看 批量转换文档 。有关这些实例的定价信息，请访问我们的 定价页面 。
