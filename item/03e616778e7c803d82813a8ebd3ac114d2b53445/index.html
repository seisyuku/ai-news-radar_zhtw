Title
AWS HealthOmics 现已支持 WDL 工作流的任务级超时
Source
AWS News
Published
2026-08-03T20:00:00Z
Summary
AWS HealthOmics 现已支持工作流描述语言（WDL）工作流的任务级超时，使您能够设置单个任务的最大执行时长。 AWS HealthOmics 是一项符合 HIPAA 标准的服务，能够通过完全托管式生物信息学工作流，帮助医疗保健与生命科学客户大规模加速取得科学突破。 使用任务级超时，您可以定义单个 WDL 任务的时间上限，以控制成本并实现自动错误恢复。HealthOmics 提供 omicsTimeout 运行时属性，您可以将其添加到任何任务的运行时部分，以指定允许任务运行的最大时长。当任务超过指定的时长时，HealthOmics 会停止该任务并将任务和运行状态设置为失败。omicsTimeout 属性接受使用标准时间单位（例如 90s、2h、1d）的时长值。这可以防止任务无休止消耗资源，并帮助您在工作流开发期间设置成本护栏。 WDL 工作流的任务级超时功能已在所有支持 AWS HealthOmics 的区域推出：美国东部（弗吉尼亚州北部、俄亥俄州）、美国西部（俄勒冈州）、欧洲地区（法兰克福、爱尔兰、伦敦）、以色列（特拉维夫）和亚太地区（首尔、新加坡、东京）。要了解更多信息，请访问 WDL 工作流定义细节 文档。
