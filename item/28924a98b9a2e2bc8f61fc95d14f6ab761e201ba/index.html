新聞標題（原文）
Amazon Route 53 Domains 现已支持对已过期和已删除的域名进行自助还原
收錄來源
AWS News
發布時間（來源提供）
2026-11-12T08:00:00Z
來源摘要（原文）
Amazon Route 53 Domains 现支持您使用 Amazon Route 53 控制台、AWS CLI 或 AWS SDK 自行还原已过期或最近已删除的域名。以前，需要向 AWS Support 提出请求才能还原域名。现在，您可以恢复因错过续订、付款方式过期或意外删除而导致丢失的域名，并还原依赖该域名的网站、电子邮件和应用程序。 要还原域名，您需要输入域名、查看还原价格、接受费用并提交请求。Route 53 会与顶级域名（TLD）注册局协同，重新激活该域名的注册，并将其交还至您的 AWS 账户。大多数 TLD 注册局都支持还原，但各个注册局会设定域名在过期或被删除后仍可还原的时限。域名的还原成本通常高于其注册或续订成本。 要了解更多信息，请参阅《Route 53 开发人员指南》中的 还原已过期或已删除的域名 ，或访问 Amazon Route 53 Domains 页面 。有关支持的 TLD 的完整列表，请参阅 Route 53 TLD 列表 。有关定价，请访问 Route 53 定价页面 。
