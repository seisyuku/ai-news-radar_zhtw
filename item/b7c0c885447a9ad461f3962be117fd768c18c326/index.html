Title
AWS 网络负载均衡器现已支持用于自定义流量路由的侦听器规则
Source
AWS News
Published
2026-07-22T19:13:00Z
Summary
网络负载均衡器（NLB）现已支持侦听器规则，可让您根据源 IP 地址类型将连接路由到不同的目标组。利用侦听器规则，单个双栈 NLB 可将 IPv6 客户端流量发送到 IPv6 目标，将 IPv4 客户端流量发送到 IPv4 目标，从而针对两个地址系列端到端保留原始客户端 IP 地址。 以前，在使用一个 NLB 同时服务 IPv4 和 IPv6 客户端时，需要做出取舍：要么运行两个独立的负载均衡器（每个 IP 版本一个），通过 DNS 实现客户端分流；要么将所有流量发送到同一目标组，但会因协议转换而丢失原始客户端 IP。侦听器规则通过在第 3 层启用条件路由，消除了这一取舍，将每个连接定向至同地址系列的目标组，无需协议转换，也无需额外基础设施。 您可以将侦听器规则添加到现有的双栈 NLB 中，而无需重新创建这些 NLB。侦听器规则适用于 TCP、UDP、TCP_UDP 和 TLS 侦听器，可与现有 NLB 功能配合使用，这些功能包括连接耗尽、目标组粘性、跨区域负载均衡、加权目标组和客户端 IP 保留。 适用于网络负载均衡器的侦听器规则已在所有 AWS 商业区域和 AWS GovCloud（美国）区域推出，无需额外付费。但适用标准 NLB 定价，即按负载均衡器运行小时数和 LCU 计费。要开始使用，请参阅 这篇 AWS 博客 和 网络负载均衡器用户指南 。
