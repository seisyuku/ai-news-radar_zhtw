Amazon Bedrock AgentCore 现在提供 Web 搜索 API
收錄來源

發布時間（來源提供）

來源摘要（原文）
今天，AWS 宣布在 Amazon Bedrock AgentCore 上正式推出 Web 搜索 API，它允许您通过单次 API 调用搜索网络。AgentCore 上的 Web 搜索已作为 MCP 工具通过 AgentCore 网关提供。新的 InvokeWebSearch API 可在无需创建任何资源的情况下，为应用程序、自定义智能体循环和数据管道提供搜索结果。 该 API 返回来自 AgentCore 上的 Web 搜索背后由亚马逊运营的网页索引的排序结果。每个结果都包括文本摘录（如果有）、页面标题、URL 和发布时间。您可以按域名和发布时间筛选每个请求，例如查找最近的产品公告或对照可信域名核查某项声明。 您可以使用 AWS SDK 或 AWS 命令行界面（AWS CLI）调用 API，并使用 AWS Identity and Access Management（IAM）授权调用。您可以通过 AWS PrivateLink 从您的虚拟私有云（VPC）调用该服务，并将请求作为 AWS CloudTrail 数据事件进行记录。Web 搜索 API 的查询按每 1000 次查询 7 USD 计费，与通过 AgentCore 网关进行的 Web 搜索计费标准相同，且不收取网关费用。 Web 搜索 API 适用于美国东部（弗吉尼亚州北部）、美国东部（俄亥俄州）、美国西部（俄勒冈州）、亚太地区（悉尼）、亚太地区（东京）和欧洲地区（爱尔兰）区域。要了解更多信息，请参阅“AgentCore Developer Guide”中的 Search the web with the InvokeWebSearch API 、 Web 搜索 页面和 AgentCore 定价 。
