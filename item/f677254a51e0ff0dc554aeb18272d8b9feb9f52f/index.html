Title
SageMaker MLflow 现在支持客户自主管理型密钥
Source
AWS News
Published
2026-08-24T19:26:00Z
Summary
SageMaker MLflow 现在支持客户通过 AWS Key Management Service（KMS），使用客户自主管理型密钥（CMK）对数据进行加密。 这一增强功能使具有严格的安全性与合规性要求的组织能够自行管理加密密钥。借助客户自主管理型密钥，您可以通过与 AWS CloudTrail 的集成获得更强大的安全控制能力和全面的审计功能。您可以使用自己的 KMS 密钥对数据进行加密，并跟踪所有数据访问以进行安全审计。 客户自主管理型密钥必须在您的 MLflow App 所属的 AWS 账户和区域中创建，且仅支持对称的 AWS KMS 密钥。 此功能已在 提供 MLflow App 的所有 AWS 区域全面推出。要了解更多信息，请访问 SageMaker MLflow 详细信息页面 。
