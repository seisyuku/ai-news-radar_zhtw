Title
AWS Clean Rooms 支持导出用于 SQL 分析的隐私增强型分析日志
Source
AWS News
Published
2026-08-11T12:00:00Z
Summary
AWS Clean Rooms 现已支持 导出隐私增强型分析日志以进行 SQL 分析 ，提升客户的优化和问题排查能力。通过本次发布，您可以将隐私增强型分析日志导出到 S3 存储桶中，以用于在 AWS Clean Rooms 协作中运行的 SQL 查询，这可让您深入了解 Spark 执行详情，从而对查询进行优化和问题排查。协作所有者可以在创建协作时向成员赋予导出分析日志的能力，也可以提交变更请求以向现有协作的成员赋予此能力。查询运行后，您可以将隐私增强型分析日志导出到所需的 S3 路径。例如，与发布者协作的第三方测量提供方可以发现导致查询速度比平时慢的异常数据倾斜问题，从而缩短问题解决时间并优化成本。 AWS Clean Rooms 可以帮助公司及其合作伙伴轻松地分析他们的汇总数据集并进行协作，而无需透露或复制彼此的底层数据。有关提供 AWS Clean Rooms 的 AWS 区域的更多信息，请参阅 AWS 区域 表。要了解有关通过 AWS Clean Rooms 进行协作的更多信息，请访问 AWS Clean Rooms 。
