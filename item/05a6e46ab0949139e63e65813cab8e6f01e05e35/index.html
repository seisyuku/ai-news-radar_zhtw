Title
Amazon Aurora MySQL 3.13（与 MySQL 8.0.45 兼容）现已正式推出
Source
AWS News
Published
2026-08-28T16:00:00Z
Summary
即日起，Amazon Aurora MySQL 兼容版 3（与 MySQL 8.0 兼容）支持 MySQL 8.0.45，其中包括社区 MySQL 修复和 Aurora 特定改进。有关此版本的详细信息，请参阅 Aurora MySQL 3 和 MySQL 8.0.45 发行说明。 您可以使用自动次要版本升级在计划维护时段内升级数据库。要大规模简化操作，请启用 自动次要版本升级 ，并使用 AWS Organizations 升级部署策略 以分阶段编排集群升级。您可以就地或通过快照还原执行次要版本升级。提供 Aurora MySQL 的所有 AWS 区域 均支持此版本。 Amazon Aurora 设计具有全球规模的高性能和可用性，与 MySQL 完全兼容。它提供可缩减至零的无服务器计算、支持多区域韧性的 Aurora Global Database、用于提升 I/O 密集型工作负载性价比的 Aurora I/O 优化版，以及内置的安全功能和持续备份。要开始使用，请查看 Aurora 的 入门页面 。
