Amazon Cognito 将多区域复制拓展到 AWS GovCloud（美国）区域
收錄來源

發布時間（來源提供）

來源摘要（原文）
Amazon Cognito 多区域复制（MRR）现已支持 AWS GovCloud（美国）区域，将 MRR 的韧性优势拓展到更多工作负载。MRR 可让您近实时地将用户和机器身份数据（包括凭证、用户池配置和联合身份验证设置）同步到您指定的备用区域中的辅助用户池。备用区域中已留存用户数据，当主区域出现中断时，您可以重定向流量并确保身份验证正常运行。 此前，MRR 已在 16 个商业区域推出。现在，您还可以使用 MRR 在其他 AWS 区域之间进行复制，帮助您在最符合自身业务需求的区域满足韧性、数据驻留和合规性要求。 MRR 可作为 Essentials 或 Plus 功能套餐中用户池的附加功能提供，并且需要多区域 AWS KMS 客户自主管理型密钥（CMK）。有关提供 Amazon Cognito 的 AWS 区域的完整列表，请参阅 按区域探索 AWS 功能 。要开始使用，请访问 开发人员指南 查看操作说明，并访问 定价页面 了解定价详情。
