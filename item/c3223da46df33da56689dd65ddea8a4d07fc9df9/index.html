Title
Amazon EC2 M8g 实例现已在更多区域推出
Source
AWS News
Published
2026-08-06T00:27:00Z
Summary
即日起，Amazon Elastic Compute Cloud（Amazon EC2）M8g 实例在 AWS 亚太地区（台北）和 AWS 墨西哥（中部）区域推出。这些实例由 AWS Graviton4 处理器提供支持，相比基于 AWS Graviton3 的实例，其性能高出 30%。Amazon EC2 M8g 实例是针对应用程序服务器、微服务、游戏服务器、中型数据存储和缓存实例集等通用型工作负载构建的。这些实例基于 AWS Nitro System 构建，该系统将 CPU 虚拟化、存储和联网功能卸载到专用硬件和软件，从而增强工作负载的性能和安全性。 基于 AWS Graviton4 的 Amazon EC2 实例可以为在 Amazon EC2 上运行的各种工作负载提供出色性能和能效。与基于 Graviton3 的 Amazon M7g 实例相比，这些实例的 vCPU 和内存增加多达 3 倍，从而提供了更大的实例大小。与 AWS Graviton3 处理器相比，AWS Graviton4 处理器可让数据库提速高达 40%，让 Web 应用程序提速高达 30%，让大型 Java 应用程序提速高达 45%。M8g 实例有 12 种不同的实例大小可供选择，包括两种裸机大小。它们提供高达 50Gbps 的增强网络带宽和高达 40Gbps 的 Amazon Elastic Block Store (Amazon EBS) 带宽。 要了解更多信息，请参阅 Amazon EC2 M8g 实例 。要了解如何将工作负载迁移到基于 Graviton 的实例，请参阅 AWS Graviton Fast Start 迅速开启程序计划 和 Porting Advisor for Graviton 。要开始使用，请参阅 AWS 管理控制台 。
