AWS Security Hub 现可为计算资源提供 SBOM 清单

來源摘要（原文）
今天，AWS 宣布 AWS Security Hub 现在提供的清单包括软件物料清单（SBOM），让中央安全团队能够持续获得整个组织中计算资源上所安装软件包和应用程序的最新视图。 Security Hub 根据 Amazon Inspector 为 Amazon EC2 实例、Amazon ECR 容器映像和 AWS Lambda 函数生成的 SBOM 构建该清单，无需额外配置。SBOM 页面会列出每个软件包及其版本、类型以及安装该软件包的资源数量。您可以按软件包属性、账户和区域对该列表进行筛选和分组。在资源详情页面上，“已安装的软件”选项卡会列出该资源上的每个软件包，便于您在研判任何调查发现时判断其功能与重要性。您还可以通过 Security Hub API 查询该清单。 SBOM 清单已包含在 Security Hub Essentials 中，无需额外付费。它无需任何新的启用操作，在启用了 Amazon Inspector 的地方会自动填充。它已在提供 Security Hub 的所有 AWS 区域推出。要了解更多信息，请参阅 AWS Security Hub User Guide 和 AWS Security Hub 产品页面 。
