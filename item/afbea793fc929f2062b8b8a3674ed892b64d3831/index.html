Title
Amazon OpenSearch Service 现在支持 OpenSearch 版本 3.7
Source
AWS News
Published
2026-07-30T02:30:15Z
Summary
您现在可以在 Amazon OpenSearch Service 上运行 OpenSearch 版本 3.7。OpenSearch 3.7 对向量搜索性能、搜索相关性和 Query Insights 进行了改进。 通过此次发布，Faiss 和 Lucene 引擎上的 1 位标量量化技术 可对向量进行压缩，从而减少向量工作负载所需的存储空间和内存，同时保持搜索准确性。 现在，您可以使用 文档值 而不是文档来源更快地检索向量，无需重新索引。 Search Relevance Workbench 增加了新的评测指标、CSV 评判数据上传以及扩展的混合搜索优化，可帮助您衡量和提高搜索质量。 此次发布还推出了新的 Query Insights 功能，包括自动查询建议、已完成查询缓存（用于观测最近完成的查询），以及将热门查询数据导出到 Amazon S3 的选项，可帮助您识别高成本的查询并分析长期趋势。 有关升级到 OpenSearch 3.7 的信息，请参阅 文档 。OpenSearch 3.7 现已在提供 Amazon OpenSearch Service 的所有 AWS 区域推出。
