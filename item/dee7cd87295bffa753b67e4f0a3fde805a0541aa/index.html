AWS Health 推出了用于软件生命周期管理的版本目录
收錄來源
AWS News
發布時間（來源提供）
2026-10-02T18:09:00Z
來源摘要（原文）
今天，AWS Health 推出了版本目录，该目录为 AWS 服务中的软件版本提供了集中式生命周期信息来源。版本目录可帮助客户将版本升级和支持终止风险的管理方式从被动转变为主动。该目录可在 AWS Health Dashboard 中找到，而使用 Business Support Plus、Enterprise Support 或 Unified Operations 的客户，可通过 AWS Health API 将生命周期数据集成到其运营工作流程中。 在 AWS 上运行应用程序的客户需要保持最新的软件版本，以保持良好的安全性和运营状态。AWS Health 已经会在主要版本支持终止的重要时间节点到来之前，提前向客户发送针对特定账户和资源的“计划生命周期事件”通知。版本目录添加了受支持版本及其时间表的全服务视图，因此客户可以在收到针对特定账户的“计划生命周期事件”通知之前，制定升级计划、构建治理控制措施，并迁移到较新的受支持版本。 在发布之初，该版本目录便涵盖了包括 Amazon RDS、Amazon EKS 和 AWS Lambda 在内的多项 AWS 服务，未来还将陆续增加更多服务。该版本目录已在所有 AWS 商业区域推出。 要开始使用，请访问 AWS Health Dashboard 中的版本目录或阅读 文档 以了解更多信息。
