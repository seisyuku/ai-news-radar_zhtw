Title
Amazon Quick 代理式人工智能功能现已在 AWS GovCloud（美国西部）推出
Source
AWS News
Published
2026-08-11T23:00:00Z
Summary
今天，AWS 宣布 Amazon Quick 代理式人工智能功能现已在 AWS GovCloud（美国西部）推出，在隔离的、FedRAMP D 类（原“高”等级）授权环境中为政府及受监管行业团队带来一名代理式人工智能队友。Quick 基于已对 AWS GovCloud（美国）客户可用的分析和商业智能功能构建，现在可将问题转化为行动，助力团队在不切换应用程序的情况下，更快地制定任务关键型决策。 通过本次发布，团队可以构建针对特定任务工作流（包括采购、ATO 合规审批和拨款管理）定制的聊天代理，同时确保数据完全在 AWS GovCloud（美国西部）区域进行托管和管理。Spaces 通过将信息范围限定在相应的项目办公室或任务领域，强制实施最低权限访问原则，从而确保分析人员只能访问与任务相关的数据。Quick 还可与团队已使用的工具集成，包括通过 GCC High 连接器集成的 Microsoft 365、SharePoint 和 OneDrive，以及浏览器扩展。 AWS GovCloud（美国）区域是由美国本土的美国公民运营的隔离 AWS 区域，专用于托管敏感数据和受监管工作负载。客户可以满足最严苛的美国政府安全与合规要求，包括 FedRAMP D 类（原“高”等级）基线、国防部云计算安全要求指南（DoD SRG）影响等级 4 和 5、国际武器贸易条例（ITAR）、刑事司法信息服务（CJIS）以及联邦信息处理标准（FIPS）140-3。对经授权的基础模型的推理在 AWS GovCloud（美国西部）区域内处理，并且企业治理功能一经发布即可用。 本次发布后，Amazon Quick 的代理式人工智能功能已在 8 个 AWS 区域推出：美国东部（弗吉尼亚州北部）、美国西部（俄勒冈州）、欧洲（法兰克福、爱尔兰、伦敦）、亚太地区（悉尼、东京）以及 AWS GovCloud（美国西部）。 要了解更多信息，请访问 Amazon Quick 产品页面 和 AWS GovCloud（美国）文档
