Title
AWS HealthOmics 扩展了对私有工作流程的容器注册表支持
Source
AWS News
Published
2026-10-14T21:55:00Z
Summary
借助 AWS HealthOmics 对第三方容器注册表的扩展支持，您现在可以使用来自 Seqera（Wave）、NVIDIA NGC 和 Google Artifact Registry 等注册表的容器映像。您可以使用您的工作流程原本依赖的容器化工具，无需手动将映像迁移到 Amazon ECR 或编辑工作流程定义。 AWS HealthOmics 是一项符合 HIPAA 标准的服务，能够通过完全托管式生物信息学工作流，帮助医疗保健与生命科学客户大规模加速取得科学突破。 借助扩展的容器注册表支持，在运行私有工作流程时，您现在可以指示 HealthOmics 代表您将容器映像从新支持的注册表复制到您的 Amazon ECR 中。 以前，AWS HealthOmics只能从 Amazon ECR 拉式缓存 （PTC）支持的注册表中拉取映像。您的私有工作流程现在可以访问 Amazon ECR 拉式缓存注册表和新支持的第三方容器注册表，使您无需自行拉取、重新推送或重写映像 URI。 扩展的容器注册表支持已在提供 HealthOmics 的所有 AWS 区域推出：美国东部（弗吉尼亚州北部、俄亥俄州）、美国西部（俄勒冈州）、欧洲地区（法兰克福、爱尔兰、伦敦）、以色列（特拉维夫）和亚太地区（新加坡、首尔、东京）。要了解更多信息，请访问 第三方容器映像支持文档 。
