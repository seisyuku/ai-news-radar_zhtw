AWS Network Firewall 推出下一代防火墙策略

來源摘要（原文）
今天，AWS 宣布推出适用于 AWS Network Firewall 的下一代防火墙（NGFW）策略，这是一种全新的策略模型，可为安全团队提供更简洁的策略结构和更大的规则容量。AWS Network Firewall 是一项托管式网络安全服务，通过访问控制和威胁检测来保护您的 Amazon VPC。 新的策略模型通过将防火墙和 IPS 保护分层而不是合并来增强您的安全态势，这也使策略更易于管理。您可以编写防火墙规则，以实施“默认拒绝”的访问控制，例如仅允许流量流向已批准的域。对于 IPS 规则，您可以使用来自 AWS 或 AWS Marketplace 合作伙伴的托管规则组，这些规则组会随着新威胁的出现自动更新。您也可以创建自己的自定义 IPS 规则组。防火墙和 IPS 规则都有自己的容量，因此您无需再在两者之间做出取舍。对于不跨策略共享的规则，您可以创建嵌入式规则组，无需预先分配即可按需使用容量。使用 NGFW 策略，所有规则都是有状态的，并在完整的连接环境下进行评估，以实现一致、可预测的流量处理。您现有的策略将继续按原样运行，且 IPS 规则仍保持向后兼容性。 NGFW 策略现已在所有 AWS 商业区域和 AWS GovCloud（美国）区域推出，无需额外付费。有关受支持区域的完整列表，请访问 按区域探索 AWS 功能 页面。 要了解更多信息，请参阅 AWS Network Firewall 产品页面 和 文档 。
