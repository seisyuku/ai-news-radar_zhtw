AWS Step Functions 工作流现作为智能体工具提供
收錄來源

發布時間（來源提供）

來源摘要（原文）
现在，您可以通过 Amazon Bedrock AgentCore 网关 将 AWS Step Functions 工作流用作智能体的工具。您的智能体决定何时运行工作流以及传递哪些输入，而 Step Functions 会完全按照您定义的方式执行每个步骤。代理可以将您现有的标准工作流和快速工作流用作工具。 AWS Step Functions 是一项可视化工作流服务，可以编排 220 多项 AWS 服务，从而帮助客户大规模构建分布式应用程序。AgentCore 网关通过模型上下文协议（MCP）将智能体与工具连接起来。此次发布后，您的智能体每次都能按相同顺序运行多步骤业务流程。例如，客户支持智能体可以启动退款工作流，Step Functions 会依次执行资格审核、经理审批和退款等步骤，确保每笔退款都符合您的政策。它还可以查询工作流的运行记录，这样运维智能体就能告知值班工程师，昨晚哪些运行步骤失败以及失败的位置，从而让工程师直接修复出错的步骤。 此功能在所有提供 Amazon Bedrock AgentCore 网关的 AWS 区域推出。您只需按标准费率支付 Step Functions 和 AgentCore 网关的费用。 要开始使用，请按照“Step Functions 开发人员指南”中的 教程 操作。有关所有受支持的操作和配置选项，请参阅 AgentCore 网关 文档 中的“Step Functions 连接器目标”。如果您使用 Kiro 等 AI 编码助手进行开发， Agent Toolkit for AWS 将为其提供在 AWS 上进行构建所需的技能和指导。
