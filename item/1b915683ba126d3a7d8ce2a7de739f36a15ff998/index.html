Title
Amazon S3 表类数据存储服务现在支持 Apache Iceberg V3 的 Variant 数据类型
Source
AWS News
Published
2026-07-28T07:00:00Z
Summary
Amazon S3 表类数据存储服务现在支持 Apache Iceberg 版本 3（V3）规范中定义的 Variant 数据类型。现在，您可以将半结构化数据（如 JSON）直接写入 S3 表类数据存储服务，而无需事先定义固定架构，这样您就可以更快地导入数据，同时仍能获得高效的分析查询性能。 借助 Variant 数据类型，兼容 Apache Iceberg V3 的引擎会在您写入半结构化数据时将其粉碎成隐藏的列，并生成 Parquet 列统计信息。查询引擎可利用这些统计信息进行优化（例如文件修剪），从而减少分析查询需要扫描的数据量。S3 表类数据存储服务还会对 Variant 列进行持续的表维护（包括压缩），因此您可以将小文件中的数据整合到大文件中，以供 Iceberg 引擎读取。 S3 表类数据存储服务对 Variant 的支持现已在下列 AWS 区域推出：美国东部（弗吉尼亚州北部）、美国东部（俄亥俄州）、美国西部（俄勒冈州）、亚太地区（孟买）、亚太地区（首尔）、亚太地区（新加坡）、亚太地区（悉尼）、亚太地区（东京）、加拿大（中部）、欧洲地区（法兰克福）、欧洲地区（爱尔兰）、欧洲地区（伦敦）、欧洲地区（巴黎）、欧洲地区（斯德哥尔摩）和南美洲（圣保罗）。 要了解更多信息，请参阅 Amazon S3 表类数据存储服务 和 关于使用 Iceberg 表格式规范版本 3 的 AWS 规范指引 。
