Title
Amazon RDS 现已支持 Microsoft SQL Server 的最新累积更新
Source
AWS News
Published
2026-10-13T07:30:00Z
Summary
Amazon Relational Database Service（Amazon RDS）for SQL Server 现已支持 Microsoft SQL Server 的最新累积更新（CU）。此版本包括对 Microsoft SQL Server 2025 CU8 KB5104822 （RDS 版本 17.00.4075.5.v1）的支持。 有关这些更新中包含的改进和修复的更多信息，请参阅 Microsoft 关于 KB5104822 的文档。我们建议您使用 Amazon RDS 管理控制台、AWS SDK 或 CLI 升级 Amazon RDS for SQL Server 实例以应用这些更新。您可以参阅 Amazon RDS SQL Server 用户指南中关于升级 RDS Microsoft SQL Server 数据库引擎的部分 ，详细了解如何升级数据库实例。
