Title
适用于 NetApp ONTAP 的 Amazon FSx 现在支持跨 AWS 区域和账户复制备份
Source
AWS News
Published
2026-08-27T17:37:00Z
Summary
适用于 NetApp ONTAP 的 Amazon FSx 是一项基于 NetApp 广受欢迎的 ONTAP 文件系统构建的完全托管式共享存储服务，现在支持在 AWS 区域内和跨区域，以及跨 AWS 组织中的受信任账户复制备份。现在，您可以将辅助备份副本存储在与主副本不同的区域或账户中，为数据提供额外的保护层，从而更轻松地满足业务连续性、数据保护和合规性要求。 Amazon FSx 提供安全、持久性强的增量备份，旨在支持您的数据留存、存档和合规需求。备份是卷的时间点离线副本，以冗余方式存储在与文件系统位于同一区域的多个可用区中。此前，您只能在文件系统所在的同一区域和账户中创建和恢复备份。 从今天开始，您可以将备份数据复制到多个区域和账户，从而增强韧性、实现数据隔离并提升运营灵活性。 您可以在推出适用于 NetApp ONTAP 的 Amazon FSx 的 所有 AWS 区域 复制新的和现有的备份。要了解更多信息，请访问 适用于 NetApp ONTAP 的 FSx 用户指南 和 适用于 NetApp ONTAP 的 Amazon FSx 产品页面 。
