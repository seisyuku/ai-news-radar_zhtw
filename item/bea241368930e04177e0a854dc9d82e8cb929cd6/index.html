AWS Systems Manager 简化了 Google Cloud VM 的接入，实现集中管理

來源摘要（原文）
AWS Systems Manager Cloud Connector 现在将简化的多云接入支持扩展到 Google Cloud，让您可以轻松将现有 Google Cloud VM 连接到 Systems Manager，与 AWS、本地和 Azure 资源一起集中管理，无需手动安装代理。以前，管理多个云提供商的虚拟机通常需要在每个环境中分别协调和设置配置。 借助适用于 Google Cloud 的 Cloud Connector，您可以自动将 SSM Agent 大规模部署到 Google Cloud VM。连接后，Google Cloud VM 会与 EC2 实例、本地服务器和其他多云资源一起显示在统一视图中，使您能够通过单个工作流跨 AWS、本地、Azure 和 Google Cloud 使用会话管理器、Automation 运行手册、Run Command、状态管理器、补丁管理器和清单。这简化了跨多个云管理基础设施的团队的运维工作，使他们能够标准化管理实践并降低运维复杂性。 适用于 Google Cloud 的 Cloud Connector 已在以下区域推出：非洲（开普敦）、亚太地区（香港、海得拉巴、雅加达、马来西亚、墨尔本、孟买、新西兰、大阪、首尔、新加坡、悉尼、台北、泰国、东京）、加拿大（中部、卡尔加里）、欧洲地区（法兰克福、爱尔兰、伦敦、米兰、巴黎、西班牙、斯德哥尔摩、苏黎世）、以色列（特拉维夫）、墨西哥（中部）、南美洲（圣保罗）、美国东部（弗吉尼亚州北部、俄亥俄州）以及美国西部（加利福尼亚州北部、俄勒冈州）。 要了解更多信息，请参阅 AWS Systems Manager 文档。
