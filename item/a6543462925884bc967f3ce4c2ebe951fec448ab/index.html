Title
Amazon Bedrock AgentCore 内存现已支持为长期记忆配置生存时间
Source
AWS News
Published
2026-10-13T16:00:00Z
Summary
Amazon Bedrock AgentCore 内存现在支持为长期记忆记录设置生存时间（TTL），以便这些记录在您定义的保留期后自动删除。默认情况下，长期记忆记录不会过期。通过此次发布，您可以配置 TTL 以满足数据保留要求，控制存储增长，并确保过时的见解会随着时间的推移从内存中自动清除。 您可以为资源或特定记录配置保留期。配置或删除 TTL 需要新的 bedrock-agentcore:UpdateMemoryRecordExpirySpecification 权限，该权限让您能够独立控制谁可以设置记录保留期。 要了解更多信息，请参阅 Amazon Bedrock AgentCore 开发人员指南中的 为长期记忆记录设置生存时间 。此功能现已在支持 Amazon Bedrock AgentCore 内存的所有 AWS 区域推出。
