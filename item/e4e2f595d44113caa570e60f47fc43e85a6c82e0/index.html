现在可以通过 Amazon Inspector 对 EC2 亚马逊机器映像进行漏洞扫描
收錄來源

發布時間（來源提供）

來源摘要（原文）
Amazon Inspector 现已将其漏洞扫描功能扩展到 EC2 亚马逊机器映像（AMI），使您无需启动实例或安装额外软件，即可识别 AMI 中的软件漏洞。这可以帮助您在将 AMI 用于在整个实例集中启动实例之前，从根源上解决问题。 借助此功能，您可以运行持续评估，以监控 AMI 目录中是否存在新发现的漏洞，或者直接从 EC2 控制台对特定的 AMI 执行有针对性的一次性扫描。您可以在 Amazon Inspector 中为账户或整个组织启用 AMI 扫描。对于 AWS Security Hub 客户，您可以在整个组织范围内启用 AMI 扫描作为附加功能，扫描结果也会传输到 Security Hub。根据扫描结果，您可以启用 允许的 AMI 设置，指定 AMI 必须满足哪些安全标准才能在您的账户中可供使用，同时利用声明性策略在整个组织范围内强制执行此设置。使用 EC2 Image Builder 构建 AMI 的客户可以将扫描功能直接集成到其管道中，并限制不符合其安全标准的 AMI 的分发。 AMI 扫描功能可帮助您在部署管道中尽早检测和修复漏洞，从而降低部署受损计算资源的风险。安全团队现在可以在所有 AMI 中建立一致的漏洞扫描流程，从而在实例启动之前改善其安全态势。 此功能已在提供 Amazon Inspector 的所有 AWS 商业区域推出。要了解更多信息，请参阅 EC2 User Guide 、 Amazon Inspector User Guide 、 Amazon Inspector 定价页面 和 Amazon Inspector 产品页面 。
