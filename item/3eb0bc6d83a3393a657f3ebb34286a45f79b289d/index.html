來源摘要（原文）
AWS 墨西哥（中部）区域现在支持第二代 AWS Outposts 机架。Outposts 机架可将 AWS 基础设施、AWS 服务、API 和工具扩展到几乎任何本地数据中心或主机托管空间，以实现真正一致的混合体验。 从初创企业到大型企业再到公共部门机构，各种规模的组织现在都可以订购与这个新支持的区域相连的 Outposts 机架，从而根据延迟和数据驻留需求进行优化。本次区域扩展为客户的 Outposts 可以连接到的 AWS 区域数量提供了额外的灵活性。 要了解有关第二代 Outposts 机架的更多信息，请阅读本 博客文章 和 用户指南 。有关支持第二代 Outposts 机架的国家/地区和 AWS 区域的最新列表，请查看 Outposts 机架常见问题页面 。
