Title
AWS Transform 持续现代化功能现已全面推出
Source
AWS News
Published
2026-08-03T21:15:00Z
Summary
AWS Transform 持续现代化功能 现已在 支持 AWS Transform 的所有 AWS 区域 全面推出。这项功能可帮助工程团队大规模分析和修复源代码存储库中的技术债务。团队可以连接 GitHub 组织、GitLab 组和 Bitbucket 工作区，按需或定期进行分析，并根据技术债务、安全性、智能体准备情况、现代化准备情况和自定义分析标准对调查发现进行优先级排序。 借助今天发布的功能，您可以直接通过 AWS Transform Web 应用程序连接源代码提供商、启动和安排分析、查看调查发现并创建修复方案。对于有对应修复方案的调查发现，持续现代化功能会创建分支，并打开包含经过验证的代码更改的拉取请求或合并请求以供审查。分析和修复操作在您的 AWS 账户中使用您的凭证运行，同时您的源代码始终由您掌控。 您还可以使用 AWS Transform Kiro 能力包、智能体插件或 AWS Transform CLI 从 IDE 或终端进行操作，分析本地存储库，使用标签管理存储库，以及通过 Amazon EC2 或 AWS Batch 在本地或远程运行分析。要开始使用，请打开 AWS Transform Web 应用程序 或使用 AWS Transform Kiro 能力包和智能体插件 。要了解更多信息，请参阅《AWS Transform 用户指南》中的 AWS Transform 持续现代化功能 。
