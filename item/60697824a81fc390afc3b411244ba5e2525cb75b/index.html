AWS DevOps 智能体现已在 AWS GovCloud（美国西部）推出，它是您随时可用的运营队友，能够解决并主动预防事故，优化应用程序的可靠性和性能，并在 AWS、多云及本地环境中处理按需 SRE 任务。 DevOps 代理像经验丰富的队友一样调查事故并确定运营改进领域：通过了解您的应用程序及其关系，使用您的可观测性工具、运行手册、代码存储库和 CI/CD 管道，同时关联遥测、代码和部署数据。它可以自主对事故进行分类并指导团队快速解决问题，将解决问题的平均时间（MTTR）从几小时缩短到几分钟，同时分析历史事故的模式，以提供可操作的建议，防止将来出现中断。 有关提供 AWS DevOps 智能体的 AWS 区域的完整列表，请访问 区域 列表。有关定价详情，请参阅 AWS DevOps 代理 定价页面 。AWS Support 客户将根据上个月的 AWS Support 费用，获得相应的月度 DevOps 代理抵扣金：Unified Operations 为 100%，Enterprise Support 为 75%，Business Support+ 为 30%。对于许多客户而言，这可以显著降低或消除 DevOps 代理成本。有关详细信息，请访问 支持比较页面 。 要了解更多信息，请阅读 发布博客 并查看 入门指南 。
