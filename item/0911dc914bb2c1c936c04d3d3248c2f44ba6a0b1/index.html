Amazon Aurora 和 RDS 现已支持基于 Graviton5 的 R9g 数据库实例
收錄來源
AWS News
發布時間（來源提供）
2026-11-12T19:02:00Z
來源摘要（原文）
基于 AWS Graviton5 的 R9g 数据库实例现已正式推出，适用于兼容 PostgreSQL 与 MySQL 的 Amazon Aurora，以及 Amazon RDS for PostgreSQL、MySQL 和 MariaDB。 在 Amazon Aurora 上，与同等大小、基于 Graviton4 的实例相比，基于 Graviton5 的 R9g 实例在按需定价下性能最高可提升 30%，性价比最高可提升 22%，具体取决于数据库引擎、版本和工作负载。R9g 实例基于 AWS Nitro System 而构建，提供九种大小，从 large 到 48xlarge 不等。它们提供的 vCPU 数量最高可达 192 个、内存与 vCPU 的配比为 8:1、网络带宽最高可达 100 Gbps，Amazon Elastic Block Store（Amazon EBS）带宽最高可达 72 Gbps。 您可以通过 Amazon RDS 管理控制台 或使用 AWS 命令行界面 （CLI）开始使用 R9g 数据库实例。这些实例已在美国东部（弗吉尼亚州北部、俄亥俄州）、美国西部（俄勒冈州）和欧洲地区（法兰克福）区域推出。有关支持这些实例类别的具体引擎版本，请参阅 Aurora 和 RDS 文档。有关定价，请参阅 Amazon Aurora 定价 和 Amazon RDS 定价 。
