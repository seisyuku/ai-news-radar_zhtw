Title
Amazon MWAA 现在支持 Apache Airflow 版本 2.11.2
Source
AWS News
Published
2026-07-24T21:57:00Z
Summary
Amazon Managed Workflows for Apache Airflow（MWAA）现支持 Apache Airflow 版本 2.11.2。Amazon MWAA 是一项托管服务，可大规模运行 Apache Airflow，免除管理底层基础设施的运营开销。Apache Airflow 2.11.2 是一个维护版本，包括安全改进、错误修复和依赖项升级。 该版本为 Airflow Web 服务器和任务执行层更新了安全补丁、优化了稳定性，并同步升级了核心依赖项。它还针对排队任务修复了任务生命周期管理相关问题、增强了日志中的密钥掩蔽能力、更正了“任务实例”列表视图中的用户界面显示问题，并更新了用于 S3 和 CloudWatch 日志传输的提供程序包。 在所有当前已推出 Amazon MWAA 的区域，您既可以在 Amazon MWAA 上创建新的 Apache Airflow 2.11.2 环境，也可以在 AWS 管理控制台中点击几下升级现有环境。要了解更多信息，请访问 Amazon MWAA 文档 ，查看 Apache Airflow 2.11.2 版本说明 ，并浏览 MWAA 上可用的 Airflow 版本列表 。
