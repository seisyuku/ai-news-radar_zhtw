AWS Lambda MicroVMs 现已支持 x86 CPU 架构
收錄來源
AWS News
發布時間（來源提供）
2026-11-11T18:00:00Z
來源摘要（原文）
AWS Lambda MicroVMs 现已支持 x86 CPU 架构，因此您无需重新编译或移植，即可运行现有的 x86 应用程序、工具和软件依赖项。创建 MicroVM 映像时，您现在可以在 x86 和 Arm（AWS Graviton）之间选择，从而在工作负载使用的架构上为每个用户或任务提供隔离的 MicroVM。 Lambda MicroVMs 是一种无服务器计算原语，提供虚拟机级隔离、近乎即时的启动和恢复以及状态保留能力，用于运行用户编写或 AI 生成的代码，使用场景包括 AI 编码助手、CI/CD 运行器、交互式开发环境和漏洞扫描程序等。此次发布可让您在 Lambda MicroVMs 上按原样运行基于 x86 的工作负载。对于在 Arm 上运行的工作负载，您可以继续使用 AWS Graviton 处理器，这是默认的 CPU 架构选项。 要开始在 Lambda MicroVMs 上构建 x86 工作负载，请在从 Dockerfile 创建 MicroVM 映像时选择 x86 架构，然后从该映像启动 MicroVMs。您可以通过 AWS Lambda 控制台、AWS CloudFormation、AWS Cloud Development Kit 使用 MicroVMs，也可以借助 Agent Toolkit for AWS 通过首选智能体开发工具进行使用。 对 x86 CPU 架构的支持已在所有提供 Lambda MicroVMs 的 AWS 区域推出，亚太地区（香港）、亚太地区（马来西亚）、亚太地区（泰国）和欧洲（西班牙）除外。要了解更多信息，请访问 AWS Lambda MicroVMs 开发人员指南 。有关定价的信息，请参阅 Lambda MicroVMs 定价 。
