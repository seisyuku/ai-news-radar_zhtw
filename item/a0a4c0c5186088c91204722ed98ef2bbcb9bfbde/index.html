Title
Amazon Kinesis Video Streams 现已支持使用 AWS PrivateLink 的 VPC 端点
Source
AWS News
Published
2026-09-30T08:00:00Z
Summary
Amazon Kinesis Video Streams 现在支持由 AWS PrivateLink 提供支持的接口 VPC 端点，可以从 Amazon Virtual Private Cloud（Amazon VPC）建立私有连接。您的 VPC 和 Kinesis Video Streams 之间的流量停留在 AWS 网络上，不会暴露在公共互联网上，涵盖控制面板以及视频摄取和播放数据面板。 具有严格安全性、合规性或网络隔离要求的客户现在无需互联网网关、NAT 设备或公有 IP 地址即可提取、存储和播放视频。例如，私有子网中的联网摄像头或 IoT 视频工作负载可以将媒体文件发送到 Kinesis Video Streams，然后完全通过私有连接检索该媒体文件以供播放和分析。您可以通过 Amazon VPC 控制台、AWS CLI 或 AWS SDK 创建端点，还可以附加 VPC 端点策略来控制访问。 适用于 Amazon Kinesis Video Streams 的 VPC 端点已在提供 Amazon Kinesis Video Streams 的所有 AWS 区域推出，包括 AWS GovCloud（美国）区域和由北京光环新网科技股份有限公司（简称“光环新网”）运营的中国（北京）区域。 要了解更多信息，请访问我们的 入门指南 。
