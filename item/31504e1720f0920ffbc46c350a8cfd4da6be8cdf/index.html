Title
Amazon Managed Service for Prometheus 收集器现已在亚太地区（新西兰）区域推出
Source
AWS News
Published
2026-10-15T08:00:00Z
Summary
Amazon Managed Service for Prometheus 收集器是一款完全托管的无代理 Prometheus 指标收集器，现已在亚太地区（新西兰）区域推出。新西兰的客户现在可以在区域内运行与 Prometheus 兼容的监控工作负载，从而降低本地工作负载的延迟，并能够将数据保留在国内。 Amazon Managed Service for Prometheus 收集器可以从您的容器工作负载中发现并收集 Prometheus 指标，而无需自行运行和操作收集代理。客户将收集到的指标导入 Amazon Managed Service for Prometheus 工作区，然后在该处查询和分析指标。这种完全托管式方法无需维护和扩展收集基础设施，从而降低了运营开销。 要了解有关 Amazon Managed Service for Prometheus 收集器的更多信息，请访问 用户指南 或 产品页面 。
