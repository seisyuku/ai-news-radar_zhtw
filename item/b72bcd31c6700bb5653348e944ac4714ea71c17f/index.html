Title
AWS 弹性灾难恢复现已在另外 6 个 AWS 区域推出
Source
AWS News
Published
2026-07-21T22:00:00Z
Summary
AWS 弹性灾难恢复（AWS DRS）现已在另外六个 AWS 区域推出：亚太地区（曼谷）、亚太地区（马来西亚）、亚太地区（新西兰）、亚太地区（台北）、加拿大西部（卡尔加里）和墨西哥（中部）。弹性灾难恢复是推荐使用的 AWS 灾难恢复服务。借助经济实惠的存储、最少的计算和时间点恢复，可以快速、可靠地恢复本地和基于云的应用程序，有助于最大限度减少停机时间和数据丢失。借助 Elastic Disaster Recovery，您可以从物理基础设施、VMware vSphere、Microsoft Hyper-V 和云基础设施恢复 AWS 上的应用程序。还可以使用 Elastic Disaster Recovery 恢复不同 AWS 区域中的 Amazon EC2 实例。AWS DRS 可以复制和恢复各种应用程序，包括 Oracle、MySQL 和 SQL Server 等关键数据库，以及 SAP 等企业应用程序。AWS DRS 使用统一的流程进行演练、恢复和失效自动恢复，因此您不需要特定于应用程序的技能集来运行该服务。此次发布后，弹性灾难恢复现已在 36 个 AWS 区域推出。请参阅 AWS 区域服务列表 ，了解最新的可用性信息。 要了解有关 AWS 弹性灾难恢复的更多信息，请访问我们的 产品页面 或 文档 。要开始使用，请登录 AWS 弹性灾难恢复控制台 。
