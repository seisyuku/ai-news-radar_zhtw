Amazon EKS 自动模式现在支持 Kubernetes Gateway API
收錄來源
AWS News
發布時間（來源提供）
2026-10-28T17:33:00Z
來源摘要（原文）
Amazon EKS 自动模式现在支持 Kubernetes Gateway API，为客户提供了一种标准、可移植的方式来定义流量如何到达其应用程序。客户可以使用 Gateway 和 HTTPRoute 资源配置应用程序负载均衡，而 EKS 自动模式会自动预置和管理底层 AWS 基础设施。 此次发布后，EKS 自动模式客户无需安装或配置单独的控制器即可采用下一代 Kubernetes 流量管理标准。功能包括 HTTP 和 gRPC 路由、适用于多团队环境的跨命名空间流量路由、加权流量拆分、基于标头的路由，以及通过 AWS Certificate Manager 自动发现 TLS 证书。使用 Ingress 资源的现有工作负载继续与 Gateway API 资源并行运行。 要开始使用，请参阅 Amazon EKS 文档 。Gateway API 支持作为 EKS 自动模式的一部分提供，已在支持 EKS 自动模式的所有 AWS 区域推出。针对预置的 AWS 负载均衡资源收取标准费用。
