AWS Elemental MediaConnect 路由器现已支持高比特率模式
收錄來源

發布時間（來源提供）

來源摘要（原文）
AWS Elemental MediaConnect 路由器现已支持高比特率模式，新增了两个档位：250 Mbps 和 500 Mbps。这使得需要更高比特率的专业广播公司能够在不牺牲质量或可靠性的情况下传输高价值内容。 此增强功能支持行业标准工作流程，例如符合 VSF TR-07 的传输流分发，适用于广播传输、内容分发和远程制作。高比特率模式支持多达两个冗余源，可确保可靠性，并包含数据面板优化，可减少抖动以提高性能。 要了解更多信息，请访问 AWS Elemental MediaConnect 产品页面 和 MediaConnect 定价页面 。
