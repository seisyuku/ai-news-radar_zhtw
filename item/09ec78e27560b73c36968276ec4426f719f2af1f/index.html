Title
AWS Lambda 控制台将控制台到 IDE 集成扩展至 Kiro 和 Cursor
Source
AWS News
Published
2026-08-06T21:53:00Z
Summary
AWS Lambda 控制台现已将其控制台到 IDE 集成扩展至支持 Kiro 和 Cursor 集成开发环境（IDE）。此次扩展是在现有的 Visual Studio Code（VS Code）控制台到 IDE 集成基础上进行的，为使用这些常用 IDE 的无服务器开发人员提供了云与本地开发环境之间的无缝过渡。 借助扩展后的控制台到 IDE 集成，开发人员可以从 Lambda 控制台出发，按照引导式设置流程在 Kiro 或 Cursor 中开始本地开发，同时保留其现有代码和配置。此功能还使开发人员能够使用 Kiro 和 Cursor 轻松将其应用程序转换为 AWS Serverless Application Model （AWS SAM）模板，从而简化其 基础设施即代码 （IaC）实践和 CI/CD 管道集成。 此功能现已在所有 提供 Lambda 服务的 AWS 商业区域 推出，不收取额外费用。 要开始使用，创建新函数时，请在 Lambda 控制台的“代码”选项卡中或在“开始使用”弹出窗口中，单击“在 Kiro 中打开”或“在 Cursor 中打开”按钮。这将自动在您本地设备上的所选 IDE 中打开您的函数。要了解有关此体验的更多信息，请参阅 Lambda 开发人员指南 。
