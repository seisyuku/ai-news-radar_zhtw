Title
Amazon Bedrock AgentCore 中的 Web 搜索功能新增域筛选和发布日期筛选功能，并且已在欧洲和亚太地区推出
Source
AWS News
Published
2026-08-19T22:55:00Z
Summary
Amazon Bedrock AgentCore 中的 Web 搜索功能现已支持域筛选和发布日期筛选，可让代理根据请求控制所搜索的 Web 来源和时间窗口。Amazon Bedrock AgentCore 提供了构建、连接和优化人工智能代理所需的基础设施，而 Web 搜索功能可让这些代理根据当前 Web 数据进行响应。 借助运行时域筛选功能，代理可在每次调用时，将搜索结果的范围缩小至可信来源或屏蔽非目标域，无需管理员重新进行配置。借助发布日期筛选功能，代理可以使用包含的起始和结束日期界限将结果限定在特定的时间窗口内，从而确保响应仅包含时效性强、相关性高的内容。 通过此次发布，代理可以在每次工具调用中直接传递包含和排除域列表以及发布日期范围，而管理员可以获得新的网关级别的允许列表支持，并将每个列表的域上限提升至多达 100 个。这些功能非常适合受监管的行业、科研工作流以及需要严格控制信息来源与时效性的应用。 Web Search Tool 此前已在美国东部（弗吉尼亚州北部）（us-east-1）推出，现已在欧洲地区（爱尔兰）（eu-west-1）与亚太地区（东京）（ap-northeast-1）区域推出。要了解更多信息，请参阅有关域筛选和发布日期筛选功能的 技术博客 ，并查看 Amazon Bedrock AgentCore 产品文档 。
