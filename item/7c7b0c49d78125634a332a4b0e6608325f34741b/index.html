Title
Amazon Managed Grafana 现在支持创建 Grafana 13.2 工作空间
Source
AWS News
Published
2026-09-30T19:30:00Z
Summary
Amazon Managed Grafana 现在支持使用 Grafana 版本 13.2 创建新的工作空间。此版本引入了从开源 Grafana 13.0 至 13.2 版本中的各项功能，包括控制面板的 Git 同步、动态控制面板，以及 Amazon CloudWatch 数据来源插件对 PromQL 查询的支持。 使用 Git Sync，您可以将控制面板视为代码，方法是将工作区与 Git 存储库关联，从而启用版本控制以跟踪、审查和回滚控制面板的修改。动态控制面板在布局和面板设计方面提供了更具适应性的方法，可构建由条件驱动的响应式视图，这些视图会根据数据和变量进行动态调整。Amazon CloudWatch 数据来源插件现已支持 PromQL 查询，支持您使用 Prometheus 查询语言（PromQL）查询 CloudWatch 通过其 OpenTelemetry（OTLP）端点采集的指标，从而对现有的“指标搜索”和“指标洞察”查询类型进行补充。 已正式推出 Amazon Managed Grafana 的所有 AWS 区域均提供 Grafana 13.2。 要了解有关如何使用 13.2 版本创建 Amazon Managed Grafana 工作区的更多信息，请访问 用户文档 。要了解有关 Amazon Managed Grafana 功能及其定价的更多信息，请访问 产品页面 和 定价页面 。
