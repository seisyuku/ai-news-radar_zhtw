Title
Amazon RDS for SQL Server 已在更多 AWS 区域支持开发人员版
Source
AWS News
Published
2026-08-04T07:00:00Z
Summary
Amazon Relational Database Service（Amazon RDS）for SQL Server 开发人员版现已在 13 个新增 AWS 区域推出：亚太地区（香港、台北、海得拉巴、雅加达、马来西亚、墨尔本、新西兰、泰国）、加拿大西部（卡尔加里）、欧洲地区（米兰、西班牙）、以色列（特拉维夫）和墨西哥（中部）。 SQL Server 开发人员版包含企业版的所有功能，将其用作开发与测试系统无需支付许可费。经过本次扩展后，您可在距离您的数据和终端用户更近的更多区域构建和测试应用程序，降低延迟，简化开发工作流。 有关这些功能和区域可用性的更多信息，请参阅 在 RDS for SQL Server 上使用 SQL Server 开发人员版 。有关定价详情，请参阅 Amazon RDS for SQL Server 定价 。
