Title
AWS Elemental MediaConnect Router 现已支持可配置的恢复延迟模式
Source
AWS News
Published
2026-08-19T18:00:00Z
Summary
AWS Elemental MediaConnect Router 现已支持客户配置延迟设置，从而控制路由器内输入和输出之间的内部连接延迟。以前，路由器内部的协议延迟是由服务自动设置的，且无法调整。 MediaConnect Router 现已提供针对路由器输出的两个延迟配置选项：均衡模式和低延迟模式。均衡模式将保留通用使用案例的原有行为，而低延迟模式针对延迟敏感型工作流缩短了内部连接恢复时间。为每个路由器输出配置相应的模式，以便同一输入能够为具有不同延迟要求的多个输出提供数据。RouteFabricRecoveryLatency 是一项新的 CloudWatch 指标，可用于了解为每个路由配置的恢复延迟。 客户可以使用 MediaConnect API 或 AWS 管理控制台与 AWS CLI 来配置和查看延迟设置。 可配置的恢复延迟已在当前部署了 MediaConnect Router 的所有区域推出。要了解有关延迟模式的更多信息，请访问 AWS Elemental MediaConnect 文档 。
