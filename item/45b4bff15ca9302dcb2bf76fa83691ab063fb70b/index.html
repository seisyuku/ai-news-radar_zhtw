OpenAI GPT-6 Astra 现已在 Amazon Bedrock 上支持 UltraFast 模式

來源摘要（原文）
今天，AWS 宣布 OpenAI 的 GPT-6 Astra 在 Amazon Bedrock 上推出 UltraFast 模式。UltraFast 是 GPT-6 Astra 的一项高级速度层级，专为对速度要求极高的工作负载而设计。据 OpenAI 称，UltraFast 模式可将 API 推理速度提升高达 6 倍，每秒处理量高达 300 个词元。Amazon Bedrock 推理引擎可提供生产工作负载所需的性能、安全性和可靠性。 您可以使用 GPT-6 Astra UltraFast 来处理延迟敏感型应用程序，例如实时编码助手、交互式智能体，以及需要快速、高质量响应的面向客户的体验。完善的 AWS 控制措施可帮助您保护工作负载、管理访问权限和审计模型调用活动。 您可以在 Amazon Bedrock 控制台 中或通过受支持的 Amazon Bedrock API 以编程方式开始使用。有关支持的 AWS 区域 、端点、API、功能、推理配置文件和定价的信息，请参阅 Amazon Bedrock 文档 。
