针对代码漏洞的 AWS Continuum 现已正式推出
收錄來源

發布時間（來源提供）

來源摘要（原文）
今天，AWS 宣布正式推出针对代码漏洞的 AWS Continuum。针对代码漏洞的 Continuum 能够以机器级速度发现、验证、优先排序和修复代码漏洞。 针对代码漏洞的 Continuum 会基于您的 AWS 环境构建上下文图，包括资源拓扑、身份关系和网络可访问性。它知道哪些资源属于您的应用程序，以及哪些调查发现会带来真正的业务风险。它会摄取您现有的漏洞调查发现，扫描您的代码，然后通过在隔离的沙盒中测试发现来确认哪些发现可以利用。调查发现按业务影响排列优先顺序。最后，它会以拉取请求的形式直接向开发人员工作流提供修复补丁，并附带可利用性证明和影响范围评测。 针对代码漏洞的 Continuum 会为每项任务选择合适的 AI 模型。Continuum 启动时处于“学习”模式，该模式下它会提出修复建议供您审批。当它对其精确率建立足够的信任时，您可以切换到强制模式，让它在您设置的护栏内自主行动。 AWS Continuum 可与您现有的 AWS 安全服务（包括 Amazon GuardDuty 和 AWS Security Hub）配合使用。有关已推出 AWS Continuum 的 AWS 区域的更多信息，请参阅 AWS 区域表 。 要了解更多信息，请参阅 AWS Continuum 产品页面 。
