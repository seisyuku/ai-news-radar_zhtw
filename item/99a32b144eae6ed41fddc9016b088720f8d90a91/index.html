Title
AWS Lambda MicroVMs 现已在另外 5 个 AWS 区域推出
Source
AWS News
Published
2026-08-19T16:14:00Z
Summary
AWS Lambda MicroVMs 现已在另外 5 个 AWS 区域推出：亚太地区（孟买）、亚太地区（新加坡）、亚太地区（悉尼）、欧洲地区（法兰克福）和欧洲地区（斯德哥尔摩）。通过此次发布，您可以在共 10 个 AWS 区域内使用 Lambda MicroVMs。 Lambda MicroVMs 是一种无服务器计算组件，提供了虚拟机级隔离、近乎即时的启动与恢复速度并支持状态保留，可用于执行用户代码或人工智能生成的代码。 开发人员可以使用 Lambda MicroVMs 为每个用户或作业提供隔离的计算环境，而无需管理虚拟化基础设施，也不必在隔离、速度和状态保留之间进行选择。MicroVMs 支持面向应用程序的安全、有状态和响应式代码执行，包括 AI 编码助手、交互式开发环境和漏洞扫描器。 通过今日的发布，开发人员可以在另外 5 个区域内运行离最终用户更近的 Lambda MicroVMs，帮助满足延迟和数据驻留要求。要开始使用，请从您的 Dockerfile 中创建一个 MicroVM 映像，然后通过该映像启动 MicroVMs。为每个用户或作业提供独立的 MicroVM，并配置专用 HTTPS URL，以支持 HTTP/2、gRPC 和 WebSockets 等常用连接协议。您可以通过 AWS Lambda 控制台、AWS CloudFormation、AWS Cloud Development Kit 使用 MicroVMs，也可以借助 Agent Toolkit for AWS 通过首选智能体开发工具进行使用。 要了解更多信息，请访问 AWS Lambda MicroVMs 开发人员指南 。有关定价的信息，请参阅 Lambda MicroVMs 定价 。要了解最新的区域可用性，请访问 按区域探索 AWS 功能页面 。
