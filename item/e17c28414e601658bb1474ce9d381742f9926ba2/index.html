AWS DMS 架构转换功能将离线源转换扩展至 Oracle
收錄來源
AWS News
發布時間（來源提供）
2026-11-06T23:53:00Z
來源摘要（原文）
AWS 数据库迁移服务（DMS）架构转换功能 现已支持对 Oracle 数据库进行离线源转换。无需直接连接到源数据库即可转换 Oracle 架构和代码。您可以在自己的环境中使用标准数据库命令来提取元数据，然后将其上传到 DMS 架构转换功能以进行处理。这样一来，便无需进行会导致迁移项目延迟的安全审查、防火墙更改和 VPN 设置，并提供与互联方法相同的转换结果。 对于实施的安全策略会限制外部工具访问生产 Oracle 数据库的企业而言，Offline Source 是理想之选。数据库管理员可以在其现有环境中生成人类可读的元数据文件。安全团队可以在上传命令和输出之前对其进行审查，从而简化审批。通过消除连接要求，Offline Source 将耗时数周的安全审查转变为简单的命令执行与上传工作流。 Offline Source 支持所有 DMS 架构转换目标，不额外收取转换费用。有关区域可用性，请参阅 受支持的 AWS 区域 页面。要开始使用，请参阅“DMS 架构转换”文档中的 使用 Offline Source 。 要了解如何使用智能体进行离线评测和转换，请参阅此次发布的 博客文章 。
