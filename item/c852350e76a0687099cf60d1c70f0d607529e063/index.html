Title
AWS Lambda 针对 Amazon SQS 事件源映射的预置模式现已支持最多 10,000 个事件轮询器
Source
AWS News
Published
2026-08-03T18:00:00Z
Summary
AWS Lambda 现已支持在 Amazon SQS 事件源映射（ESM）的预置模式下配置最多 10,000 个事件轮询器，是此前 2,000 个限制的 5 倍。借此您可实现最高 100,000 次并发调用，从而构建满足严苛性能要求、高响应且具备可扩展性的事件驱动型应用程序。 客户使用 Amazon SQS 作为 Lambda 的事件源，以构建任务关键型应用程序，例如实时订单处理、金融交易管道、IoT 遥测数据摄取和大规模扇出工作负载，在这些场景中，事件处理延迟会直接影响业务成果。SQS ESM 的预置模式支持配置事件轮询器的最小数量和最大数量，并优化应用程序的吞吐量。 但是，此前轮询器的最大数量限制为 2,000，这限制了每个 ESM 可以达到的并发调用数量，并迫使客户将工作负载拆分到多个 ESM 中。本次发布后，客户每个 ESM 最高可支持 10,000 个事件轮询器和 100,000 次并发调用，从而能够构建满足严格延迟和吞吐量要求的大规模工作负载。 这项功能已在所有 AWS 商用区域全面推出。您可以通过使用 ESM API、AWS 管理控制台、AWS CLI、AWS SDK、AWS CloudFormation 和 AWS SAM 配置事件轮询器的最小数量和最大数量，为 SQS ESM 激活预置模式。您需要根据名为事件轮询单元（EPU）的计费单位，为使用的事件轮询器付费。要了解更多信息，请参阅 Lambda ESM 文档 和 AWS Lambda 定价 。
