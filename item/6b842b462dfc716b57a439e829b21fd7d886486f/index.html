Title
Amazon Redshift 数据 API 推出长轮询、会话管理和灵活的批处理执行
Source
AWS News
Published
2026-07-29T20:45:00Z
Summary
Amazon Redshift 数据 API 推出了多项新功能，可减少检索 SQL 语句元数据或结果所需的 API 调用次数，提供会话可见性，并允许批处理语句在独立的事务中执行。 长轮询：长轮询功能可延迟返回同步响应，直至 SQL 语句执行完毕，使您无需反复轮询直至 SQL 语句达到终止状态，即可检索 SQL 语句的元数据或结果。要使用此功能，请在 ExecuteStatement、BatchExecuteStatement、DescribeStatement、GetStatementResult 或 GetStatementResultV2 中指定 WaitTimeSeconds 参数。 ListSessions：在多个查询中重复使用会话的应用程序现在可以枚举活动会话，并按状态、计算目标或数据库进行筛选，从而无需在外部跟踪会话标识符。 灵活的批处理执行：BatchExecuteStatement 现在支持具有 AUTO_COMMIT 模式的 ExecutionMode 参数，从而允许批处理中的每个 SQL 语句独立执行，因此单次失败不再导致整个批处理回滚。这对于接受部分完成的 ETL 管道和管理脚本非常有用。此外，BatchExecuteStatement 现在支持接受 SqlParameter 数组，从而可跨批处理中的所有语句重复使用参数：只需定义一次参数即可在任何语句中引用，从而无需在每个查询中嵌入文本值。 这些功能已在支持 Amazon Redshift 数据 API 的所有 AWS 商业区域和 AWS GovCloud（美国）区域中，面向 Amazon Redshift Provisioned 和 Amazon Redshift Serverless 正式发布。要开始使用，请访问 Amazon Redshift Data API 开发人员指南 。
