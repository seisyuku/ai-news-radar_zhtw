來源摘要（原文）
Amazon Relational Database Service（Amazon RDS）for SQL Server 现在支持 Microsoft SQL Server 的最新累积更新（CU）和通用发行版（GDR）更新。此次发布包含对以下版本的支持：Microsoft SQL Server 2017 CU31+GDR KB5122774 （RDS 版本 14.00.3550.4.v1）、SQL Server 2019 CU32+GDR KB5122772 （RDS 版本 15.00.4490.9.v1）、SQL Server 2022 CU27 KB5104824 （RDS 版本 16.00.4295.3.v1）和 SQL Server 2025 CU9 KB5122048 （RDS 版本 17.00.5005.3.v1）。 有关这些更新中包含的改进和修复的更多信息，请参阅 Microsoft 关于 KB5122774、KB5122772、KB5104824 和 KB5122048 的文档。我们建议您使用 Amazon RDS 管理控制台、AWS SDK 或 CLI 升级 Amazon RDS for SQL Server 实例以应用这些更新。您可以参阅 Amazon RDS SQL Server 用户指南中关于升级 RDS Microsoft SQL Server 数据库引擎的部分 ，详细了解如何升级数据库实例。
