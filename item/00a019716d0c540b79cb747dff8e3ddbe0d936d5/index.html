Amazon Neptune 现在支持在线索引重建以回收存储空间
收錄來源
AWS News
發布時間（來源提供）
2026-10-27T08:00:00Z
來源摘要（原文）
Amazon Neptune 数据库现在支持在线索引重建，这是一项新功能，可帮助数据库管理员和应用程序团队对 Neptune 索引进行碎片整理，并在不使数据库离线的情况下回收未使用的存储空间。随着时间的推移，插入、更新和删除操作会在数据页中产生未使用的空间空隙，导致即使在数据被删除后， VolumeBytesUsed 指标仍会人为地保持在较高水平。这种碎片化会增加 I/O 成本，并降低大规模运行 Gremlin、openCypher 或 SPARQL 工作负载的团队的查询性能。 通过在线索引重建，写入器实例和只读副本上的读写查询在整个重建过程中均可不受影响地继续进行。您可以将所有索引、仅四元索引或仅字典索引作为目标，因此该功能非常适合用于删除后清理、定期维护、存储限制管理以及对严重碎片化的数据库进行性能调优。可调的并发和写入缓冲区大小设置，可让您在重建速度与对工作负载的影响之间取得平衡，而内置的存储安全机制则可防止操作过程中出现存储空间耗尽的情况。 从 Amazon Neptune 引擎版本 1.5.0.0 开始，在所有支持 Amazon Neptune 数据库的区域中，已配置的写入器实例均可使用在线索引重建功能。要了解有关配置和运行在线索引重建功能的更多信息，包括 API 参考和调优指南，请访问 Amazon Neptune 文档 。
