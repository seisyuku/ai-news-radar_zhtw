AWS Backup 现已在 AWS European Sovereign Cloud 中支持跨账户管理和跨账户备份

來源摘要（原文）
AWS Backup 现已在 AWS European Sovereign Cloud（德国）区域中支持跨账户管理、跨账户备份以及委托管理员功能。借助这些功能，您可以利用 AWS Organizations 在组织内跨各个账户集中管理、监控和复制备份。 借助跨账户管理功能，您可以使用 AWS Organizations 管理账户或委托管理员账户部署组织范围内的备份策略。您还可以从一个位置监控组织内所有账户的备份、复制和还原任务。借助跨账户备份功能，您可以将恢复点复制到组织内另一个账户的备份保管库中，从而为源账户提供针对意外或恶意删除的额外保护。此外，您还可以将成员账户注册为委托管理员，这样您的团队无需访问管理账户，即可管理整个组织范围内的备份。 使用这些功能无需额外付费；适用标准 AWS Backup 定价。了解更多信息，请参阅 AWS Backup 文档： https://docs.aws.amazon.com/aws-backup/ 。要开始使用，请访问 AWS Backup 控制台： https://console.aws.amazon.com/backup 。
