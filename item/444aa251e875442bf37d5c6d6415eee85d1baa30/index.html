Title
AWS Continuum 现已支持凭证测试和可访问域名建议
Source
AWS News
Published
2026-09-18T18:34:00Z
Summary
用于渗透测试的 AWS Continuum 是一款前沿智能体，可通过按需、定制化的渗透测试及真实可利用性测试，在整个开发生命周期中主动保护应用程序。开发人员和安全团队现在可以在渗透测试开始前测试登录凭证并获取建议域名。这让用户从一开始就更容易配置准确的网络范围，减少配置错误和无效测试周期。 以前，识别应用程序访问的所有 URL 需要手动操作，而身份验证失败问题只能在完整测试周期结束后才会发现，这会消耗时间和资源。此次发布后，当您在测试配置期间添加登录凭证时，AWS Continuum 会像真实用户一样登录应用程序，捕获登录过程中访问的每个可访问域名，并将其作为范围内 URL 建议列出。您可以在正式测试开始前查看可访问域名、验证凭证，并确认智能体覆盖了正确的端点。无论凭证测试成功、失败还是超时，都会返回可访问域名。您可以在我们更新后的 文档 中了解有关此功能的更多信息。 此功能现在所有支持 AWS Continuum 渗透测试的区域推出，详情请参见 AWS Continuum 产品页面 。
