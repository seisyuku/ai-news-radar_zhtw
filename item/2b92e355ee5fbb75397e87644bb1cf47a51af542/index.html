宣布推出 Blockchain Snapshots on AWS 进行节点引导启动

來源摘要（原文）
对于运行 Ethereum 或 Solana 的区块链节点运营商，AWS 宣布推出 Blockchain Snapshots on AWS，该计划在 Amazon Simple Storage Service（Amazon S3） 中发布预先同步的公共区块链节点链数据，这样您就可以从快照引导启动节点，而不是从网络进行点对点同步。这些快照托管在 AWS 基础设施内的 Amazon S3 上，使在 AWS 上运行节点的客户能够受益于更低的延迟和更优化的数据传输。Blockchain Snapshots on AWS 会以针对多核并行提取进行了优化的格式，重新发布每个网络的权威快照，从而缩短设置时间，这些快照可供 Amazon Elastic Compute Cloud（Amazon EC2） 实例使用。 快照涵盖 Ethereum 和 Solana，可免费使用，且更新频率与上游提供商保持一致。使用它们为远程过程调用（RPC）实例集添加容量、恢复故障节点或重新同步损坏的数据库。 您可以在以下 AWS 区域使用 Blockchain Snapshots on AWS：美国东部（弗吉尼亚州北部）、欧洲地区（爱尔兰）和亚太地区（东京）。访问需要一个位于同一区域且具有 Amazon S3 网关 VPC 端点的 Amazon EC2 实例。 要开始使用，请访问 Blockchain Snapshots on AWS 文档 ，浏览设置说明并下载最新的快照。
