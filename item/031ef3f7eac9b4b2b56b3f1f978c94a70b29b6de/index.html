Title
Amazon Quick 现已在 AWS 新加坡区域推出
Source
AWS News
Published
2026-10-22T07:00:00Z
Summary
Amazon Quick 现已在 AWS 亚太地区（新加坡）区域（ap-southeast-1）推出。此次发布后，新加坡的客户能够使用 Amazon Quick 的全部功能，同时满足当地对数据主权的要求。 Amazon Quick 为业务用户提供了一位“代理型协作伙伴”，它能快速回答工作中的问题，并将这些回答转化为行动。借助 Amazon Quick，每位用户都能利用值得信赖的 AI 做出更明智、更快速的决策，且无需切换应用程序即可执行操作。自今日起，客户即可利用 Amazon Quick 的各项功能，包括 AI 驱动的聊天、研究、空间以及 QuickSight 控制面板，所有数据均在 AWS 新加坡区域内进行本地存储和处理。 有关已推出 Amazon Quick 的 AWS 区域的完整列表，请访问 区域可用性速览页面 。 要了解更多信息，请访问 Amazon Quick 文档 或 产品详细信息页面 。
