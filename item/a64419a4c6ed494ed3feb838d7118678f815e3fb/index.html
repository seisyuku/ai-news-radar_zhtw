Amazon SageMaker 融通式合作开发工作室现在支持针对称号的自定义布局
收錄來源
AWS News
發布時間（來源提供）
2026-11-13T08:00:00Z
來源摘要（原文）
Amazon SageMaker 融通式合作开发工作室现在支持布局自定义，这项新功能让域管理员可以根据项目成员的称号控制其可见的工具和左侧导航项。在单个平台上拥有数据工程、分析和机器学习团队的组织可以在每个称号定义中配置布局，该布局会应用于域中的所有项目，无需逐个项目地配置。 以前，所有项目成员无论角色如何都会看到相同的界面，这会造成混淆和潜在的治理问题。利用布局自定义，管理员可以将布局定义为某个称号的一部分，该称号规定了分配给该称号的项目成员可以看到的左侧导航项。当项目成员打开项目时，SageMaker 融通式合作开发工作室会解析该成员的称号，并仅显示其称号的布局中包含的工具。例如，可以将 SQL 分析师称号配置为仅显示查询编辑器，而机器学习工程师称号则显示笔记本、训练作业和模型端点。导航项可跨多个类别进行配置，包括数据分析、人工智能与机器学习（AI/ML）、生成式人工智能和 IDE。如果项目成员直接导航到隐藏页面，则会看到“访问被拒绝”页面。对于拥有多个称号的成员，可见工具是其所有称号布局的结合。对于具有已配置布局的称号，SageMaker 融通式合作开发工作室中新增的导航项在管理员添加它们之前处于隐藏状态。 该功能已在提供 Amazon SageMaker 融通式合作开发工作室的所有 AWS 区域 推出。要了解更多信息，请访问 Designations 文档。
