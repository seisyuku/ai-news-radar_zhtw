AWS Marketplace 现支持合作伙伴“一次发布，多子公司账户销售”
收錄來源

發布時間（來源提供）

來源摘要（原文）
今日，AWS 宣布，运营多个法律实体的 AWS 合作伙伴只需在其主账户中发布一次产品，即可让其当地子公司通过直接私下报价进行销售，从而无需在每个账户中重复创建和维护产品列表。 合作伙伴可通过主账户（该账户保留产品列表的所有权）授权各子公司可销售哪些产品，以及可向哪些买家国家/地区发出私下报价。各子公司均以其自身的本地税务身份进行交易，选择支持的本地货币，并设置自己的款项结算偏好和银行账户。主账户中的 AWS Marketplace 洞察报告可提供所有关联子公司账户中的报价、协议和续订情况的汇总视图。合作伙伴可随时撤销子公司账户的授权或断开子公司账户的连接，此操作将立即阻止相关子公司账户创建新报价，已向买家发出的协议和报价保持不变。 此功能即日起在所有提供 AWS Marketplace 的 AWS 区域内推出，无需额外付费。如需开始使用，请参阅 管理子公司账户连接 和 以子公司账户身份创建私有报价 。
