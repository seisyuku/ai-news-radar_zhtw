Amazon DynamoDB Accelerator（DAX）现已在更多区域推出
收錄來源

發布時間（來源提供）

來源摘要（原文）
Amazon DynamoDB Accelerator（DAX）现已在另外两个 AWS 区域推出：加拿大（中部）和非洲（开普敦）。DAX 是适用于 Amazon DynamoDB 的完全托管且高度可用的内存缓存，可实现高达 10 倍的性能提升（从个位数毫秒缩短到微秒），即使在每秒处理的请求数量达到数百万个的情况下也是如此。 借助 DAX，您可以加速读取密集型和突发性工作负载（例如实时竞价、游戏排行榜和零售商品目录），同时将读取流量从 DynamoDB 表中分流出去。DAX 与 DynamoDB 的 API 兼容，因此您只需对代码进行最少的更改即可为应用程序添加微秒级延迟缓存。客户现在可以在该区域内保留缓存数据，并满足低延迟要求，同时还能受益于完全托管式服务，包括自动补丁更新和失效转移。 要了解更多信息，请参阅 Amazon DynamoDB Accelerator 页面 。有关 DAX 可用区域的完整列表，请参阅 AWS 区域性服务页面 。
