Amazon ElastiCache 无服务器的公有端点现已在 AWS GovCloud（美国）推出
收錄來源

發布時間（來源提供）
2026-10-28T19:00:00Z
來源摘要（原文）
适用于 Valkey 的 Amazon ElastiCache 无服务器现已在 AWS GovCloud（美国）区域支持公有端点。通过公有端点，您可以从无服务器函数或运行在 VPC 外部的任何应用程序连接到缓存，而无需设置 VPN、堡垒主机或 SSH 隧道。 借助公有端点，ElastiCache 无服务器为您提供了一个完全托管式缓存，无需配置 VPC，也无需部署基础设施，且创建过程不到一分钟。每个连接均通过 TLS 1.3 使用 IAM 身份验证，因此无需存储或轮换密码。您可以使用内置 IAM 支持的 Valkey GLIDE 2.2 或更高版本进行连接，也可以使用其他 Valkey 客户端配合 Developer Toolkit for ElastiCache，这是一个开源库，可为您生成并刷新 IAM 认证令牌。 此次扩展后，ElastiCache Serverless 的公有端点现已在所有商业 AWS 区域、AWS GovCloud（美国）区域以及中国区域提供。使用公有端点只需支付标准 ElastiCache 无服务器定价，没有任何额外费用。 要开始使用，请使用 AWS 管理控制台、AWS SDK 或 AWS CLI 创建一个带公有端点的 Valkey 9.0 或更高版本的无服务器缓存。要了解有关公有端点的更多信息，请参阅 创建带公有端点的 Valkey 无服务器缓存 。
