Amazon S3 服务器访问日志向 Amazon CloudWatch Logs 的传输功能现已在另外五个 AWS 区域推出
收錄來源

來源摘要（原文）
Amazon S3 服务器访问日志向 Amazon CloudWatch Logs 的传输功能现已在 AWS GovCloud（美国）区域、AWS European Sovereign Cloud 和 AWS 中国区域推出。访问日志存放在 CloudWatch Logs 中，您可以在访问日志到达时对其进行查询、设置警报以及使用 AWS Key Management Service（AWS KMS）密钥对其进行加密。这个新的传输路径补充了支持向 S3 通用存储桶传输服务器访问日志的现有功能，为您监控和分析数据访问提供了更大的灵活性。 通过传输到 CloudWatch Logs，您可以设置错误率警报、监控流量模式、调查访问事件，并将 S3 访问活动与其他操作数据进行关联分析。 S3 服务器访问日志向 CloudWatch Logs 的传输功能现已在所有 AWS 区域推出。Amazon CloudWatch Logs 将针对公开日志收费。有关定价详情，请访问 Amazon CloudWatch 定价 。要了解更多信息，请访问 Amazon S3 用户指南 。
