Title
Amazon Keyspaces（Apache Cassandra 兼容）现已在加拿大西部（卡尔加里）区域（ca-west-1）推出
Source
AWS News
Published
2026-08-05T20:06:00Z
Summary
Amazon Keyspaces（Apache Cassandra 兼容） 现已在加拿大西部（卡尔加里）区域（ca-west-1）推出，使加拿大西部区域的客户能够构建与 Cassandra 兼容的应用程序，在降低延迟的同时，确保数据留存于本地区域，满足数据驻留要求。 Amazon Keyspaces（Apache Cassandra 兼容）是一种可扩展、高度可用、托管的 Apache Cassandra 兼容数据库服务。Amazon Keyspaces 是无服务器的，因此您只需为所使用的资源付费，即可构建每秒可处理数千个请求的应用程序，且吞吐量和存储空间几乎不受限制。 这种区域扩展使加拿大的企业能够使用熟悉的 Cassandra 查询语言（CQL）构建高度可扩展、低延迟的应用程序，而无需承受管理 Cassandra 集群的运营负担。 要了解有关 Keyspaces 的更多信息，请访问 Amazon Keyspaces 文档 。
