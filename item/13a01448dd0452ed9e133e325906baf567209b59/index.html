Title
Amazon GameLift Streams 现提供服务托管式着色器缓存
Source
AWS News
Published
2026-08-10T21:15:00Z
Summary
Amazon GameLift Streams 现在可以为您的应用程序管理着色器缓存的捕获和分发。您只需从流会话中捕获着色器缓存，该服务便会自动将其提供给您所有流媒体位置的未来会话使用，无需更改应用程序。 捕获着色器缓存有助于在会话期间缩短加载时间并减少画面卡顿。借助服务托管式着色器缓存功能，您可以指定一个流会话进行捕获，并运行应用程序来生成缓存。随后，Amazon GameLift Streams 会将该缓存复制到兼容的流组和位置，并在未来的会话中自动加载该缓存。 您可以通过 ListApplicationShaderCaches API 或 Amazon GameLift Streams 控制台监控着色器缓存状态和存储大小。该功能支持 Linux（Ubuntu 22.04）、Proton 和 Windows Server 2022 运行时。 您需要为每个着色器缓存的最新版本的存储付费。有关定价详情，请访问 Amazon GameLift Streams 定价页面 。要查看受支持的区域，请参阅 AWS 区域表 。
