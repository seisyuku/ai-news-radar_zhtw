AWS Glue 新增 100 款面向主流 SaaS 应用程序的原生连接器

來源摘要（原文）
AWS Glue 现已支持 100 款新的原生连接器，可简化对主流 SaaS 应用程序和基于 REST API 的应用程序中数据的访问。以前，需要编写自定义代码才能将数据从 SaaS 应用程序导入 AWS。现在，团队可以在 AWS Glue Data Catalog 中一次创建一个连接，并跨 ETL 作业重复使用该连接，同时采用他们已用于 AWS Glue 的相同权限模型。 这些新增的连接器涵盖生成式人工智能、金融、支付、市场营销、产品分析、人力资源、工程、IT 运维和协作工具。人工智能团队可以从 Anthropic 等模型提供商处获取使用情况和成本数据，以跟踪生成式人工智能的采用和支出情况。财务团队可以整合来自 Adyen、Square 和 Xero 等应用程序的交易数据，以更快地生成报告。产品和市场营销团队可以整合来自 Chargebee、Amplitude 和 Klaviyo 等工具的账单、使用情况和活动数据，以深入了解客户生命周期价值。人力资源团队可以整合来自 BambooHR 和 Gusto 等系统的员工数据，以规划人员编制。工程团队可以整合来自 PagerDuty、Sentry、Jenkins 和 Vercel 等工具的事件和部署数据，以跟踪可靠性。您可以将集成数据加载到 Amazon S3 或 Amazon Redshift 中，以分析数据并生成报告。 这 100 款新增的 AWS Glue 连接器已在所有 AWS 商业区域提供，适用于 Glue 版本 5.0 及更高版本。 要了解更多信息，请参阅 可用连接器的完整列表 ，以及 AWS Glue 文档中的 连接到各个连接器 。
