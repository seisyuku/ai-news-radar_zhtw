Title
Amazon GameLift Servers 现支持 21 种新的 EC2 实例类型
Source
AWS News
Published
2026-08-07T08:00:00Z
Summary
Amazon GameLift Servers 现已在托管 EC2 实例集和托管容器实例集中支持 21 种新增 Amazon EC2 实例类型。Amazon GameLift Servers 是一项完全托管的服务，可帮助游戏开发者和工作室在云中部署、运营和扩展专用游戏服务器。此次扩展使客户能够使用最新的计算优化型和通用型实例系列。 新支持的实例类型涵盖两个系列中的六个实例系列：计算优化型 C 系列（C8a、C8i、C9g）和通用型 M 系列（M8a、M8i、M9g）。客户现在可以在 x86 和 Arm 架构之间进行选择，选用第 5 代 AMD EPYC、定制版 Intel Xeon 6 或 AWS Graviton5 处理器，以针对性能、成本和引擎兼容性优化游戏服务器工作负载。使用案例包括在 C 系列实例上运行 CPU 密集型多人游戏服务器逻辑，以及使用基于 Graviton5 的 M9g 实例以经济高效的方式扩展通用型实例集。 这些实例类型现已在支持 Amazon GameLift Servers 的区域（AWS 中国除外）推出。有关使用这些 EC2 实例启动实例集的更多信息，请访问 Amazon GameLift Servers 文档 。
