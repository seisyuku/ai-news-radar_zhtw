Title
Amazon Redshift RG large 和 12xlarge 实例现已在跟踪轨道上推出
Source
AWS News
Published
2026-07-30T20:02:00Z
Summary
Amazon Redshift 现已支持在 跟踪轨道 上运行基于 Graviton 的 RG 实例。 即日起，rg.large 和 rg.12xlarge 实例类型可供在跟踪轨道（补丁 P202 及更高版本）上运行工作负载的客户使用。 跟踪轨道专为将生产工作负载稳定性置于首位的客户设计，并基于已通过领先轨道验证的版本运行。RG 实例现已支持在两条轨道上使用，客户可以获得 AWS Graviton 带来的性能提升，相较于 RA3 实例，查询性能最高提升 2.4 倍，每 vCPU 价格降低 30%。 使用跟踪维护轨道（补丁 P202 及更高版本）的客户，现在可以在全面推出 RG 的所有 AWS 区域创建 Amazon Redshift RG 集群。要开始使用，客户可以通过 AWS 管理控制台、AWS CLI 或 AWS SDK，预置新集群或将现有集群调整为 rg.large 或 rg.12xlarge 实例类型。有关更多信息，请参阅 Amazon Redshift 集群版本 。
