Title
Amazon EC2 C7i 实例现已在更多区域推出
Source
AWS News
Published
2026-07-31T00:17:00Z
Summary
即日起，由定制的第四代英特尔至强可扩展处理器（代号为 Sapphire Rapids）提供支持的 Amazon Elastic Compute Cloud（Amazon EC2）C7i 实例将在欧洲地区（米兰）和加拿大西部（卡尔加里）区域推出。这些定制处理器仅在 AWS 上可用，与其他云提供商使用的基于 x86 的同类英特尔处理器相比，性能提高多达 15%。 与 C6i 实例相比，C7i 实例的性价比提升了高达 15%，是所有计算密集型工作负载的最佳选择，例如批处理、分布式分析、广告投放以及视频编码。C7i 实例提供更大的实例大小（最大可达 48xlarge）以及两种裸机大小（metal-24xl、metal-48xl）。这些裸机大小支持内置的英特尔加速器：数据流加速器、内存分析加速器和 QuickAssist 技术，可用于促进高效卸载和加快数据操作，并优化工作负载的性能。要了解更多信息，请访问 EC2 C7i 实例页面 。
