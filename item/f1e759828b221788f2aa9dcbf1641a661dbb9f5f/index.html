新聞標題（原文）
Amazon CloudFront 现在支持通过自助方式提高 AWS 服务配额
收錄來源
AWS News
發布時間（來源提供）
2026-11-02T08:00:00Z
來源摘要（原文）
Amazon CloudFront 现在支持 AWS 服务配额，因此您可以通过服务配额控制台或 API 查看、监控 28 项 CloudFront 配额，并申请提高配额。 此前，若要提高分发、缓存策略、源服务器或备用域名等资源的配额，必须提交支持案例并等待人工审核。如果您拥有 AWS Business Support 或更高版本，那么在已公布的阈值范围内提出的配额提高请求现将自动获批。例如，您可以将分发配额从 500 提高到 1000，或将每个分发的备用域名数量从 100 增加到 500，而无需提交支持案例。某些配额还会每 5 分钟向 Amazon CloudWatch 发布使用情况指标，因此您可以在达到限制之前设置警报并申请提高配额。 此功能已在支持 Amazon CloudFront 的所有 AWS 区域推出。 要开始使用，请访问 服务配额控制台 ，查看并申请提高 CloudFront 配额。要了解更多信息，请参阅 Amazon CloudFront 开发人员指南中的 Amazon CloudFront 配额 。
