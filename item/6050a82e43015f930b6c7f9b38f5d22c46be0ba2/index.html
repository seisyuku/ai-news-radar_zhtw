推出下一代 Amazon OpenSearch 无服务器的时间序列集合

來源摘要（原文）
今天，我们宣布支持下一代 Amazon OpenSearch 无服务器上的时间序列集合。借助时间序列集合，您无需预置或管理集群即可摄取、存储和分析日志、指标、跟踪记录和事件数据。它们能够自动吸收数据摄取峰值，确保近期数据可快速查询，并以较低的成本实现对数月或数年历史数据的检索，所有这些均集成在同一个集合之中。 除了现有的热存储层外，时间序列集合还增加了一个新的、成本较低的暖存储层，因此客户无需支付热存储价格即可保留不经常访问的数据。客户可以自行决定数据在转入暖存储之前保持“热”状态的时间长度。 每个集合最多可提供 100 TB 的热存储空间，因此时间序列集合能够处理大容量的可观测性工作负载，例如应用程序监控、安全分析和 IoT 遥测。现在还提供警报和异常检测功能，因此客户无需使用单独的工具，即可收到问题通知，并发现日志和事件数据中的异常模式。 时间序列集合现已在所有提供 OpenSearch 无服务器的 AWS 区域 中推出。要详细了解新的暖存储的定价，请参阅 OpenSearch 无服务器定价 。要了解有关 Amazon OpenSearch 无服务器上的时间序列集合的更多信息，请参阅 OpenSearch 无服务器功能页面 、 发布博客 和 AWS 文档 。
