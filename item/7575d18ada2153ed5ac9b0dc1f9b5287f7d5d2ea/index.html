來源摘要（原文）
今天，AWS 宣布 AWS 互连 – 最后一英里在美国弗吉尼亚州北部新增一个都会区。弗吉尼亚州北部成为继纽约之后第二个可以将您的数据中心、分支机构或主机托管设施连接到 AWS 的都会区。 AWS 互连 – 最后一英里为您提供了与 AWS 的托管私有弹性连接，使您无需订购交叉连接或配置路由器。默认情况下，每个连接都跨两个物理隔离的位置进行预置且配备四条冗余链路，开箱即提供最大韧性，且直连 Direct Connect 端口享有 99.99% 可用性 SLA 保障。默认情况下，AWS 和合作伙伴边缘设备之间的流量使用 MACsec 进行加密。 美国本土任何地方的 Lumen 客户都可以通过弗吉尼亚州北部都会区订购正式推出的连接，以访问所有公共 AWS 区域（中国区域除外）和 AWS Local Zones。AWS 互连 – 最后一英里还可在弗吉尼亚州北部都会区通过 Megaport 和 Equinix 以预览版形式提供。您可以使用 AWS 管理控制台、AWS CLI 或 AWS 互连 API 创建连接。有关定价，请参阅 AWS 互连 – 最后一英里定价 。
