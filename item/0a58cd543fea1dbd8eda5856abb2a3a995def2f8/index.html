Title
AWS Cost Explorer 成本管理服务、Budgets 和控制面板现已支持 Amazon Bedrock 产品属性
Source
AWS News
Published
2026-10-08T18:51:00Z
Summary
通过 AWS Cost Explorer 成本管理服务、AWS Budgets 和 AWS 成本管理控制面板，您现在可以按产品属性分析 Amazon Bedrock 成本。这是一项新维度，可根据模型、模型提供商、推理类型和功能细分 Bedrock 成本。在 Cost Explorer 成本管理服务和控制面板中，您可以按这些属性对成本进行分组和筛选。在 Budgets 中，您可以按相同的属性筛选预算。 通过此次发布，财务与平台团队能够直接查看哪些模型与工作负载产生了 Bedrock 费用，并利用现有的账单管理工具采取相应措施。这些属性包括模型（例如 Claude Sonnet 5 或 Claude Haiku 4.5）、模型提供商（例如 Anthropic 或 Cohere）、推理类型（例如输入 Token 或输出 Token）以及功能（例如按需推理或重排序器）。您可以将产品属性与应用程序推理配置文件、项目或工作区上的成本分配标签结合使用，了解各应用程序在每个模型上的支出；也可以与 IAM 主体标签结合使用，追溯产生费用的具体用户或角色。在 Cost Explorer 成本管理服务中按模型对一个月内的 Bedrock 支出进行分组，以找出成本最高的模型；构建一个用于跟踪各提供商成本的控制面板小部件；或者设置预算提醒，在单个模型的支出超出预算时向您发送提醒。 Amazon Bedrock 产品属性维度现已在所有 AWS 区域推出，但 AWS GovCloud（美国）区域以及中国（北京）和中国（宁夏）区域除外，不收取额外费用。要了解更多信息，请参阅 Cost Explorer 成本管理服务 、 Budgets 和 控制面板 的用户指南。
