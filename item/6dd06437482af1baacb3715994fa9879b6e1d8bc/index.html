Title
Amazon RDS for SQL Server 现支持在多可用区实例上还原启用了 TDE 的数据库
Source
AWS News
Published
2026-07-27T07:00:00Z
Summary
Amazon Relational Database Service（Amazon RDS）for SQL Server 现在支持使用原生备份和还原功能，在多可用区实例以及同区域内配置了只读副本的实例上还原启用了透明数据加密（TDE）的 SQL Server 数据库。此前，还原启用了 TDE 的数据库仅适用于单可用区实例，您需要先禁用 TDE 或迁移至单可用区配置，然后才能还原加密数据库。 现在，您可以直接将启用了 TDE 的数据库备份还原到 Amazon RDS for SQL Server 的多可用区实例以及同区域内配置了只读副本的实例上。您需要先备份现有的 TDE 证书，将其存储在 Amazon S3 中，然后在启用 TDE 选项的情况下将其还原到 Amazon RDS 实例。 然后使用 Amazon RDS 原生备份和还原功能，从 Amazon S3 还原启用了 TDE 的数据库备份。当您同时需要 TDE 提供的静态加密以及多可用区部署的高可用性时，这一功能将简化您的迁移和恢复工作流程。 此功能现已在所有支持 Amazon RDS for SQL Server 的 AWS 区域推出。要了解更多信息，请参阅 Amazon RDS for SQL Server 用户指南 。
