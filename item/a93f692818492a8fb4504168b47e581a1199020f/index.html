Amazon Managed Grafana 现支持就地升级到 Grafana 版本 13.2
收錄來源
AWS News
發布時間（來源提供）

來源摘要（原文）
Amazon Managed Grafana 现在支持从 Grafana 版本 12.4 就地升级到 13.2。升级至 13.2 版本后，您将获得开源 Grafana 13.0 至 13.2 版本中的各项功能，包括控制面板的 Git 同步、动态控制面板，以及 Amazon CloudWatch 数据来源插件对 PromQL 查询的支持。 借助 Git Sync，您可以通过将工作区与 Git 存储库关联，将控制面板视为代码。您可以通过版本控制对控制面板的修改进行跟踪、审查和回滚。动态控制面板为布局和面板设计提供了一种更具适应性的方法。您可以构建响应式视图，这些视图由条件驱动，能够根据范围内的数据和变量做出响应。借助 Amazon CloudWatch 数据来源插件对 Prometheus 查询语言（PromQL）的支持，除了现有的“指标搜索”和“指标洞察”查询类型外，您还可以使用 PromQL 查询 CloudWatch 通过其 OpenTelemetry（OTLP）端点接收的指标。 已全面推出 Amazon Managed Grafana 的所有 AWS 区域 都支持就地升级到 Grafana 13.2。您只需在 AWS 管理控制台中单击几下或通过 AWS SDK 或 AWS CLI 即可升级。有关新功能的完整列表，请参阅《Amazon Managed Grafana 用户指南》中的 Grafana 各版本之间的区别 。有关升级说明，请参阅 更新您的工作区版本 。要了解有关 Amazon Managed Grafana 功能及其定价的更多信息，请访问 产品页面 和 定价页面 。
