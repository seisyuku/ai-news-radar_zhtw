來源摘要（原文）
Amazon DocumentDB（兼容 MongoDB）现已在亚太地区（台北）和亚太地区（新西兰）区域推出，进一步扩充了可使用 Amazon DocumentDB 的 可用区域 列表。 Amazon DocumentDB 是一个完全托管的原生 JSON 数据库，有助于轻松且经济高效地运行几乎任何规模的关键文档工作负载，并且无需管理基础设施。Amazon DocumentDB 旨在提供运行任务关键型 MongoDB 工作负载所需的可扩展性和持久性。此外，Amazon DocumentDB 原生集成了 Amazon CloudWatch、AWS CloudTrail、AWS Lambda 和 AWS Backup 等服务。Amazon DocumentDB 支持每秒处理数百万个请求，并且可在几分钟内横向扩展到 15 个低延迟只读副本，而不会导致应用程序停机。 要了解有关 Amazon DocumentDB 的更多信息，请访问 Amazon DocumentDB 产品页面 和 定价页面 。您可以通过 AWS 管理控制台 、 AWS 命令行界面（CLI） 或 AWS SDK 创建 Amazon DocumentDB 集群。
