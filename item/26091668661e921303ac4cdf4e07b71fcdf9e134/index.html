Amazon RDS for Oracle 和 Amazon RDS for SQL Server 现支持在额外存储卷上进行存储自动扩展
收錄來源
AWS News
發布時間（來源提供）
2026-10-29T18:06:00Z
來源摘要（原文）
Amazon RDS for SQL Server 和 Amazon RDS for Oracle 现已支持在 附加存储卷 上启用 RDS 存储自动扩展。RDS 存储自动扩展会自动扩展存储容量，以响应不断增加的数据库工作负载，且不会造成任何停机。 通过附加存储卷功能，您可以添加最多三个卷，将存储容量扩展至 256TiB。此前，您必须根据预期的应用程序容量需求在附加存储卷手动预置存储容量，但可以在主存储卷上启用自动扩展功能。配置不足可能会导致应用程序停机，而过量配置则可能导致资源利用率过低和成本增加。借助 RDS 存储自动扩展功能，您只需为每个附加存储卷设置所需的最大存储限制，其余工作将由自动扩展功能自动处理。 RDS 存储自动扩展功能会持续监控实际的存储消耗，在实际利用率接近预置的存储容量时自动扩展容量。自动扩展功能适用于新的和现有的数据库实例。自动扩展功能柜不会产生额外费用，您只需为预置的存储资源付费。您可以通过 AWS 管理控制台、AWS CLI 或 Amazon RDS API 启用此功能。 适用于附加存储卷的 RDS 存储自动扩展功能现已在所有 AWS 商业区域以及 AWS GovCloud（美国）区域中的 Amazon RDS for SQL Server 和 Amazon RDS for Oracle 上推出。要了解更多信息，请访问 Amazon RDS 存储自动扩展 文档。
