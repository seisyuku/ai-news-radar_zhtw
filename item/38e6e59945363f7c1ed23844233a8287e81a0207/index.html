來源摘要（原文）
一款新的模型现已在 AWS GovCloud（美国）区域的 Kiro IDE 和 CLI 中推出。 Grok 4.7 是 SpaceXSI 面向编码和知识工作推出的能力最强的模型。它专为持续数小时的艰巨任务而设计，能够始终保持专注，并在继续下一步前检查自己的工作。与 Grok 4.6 相比，它在存储库规模编码工作中的规划和错误恢复能力更加可靠。Grok 4.7 提供了实验性支持和 500K 上下文窗口。不超过 20 万 Token 的请求按 2.7 倍积分系数计费，超过 20 万 Token 的请求按 5.4 倍计费。 Kiro 管理员可控制向用户开放哪些模型，使组织能够根据内部策略管理模型访问权限。 确保您的 IDE 或 CLI 已更新到最新版本，然后重新启动它以从模型选择器访问新模型。如需了解更多详情，请访问 GovCloud 文档 、 监控和跟踪指南 ，或联系您的 AWS 账户团队。要了解有关 Kiro 的更多信息，请参阅 Kiro 产品页面 。
