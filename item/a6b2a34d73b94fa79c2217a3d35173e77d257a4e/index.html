Amazon MWAA 无服务器支持 Apache Airflow 连接和变量
收錄來源
AWS News
發布時間（來源提供）
2026-11-06T18:00:00Z
來源摘要（原文）
Amazon Managed Workflows for Apache Airflow（Amazon MWAA）无服务器现已支持 Apache Airflow 连接和变量，可让您的工作流访问数据库、API 和其他外部系统。您可以在工作流代码之外管理凭证和配置。 您可以将敏感连接和变量存储在选定的密钥后端（例如 AWS Secrets Manager、AWS Systems Manager Parameter Store 或您自己的自定义后端），在工作流中对其进行配置，并向工作流执行角色授予访问权限。任务会在运行时通过标准 Apache Airflow 方法检索这些项目。您可以将非密钥值定义为工作流中的环境变量。 此功能已在提供 Amazon MWAA 无服务器的所有 AWS 区域推出。有关更多信息，请参阅 Amazon MWAA 无服务器区域 。 要了解更多信息，请参阅《Amazon MWAA 无服务器用户指南》中的 管理连接和变量 和 在 Amazon MWAA 无服务器工作流中使用环境变量 。
