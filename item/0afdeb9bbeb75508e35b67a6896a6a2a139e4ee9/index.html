Title
Amazon EKS 现已在 Amazon EKS 自动模式和 Karpenter 中支持 EFA 和置放群组
Source
AWS News
Published
2026-07-22T14:30:00Z
Summary
Amazon Elastic Kubernetes Service（EKS）现已支持在 EKS 自动模式和开源 Karpenter 项目中为节点池配置 Amazon EC2 置放群组和 Elastic Fabric Adapter（EFA）网络设备，使您能够优化 EKS 工作负载以实现高性能和可用性。利用这些功能，您可以管理 EFA 网络接口配置，并控制 EC2 实例在 AWS 基础设施上的物理分布方式，从而满足分布式训练与推理工作负载的需求。 借助 EKS 自动模式和 Karpenter 的 EFA 配置，您可以在支持 EFA 的实例上，针对动态和静态容量节点池，将网络接口指定为仅 EFA 或标准 ENI 模式。仅 EFA 接口不占用 IP 地址，使您能够精细控制 VPC 中的 IP 利用率，并获得完整互连带宽。有了置放群组支持，您可以直接从 EKS 自动模式或 Karpenter 节点池配置中，使用集群、分散或分区策略启动 EC2 实例，无需额外的运营解决方法即可控制实例的物理分布方式。总而言之，通过这些功能，您可以根据工作负载所需的性能、可用性和故障隔离特性进行优化，为分布式训练作业实现最大吞吐量，或者为关键生产服务实现最小爆炸半径。 这些功能已在提供 Amazon EKS 的所有 AWS 区域推出。要开始使用并了解更多信息，请参阅 EKS 自动模式用户指南 和 Karpenter 文档 。
