新聞標題（原文）
ACM 现支持通过 ACME 在 AWS GovCloud（美国）签发公有证书
收錄來源
AWS News
發布時間（來源提供）
2026-10-29T08:00:00Z
來源摘要（原文）
AWS Certificate Manager（ACM）现已在 AWS GovCloud（美国东部）和 AWS GovCloud（美国西部）中支持 ACME 协议，提供了一个完全托管的 ACME 服务器端点，该端点使用任何与 ACMEv2 兼容的客户端（包括 Certbot、cert-manager for Kubernetes 以及 acme.sh）通过 Amazon Trust Services 签发公有 TLS 证书。随着 CA/Browser Forum 规定在 2029 年之前公有证书有效期仅为 47 天，手动管理此类证书将不再可行。ACM 对 ACME 的支持为开发人员提供了一条基于标准的路径，以实现证书颁发与续订的完全自动化。 要了解更多信息，请访问 AWS 新闻博客文章 、 ACM ACME 文档 、 ACM 定价页面 以及 AWS 区域性服务页面 。
