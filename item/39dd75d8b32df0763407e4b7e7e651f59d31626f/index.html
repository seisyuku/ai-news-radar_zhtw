Amazon RDS for Oracle 现已在更多 AWS 区域支持 M8i 和 R8i 实例
收錄來源
AWS News
發布時間（來源提供）
2026-11-03T00:00:00Z
來源摘要（原文）
Amazon Relational Database Service（Amazon RDS）for Oracle 现已在更多 AWS 区域支持 M8i 和 R8i 实例。M8i 和 R8i 实例现已在亚太地区（新西兰）和加拿大西部（卡尔加里）推出，R8i 实例现还在欧洲地区（米兰、斯德哥尔摩和苏黎世）以及以色列（特拉维夫）推出。 这些实例由定制英特尔至强 6 处理器提供支持，仅在 AWS 上可用，在云中的同类英特尔处理器中性能最高，内存带宽最快。与上一代基于英特尔的实例相比，M8i 和 R8i 实例的性价比提升高达 15%，内存带宽增加 2.5 倍。 对于 Oracle Database Enterprise Edition（EE）和 Oracle Database Standard Edition 2（SE2），M8i 和 R8i 实例适用于采用自带许可（BYOL）模式的 Amazon RDS for Oracle。对于 EE，实例规格从 large 到 48xlarge 可供选择，此外还有裸机规格 metal-48xl 和 metal-96xl 可供选择。对于 SE2，实例规格从 large 到 4xlarge 可供选择，还有裸机规格 metal-48xl 和 metal-96xl 可供选择。有关可用的实例配置、定价和区域可用性，请参阅 Amazon RDS for Oracle 定价 。
