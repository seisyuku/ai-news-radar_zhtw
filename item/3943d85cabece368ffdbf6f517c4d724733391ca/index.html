AWS 云 WAN 现已支持流日志
收錄來源

來源摘要（原文）
AWS 云 WAN 现已支持 VPC 流日志，让您可以集中查看全球网络中的 IP 流量。流日志会记录每个流的详细信息，因此您无需离开 AWS 云 WAN 账户，即可了解流量如何在您的核心网络中传输。 在此之前，网络管理员必须将来自众多 VPC、账户和区域的 VPC 流日志拼凑在一起，才能查看其全球网络中的流量。他们往往需要依赖其他团队来获取这些日志。云 WAN 流日志为核心网络所有者提供一个综合视图，涵盖各 VPC、各区域以及通过 AWS Direct Connect、AWS Site-to-Site VPN 或 SD-WAN 连接的各本地网络之间的流量。利用这些数据，您可以排查连接和性能问题、根据历史带宽趋势规划容量、发现异常流量模式，并留存记录以满足安全性与合规性要求。流日志记录包括 IP 地址、端口、协议、流量大小和数据包丢失计数器，以及分段、区域、服务插入跳数和连接详情等云 WAN 元数据。您可以为整个核心网络、单个核心网络边缘或单个连接开启流日志。您可以将日志传输到 Amazon CloudWatch Logs、Amazon Simple Storage Service（Amazon S3）或 Amazon Data Firehose。云 WAN 不针对流日志收取额外费用。对于各传输目的地，需要收取标准费用。 云 WAN 流日志现已在所有提供 AWS 云 WAN 的 AWS 区域推出。您可以通过 AWS 管理控制台、AWS CLI 或 API 开始使用。要了解更多信息，请参阅 AWS 云 WAN 流日志 用户指南 。
