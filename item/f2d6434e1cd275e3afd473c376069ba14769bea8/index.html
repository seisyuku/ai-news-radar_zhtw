AWS Capabilities by Region 现提供针对单个功能的可用性通知并支持高级筛选条件

來源摘要（原文）
今天，AWS 宣布在 AWS 构建者中心的 AWS Capabilities by Region 中推出功能级可用性通知和高级筛选条件。您现在可以针对您感兴趣的 AWS 区域，为 AWS 服务或 AWS 服务的单个功能设置可用性通知，并接收应用程序内通知和每周电子邮件摘要，内容涵盖自您启用可用性通知以来变为可用的所有功能。为服务设置可用性通知会涵盖该服务中的每项功能，“所有区域”选项会涵盖每个区域，包括未来推出的 AWS 区域。 除了功能级别的可用性通知外，您现在还可以根据可用性状态筛选 API 操作和 CloudFormation 资源，并比较不同区域，以显示所有功能、仅显示匹配的功能，或仅显示差异。凭借超过 19000 项 API 操作和 5000 多种 CloudFormation 资源类型，这些筛选条件可与搜索功能及现有的显示偏好设置协同工作，快速将完整列表缩小至不同区域之间的确切差异。 在 AWS Capabilities by Region 中比较功能不需要账户。设置可用性通知需要构建者 ID，该 ID 可免费获取。要开始使用，请访问 AWS 构建者中心的 按区域探索 AWS 功能 。要了解更多信息，请参阅 AWS 构建者中心常见问题 。
