Title
AWS 并行计算服务现在支持节点生命周期操作
Source
AWS News
Published
2026-07-23T12:28:00Z
Summary
今天，AWS 宣布在 AWS 并行计算服务（PCS）中全面推出节点生命周期操作。通过节点生命周期操作，您可以在计算节点生命周期的特定时间点自动运行自定义脚本。您可以用其帮助节点做好工作准备。例如，您可以挂载共享存储、联接目录服务、安装软件或设置监控。 创建或更新组时，您可以在 PCS 计算节点组配置中定义节点生命周期操作，并且可以在多个计算节点组和集群中重复使用相同的脚本。对于每个脚本，您可以设置其位置（使用 Amazon S3 或 HTTPS URI）、要传递的参数、其运行所在的生命周期阶段、重启时是否重新运行，以及其错误处理行为。AWS PCS 可将输出写入专用的日志文件，使您能够查看运行的内容。 AWS PCS 是一项托管服务，可简化在 AWS 上使用 Slurm 运行和扩展高性能计算（HPC）工作负载的过程。您可以构建集成了计算、存储、联网和可视化工具的完整弹性环境，该服务负责管理集群更新并提供内置的可观测性。 节点生命周期操作已在支持 AWS PCS 的所有 AWS 区域推出。要了解更多信息，请参阅《AWS PCS 用户指南》中的 。
