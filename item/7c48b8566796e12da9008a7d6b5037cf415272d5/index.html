AWS Network Firewall 现已支持 Route 53 Resolved IP Validation
收錄來源
AWS News
發布時間（來源提供）

來源摘要（原文）
AWS Network Firewall 现已支持 IP 验证，将基于域的过滤从 HTTP/HTTPS 扩展到 SFTP 和 SSH 等协议。这项新功能可验证连接的目标 IP 地址是否已通过您的 VPC 的 Amazon Route 53 VPC Resolver 进行解析，填补客户端可能绕过域规则的安全漏洞。 此功能使 Network Firewall 客户能够针对任何协议（而不仅仅是 HTTP/HTTPS）实施域过滤规则，从而提供相比单纯基于 IP 的规则更灵活的安全策略。该功能通过将 Route 53 VPC Resolver 解析得到的 IP 与服务器名称指示（SNI）进行校验，简化针对 SNI 欺骗的防护流程，确保流量仅流向合法解析的目标地址。组织现已可在所有出站流量类型（从 Web 应用程序到文件传输协议）上强制执行一致的基于域的安全策略，无需采用复杂的变通方案。此外，Route 53 Resolver DNS 防火墙可搭配 VPC Resolver 使用，进一步提高 DNS 安全性。 Resolved IP Validation 现已在提供 AWS Network Firewall 和 Route 53 Resolver DNS 防火墙的所有 AWS 商业区域推出，不收取额外费用。有关受支持区域的完整列表，请访问 按区域探索 AWS 功能 页面。 要开始使用，请访问 AWS Network Firewall 产品页面 和服务 文档 。
