Title
AWS Marketplace 推出对 Amazon Lightsail 的支持
Source
AWS News
Published
2026-08-19T17:04:00Z
Summary
今天，AWS Marketplace 宣布支持在 Amazon Lightsail 上启动部分亚马逊机器映像（AMI）。希望获得简单、可预测定价和简化实例创建体验的客户，现在只需单击几下，即可在 Amazon Lightsail 上轻松部署符合条件的 AWS Marketplace AMI。Lightsail 实例套餐包含计算资源、存储空间，以及按固定月费提供的充足数据传输额度。Lightsail 还提供托管数据库、容器和负载均衡器等，使客户能够在业务增长时轻松扩展其应用程序。 当订阅支持的 AWS Marketplace 产品（包括 Microsoft Windows Server、Microsoft SQL Server Express、Ubuntu、cPanel & WHM 和 Plesk）时，除了 Amazon EC2 之外，客户现在还可以选择 Amazon Lightsail。选择 Lightsail 后，客户将跳转至预先配置了所选 AMI 和区域的 Lightsail 控制台，只需单击几下即可按可预测的月费进行部署。 “在 Lightsail 上启动”部署选项适用于所有 提供 Lightsail 的 AWS 区域 中符合条件的产品。要开始使用，请访问 AWS Marketplace 并订阅兼容的产品。有关 Amazon Lightsail 的更多信息，请访问 Amazon Lightsail 产品页面 。
