Title
AWS Transform 宣布推出从 Azure 到 AWS 的云原生代码转换功能
Source
AWS News
Published
2026-10-16T13:50:00Z
Summary
今日，AWS 宣布在 AWS Transform 中正式推出从 Azure SDK 到 AWS SDK 的应用程序代码转换功能，为您提供将 Microsoft Azure 云原生 .NET 应用程序迁移至 AWS 的更快途径。AWS Transform .NET 现代化智能体可识别 Azure 服务代码并将其转换为等效的 AWS 服务代码。例如，使用 Azure Cosmos DB 的 Azure Functions 无服务器函数可以转换为使用 Amazon DynamoDB 的 AWS Lambda 函数。 AWS Transform 会在您提交的源代码中发现 Azure SDK，并在评估报告和现代化计划中展示转换选项。在启动现代化流程之前，您可以接受系统提供的选项，也可以根据自己的偏好对选项进行调整。然后，AWS Transform 将识别出的 Azure 服务代码转换为等效的 AWS SDK 调用，并验证更改是否已纳入转换后的代码。该功能支持将 Azure Functions 转换为 AWS Lambda 函数、将 Azure Blob Storage 转换为 Amazon S3 以及将 Azure Queue Storage 转换为 Amazon SQS；Azure Cosmos DB 到 Amazon DynamoDB 的转换还处于预览版阶段。 AWS Transform 已在八个 AWS 区域推出：美国东部（弗吉尼亚州北部）、亚太地区（孟买、东京、首尔、悉尼）、加拿大（中部）和欧洲地区（法兰克福、伦敦）。 要了解更多信息，请参阅《AWS Transform 用户指南》中的 将云原生代码转换为 AWS 。
