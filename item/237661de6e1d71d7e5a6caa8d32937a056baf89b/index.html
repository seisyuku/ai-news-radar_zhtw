Title
Amazon ECR 现已支持最大 200GB 的映象层
Source
AWS News
Published
2026-08-03T15:00:00Z
Summary
Amazon Elastic Container Registry（Amazon ECR）已将通过 Docker push 推送的映象的最大单层大小限制提升至 200GB。 此前，打包资产时需要将数据拆分到多个层中，或转存到外部存储系统。本次更新后，客户可在单个映象层中存储最高 200GB 数据，从而消除在嵌入大型语言模型、打包基因组数据集或将大型二进制依赖项直接封装到容器映象等使用案例中的额外复杂性。对于使用 AWS SDK 或 CLI（即 UploadLayerPartAPI）推送的映象，单层大小限制仍为 50GB。 这项功能已在支持 Amazon ECR 的所有 AWS 区域和分区提供，但中东（巴林）和中东（阿联酋）区域除外。要了解更多信息，请访问 Amazon ECR 产品页面 并参阅 Amazon ECR 用户指南 。有关定价信息，请参阅 Amazon ECR 定价页面 。
