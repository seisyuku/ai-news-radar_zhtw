AWS Marketplace SaaS 免费试用现可自动转换为付费订阅
收錄來源

來源摘要（原文）
今天， AWS Marketplace 宣布，基于使用量的软件即服务（SaaS）产品的免费试用现在可以自动转换为付费订阅。免费试用结束后，买家的订阅将按卖家的按量计费标准继续，因此试用期结束后，买家只需为实际使用量付费。这可以帮助卖家将更多的试用用户转变为付费客户。买家可以轻松在购买之前评估软件，无需进行新的订阅，也不会中断使用。 卖家可以提供 7 到 90 天的免费试用，试用期结束后将自动转为按其设定的价格收取费用的付费订阅。例如，数据团队可以试用分析产品 30 天，如果该产品符合他们的需求，试用期结束后仍可继续使用。买家在订阅之前会看到试用期限、转换日期和价格。他们在试用转换之前会收到提醒电子邮件，并且可以在转换前随时免费取消。 卖家可以在 AWS 合作伙伴中心中创建免费试用，也可以更新现有的免费试用优惠以自动转换。在所有支持 AWS Marketplace 的 AWS 区域中，此功能通过公开优惠提供。 要了解更多信息，请参阅 AWS Marketplace Seller Guide 或 AWS Marketplace Buyer Guide 。
