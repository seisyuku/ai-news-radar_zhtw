來源摘要（原文）
您的编程智能体可以在 Amazon SageMaker AI 上选择、训练、优化和部署模型，同时通过单一自然语言工作流在您的整个 AWS 环境中处理其余工作。AWS AI/ML 技能现已成为 Agent Toolkit for AWS 中的核心技能，因此可与该工具包中的其他 AWS 技能（例如 EC2、Bedrock 等）协同工作。 我们已在 Agent Toolkit for AWS 上发布了全新的 AWS AI/ML 技能。该工具包现已成为受支持的单一集成点，取代了之前的 AWS Labs 技能和插件，并提供了统一且简便的安装和更新路径。这些技能还预装在 SageMaker Studio JupyterLab 中，可与 Kiro 或您选择的编程智能体配合使用。 此外，我们还扩展了这些技能所支持的 SageMaker AI 功能领域。 推理优化 ：针对延迟、吞吐量和成本对已部署的模型进行优化 模型定制 ：端到端的引导式微调工作流，涵盖从使用案例定义到训练、评估和部署的全过程 面向传统机器学习和生成式人工智能的有服务器训练 MLflow：实验跟踪与模型生命周期管理 JumpStart 模型部署和模型建议：部署预构建的 JumpStart 模型，并获取针对具体使用案例的合适模型的指导性建议 处理任务：在托管计算环境中进行数据准备和 ETL 处理 AWS AI/ML 技能不收取额外费用；您只需为智能体使用的 AWS 资源付费。要开始使用，请在 GitHub 上通过 Agent Toolkit for AWS 安装这些技能，或直接使用原装在 SageMaker Studio JupyterLab 中的技能。要了解有关 在 SageMaker AI 工作流中使用编程助手 的更多信息，请参阅 Amazon SageMaker AI 文档。
