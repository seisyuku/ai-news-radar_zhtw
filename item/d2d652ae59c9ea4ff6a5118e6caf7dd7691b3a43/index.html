Title
Amazon SageMaker 融通式合作开发工作室现已支持 Amazon OpenSearch
Source
AWS News
Published
2026-07-21T17:36:00Z
Summary
Amazon SageMaker 融通式合作开发工作室现已支持将 Amazon OpenSearch 作为数据来源，使您能够直接对搜索数据和日志分析数据与其他数据资产进行联合查询和分析。借助这一新连接，您可以在单一受监管环境中，结合使用 OpenSearch 中的运维搜索数据与来自 Amazon Redshift、Amazon S3 和关系数据库等来源的数据。 当您需要在分析工作负载和运维工作负载之间关联数据时，这一集成特别有用。例如，您可以将存储在 OpenSearch 中的应用程序日志和指标与事务数据关联起来，从而深入了解系统性能和用户行为。数据工程师和分析师可以构建数据管道，整合实时搜索和分析数据与结构化数据集，从而简化跨来源工作流程，无需在各种工具之间切换。要开始使用，请在项目的数据部分下添加一个 Amazon OpenSearch 连接。此时，您的 OpenSearch 数据会与其他项目数据一起显示在数据资源管理器中。然后，您可以通过查询编辑器直接查询数据、在 Notebook 中探索数据，或将数据纳入可视化 ETL 作业中，全程无需退出该工作室。 对 Amazon OpenSearch 连接的支持已在 提供 Amazon SageMaker 融通式合作开发工作室的所有 AWS 区域 推出。 要开始使用，请参阅 Amazon SageMaker Unified Studio User Guide 中的 Connecting to a new data source 。有关 Amazon OpenSearch Service 的更多信息，请访问 Amazon OpenSearch Service 页面 。
