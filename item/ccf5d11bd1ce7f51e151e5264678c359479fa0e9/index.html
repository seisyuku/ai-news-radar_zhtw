新聞標題（原文）
AWS IAM Identity Center 的 Identity Store 现在支持通过 Amazon EventBridge 发送变更通知
收錄來源
AWS News
發布時間（來源提供）
2026-10-28T08:00:00Z
來源摘要（原文）
现在，当用户、组、组成员身份或身份存储库本身被创建、更新或删除时，AWS IAM Identity Center 的 Identity Store 可向 Amazon EventBridge 发送实时事件。AWS IAM Identity Center Identity Store 是一个中央存储库，允许您管理 AWS 账户和应用程序中的身份和访问权限，作为 AWS IAM Identity Center 的身份源。这项新功能可帮助您自动响应身份生命周期事件，并通过实时检测变更，为您的安全性与合规性流程提供支持。 借助 Identity Store 变更通知，您可以构建自动化工作流来响应企业中的身份变更。例如，安全团队可以创建 EventBridge 规则，触发 AWS Lambda 函数来审计用户预置活动、向安全信息和事件管理（SIEM）系统发送警报，或者在用户或组发生变化时更新下游应用程序中的访问权限。管理大量员工的企业还可以利用这些数据，在用户被添加到或从特定组中移除时，自动完成入职和离职流程。 在所有支持 IAM Identity Center 的 AWS 区域中均可使用变更通知，且事件会发送至您实例所在的每个已启用该功能的区域。有关区域列表，请参阅 按区域探索 AWS 功能 。除了标准的 Amazon EventBridge 使用费用外，变更通知不收取任何额外费用。要了解更多信息，请参阅《AWS IAM Identity Center 用户指南》中的 事件通知 和《Amazon EventBridge 事件参考》中的 Identity Store 事件 。
