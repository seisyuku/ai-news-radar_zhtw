Title
AWS 现在可让客户注册 AWS 并使用 ACH 直接借记支付发票
Source
AWS News
Published
2026-10-11T08:00:00Z
Summary
即日起，美国的 AWS 客户可以使用美国银行账户注册 AWS 并通过 ACH 直接借记支付其 AWS 服务费用。该功能让客户能够通过一种便捷、安全的方式直接从美元银行账户管理 AWS 付款。 客户可以安全地连接个人或企业美国银行账户，并使用该账户支付 AWS 发票。以前，新的 AWS 客户需要信用卡或借记卡才能完成账户注册。 注册期间，客户可以在 AWS 注册页面选择“银行账户”，选择所属银行，然后通过银行的移动应用程序或网上银行凭证完成身份验证。此流程可以安全地验证账户所有权，并将银行账户与 AWS 账户绑定。默认情况下，该账户将用于支付后续 AWS 发票。 现有客户可以在 AWS 账单与成本管理控制台的“付款首选项”页面添加银行账户。他们可以依次选择“添加付款方式”和“绑定银行账户”，然后按照与新客户相同的银行选择和身份验证流程操作。验证通过后，该银行账户将作为付款方式，用于支付后续 AWS 发票。 对于美元银行账户，AWS 客户无需支付额外费用即可使用 ACH 直接借记。要了解更多信息，请参阅 Managing ACH direct debit 。
