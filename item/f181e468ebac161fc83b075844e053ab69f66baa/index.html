Amazon SNS 现已在另外四个 AWS 区域支持推送通知
收錄來源

來源摘要（原文）
Amazon Simple Notification Service（Amazon SNS） 现已在亚太地区（海得拉巴）、亚太地区（墨尔本）、欧洲（苏黎世）和 AWS GovCloud（美国东部）区域支持发送推送通知。 Amazon SNS 是一项完全托管的发布/订阅服务，可向多个端点传输消息，包括 AWS Lambda、Amazon SQS、Amazon Data Firehose、HTTP、AWS 终端用户消息发送 SMS 服务、推送通知以及电子邮件。通过此次发布，上述四个区域的客户可以使用 Amazon SNS 向以下受支持的推送通知服务发送推送通知：Amazon Device Messaging（ADM）、Apple Push Notification Service（APNS）、百度云推送（百度）、Firebase Cloud Messaging（FCM）和 Windows Push Notification Services（WNS）。 有关可以发送推送通知的区域的完整列表，请参阅《Amazon SNS 开发人员指南》中的 受支持的区域和国家/地区 。有关更多信息，请参阅 Amazon SNS 推送通知文档 。
