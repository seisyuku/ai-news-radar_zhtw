來源摘要（原文）
Amazon Managed Workflows for Apache Airflow（Amazon MWAA）预置环境现已在墨西哥（中部）区域（mx-central-1）推出。Amazon MWAA 无服务器此前已在该区域推出，客户现在还可以在其 Apache Airflow 工作流中使用 Amazon MWAA 预置环境。Amazon MWAA 是适用于 Apache Airflow 的一项托管式编排服务，使客户能够更轻松地在云中大规模设置和运营端到端数据管道。 客户可以使用 AWS 管理控制台、AWS CLI、AWS SDK 或 AWS CloudFormation 创建 Amazon MWAA 预置环境。墨西哥（中部）的客户现在可以在更靠近数据来源和最终用户的位置运行其 Amazon MWAA 预置工作流，从而减少延迟并帮助满足数据驻留要求。要了解更多信息，请访问 Amazon MWAA 产品页面 和 Amazon MWAA 支持的区域文档 。
