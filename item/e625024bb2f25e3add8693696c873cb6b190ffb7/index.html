Title
Amazon EC2 专属主机现已支持无自主管理许可证的主机资源组
Source
AWS News
Published
2026-07-24T21:00:00Z
Summary
即日起，客户可以为 EC2 专属主机创建主机资源组（HRG），无需再执行以往必要步骤：通过 AWS License Manager 创建自主管理许可证（SML）并关联 AMI。 该灵活特性对两类客户尤为实用：使用 EC2 Mac 实例的客户，以及仅需专属主机实现硬件级隔离、并非出于自带许可（BYOL）需求的客户。运行 BYOL 工作负载的客户仍可创建带 SML 的 HRG，一方面限定仅关联 AMI 的实例可在该主机启动，另一方面实现主机级别许可证用量跟踪。 要创建无 SML 的 HRG，可在 EC2 控制台中创建主机资源组时取消选中“仅限于与自主管理许可证关联的 AMI”选项，或通过 AWS CLI 将 instance-launch-option 设置为 license-configuration-required。 此功能现已在支持主机资源组的所有 AWS 区域推出。要了解更多信息，请访问 主机资源组用户指南
