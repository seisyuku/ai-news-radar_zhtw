Amazon EKS 仪表板现在可提供整个实例集范围内对证书颁发机构（CA）轮换情况的可见性

來源摘要（原文）
今天，Amazon Elastic Kubernetes Service（Amazon EKS）宣布在 Amazon EKS 仪表板中新增证书颁发机构（CA）轮换情况视图，让您能够集中查看所有集群中的 CA 轮换情况。Amazon EKS 仪表板已可集中展示您在各个 AWS 区域和账户中的集群状况，现在还新增了 CA 轮换视图，因此您无需逐一检查每个集群，即可了解哪些方面需要执行操作。 每个 Amazon EKS 集群都有自己的 CA，自 2018 年以来创建的集群的 CA 的有效期为 10 年，现已临近需启动轮换操作的时间节点。在 EKS 仪表板中，您现在可以查看您的集群及其 CA 轮换状态、哪些集群的 CA 即将过期，以及即将发生的自动轮换事件，因此，运营多个集群的平台团队可以从一个位置对整个实例集中的操作进行优先级排序。 Amazon EKS 仪表板通过 AWS Organizations 汇总您各账户和区域的数据，因此您需要在企业的管理账户中为该仪表板启用受信任访问权限，以便使用此功能。您可以从美国东部区域（us-east-1）查看该仪表板，无需额外付费即可使用。CA 轮换支持扩展到所有 AWS 商业区域，该仪表板将轮换状态汇总到一个实例集视图中。要了解更多信息，请参阅 Amazon EKS 文档 。
