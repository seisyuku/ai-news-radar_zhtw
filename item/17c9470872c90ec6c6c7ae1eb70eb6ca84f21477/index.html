Title
Amazon S3 元数据现已在另外六个 AWS 区域推出
Source
AWS News
Published
2026-10-15T13:00:00Z
Summary
Amazon S3 元数据现已在另外六个 AWS 区域全面推出：亚太地区（海得拉巴）、亚太地区（马来西亚）、亚太地区（新西兰）、亚太地区（台北）、亚太地区（泰国）和墨西哥（中部）。 S3 元数据是即时发现和了解 S3 数据的快速、简单的方法，包含可近乎实时地自动更新且易于查询的元数据。该功能可以帮助您整理和识别 S3 数据，并将这些数据用于业务分析、实时推理应用程序等。S3 元数据自动填充新对象和现有对象的元数据，为您提供全面的可查询数据视图。注释扩展了 S3 元数据功能，可让您以 JSON、XML 或 YAML 格式将丰富的业务上下文直接附加到对象，每个对象最多支持 1 GB 的数据。要大规模查询注释，您可以将它们显示在这些区域的 S3 元数据注释表中。 通过此次发布，S3 元数据现已在 38 个 AWS 区域 正式推出。要了解定价详情，请访问 S3 定价页面 。要了解更多信息，请访问 产品页面 和 文档 。
