Title
Amazon EC2 支持使用来自 Outposts 上运行的实例的本地快照创建 AMI
Source
AWS News
Published
2026-08-19T21:30:00Z
Summary
Amazon EC2 现已支持使用来自 AWS Outposts 上运行的实例的本地快照创建亚马逊机器映像（AMI）。利用此功能，客户可以更轻松地创建 AMI，同时将快照直接存储在 Outpost 上以满足数据驻留要求。 客户现在可以使用存储在 Outpost 上或父 AWS 区域内的快照创建 AMI。将数据保留在本地时，EC2 会自动根据实例的位置确定目标 Outpost，而无需手动指定 Outpost ARN。这也使客户能够将 AMI 创建操作集成到 Outposts 上实例的现有备份和生命周期工作流中，同时确保满足数据驻留要求。 此功能已在 AWS Outposts 支持本地快照存储的所有 AWS 区域推出。要了解更多信息，请访问 文档 。
