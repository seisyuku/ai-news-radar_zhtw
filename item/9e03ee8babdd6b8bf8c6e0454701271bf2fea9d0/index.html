Title
AWS Marketplace 现在允许卖家在私有优惠中配置净付款期限
Source
AWS News
Published
2026-08-06T14:49:00Z
Summary
AWS Marketplace 现已支持在私有优惠中配置净付款期限，选项包括 Net 30、Net 45、Net 60 和 Net 90。在本次发布之前，所有 AWS Marketplace 购买的净付款期限均统一遵循买家与 AWS 议定的付款期限。这项新功能可让卖家配置付款到期时间，从而使发票到期日期与买家和卖家商定的到期日期保持一致。这样一来，买家便能提前明确付款到期日期，并有机会享受更有利的付款期限；同时，卖家可以在创建私有优惠时设置净付款期限，从而提升现金流的可预测性。 买家在接受私有优惠之前，可以在采购页面上查看已配置的付款期限。净付款期限统一应用于私有优惠中的所有 AWS Marketplace 费用，包括预付费、分期付款和基于使用量的费用。对于渠道合作伙伴私有优惠（CPPO），ISV 可设置付款期限的上限，渠道合作伙伴提供的期限不能超过此上限。 此功能已在所有 AWS 商业区域全面推出，以供创建私有优惠的卖家使用。无需额外的设置或入门操作。灵活的净付款期限适用于通过发票付款的买家。默认行为保持不变。如果未设置自定义付款期限，则买家的标准 AWS 付款期限仍将适用。 要了解更多信息，请参阅 AWS Marketplace 卖家指南 或 AWS Marketplace 买家指南 。
