Title
AWS Network Security Manager 现已在美国东部（弗吉尼亚州北部）区域正式推出
Source
AWS News
Published
2026-09-24T15:00:00Z
Summary
今天，AWS 宣布正式推出 AWS Network Security Manager。这是一款全面的网络安全管理解决方案，旨在简化大规模安全策略的部署和执行。Network Security Manager 支持 AWS WAF 和 AWS Shield Advanced，不久还将支持 AWS Network Firewall。AWS Network Security Manager 使安全团队能够在整个 AWS 组织范围内一致地执行防火墙和 DDoS 防护配置。 Network Security Manager 具备始终在线的安全部署自动化功能，可将 AWS WAF 和 AWS Shield Advanced 安全保护应用于面向互联网的资源，例如 AWS 应用程序负载均衡器和 Amazon CloudFront。这种自动化方法可以帮助安全团队高效地部署和管理 WAF 规则以及 Shield Advanced 防护，确保目标账户和资源的安全态势保持一致。团队可以集中管理安全策略、自动检测配置漂移，并实施修复措施，在提供全面保护的同时降低手动安全管理带来的运营开销。 AWS Network Security Manager 已经在美国东部（弗吉尼亚州北部）正式推出。有关定价信息，请访问 AWS Network Security Manager 定价页面 。
