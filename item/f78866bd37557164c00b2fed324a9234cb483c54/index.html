Title
PostgreSQL 19 RC1 现已在 Amazon RDS 数据库预览环境中推出
Source
AWS News
Published
2026-10-15T16:00:00Z
Summary
即日起， Amazon RDS for PostgreSQL 19 测试版本 1（RC1）已在 Amazon RDS 数据库预览环境 中提供，您现已可以在 Amazon RDS for PostgreSQL 上评测预发布的 PostgreSQL 19。 PostgreSQL 19 RC1 侧重于稳定性，包含对测试版 4 测试期间的错误修复和改进。此版本改进了复杂文本搜索表达式的错误处理，增强了并行 autovacuum，并提高了 GIN 索引维护的可靠性。有关更多详情，请参阅 PostgreSQL 社区公告。有关更多详情，请参阅 PostgreSQL 社区公告 。 Amazon RDS 数据库预览环境数据库实例最长保留 60 天，保留期过后将自动删除。在 Preview Environment 中创建的 Amazon RDS 数据库快照只能用于在 Preview Environment 内创建或恢复数据库实例。您可以使用 PostgreSQL 转储和加载功能向预览环境导入或从中导出数据库。Amazon RDS 数据库预览环境数据库实例的定价与美国东部（俄亥俄州）区域的 定价 一致。
