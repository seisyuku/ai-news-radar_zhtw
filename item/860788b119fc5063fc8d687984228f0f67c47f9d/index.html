Title
Amazon CloudFront 现已支持 AWS Lambda Web Functions 作为源
Source
AWS News
Published
2026-10-12T23:10:00Z
Summary
即日起，您可以通过 CloudFront 的全球边缘网络交付基于 AWS Lambda Web Functions 构建的 Web 应用程序。 在 Lambda Web Function 前面使用 CloudFront，您可以在边缘终止 TLS 来降低延迟和加快连接、通过缓存来提升性能，并使用托管式 TLS 证书来自定义域。无需更改应用程序代码。CloudFront 源访问控制（OAC）能够限制 Lambda Web Function，使其只能通过 CloudFront 进行访问，让绕过安全保护的意外请求无法到达源。实施 OAC 后，CloudFront 的边缘网络可以保护 Lambda Web Function 免受网络层 DDoS 攻击，您可以连接 AWS WAF 来进一步提高应用程序层的安全性。对于需要针对自己的用户进行身份验证的应用程序，OAC 可以确保原始凭证原封不动地到达应用程序，让现有登录流程继续正常运行。 CloudFront 对 AWS Lambda Web Functions 的支持已在全球范围内推出，但 CloudFront 中国区域除外。要开始使用，请通过 CloudFront 控制台、SDK、CLI 或 CloudFormation 将 Lambda Web Function 配置为 CloudFront 源。有关更多信息，请参阅 CloudFront Developer Guide 。此功能不收取任何额外费用。
