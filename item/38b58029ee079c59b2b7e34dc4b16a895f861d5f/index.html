新聞標題（原文）
Amazon Quick 桌面版现在支持使用企业现有的 Amazon Quick 登录方法
收錄來源
AWS News
發布時間（來源提供）
2026-11-02T18:36:00Z
來源摘要（原文）
对于使用 Amazon Quick 的企业，桌面应用程序现在支持使用与企业在 Quick Web 版上使用的相同登录方法让用户登录。管理员无需再在身份提供者中注册 OIDC 应用程序，也无需设置单独的桌面登录方法，即可让用户开始登录。如果用户可以登录 Quick Web 版，则该用户就可以登录桌面应用程序。 要开启桌面访问权限，管理员只需在 Amazon Quick 控制台中添加一次桌面连接器。然后，用户输入其 Quick 账户名，选择“登录”，即可通过浏览器完成登录。这适用于使用 IAM Identity Center、IAM 联合身份验证或原生 Amazon Quick 用户的账户。如果您的企业希望单独管理桌面登录，您仍然可以使用 Microsoft Entra ID、Google Workspace、Okta 或 Ping Identity 等提供者来设置专用的身份提供者配置。 Amazon Quick 桌面版已在 支持完整 Amazon Quick 功能集的 AWS 区域 推出。 要开始使用，请参阅 Amazon Quick User Guide 中的 Amazon Quick on desktop 。
