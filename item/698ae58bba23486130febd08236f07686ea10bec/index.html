AWS Marketplace 现在对视同销售退款支持增值税贷项通知单
收錄來源
AWS News
發布時間（來源提供）

來源摘要（原文）
AWS Marketplace 卖家现在可以通过 AWS 合作伙伴中心中的自助服务，就已退款的视同销售交易提交增值税（VAT）贷项通知单。以前，对于符合条件的交易，AWS 会向卖家支付增值税；如果买家随后获得退款，卖家必须联系 AWS 提交相应的贷项通知单。此次发布简化了卖家的退款后增值税单据处理。 卖家可以在“视同销售增值税”部分查看符合条件的退款行项目，选择贷项通知单涵盖的退款，上传 PDF 或适用的电子发票形式单据，并跟踪提交状态。在适用的情况下，卖家可以将多笔符合条件的退款合并为一张贷项通知单，并在 Seller Insights 报告中查看相关的财务调整。 这些功能适用于受支持的欧盟成员国、挪威和英国境内符合条件的 AWS Marketplace 交易，包括渠道合作伙伴专属优惠（CPPO）交易。特定于国家/地区的开票和电子开票要求继续适用。 要开始使用，请登录 AWS 合作伙伴中心，然后转到“设置”→“税务信息”→“视同销售增值税”。要了解更多信息，请访问 AWS Marketplace 卖家指南 或 视同供应常见问题 。
