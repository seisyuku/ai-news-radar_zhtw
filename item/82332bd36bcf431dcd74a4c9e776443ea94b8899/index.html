Title
AWS CloudFormation 现在简化了堆栈更新回滚操作
Source
AWS News
Published
2026-10-22T17:30:00Z
Summary
AWS CloudFormation 现在让完成更新回滚和恢复部署变得更轻松。更新回滚可让堆栈恢复到已知的良好状态。即日起，如果某些资源无法自动回滚，您可以通过强制回滚在单个操作中完成回滚。它适用于所有 CloudFormation 工作流 – 从 AWS CLI 和 SDK 到 AWS CDK 和智能体。 利用强制回滚，CloudFormation 可在一次操作中完成更新回滚并将堆栈恢复到可部署状态，无需您识别和列出每个受影响的资源并对其重试相关操作。任何仍需关注的资源（如受 CloudFormation 外部的变更影响的资源）都会被记录下来，供您在下次部署前查看和解决。 要开始使用，请使用强制回滚选项运行 Continue update rollback（继续更新回滚），然后创建 漂移感知变更集 以在下次部署前查看任何配置差异。要了解更多信息，请参阅 AWS CloudFormation 用户指南中的 继续回滚更新 。 强制回滚已在所有区域推出，无需额外付费。有关服务可用性的详细信息，请参阅 AWS 区域表 。
