Amazon OpenSearch Service 优化引擎现已支持智能体跟踪

來源摘要（原文）
如今，Amazon OpenSearch Service 优化引擎新增对智能体跟踪的支持，包括 OpenTelemetry 跟踪。您的跟踪和日志现在位于同一个地方。您可以全程追踪一个请求或一次智能体会话、找出失败或变慢的步骤并查看相关日志，无需切换工具。 优化引擎会将 OpenTelemetry 日志和跟踪映射到对象、嵌套对象字段和扁平化对象字段，并支持多值数组。跨度事件、跨度链接、提示和工具调用会保留其嵌套结构，让您在摄取期间无需扁平化数据即可进行字段级查询。 对于热层数据，该引擎支持按文档 ID 进行更新、删除和更新插入操作。 当数据延迟到达或存在错误时，您可以就地更正，从而使控制面板和警报基于准确的数据工作。在 OpenSearch UI 中，您可以使用发现跟踪、应用程序性能监控、服务地图以及智能体跟踪和会话视图来分析这些数据。 这些功能已在以下 AWS 区域针对 OpenSearch 3.7 推出（无需额外付费）：美国东部（弗吉尼亚州北部）、美国东部（俄亥俄州）、美国西部（俄勒冈州）、加拿大（中部）、亚太地区（孟买）、亚太地区（新加坡）、亚太地区（悉尼）、亚太地区（东京）、欧洲地区（法兰克福）、欧洲地区（爱尔兰）、欧洲地区（伦敦）和欧洲（西班牙）。 要开始使用，请将 OpenTelemetry 数据发送到您的域，例如通过使用 Amazon OpenSearch Ingestion。要了解更多信息，请参阅 文档 。
