Title
EKS 上的 Amazon EMR 将 EMR 费用降低了 30%
Source
AWS News
Published
2026-10-23T08:00:00Z
Summary
Amazon EMR 宣布，运行 EKS 上的 EMR 时，附加到 EKS 的 EMR 费用降低 30%。此次降价适用于每个 vCPU 每小时的费用和每个 GB 每小时的费用，基础 Amazon EKS 费用则保持不变。在 EKS 部署选项上运行的所有 EMR 工作负载都将受益于此变更。现在，您能够以更低的成本在 Amazon Elastic Kubernetes Service（EKS）上运行 Apache Spark 工作负载，并且新的价格会自动应用于 EKS 上的 EMR 工作负载，无需您采取其他行动。 EKS 上的 EMR 降价 30% 已在提供 EKS 上的 Amazon EMR 的所有 AWS 区域推出。要了解有关 EKS 上的 EMR 的更多信息，请访问 EKS 上的 Amazon EMR 文档 和 Amazon EMR 定价页面 。
