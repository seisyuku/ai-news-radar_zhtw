适用于全栈 Windows 现代化改造的 AWS Transform 现在支持在另外 7 个区域部署 Aurora PostgreSQL
收錄來源
AWS News
發布時間（來源提供）
2026-10-15T17:00:00Z
來源摘要（原文）
如今，适用于全栈 Windows 现代化改造的 AWS Transform 增加了对转换后的 Amazon Aurora PostgreSQL 数据库的跨区域部署的支持，并在另外七个 AWS 区域推出。这些变更结合在一起，使客户在 SQL Server 现代化改造后可以更好地控制其现代化数据库的部署位置，从而满足数据驻留、延迟和灾难恢复要求。 客户可以上传 SQL Server 数据库设计语言（DDL）文件并在转换计划中设置目标 AWS 区域，以转换数据库并将生成的 Aurora PostgreSQL 集群部署到不同的 AWS 区域。同一工作流还会让依赖的 .NET 应用程序与 PostgreSQL 兼容，并更新连接字符串、ADO.NET 和 Entity Framework 数据访问调用。 通过此次扩展，适用于全栈 Windows 现代化改造的 AWS Transform 现已在以下区域推出： 美国东部（弗吉尼亚州北部）、欧洲地区（法兰克福）、欧洲地区（伦敦）、亚太地区（孟买）、亚太地区（首尔）、亚太地区（东京）、亚太地区（悉尼）和加拿大（蒙特利尔）。 要开始使用，您可以前往 AWS Transform 产品页面 或参阅 适用于全栈 Windows 的 AWS Transform 文档 。
