來源摘要（原文）
AWS Network Security Manager 现已在 AWS European Sovereign Cloud 区域和 31 个新增区域推出 今天，AWS 宣布在 AWS European Sovereign Cloud 区域和新增区域正式推出 AWS Network Security Manager。Network Security Manager 是一款全面的网络安全管理解决方案，旨在简化大规模安全策略的部署和执行。Network Security Manager 支持 AWS European Sovereign Cloud 区域中的 AWS WAF 和 AWS Shield。 新增区域为：美国东部（俄亥俄州）、美国西部（北加利福尼亚）、美国西部（俄勒冈州）、亚太地区（孟买）、亚太地区（香港）、亚太地区（台北）、亚太地区（首尔）、亚太地区（大阪）、亚太地区（海得拉巴）、亚太地区（新加坡）、亚太地区（悉尼）、亚太地区（墨尔本）、亚太地区（马来西亚）、亚太地区（新西兰）、亚太地区（泰国）、亚太地区（柔佛）、亚太地区（东京）、加拿大（中部）、加拿大西部（卡尔加里）、墨西哥（中部）、欧洲地区（法兰克福）、欧洲（苏黎世）、欧洲地区（斯德哥尔摩）、欧洲地区（爱尔兰）、欧洲地区（米兰）、欧洲（西班牙）、欧洲地区（伦敦）、欧洲地区（巴黎）、以色列（特拉维夫）、南美洲（圣保罗）、非洲（开普敦）。 Network Security Manager 具备始终在线的安全部署自动化功能，可将 AWS WAF 安全保护应用于面向互联网的资源，例如 AWS 应用程序负载均衡器。这种自动化方法可以帮助安全团队高效地部署和管理 WAF 规则以及 AWS Shield Advanced 防护，确保目标账户和资源的安全态势保持一致。团队可以集中管理安全策略、自动检测配置漂移，并实施修复措施，在提供全面保护的同时降低手动安全管理带来的运营开销。 要查看已推出 AWS Network Security Manager 的区域，请访问 AWS 区域表 。有关定价信息，请访问 AWS Network Security Manager 定价页面 （对于标准区域）和 European Sovereign Cloud 定价 页面。
