Title
Amazon ECS 快速模式现已支持 AWS Graviton（ARM64）工作负载
Source
AWS News
Published
2026-09-18T17:27:00Z
Summary
Amazon Elastic Container Service （Amazon ECS）快速模式现已支持将服务的 CPU 架构指定为 ARM64，让您可以轻松地将基于 ARM 的容器映像部署到由 AWS Graviton 提供支持的计算资源上，并获得相比基于 x86 的实例最高约 40% 的性价比提升。 Amazon ECS 快速模式通过编排和管理应用程序的云架构，让您可以轻松快速地启动容器化应用程序，包括 Web 应用程序和 API。您只需提供容器映像，其余工作由 ECS 快速模式完成：配置联网、负载均衡、自动扩缩和部署，并为您的应用程序提供自动生成的 URL。借助 ARM64 架构支持，您可以选择最适合工作负载的计算架构，无论是使用 Graviton 优化成本、与现有实例集保持一致，还是部署原生面向 ARM 构建的映像。 您可以使用 AWS 管理控制台、AWS CLI、AWS SDK 以及基础设施即代码（IaC）工具，为新建和现有的 Amazon ECS 快速模式服务配置 CPU 架构。这一功能已在所有 AWS 商业区域和 AWS GovCloud（美国） 区域 推出。要了解更多信息，请参阅 ECS 快速模式文档 。
