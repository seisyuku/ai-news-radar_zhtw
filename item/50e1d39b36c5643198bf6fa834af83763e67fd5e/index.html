新聞標題（原文）
Amazon RDS for Oracle 现支持使用自管理的 Active Directory 进行 Kerberos 身份验证
收錄來源
AWS News
發布時間（來源提供）
2026-11-05T10:30:00Z
來源摘要（原文）
Amazon Relational Database Service（Amazon RDS）（ Amazon Relational Database Service（Amazon RDS）for Oracle ）现可让客户直接将其 RDS for Oracle 数据库实例加入自管理的 Microsoft Active Directory（AD）域。您的自管理 AD 可以在本地、Amazon EC2 或其他云提供商上运行。您的 AD 域中的用户可以使用 Kerberos 对 RDS for Oracle 数据库实例进行身份验证。 以前，客户若要为其 RDS for Oracle 实例使用基于自管理 AD 的 Kerberos 身份验证，则需要部署 AWS Managed Microsoft AD，并在 AWS 托管域和自管理域之间建立信任关系。现在，客户可以直接加入其现有的自管理 AD 以对用户进行身份验证和授权，无需设置额外的目录或信任关系。您可以使用 AWS 管理控制台、AWS CLI 或 AWS SDK 进行此设置。您可以使用自管理 AD 而不支付任何额外费用。 Amazon RDS for Oracle 中基于自管理 Active Directory 的 Kerberos 身份验证现已在提供 Amazon RDS for Oracle 的 所有 AWS 商业区域 推出。要详细了解基于自管理 Active Directory 的 Kerberos 身份验证，请参阅《Amazon RDS User Guide》中的 Working with self-managed Active Directory with an Amazon RDS for Oracle DB instance 。
