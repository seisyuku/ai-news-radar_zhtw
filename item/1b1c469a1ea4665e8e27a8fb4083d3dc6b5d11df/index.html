來源摘要（原文）
​​​AWS Secrets Manager 现在与 AWS Recommended Actions 框架 集成，可直接在 Secrets Manager 控制台中为您的密钥提供符合情境、切实可行的建议。​ ​此次发布之后，您可以查看量身定制的建议以及您的密钥，从而改善安全态势并遵循最佳实践，整个过程无需离开控制台。例如，您可以确定需要配置轮换的密钥、使用客户自主管理型密钥而不是服务提供的默认密钥进行加密，并根据密钥配置改进采取行动，所有这些操作都在单一视图中完成。 ​此功能已在提供 AWS Secrets Manager 的所有 AWS 商业 区域 推出，无需支付额外费用。要开始使用，请访问 AWS Secrets Manager 控制台 。
