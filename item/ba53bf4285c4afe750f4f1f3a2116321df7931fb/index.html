AWS DataSync 增强模式支持适用于 Google Cloud 和 Microsoft Azure 的 OpenID Connect（OIDC）

來源摘要（原文）
AWS DataSync 增强模式现已支持对 Google Cloud Storage 和 Microsoft Azure Blob Storage 位置进行 OpenID Connect（OIDC）身份验证。DataSync 使用 AWS Identity and Access Management（IAM）角色从 Google Cloud 或 Microsoft Entra ID 获取短期凭证并自动刷新它们，确保您的传输持续进行。 您现在可以使用 DataSync 访问 Google Cloud Storage 和 Azure Blob Storage，而无需使用长期凭证，例如 HMAC 散列消息认证码密钥或共享访问签名（SAS）令牌。这可让您跨云移动数据，同时遵守可能禁止使用长期凭证的安全策略。 要开始使用，您可以使用 AWS CLI、API 或 AWS CloudFormation 向 DataSync 位置添加 IAM 角色。此功能已在支持 DataSync 增强模式的所有 AWS 区域推出。要了解更多信息，请访问 AWS DataSync User Guide 。
