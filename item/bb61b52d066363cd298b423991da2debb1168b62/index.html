Title
GitHub HydraFusion進入VS Code，AI可依任務自動安排多模型分工
Source
iThome
Published
2026-10-02T08:10:28Z
Summary
GitHub擴大HydraFusion研究預覽範圍，除了原本的Copilot命令列工具，現在也於VS Code與GitHub Copilot應用程式提供。使用者可從Copilot模型選單選擇HydraFusion，不過，HydraFusion並非單一AI模型，而是一套協調模型工作的機制，會依照任務決定由一個模型直接處理，或讓多個模型接力完成並檢查結果。
