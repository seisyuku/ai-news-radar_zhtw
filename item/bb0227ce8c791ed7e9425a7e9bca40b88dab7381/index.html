Title
Amazon EC2 C7i-flex 实例现已在欧洲地区（米兰）区域推出
Source
AWS News
Published
2026-07-31T00:21:00Z
Summary
即日起，由定制的第四代英特尔至强可扩展处理器（代号为 Sapphire Rapids）提供支持的 Amazon Elastic Compute Cloud（Amazon EC2）C7i-flex 实例将在欧洲地区（米兰）区域推出。这些定制处理器仅在 AWS 上可用，与其他云提供商使用的基于 x86 的同类英特尔处理器相比，性能提高多达 15%。 C7i-flex 实例使您能够以最简单的方式获得大多数计算密集型工作负载的性价比优势，与 C6i 实例相比，性价比提升高达 19%。C7i-flex 实例提供最常见的大小，从 large 到 16xlarge。对于没有充分利用所有计算资源的应用程序来说，这是不错的首选。使用 C7i-flex 实例，您可以无缝运行 Web 和应用程序服务器、数据库、缓存、Apache Kafka 和 Elasticsearch 等。 要了解更多信息，请访问 EC2 C7i-flex 实例页面。
