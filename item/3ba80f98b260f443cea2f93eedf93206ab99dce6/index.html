Title
Amazon Quick 现已支持共享审批策略
Source
AWS News
Published
2026-08-14T21:00:00Z
Summary
Amazon Quick 现已提供审批策略，帮助管理员对组织内部资产的共享方式实施治理控制。通过审批策略，管理员可以要求指定的审批人在授予访问权限之前，先对共享请求进行审核与批准，从而帮助组织确保敏感资产的共享经过充分确认、符合合规要求，且全程可审计。 管理员可以创建适用于特定资产类型的审批策略，涵盖知识库、空间和自定义聊天代理。当用户对适用审批策略的资产提交共享请求时，该请求会自动发送至指定的审批人组进行审核。审批人可以在批准或拒绝请求之前直接评估相关资产，并且所有工作流事件都会记录在 AWS CloudTrail 中，实现全程可审计。对于自定义聊天代理，审批人可以在单个请求中审核并处理整个依赖包。 这项功能适用于专业版和企业版套餐，并且已在支持 Amazon Quick 代理式功能的所有 AWS 区域推出。有关更多信息，请参阅 AWS 区域表 。 请访问 Quick 网站 ，了解关于 Amazon Quick 的更多信息。要了解关于审批策略的更多信息，请参阅 Amazon Quick 用户指南 中的“审批策略”部分。
