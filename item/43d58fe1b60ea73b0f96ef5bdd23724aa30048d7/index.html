适用于 Apache Flink 的亚马逊托管服务推出增强型快照功能

來源摘要（原文）
适用于 Apache Flink 的亚马逊托管服务现已支持增强型快照功能，该功能可让您跨 Apache Flink 应用程序和 AWS 区域捕获、导出和还原应用程序状态，这样您就能运行蓝绿部署，轻松将自管理的工作负载迁移到适用于 Apache Flink 的亚马逊托管服务而不丢失状态，并将备份保留在备用区域以进行跨区域还原。 要在不暂停业务处理的情况下部署应用程序更新以实现蓝绿部署，请从应用程序创建增强型快照，并使用该快照启动第二个应用程序。要迁移自管理的工作负载，请将其 Apache Flink 保存点作为增强型快照导入到适用于 Apache Flink 的亚马逊托管服务中。对于跨区域恢复，请将增强型快照导出到 Amazon Simple Storage Service（Amazon S3）存储桶，并将导出的状态复制到备用区域的存储桶。 增强型快照现已适用于 Apache Flink 1.20 及更高版本中的应用程序，并且已在提供适用于 Apache Flink 的亚马逊托管服务的所有 AWS 区域推出，但 European Sovereign Cloud（德国）区域除外。增强型快照存储作为持久化应用程序备份，按 GB/月计费。要了解更多信息并开始使用，请参阅《适用于 Apache Flink 的亚马逊托管服务开发人员指南》中的 增强型快照 。您还可以将 Agent Toolkit for AWS 与 Kiro、Claude Code 或 Cursor 结合使用，获取有关基于增强型快照构建并运行 Flink 应用程序的指导。
