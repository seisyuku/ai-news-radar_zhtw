Anthropic 給 Claude Artifacts 加“安裝爲應用”：AI 生成的工具可裝進 macOS 和 Windows 桌面
收錄來源
AIBASE
發布時間（來源提供）

來源摘要（原文）
Anthropic 於 11 月 25 日爲 Claude 交互式 Artifacts 推出“安裝爲應用”選項，用戶可將 AI 生成的網頁小工具直接安裝到 macOS 和 Windows 桌面，作爲獨立軟件啓動，不再侷限於瀏覽器標籤頁、關窗即消失。官方介紹，安裝後的 Artifacts 應用將擁有獨立的桌面窗口，體驗更接近本地應用。
