Title
AWS 现支持自动贷项通知单应用偏好设置
Source
AWS News
Published
2026-07-23T18:16:00Z
Summary
AWS 现允许通过电子资金转账付款的客户配置偏好设置，以指定如何将贷项通知单自动应用至未结清发票。客户可直接在“账单与成本管理”控制台上从不同的应用偏好中选择，以匹配其内部付款流程。这些选项包括将贷项通知单应用至原始发票、下一张符合条件的发票以及最早未付发票的多种组合。默认情况下，贷项通知单将优先应用至原始发票，然后再应用至后续发票，除非选择了其他偏好设置。 自动贷项通知单应用偏好设置现已在所有 AWS 商业区域推出。要开始使用，请访问“AWS 账单与成本管理”控制台中的 付款偏好设置 页面。要了解更多信息，请参阅 管理余额应用偏好设置 。
