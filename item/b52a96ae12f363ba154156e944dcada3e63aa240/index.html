Amazon SageMaker 融通式合作开发工作室为基于 IDC 的域新增浅色模式支持
收錄來源

來源摘要（原文）
今天，AWS 宣布 Amazon SageMaker 融通式合作开发工作室为基于 Identity Center（IDC）的域提供浅色模式支持。客户现在可以根据个人偏好配置视觉界面模式，在深色和浅色主题之间进行选择。通过此次发布，客户可以在基于 IAM 和基于 IDC 的域中设置此视觉偏好。 浅色模式有助于提升明亮环境下的阅读体验，并为偏好浅色界面的用户提供熟悉的视觉体验。结合现有的深色模式，此次更新让您能够完全掌控开发环境的外观，提升不同光线条件下的可访问性，并减轻眼睛疲劳。在 SageMaker 融通式合作开发工作室设置中，您可以在“配置文件”设置下选择“自定义外观”以在多个视觉模式之间进行选择，包括深色模式、浅色模式和设备设置（跟随操作系统的设置）。该设置在不同浏览器和设备上保持一致。 这项功能现已在提供 Amazon SageMaker 融通式合作开发工作室的所有 AWS 区域推出。要了解更多信息，请参阅 Amazon SageMaker Unified Studio User Guide 。
