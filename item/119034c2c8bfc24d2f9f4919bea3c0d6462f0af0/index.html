Amazon EC2 容量管理器的新功能

來源摘要（原文）
Amazon EC2 容量管理器现已提供实时可支持性检查和容量满足指标。实时可支持性检查可以为每个实例类型和可用区对某一请求的支持程度打分，从而帮助客户在不启动或预留实例的情况下查找容量。容量满足指标显示相对于所请求数量，实际提供了多少容量。 在数百个账户中运行数千个工作负载的全球企业通常会将每个工作负载分散到多个实例类型和可用区中，这为 Amazon EC2 提供了更多选择来满足每个请求。即日起，客户可以使用容量管理器中的可支持性检查，了解哪些可用区和实例类型为他们提供了获得所需容量的最佳机会。该检查会为每个选择返回“高”、“中”或“低”评分，并给出一个总体评分。此外，借助满足指标，客户可以衡量其 AWS 组织、账户、区域和带标签工作负载的满足率，并按实例类型和可用区进行细分，以展示这些选择的效果。 这两项功能均包含在 AWS Unified Operations （针对运行任务关键型工作负载的全球企业的 AWS Support 计划）中，并且已在所有 AWS 商业区域推出。 要了解更多信息，请阅读 AWS 计算博客上的 Plan and measure EC2 flexibility with Amazon EC2 Capacity Manager 并参阅 Amazon EC2 容量管理器用户指南 。要开始使用，请访问 容量管理器控制台 。
