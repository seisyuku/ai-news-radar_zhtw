Title
Amazon Redshift 在 AWS GovCloud（美国）区域新增 rg.large 和 rg.12xlarge 实例大小
Source
AWS News
Published
2026-08-13T19:34:00Z
Summary
Amazon Redshift 现已在 AWS GovCloud（美国西部）和 AWS GovCloud（美国东部）区域提供 rg.large 和 rg.12xlarge 两种 RG 实例大小。RG 实例性能更优，运行数据仓库和数据湖工作负载的速度最高可达上一代 RA3 实例的 2.4 倍，且每 vCPU 价格降低 30%。RG 实例集成了 Redshift 专有的向量化数据湖查询引擎，可在集群节点上处理 Apache Iceberg 和 Parquet 数据，使您能够使用单个引擎在数据仓库和数据湖中执行 SQL 分析。 rg.large 和 rg.12xlarge 实例大小适用于补丁版本 P202 及更高版本。客户可以通过 Elastic Resize 或 Classic Resize 将现有的 RG 或 RA3 集群调整为这些新实例大小。已拥有 RA3 集群的客户可以通过快照与恢复方式升级到 RG 实例。 RG 实例共有四种大小可供选择：rg.large、rg.xlarge、rg.4xlarge 和 rg.12xlarge。RG 实例提供灵活的定价选项，包括按需实例，以及 1 年期和 3 年期预留实例（支持全额预付、部分预付和无预付付款方式）。要了解定价详情，请访问 Amazon Redshift 定价页面 。 要开始使用，请参考以下资源： Amazon Redshift RG 实例文档 RA3 到 RG 升级指南 Amazon Redshift 定价
