Title
Amazon Managed Workflows for Apache Airflow 现在提供了智能体技能
Source
AWS News
Published
2026-10-15T08:00:00Z
Summary
Amazon Managed Workflows for Apache Airflow（MWAA）现已与 Agent Toolkit for AWS 集成，可提供内置的智能体技能，使您能够使用任何支持智能体技能的人工智能编码助手创作、调试和测试 MWAA 工作流程并升级 MWAA 环境。 这四项技能是 authoring-mwaa-workflow、debugging-mwaa-workflow、testing-mwaa-workflow 和 upgrading-mwaa-environments。它们结合在一起，可让您的人工智能助手使用自然语言直接与 MWAA 进行交互，从而减少构建和维护数据管道的手动工作。例如，您可以用通俗易懂的语言描述 ETL 管道，创作技能会生成一个包含任务依赖关系和错误处理的有效 DAG。 Amazon MWAA 智能体技能适用于 Amazon MWAA 预置环境和 Amazon MWAA 无服务器环境，并且已在所有提供了 Amazon MWAA 的 AWS 区域推出。 要开始使用，请安装 aws-data-analytics 插件 并将您的人工智能编码助手配置为使用 MWAA 智能体技能。要了解更多信息，请参阅《Amazon MWAA 用户指南》中的 使用 Amazon MWAA 智能体技能 以及 Agent Toolkit for AWS 文档 。
