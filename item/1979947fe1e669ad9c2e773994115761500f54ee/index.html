Title
Amazon Bedrock 现在支持具有跨区域推理功能的 SpaceXAI Grok 4.6
Source
AWS News
Published
2026-08-19T05:18:00Z
Summary
Amazon Bedrock 现在支持 SpaceXAI Grok 4.6，这是一种专为编码、代理式任务和知识工作而构建的前沿模型，具有美国地理位置和全球跨区域推理功能。客户现在可以通过跨多个 AWS 区域路由请求的跨区域推理功能，大规模访问 Grok 4.6，从而提高吞吐量并降低推理成本。 跨区域推理功能会自动跨多个 AWS 区域路由推理请求，从而为您提供更高的吞吐量，同时让您无需跨多个区域管理容量。美国地理位置推理配置文件（us.xai.grok-4.6）仅在美国地理区域内路由请求，因此您可以进行扩展，同时确保在美国境内处理数据，以满足数据驻留要求。全球推理配置文件（global.xai.grok-4.6）可以处理来自提供该模型的任何 AWS 商业区域的请求，从而在需求高峰期为您提供最大的 Bedrock 容量访问权限和最高的吞吐量，同时降低每个令牌的成本。该模型在 bedrock-runtime 端点上运行，支持 Responses API、Chat Completions API 和 Converse API；并且可使用您已用于 Bedrock 上的其他模型的相同账户级控制措施，包含模型调用日志记录（可传输至 Amazon S3 或 Amazon CloudWatch Logs）、Amazon CloudWatch 指标以及 AWS Cost Explorer 成本管理服务与 AWS 成本和使用情况报告中的成本分项核算。 适用于 Grok 4.6 的跨区域推理功能已在提供 Amazon Bedrock 的所有 AWS 区域推出。要开始使用，请查看《Amazon Bedrock 用户指南》中的 Grok 4.6 模型卡片 。
