Title
AWS 最终用户消息发送服务现支持 WhatsApp 语音通话
Source
AWS News
Published
2026-09-25T07:00:00Z
Summary
AWS 最终用户消息发送服务 现在支持企业使用其发送消息所用的同一经过验证的企业身份，直接在 WhatsApp 内与客户进行语音通话。借助 WhatsApp 语音通话功能，对话可以无缝地从聊天记录切换到语音通话，无需切换到其他渠道或应用程序，因此对话上下文不会丢失，客户也能始终留在对话开始的聊天记录中。 语音通话支持双向通信。客户可以在 WhatsApp 聊天中致电企业，企业也可以致电已授权接收联系的客户。您可以通过 AWS 最终用户消息发送服务控制台或 API，在已注册的 WhatsApp 企业电话号码上启用并管理 WhatsApp 语音通话功能。 WhatsApp 语音通话功能已在提供 AWS 最终用户社交消息的所有区域推出。 要了解更多信息并开始使用，请参阅 AWS 最终用户社交消息用户指南 。
