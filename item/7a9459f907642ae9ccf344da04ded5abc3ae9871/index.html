Title
Amazon Bedrock AgentCore 内存现已支持从非对话 JSON 有效载荷中提取记忆
Source
AWS News
Published
2026-08-20T20:00:00Z
Summary
Amazon Bedrock AgentCore 内存现已接受 CreateEvent API 上的 JSON 有效载荷类型，因此代理可以从结构化数据和多回合对话中提取和整合长期记忆。开发人员可以将行为事件、活动日志、系统事件和其他 JSON 数据（每个有效载荷最多 100 KB）直接传递到提取管道中。无需先将其重塑为合成对话消息。 提取管道处理 JSON 有效载荷的方式与处理对话相同，利用所有四种提取策略生成长期记忆：语义、用户偏好、摘要和情景。 非对话 JSON 有效载荷摄取功能现已在支持 AgentCore 内存的所有区域推出，与现有功能完全兼容。要开始使用，只需将 JSON 有效载荷添加到您的 事件 中即可。
