Title
Amazon Bedrock AgentCore Memory 现在支持灵活的命名空间变量
Source
AWS News
Published
2026-08-28T20:00:00Z
Summary
Amazon Bedrock AgentCore Memory 现在允许开发人员定义灵活的命名空间变量，以便根据任何应用程序特定的维度（例如组织、租户、团队或环境）来限定长期记忆的范围，而无需创建重复的策略或过量加载内置变量。这为多租户和复杂层次结构的应用程序提供了对记忆的组织、隔离和访问方式的精细控制。 在记忆资源上定义密钥，在策略的命名空间模板中引用它们，并在运行时通过 CreateEvent API 提供值。在长期记忆提取期间，该服务会将它们替换为命名空间模板。每个记忆资源最多可以定义五个密钥，每个密钥都可以在多个策略中引用。 灵活的命名空间变量现已在所有正式推出 Amazon Bedrock AgentCore Memory 的 AWS 区域中提供，无需额外付费。要开始使用，请参阅《Amazon Bedrock AgentCore 开发人员指南》中的 使用命名空间指定长期记忆组织 。
