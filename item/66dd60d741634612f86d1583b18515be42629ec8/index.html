Title
SpaceXAI Grok 4.6 现已在 AWS GovCloud（美国）的 Amazon Bedrock 中推出
Source
AWS News
Published
2026-08-28T13:17:00Z
Summary
AWS GovCloud（美国）的 Amazon Bedrock 现在支持 SpaceXAI Grok 4.6，这是一种专为编码、代理式任务和知识工作而构建的前沿模型。Grok 4.6 是 SpaceXAI 的最新旗舰模型，专为长期运行的代理以及具有挑战性的交互式视觉工作而设计。它提供 50 万个上下文窗口和可配置的推理强度（低、中、高、极高）。 该模型在 bedrock-runtime 端点上运行，支持 Responses API、Chat Completions API 和 Converse API；客户可以通过跨两个 AWS GovCloud（美国）区域的跨区域推理路由请求，大规模访问 Grok 4.6。Grok 4.6 也可以通过 AWS GovCloud（美国东部）中的 bedrock-mantle 端点访问。 要开始使用，请查看《Amazon Bedrock 用户指南》中的 Grok 4.6 模型卡片 。
