Title
Amazon MWAA 新增与 Amazon CloudWatch 集成的内置监控功能
Source
AWS News
Published
2026-09-03T15:00:00Z
Summary
Amazon Managed Workflows for Apache Airflow（MWAA）现已在 AWS 管理控制台 的环境详细信息页面内置监控体验。新的指标控制面板可集中展示环境的关键 Amazon CloudWatch 指标，并且每个图表均包含一个可选开关，可叠加显示建议的警告范围，助您快速识别可能影响环境的运行状况与性能的问题。 此外，环境详细信息页面现在还会显示一个警报表，其中列出了与您的 MWAA 环境相关的所有 Amazon CloudWatch 警报。您可以使用“一键创建推荐警报”操作，从 AWS 托管的模板预置一组精选警报，这样就能开始监控关键指标，而无需手动配置每个警报。此功能适用于 提供 Amazon MWAA 的所有区域内的 Amazon MWAA 预置环境。指标查询和警报按 Amazon CloudWatch 标准定价计费。 要开始使用，请打开 AWS 管理控制台 ，查看 支持 Amazon MWAA 的区域 或访问 Amazon MWAA 文档 以了解更多信息。
