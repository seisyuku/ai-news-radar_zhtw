Claude 生成的應用可以“裝”進桌面了：Artifacts 推出 Install as app，一句話寫的工具變成獨立軟件

來源摘要（原文）
Anthropic 於11月25日爲 Claude 交互式 Artifacts 推出“安裝爲應用”選項。此前，用 Claude 現場生成的小應用只能待在瀏覽器標籤頁，關閉即消失；如今可將其作爲獨立軟件安裝到 macOS 和 Windows 桌面，讓一句需求生成的工具擁有桌面圖標。安裝後體驗類似把網頁應用安裝到電腦，使其脫離標籤頁獨立運行。
