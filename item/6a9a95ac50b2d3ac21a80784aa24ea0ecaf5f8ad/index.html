AWS 分析服务现已支持 Workday Data Cloud 集成

來源摘要（原文）
今日，AWS 宣布推出 AWS 分析服务与 Workday Data Cloud 之间的全新双向、零拷贝集成。联合客户现在无需构建和维护 ETL 管道来在各个系统之间复制数据，即可就地跨 AWS 和 Workday 数据集进行查询，无需移动或复制数据，同时保留两个环境中现有的安全控制措施。 在 AWS，您可使用 Amazon SageMaker 融通式合作开发工作室、Amazon EMR、AWS Glue、Amazon Redshift 以及 Amazon Athena，借助 Workday Live Data Query 查询 Workday 数据，或通过目录联合身份验证对 Workday Data Cloud 种的 Apache Iceberg 表进行联合身份验证。只需在 SageMaker 融通式合作开发工作室、AWS Glue 或 AWS Lake Formation 控制台中配置连接，即可立即开始查询。访问权限由 AWS 与 Workday 权限控制。 在 Workday，您可将 AWS Glue Data Catalog Iceberg REST 端点注册为 Workday Analytics 中的外部目录，并直接查询 AWS Iceberg 表。常见使用案例包括将人力数据与业务数据联接，以进行人才分析、人力规划和机器学习。 此集成已在提供 AWS Glue 的所有 AWS 商业区域推出。要了解更多信息，请参阅 AWS Glue 用户指南 、Workday Data Cloud 上的 Workday Data Cloud 与 AWS 集成 以及 AWS 大数据博客文章 。
