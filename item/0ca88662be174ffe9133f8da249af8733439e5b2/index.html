Title
Amazon EC2 M8i 和 M8i-flex 实例现已在加拿大西部（卡尔加里）区域推出
Source
AWS News
Published
2026-08-25T13:00:00Z
Summary
自今日起，Amazon EC2 M8i 和 M8i-flex 实例已在加拿大西部（卡尔加里）区域推出。这些实例由定制英特尔至强 6 处理器提供支持，仅在 AWS 上可用，在云中的同类英特尔处理器中性能最高，内存带宽最快。与上一代基于英特尔的实例相比，M8i 和 M8i-flex 实例的性价比提升了高达 15%，内存带宽增加了 2.5 倍。其性能较 M7i 和 M7i-flex 实例提升了高达 20%，特定工作负载下的性能提升甚至更为显著。与 M7i 和 M7i-flex 实例相比，M8i 和 M8i-flex 实例在运行 PostgreSQL 数据库时速度提升了高达 30%，在运行 NGINX Web 应用程序时速度提升了高达 60%，在运行 AI 深度学习推荐模型时速度提升了高达 40%。 M8i-flex 实例是大多数通用型工作负载（如 Web 服务器、应用程序服务器、微服务、中小型数据存储、虚拟桌面和企业应用程序）实现性价比优势的最简单方法。R8i-flex 实例提供最常见的大小，从 large 到 16xlarge。对于没有充分利用所有计算资源的应用程序来说，这是不错的首选。 M8i 实例是所有通用型工作负载的理想选择，尤其适用于需要最大实例大小或持续高 CPU 使用率的工作负载。经过 SAP 认证的 M8i 实例提供 13 种大小，包括 2 种裸机大小以及适用于超大型应用程序的全新 96xlarge 大小。 要开始使用，请登录 AWS 管理控制台 。有关新实例的更多信息，请访问 M8i 和 M8i-flex 实例页面 ，或参阅 AWS 新闻 博客 。
