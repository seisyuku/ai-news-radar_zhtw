Title
用于迁移的 AWS Transform 可自动执行启动后的操作
Source
AWS News
Published
2026-08-06T17:00:00Z
Summary
AWS Transform 现在通过迁移工作流自动配置和执行启动后操作。在账户级别定义操作，并将其自动应用于目标账户中的每台源服务器，包括多账户迁移。通过自动执行这些操作，可消除逐台服务器手动配置所涉及的低效且易出错的工作，助力团队以更少的人力投入迁移更多服务器。 启动后操作在测试或割接启动后，立即通过 AWS Systems Manager（SSM）运行。您可以使用预定义的操作或自带 SSM 文档。对于源服务器批量配置，迁移清单文件现在包括启动后操作的新结构，使您能够更轻松地按源服务器审查和修改操作。 用于迁移的 AWS Transform 代理可端到端地自动执行迁移配置，包括复制模板、EC2 启动模板、EC2 大小调整和启动后操作，并支持在源服务器级别灵活地创建和编辑其中任何一项配置。 这一新功能现已在 提供 AWS Transform 的所有 AWS 区域推出。 要了解更多信息，请参阅 AWS Transform 用户指南 。
