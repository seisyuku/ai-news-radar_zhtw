Amazon GuardDuty RDS Protection 现在可以检测 Aurora 和 RDS 数据库中的数据泄露和破坏行为

來源摘要（原文）
Amazon GuardDuty 宣布扩展 RDS Protection 功能，将威胁检测范围从登录异常扩展至识别针对 Amazon Aurora PostgreSQL 和 Amazon RDS for PostgreSQL 数据库的数据泄露及数据破坏攻击。这项新功能名为“RDS Protection”，主要针对数据活动，利用基于机器学习（ML）的异常检测和集成威胁情报，持续监控数据库查询模式，并帮助您检测异常数据活动，且无需部署智能体、增加额外基础设施或更改数据库配置。 越来越多的攻击者通过网络钓鱼、社会工程学或错误配置获取有效凭证后，将数据库作为窃取或破坏关键数据的目标，其恶意数据库活动往往与合法的应用程序行为难以区分。 针对数据活动的 RDS Protection 可以针对正常查询模式建立行为基准，使 GuardDuty 能够检测到传统工具无法发现的威胁。 您可以启用针对数据活动的 RDS Protection，将其作为针对登录活动的 RDS Protection 的附加功能。只需在 GuardDuty 控制台中单击一下，即可为整个组织启用该功能；也可以通过 API、SDK、CLI 或 AWS CloudFormation 以编程方式启用该功能。每个账户在每个区域均可享受 30 天免费试用。 该功能现已在所有 AWS 商业区域和 AWS GovCloud（美国）区域推出，这些区域均提供 Amazon GuardDuty RDS Protection，并支持 Aurora PostgreSQL 和 Amazon RDS for PostgreSQL。有关支持的版本，请访问 GuardDuty RDS Protection 文档 。 要了解更多信息并开始免费试用，请访问 Amazon GuardDuty 产品页面 。
