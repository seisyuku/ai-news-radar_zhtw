Title
Amazon SageMaker 融通式合作开发工作室现已支持数据分析与异常检测
Source
AWS News
Published
2026-08-18T18:49:00Z
Summary
Amazon SageMaker 融通式合作开发工作室现已支持数据分析与异常检测，并由 AWS Glue 数据质量自动监测功能提供支持。数据管理员、工程师和分析师可以生成数据的统计分析结果以了解其形态与完整度，并跟踪这些统计数据随时间的变化趋势。异常检测有助于识别数据点偏离历史模式的时间，而无需使用预定义阈值或自定义规则。这两项功能同时适用于目录表中的静态数据与可视化 ETL 作业中的传输中数据。 本次发布后，目录表上的专用“数据分析”选项卡会提供按需和定期分析，以便计算数据集级和列级统计数据。随着分析历史数据的不断累积，异常检测将构建预期行为的基线，并标记超出预测范围的数据点。这在以下情况下特别有用：您不知道具体阈值，或预期值随时间发生变化且固定规则失效。对于传输中数据，可以在任意采用 Evaluate Data Quality 转换的可视化 ETL 作业的结果页面上，使用相同的分析统计数据与异常检测。 这项功能现已在提供 Amazon SageMaker 融通式合作开发工作室的所有 AWS 区域推出。要了解更多信息，请访问 Amazon SageMaker 融通式合作开发工作室文档 。
