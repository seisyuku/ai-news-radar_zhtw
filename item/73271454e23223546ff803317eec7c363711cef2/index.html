Title
AWS Glue 新增从 AWS 管理控制台一键访问 SageMaker 融通式合作开发工作室的功能
Source
AWS News
Published
2026-08-11T14:57:00Z
Summary
AWS Glue 现已支持直接访问 Amazon SageMaker 融通式合作开发工作室，数据工程师和分析师只需点击一下，便可从在 Glue 控制台中查看目录，切换到在 SageMaker 融通式合作开发工作室中查询数据、运行数据质量检查以及构建数据管道。借助这一全新集成，已在 Glue 控制台中工作的客户可以访问 SageMaker 融通式合作开发工作室中的数据与 AI 功能。通过本次发布，现在只需点击一下，即可从 S3 表类数据存储服务、Athena、EMR、Redshift 和 Glue 控制台访问 SageMaker 融通式合作开发工作室。 现在，在 AWS Glue 控制台中浏览目录表或构建 ETL 作业时，您可一键打开 SageMaker 融通式合作开发工作室，可使用同一 IAM 角色，立即开始使用目录中的数据，或通过 SageMaker 笔记本查询您的数据。对于尚未设置 SageMaker 融通式合作开发工作室的 Glue 控制台客户，可使用新的内联权限面板，直接在设置工作流中创建和配置所需的 IAM 策略，无需导航到 IAM 控制台并切换浏览器标签页。您可以使用现有的 IAM 角色，并在上下文中自定义权限，从而减少开始使用所需的步骤。 这项功能已在支持 Amazon SageMaker 融通式合作开发工作室的所有 AWS 区域推出。要开始使用，请导航到 AWS Glue 控制台 。
