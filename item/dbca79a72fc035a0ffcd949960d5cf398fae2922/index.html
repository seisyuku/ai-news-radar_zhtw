Title
宣布在 Amazon Bedrock AgentCore 中推出临时策略和速率限制
Source
AWS News
Published
2026-08-06T04:00:00Z
Summary
Amazon Bedrock AgentCore 宣布推出两项新的控制机制：针对有状态代理授权的临时策略和针对 AI 流量的速率限制。 临时策略可让您定义有状态授权规则，在会话中根据代理先前操作的上下文来评估每一次请求，因为单个工具调用在孤立状态下也许是安全的，但如果结合其前置操作来看，则可能带来风险。借助临时策略，您可以强制实施工作流排序，要求工具参数与先前调用的输出精确匹配，要求在执行特权操作前进行人工审批，以及强制实现数据时效性。 速率限制支持按用户或按组来控制流向连接到网关的工具、模型和代理的流量大小。借助由 OAuth 或 AWS IAM 限定范围的规则，您可以对跨所有目标类型的请求、针对推理目标的令牌，以及长时间运行的并发会话的并发连接设置速率限制，这将有助于保障下游服务的可用性，并强制执行公平的配额分配。 要了解区域可用性以及更多信息，请参阅 文档 和 公告博客 ，并探索 Dogwood 参考实现 。
