Title
Amazon EC2 Hpc8a 实例现已在亚太地区（新加坡）区域推出
Source
AWS News
Published
2026-10-05T20:33:00Z
Summary
即日起，Amazon EC2 Hpc8a 实例将在亚太地区（新加坡）AWS 区域推出。这些实例由第 5 代 AMD EPYC 处理器（以前代号为 Turin）提供支持。Hpc8a 实例的最大频率为 4.5 GHz，与 Hpc7a 实例相比，性能提高多达 40%，性价比提高多达 25%，可帮助客户加快计算密集型工作负载，同时优化成本。此外，与 Hpc7a 实例相比，Hpc8a 实例的内存带宽高出多达 42%，进一步提高了内存密集型模拟和科学计算工作负载的性能。 Hpc8a 实例基于最新的第六代 AWS Nitro 卡 构建，专为计算密集、延迟敏感的 HPC 工作负载而设计。它们非常适合紧密耦合的应用程序，例如计算流体动力学（CFD）、天气预报、显式有限元分析（FEA）以及需要快速节点间通信和持续高性能的多物理场模拟。 要开始使用，请登录 AWS 管理控制台 。要了解更多信息，请访问 Amazon EC2 Hpc8a 实例页面 或 AWS 新闻博客 。
