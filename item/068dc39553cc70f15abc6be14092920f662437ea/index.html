Amazon CloudWatch 日志集中化现已在 AWS GovCloud 和其他商业区域推出

來源摘要（原文）
Amazon CloudWatch 日志集中化现已在 AWS GovCloud（美国）以及另外 13 个商业区域推出。CloudWatch 日志集中化可将来自多个 AWS 账户和区域的日志数据复制到单个目标账户中，它与 AWS Organizations 集成，实现高效聚合，无需自定义解决方案。 通过此次发布，AWS GovCloud（美国）分区和商业分区中的组织可跨自身账户和区域将日志集中化以进行集中监控。您可以将集中化规则的范围限定为整个组织、特定组织单位或选定的账户，并将日志复制到单个账户，同时通过增强的系统字段保留源上下文。 CloudWatch 日志集中化现已在非洲（开普敦）、亚太地区（香港）、亚太地区（海得拉巴）、亚太地区（雅加达）、亚太地区（马来西亚）、亚太地区（墨尔本）、加拿大西部（卡尔加里）、欧洲地区（米兰）、欧洲（西班牙）、欧洲（苏黎世）、以色列（特拉维夫）、中东（巴林）、中东（阿联酋）、AWS GovCloud（美国东部）和 AWS GovCloud（美国西部）推出。要查看受支持的区域的完整列表，请参阅 AWS 区域表 。 要开始使用，请在 Amazon CloudWatch 控制台中或者使用 AWS CLI 或 AWS SDK，创建集中化规则。要了解更多信息，请参阅 Amazon CloudWatch Logs 用户指南中的 日志集中化 。客户可以免费集中化一个日志副本；新增副本按 0.05 USD/GB 计费。有关详细信息，请参阅 Amazon CloudWatch 定价 。
