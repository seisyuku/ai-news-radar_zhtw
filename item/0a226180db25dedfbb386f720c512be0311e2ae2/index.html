新聞標題（原文）
AWS Budgets 现已支持对通知订阅者进行电子邮件验证
收錄來源
AWS News
發布時間（來源提供）
2026-10-01T08:00:00Z
來源摘要（原文）
AWS Budgets 可让您设置自定义成本和使用量阈值，并在支出超过阈值时通过电子邮件提醒您。现在，AWS Budgets 在向新的电子邮件订阅者发送预算提醒之前，会对其进行验证。当您在预算通知中添加电子邮件地址时，AWS Budgets 会向该地址发送一封验证电子邮件，收件人确认后，该地址才会开始接收通知。 验证流程适用于从 2026 年 9 月 30 日起添加的电子邮件地址。已针对现有预算订阅的地址不受影响，您无需采取任何措施。对于新地址，收件人需要通过验证电子邮件中的链接进行确认，这将打开 AWS 管理控制台。AWS Budgets 控制台会显示每位订阅者的验证状态，对于仍在等待确认的地址，还提供重新发送选项。AWS Budgets 将通过 AWS 用户通知服务发送这些通知，收件人可以随时选择退出。 AWS Budgets 电子邮件验证已在所有 AWS 区域推出，但 AWS GovCloud（美国）区域和中国区域除外。 要了解更多信息，请参阅 AWS Billing and Cost Management User Guide 中的 Adding email recipients to a budget notification 。
