來源摘要（原文）
安全团队需要强大的工具来发现漏洞、测试漏洞攻击和建立防御措施。OpenAI 的 Daybreak Red 现已面向 AWS GovCloud（美国东部）区域 Amazon Bedrock 上符合条件的客户开放，为相关工作带来先进的 AI 技术。 作为 OpenAI 的 Daybreak 网络防御计划的一部分，Daybreak Red: GPT-5.6 Cyber 专为授权的漏洞研究、漏洞攻击复现和缓解措施开发而构建。它为经过身份验证的防御人员提供了更大的空间来调查复杂的安全问题，同时此类工作的拒绝率更低，且身份验证、监控和访问控制措施更为严格。 Daybreak Red 基于 Bedrock 的新一代推理引擎运行，并在芯片层级强制执行零操作员访问。您的推理数据不会用于训练模型；您也无需与 OpenAI 共享您的 Daybreak Red 数据。 该模型已在美国东部（俄亥俄州）和 AWS GovCloud（美国东部）推出。需先申请获得 OpenAI 的 Daybreak 访问权限 ，之后才能访问该模型。 要开始使用，请联系 OpenAI 或您的 AWS 客户团队，了解您是否符合 Daybreak 的使用资格。获得批准后，请与您的 AWS 客户团队合作启用访问权限。 要了解更多信息，请参阅此 博客 。
