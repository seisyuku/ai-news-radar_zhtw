Title
Amazon MWAA 无服务器现已在 AWS GovCloud（美国）推出
Source
AWS News
Published
2026-09-04T22:00:00Z
Summary
Amazon Managed Workflows for Apache Airflow（MWAA）无服务器现已在 AWS GovCloud（美国东部）和 AWS GovCloud（美国西部）推出。Amazon MWAA 无服务器通过按需自动预置和扩展计算资源，消除了管理 Apache Airflow 基础设施带来的运营开销；它采用按使用量付费模式，仅按实际工作流运行时间进行收费。 有关受支持区域的完整列表，请参阅 Amazon MWAA 无服务器区域页面 。要了解更多信息，请参阅 Amazon MWAA 无服务器文档 。
