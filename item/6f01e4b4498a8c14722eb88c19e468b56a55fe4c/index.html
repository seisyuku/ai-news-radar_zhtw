來源摘要（原文）
即日起， Amazon MSK Connect 和 AWS Glue Schema Registry 在 AWS European Sovereign Cloud（德国）区域推出。这两项功能与该地区此前已上线的 Amazon MSK Standard 代理相结合，为在 AWS European Sovereign Cloud 上运行流式工作负载的客户提供了一套更完备的工具，用于构建、连接和管理其 Apache Kafka 应用程序。 MSK Connect 允许您使用 Amazon MSK 运行完全托管式 Kafka Connect 集群，即部署、监控和扩展在 Apache Kafka 和外部系统（如数据库、文件系统和搜索索引）之间传输数据的连接器，无需预置基础设施，支持自动扩缩，并采用即用即付定价模式。作为补充， AWS Glue Schema Registry 是 AWS Glue 的一项无服务器免费功能，它允许您使用 Apache Avro、JSON 和 Protobuf 架构来验证和控制流数据的变化。作为跨多个解耦应用程序的数据格式和结构的集中存储库，它减少了数据验证逻辑、跨团队协调和下游故障，并与为 Amazon MSK 、 Amazon Kinesis Data Streams 、 适用于 Apache Flink 的亚马逊托管服务 和 AWS Lambda 构建的 C# 和 Java 应用程序集成。 要开始使用，请访问 Amazon MSK 开发人员指南 和 AWS Glue Schema Registry 文档。
