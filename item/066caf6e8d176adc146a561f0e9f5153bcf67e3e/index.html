Title
Amazon SageMaker AI 无服务器模型自定义现已支持全参数微调
Source
AWS News
Published
2026-08-03T17:00:00Z
Summary
Amazon SageMaker AI 无服务器模型自定义现已支持对超过 25 个开源模型全参数微调，其中包括来自 gpt-oss、Gemma、Llama、Nemotron 和 Qwen 模型系列的热门模型。除了 LoRA 等参数高效微调方法（只更新模型权重中的一小部分）之外，现在您还可以根据使用案例的需求，更新模型中的所有参数，以实现更深度的调优。 全参数微调让模型能够更全面地了解您所在领域的特定模式、术语和任务结构。当您需要模型习得超越表面风格调整的功能时（例如学习专业的推理模式、采用复杂的输出格式，或从大型专有数据集中内化领域知识），这一点尤为重要。通过无服务器模型自定义，SageMaker 可以管理所有基础设施预置和训练编排，因此您无需预置或管理任何基础设施即可运行全参数微调任务，并且只需为实际使用量付费。 SageMaker 上的无服务器全参数微调功能已在美国东部（弗吉尼亚州北部）、美国西部（俄勒冈州）、亚太地区（东京）和欧洲地区（爱尔兰）提供。要开始使用，请导航到 Amazon SageMaker Studio 中的“JumpStart 和模型”页面以启动自定义作业，或者使用 SageMaker Python SDK 。要了解更多信息并查看支持的模型列表，请参阅 Amazon SageMaker AI 模型自定义文档 。
