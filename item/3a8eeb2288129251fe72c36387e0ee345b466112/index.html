Title
AWS Glue Schema Registry 现已在另外十个 AWS 区域推出
Source
AWS News
Published
2026-08-06T18:56:00Z
Summary
现在，您可以在亚太地区（新西兰）、亚太地区（泰国）、亚太地区（海得拉巴）、亚太地区（大阪）、亚太地区（马来西亚）、亚太地区（墨尔本）、墨西哥（中部）、以色列（特拉维夫）、亚太地区（台北）、加拿大西部（卡尔加里）区域使用 AWS Glue Schema Registry （ AWS Glue 的一项无服务器免费功能），通过已注册的 Apache Avro、JSON 和 Protobuf 架构格式来验证和控制流数据的演进。 Schema Registry 充当集中存储库，用于管理数据流系统中解耦的应用程序之间的数据格式和结构。使用它时，不再需要数据验证逻辑和跨团队协作，并且可以提高流数据质量和减少下游应用程序故障。通过 Apache 许可的序列化器和反序列化器，Schema Registry 可与为 Apache Kafka/Amazon Managed Streaming for Apache Kafka 、 Amazon Kinesis Data Streams 、 Apache Flink/适用于 Apache Flink 的亚马逊托管服务 和 AWS Lambda 开发的 C# 和 Java 应用程序集成。 要开始使用，请参阅 AWS Glue Schema Registry 文档。有关提供 AWS Glue Schema Registry 的 AWS 区域的完整列表，请参阅 AWS 区域服务列表 。
