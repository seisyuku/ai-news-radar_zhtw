Title
AWS Backup 将针对 Amazon Neptune 的逻辑上受物理隔离的保管库支持扩展到另外三个 AWS 区域
Source
AWS News
Published
2026-08-06T07:00:00Z
Summary
AWS Backup 针对 Amazon Neptune 的逻辑上受物理隔离的保管库支持现已在另外三个 AWS 区域推出：亚太地区（墨尔本）、欧洲（西班牙）和欧洲（苏黎世）。 通过本次扩展，您可以将 Neptune 备份存储在这些区域内逻辑上受物理隔离的保管库中。逻辑上受物理隔离的保管库是不可变的，默认处于锁定状态，并使用 AWS 自有密钥或客户自主管理型密钥进行加密。您可以跨账户和区域复制备份，使用 AWS Resource Access Manager（RAM）共享保管库以进行恢复，以及在账户遭到入侵时通过多方审批来保障保管库的访问安全。这有助于缩短恢复时间，并满足您的灾难恢复和合规性要求。 要开始使用，请访问 AWS Backup 控制台、AWS 命令行界面（CLI）或 AWS SDK。有关受支持的区域和功能的完整列表，请访问 AWS Backup 文档 。要了解有关逻辑上受物理隔离的保管库的更多信息，请参阅 产品页面 和 定价页面 。
