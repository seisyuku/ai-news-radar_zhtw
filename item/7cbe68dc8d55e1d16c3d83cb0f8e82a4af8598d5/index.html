來源摘要（原文）
自定义账单视图现在支持 AWS 账单管理处和 AWS 账单转移视图作为源视图。这些是 AWS 针对每个账单组和每个账单转移关系维护的视图。您可以将它们组合成一个自定义账单视图，应用筛选条件，并在 Cost Explorer、AWS Budgets 以及账单与成本管理控制台中使用该视图。有三种源视图类型。账单组视图包含每个账单管理处账单组的成本，您可以将这些成本整合到一起，以便在各个业务部门之间进行成本分摊和成本展示。账单转移视图包含每位终端客户转账给您的费用，转账成本展示视图包含最终客户看到的成本。汇总每种类型可以得出您的总转移成本和最终客户看到的账单总额。 您的访问权限不会改变：您只能在已具备访问权限的情况下，将 AWS 管理的视图用作数据源。创建完成后，您可以通过 AWS Resource Access Manager 将自定义账单视图与组织内部或外部的账户共享，以便您的财务团队或下游销售商在其各自的账户中处理这些数据。无论您是转售 AWS 服务的 AWS 合作伙伴，还是使用账单组进行预估计费的组织，您都能获得一个综合视图，而非针对每个客户或每个组分别显示一个视图。 此功能已在所有 AWS 商业区域推出，不额外收费。要开始使用，请导航至 AWS 账单与成本管理控制台或查看 用户指南 。
