Title
Amazon MWAA 无服务器现已支持 PythonOperator 和 BashOperator
Source
AWS News
Published
2026-08-18T18:00:00Z
Summary
Amazon Managed Workflows for Apache Airflow（Amazon MWAA）无服务器现已支持使用 PythonOperator 和 BashOperator 在无服务器运行时中直接运行自定义 Python 函数和 Shell 脚本。本次发布后，数据工程团队无需预置额外的基础设施，即可执行他们每天依赖的代码模式，包括数据转换、格式转换和数据质量检查。 将您的 Python 模块或 Shell 脚本打包为代码包，将其上传到 Amazon S3，并在创建或更新工作流时进行引用。该服务会在创建工作流时为代码生成快照，并将该快照用于所有后续运行，从而确保各次执行的一致性。 此功能已在提供 Amazon MWAA 无服务器的所有 AWS 区域推出。要了解更多信息，请访问 使用 Python 和 Bash 运算符 。
