Title
Amazon Connect 现在支持 Azure Virtual Desktop 和 Windows 365 Cloud PC 的音频优化
Source
AWS News
Published
2026-07-24T23:11:00Z
Summary
使用 Microsoft Azure Virtual Desktop（AVD）或 Windows 365 Cloud PC 的坐席，现在开启音频优化后，可直接在虚拟桌面会话内接听来电。要开始使用，IT 管理员需要为其虚拟桌面环境完成一次性设置。配置完成后，媒体将从虚拟桌面重定向到坐席的本地设备，从而提高音频质量。 坐席只需登录其 Azure Virtual Desktop 或 Windows 365 Cloud PC 会话，然后使用 Amazon Connect Customer 坐席工作区或使用 Amazon Connect Customer 开源 JavaScript 库构建的自定义坐席界面开始接听电话。此项支持是对 Amazon WorkSpaces、Citrix 云桌面和 Omnissa 云桌面的现有音频优化的补充。 除了 AWS GovCloud（美国西部）区域之外，所有提供 Amazon Connect Customer 的 AWS 区域均提供此功能。要了解更多信息，请参阅 Amazon Connect Customer 管理员指南 。
