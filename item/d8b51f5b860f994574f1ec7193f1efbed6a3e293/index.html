Title
Amazon MSK 现在支持从 Apache ZooKeeper 到 KRaft 的就地迁移
Source
AWS News
Published
2026-08-10T17:00:00Z
Summary
Amazon Managed Streaming for Apache Kafka（Amazon MSK）现在支持从 Apache ZooKeeper 到 KRaft 的就地迁移，使客户无需预置新基础设施、迁移数据或重新配置客户端应用程序，即可将现有集群迁移到 KRaft。 KRaft 是 Apache Kafka 的共识协议，消除了对使用 Apache ZooKeeper 进行元数据管理的依赖。KRaft 可以将元数据管理从外部 ZooKeeper 节点转移到 Kafka 自身内部的一组控制器上，使元数据能够作为主题在 Kafka 代理内进行存储和复制，从而加快元数据传播、提高可扩展性并简化集群架构。Kafka 3.9.x 是最后一个支持 ZooKeeper 的版本，而 Kafka 4.x 仅支持 KRaft。这种就地迁移为客户提供了一条轻松路径，使其能够在现有集群上迁移到 KRaft 并升级至 Kafka 4.x。 要开始使用，客户需要先升级至 Kafka 3.9.x（如果他们使用的是旧版本），然后才能启动迁移。在这整个过程中，集群始终可用。所有步骤均可通过 MSK 控制台、AWS CLI 或 API 执行。目前，除欧洲主权云（德国）外，所有提供 Amazon MSK 预置的 AWS 区域 均支持从 Apache Zookeeper 到 KRaft 的就地迁移。要了解如何开始使用，请参阅 Amazon MSK 开发人员指南 。
