Title
Amazon Corretto 2026 年 7 月季度更新
Source
AWS News
Published
2026-07-22T18:00:00Z
Summary
2026 年 7 月 22 日，Amazon 宣布推出了 OpenJDK 的 Amazon Corretto Long-Term Supported（LTS）和 Feature Release（FR）版本的季度安全漏洞修复与重要更新。Corretto 26.0.2、25.0.4、21.0.12、17.0.20、11.0.32 和 8u502 现已可供 下载 。Amazon Corretto 是 OpenJDK 的免费、多平台生产就绪型发行版。 从该版本开始，默认 Amazon Corretto Docker 映像将基于 Amazon Linux 2023。Amazon Linux 2 映像将继续作为非默认选项提供给尚无法迁移的客户使用。 从该版本开始，Corretto 8 将不再包含 JavaFX 二进制文件。您可以在 Corretto 8 GitHub 上了解有关迁移建议的更多信息。 访问 Corretto 主页 即可下载 Corretto 26、Corretto 25、Corretto 21、Corretto 17、Corretto 11 或 Corretto 8。您还可以通过在 Linux 系统上配置 Corretto Apt、Yum 或 Apk 存储库 来获取更新。 欢迎 提供反馈！
