在 AWS GovCloud（美国）区域，AWS Compute Optimizer 现在支持更多 Amazon EC2 实例类型
收錄來源

來源摘要（原文）
AWS Compute Optimizer 现在为 AWS GovCloud（美国西部）区域中的另外 389 种 Amazon Elastic Compute Cloud（Amazon EC2）实例类型和 AWS GovCloud（美国东部）区域中的 276 种实例类型提供调整建议。运行受监管工作负载和政府工作负载的客户，无需手动分析，即可在当前一代实例类型上获得相同的成本和性能优势。 Compute Optimizer 已扩展支持范围，涵盖了每个工作负载类别中的最新一代处理器系列。新增支持范围涵盖计算优化型实例（C7i、C7i-flex、C8g、C8gn）、通用型实例（M7i、M7i-flex、m8g、m8gd、M8i、M8i-flex）、内存优化型实例（R7i、R8g、R8i、R8i-flex）、内存密集型实例（X2iedn、X8i）和存储优化型实例（i7i、i7Ie、i8G、i8GE）。通过此次扩展，Compute Optimizer 现已在 AWS GovCloud（美国西部）区域支持 102 个系列中的 724 种实例类型，并在 AWS GovCloud（美国东部）区域支持 69 个系列中的 542 种实例类型，涵盖 EC2 实例和 EC2 Auto Scaling 组的推荐方案。 如今，这种扩展支持范围适用于 AWS GovCloud（美国西部）和 AWS GovCloud（美国东部）区域，没有额外费用。您可以通过 AWS 管理控制台、AWS CLI 或 AWS SDK 开始使用 Compute Optimizer。要了解更多信息，请参阅 AWS Compute Optimizer 产品页面 和“AWS GovCloud (US) User Guide”中的 AWS Compute Optimizer 。
