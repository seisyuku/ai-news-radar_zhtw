Title
Claude Opus 5 现已在 AWS 上推出
Source
AWS News
Published
2026-07-24T15:00:00Z
Summary
AWS 现已推出 Claude Opus 5，这是迄今为止最先进的 Opus 模型，兼容零数据留存（ZDR），为追求顶尖构建能力的团队实现了编码、长时间运行代理与复杂专业工作场景的跨越式提升。 Claude Opus 5 如同资深工程师，在编码、解读与遍历代码库方面实现能力提升，可编写出生产级代码，并能在运行过程中调整其策略。它可驱动稳定可靠的代理，支持数小时甚至通宵持续运行，能灵活绕过各类卡点、从错误中恢复并完成任务目标。此外，它针对长文档具备更强的深度推理能力，处理复杂分析时准确度更高，在文档密集型企业业务场景下提升效果最为突出。 客户可通过两种方式访问 Claude Opus 5：Amazon Bedrock 和 AWS 云端 Claude Platform。 Amazon Bedrock 提供默认启用零数据留存（ZDR）的 Claude Opus 5，在满足数据治理要求的同时，为您提供 Opus 的顶级智能能力。它依托区域数据驻留机制，将您的数据保存在 AWS 基础设施内，并通过搭载了护栏和知识库等 AWS 托管式功能的统一服务，提供访问权限。要了解更多信息，请参阅 Amazon Bedrock 文档 和 区域可用性 。 借助 AWS 云端 Claude Platform，您可以通过 AWS 管理控制台直接访问 Anthropic 原生平台的体验和功能，零数据留存（ZDR）功能支持按需申请开通。您可借助与直接使用 Anthropic 完全一致的 API、功能与控制台体验开展构建、测试及部署工作，整套流程统一对接 AWS 计费和身份验证。要开始使用，请参阅 AWS 云端 Claude Platform 文档 。
