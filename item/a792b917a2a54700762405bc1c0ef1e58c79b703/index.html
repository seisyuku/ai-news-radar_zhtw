來源摘要（原文）
用于渗透测试的 AWS Continuum（CPT）（AWS Security Agent）是一项 AWS 安全服务，旨在帮助企业主动识别并修复其应用程序中的漏洞。CPT 现在支持额外的第三方集成，使安全和开发团队能够连接更多工具链，并将相关构件纳入渗透测试评估中。 此次扩展后，CPT 新增了对四项新集成的支持，以满足不同开发工作流的需求。使用 Azure DevOps 和 Bitbucket Data Center 的团队现在可以将这些工具连接到 CPT，从而更轻松地将源代码和 CI/CD 管道配置纳入渗透测试范围。新的 GitHub App（只读）集成支持用户在不授予写入权限的情况下将 GitHub 存储库连接到 CPT，从而以一种非侵入性的方式导入存储库配置和源代码以进行评估。Confluence 集成使安全团队能够将文档纳入测试范围，并将渗透测试报告直接导出回 Confluence。 要进一步了解用于渗透测试的 AWS Continuum 如何通过扩展的第三方集成来增强您的安全态势，请访问 用于渗透测试的 AWS Continuum 产品页面 。
