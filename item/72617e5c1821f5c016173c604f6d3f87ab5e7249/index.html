Title
RDS SQL Server 现已支持将 SQL Server 审计日志发布到 CloudWatch
Source
AWS News
Published
2026-08-04T07:00:00Z
Summary
Amazon Relational Database Service（Amazon RDS）for SQL Server 现已支持将 SQL Server 审计日志发布到 CloudWatch。 SQL Server 审计是一项原生 SQL Server 功能，允许跟踪和记录数据库引擎上发生的事件。在 Amazon RDS 上，您可以按照为本地 SQL Server 数据库服务器创建审计和审计规范的方式来创建它们。 现在，您可以将审计日志发布到 S3 和/或 CloudWatch。如果您同时启用 S3 和 CloudWatch 选项，则只有在审计日志文件上传到 S3 和 CloudWatch 后，审计日志发布才会标记为“已完成”。审计日志存入 CloudWatch 后，您可以对日志数据进行实时分析。如果您启用保留，RDS 将在配置的时间段内将审计日志保留在数据库实例上。 有关更多信息，请参阅 SQL Server 文档中的 SQL Server 审计（数据库引擎） 。有关详细的配置说明，请参阅 Amazon RDS for SQL Server 用户指南 。此功能现已在提供 Amazon RDS for SQL Server 的所有 AWS 商业区域和 AWS GovCloud（美国）区域推出。
