Title
AWS IAM 现已默认支持为每个角色配置 20 个托管策略
Source
AWS News
Published
2026-08-19T15:00:00Z
Summary
AWS Identity and Access Management（IAM） 已将每个角色的托管策略的默认配额从 10 个增至 20 个。 通过增加默认配额，减少了以下情况下提交服务配额请求的需求：遵循 IAM 最佳实践（例如，将权限拆分到按用途划分的策略中）时，或接入需要附加更多托管策略的 AWS 合作伙伴产品时。如果您需要为每个角色配置超过 20 个托管策略，则可以使用服务配额 请求增加配额 至最多 25 个。 此更改应用于所有 AWS 商业区域、AWS GovCloud（美国）和中国区域，并自动应用于您账户中的所有 IAM 角色，而无需执行任何操作。要了解更多信息，请参阅《IAM 用户指南》中的 IAM 和 AWS STS 配额 。
