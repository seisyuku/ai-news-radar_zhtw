适用于大型机的 AWS Transform 改进了重新构想现代化工作流

來源摘要（原文）
适用于大型机的 AWS Transform 现可实现字段级精度的业务功能识别，并在评测与重新构想工作流中生成新的要求覆盖范围报告。以前，使用相同表或文件的业务功能会被归为一组，您需要根据 AWS Transform 构件自行生成可追溯性报告。此次发布后，您可以基于更准确的业务功能目录，开始对 z/OS COBOL 和 PL/I 工作负载进行现代化改造，并在构建之前验证要求覆盖范围。 现在，仅在业务功能影响相同数据字段时才会将其归为一组。这些功能还包括屏幕和队列，并具备更清晰的名称和描述。新的要求覆盖范围报告显示了生成的要求是如何覆盖应用程序的每个部分的。每行源代码都会根据其处理方式进行分类，每条业务规则都会与它所源自的具体行相关联，而每项要求都由支撑它的业务规则作为依据。在 Kiro 及其他 IDE 中进行正向工程之前，您可以审查从整个代码组合到单行代码的覆盖范围。 这些功能现已在提供适用于大型机的 AWS Transform 的所有 AWS 区域推出。有关更多信息，请参阅 AWS 区域表 。要了解更多信息，请访问 适用于大型机的 AWS Transform 或参阅 适用于大型机的 AWS Transform 文档 。
