Title
AWS Backup 现已在亚太地区（新西兰）区域支持 Amazon FSx 文件系统
Source
AWS News
Published
2026-10-14T08:00:00Z
Summary
AWS Backup 现已在亚太地区（新西兰）区域支持适用于 Lustre 的 Amazon FSx、适用于 NetApp ONTAP 的 Amazon FSx、适用于 OpenZFS 的 Amazon FSx 和适用于 Windows File Server 的 Amazon FSx。 通过此次发布，您可以使用 AWS Backup 对亚太地区（新西兰）区域的 Amazon FSx 文件系统以及其他受支持的 AWS 资源的数据保护进行集中式自动化和管理。您可以创建基于策略的备份计划来安排备份和应用保留规则，将备份存储在加密的保管库中，并在需要时还原文件系统。这可以帮助您通过单一的集中化服务满足业务连续性、灾难恢复和监管合规性要求。 要开始使用，请访问 AWS Backup 控制台、AWS 命令行界面（CLI）或 AWS SDK。有关受支持的区域和功能的完整列表，请访问 AWS Backup 文档 。要了解有关 AWS Backup 的更多信息，请访问 产品页面 和 定价页面 。
