AWS Transform 增加了针对 Amazon S3、EBS、EFS 和 FSx 的存储迁移评测

來源摘要（原文）
AWS Transform 中的迁移评测 现已可评测本地存储向 AWS 迁移的适配情况。您无需手动分析分布在不同协议、容量和性能规格中的数千个卷，只需上传存储清单，AWS Transform 就会为您完成映射。它会为每个工作负载匹配最合适的服务，给出规格建议，并预测成本以生成总拥有成本商业案例。可通过 NetApp Digital Advisor 导出、RVTools 文件或其他清单导入 NAS 共享、SAN LUN、直连磁盘或备份存储库。AWS Transform 可将工作负载分配至 Amazon S3、Amazon EBS、Amazon EFS 和 Amazon FSx（含 NetApp ONTAP、Windows File Server、OpenZFS、Lustre）。运行假设分析场景，对比各类部署选项（例如单可用区与多可用区，或成本优化型与性能优化型），然后在聊天中针对任何分析结果发起后续提问。 存储迁移评测已在提供 AWS Transform 的所有 AWS 区域推出。要了解更多信息，请参阅 AWS Transform 用户指南 。
