Title
AWS 弹性灾难恢复推出恢复计划，实现编排式应用程序恢复
Source
AWS News
Published
2026-08-27T18:00:00Z
Summary
AWS 弹性灾难恢复（AWS DRS）现已推出恢复计划，可在恢复和演习过程中自动按顺序启动多服务器应用程序。您无需逐个启动服务器并手动跟踪依赖关系，只需定义一次恢复顺序，在需要时通过单次操作即可执行。这一计划解决了客户在运行由数据库、应用层和支持服务组成的应用程序时，必须按特定顺序启动的常见难题。 借助恢复计划，您可以将服务器按顺序分组启动，并可配置各组之间的等待时间，从而确保应用程序每次都能以可预测且一致的方式恢复。您可以在非破坏性演习模式下运行计划，以验证流程、在需要人工干预的地方添加审批步骤，并实时监控进度。这种自动化缩短了恢复时间，并避免了在高压灾难场景下编排服务器启动顺序时出现的常见失误。 恢复计划在已提供 AWS DRS 的所有 AWS 区域均可使用，除了标准 DRS 使用费用外，无需额外付费。要了解更多信息，请参阅 AWS 弹性灾难恢复用户指南 。
