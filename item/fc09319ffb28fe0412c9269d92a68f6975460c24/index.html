Title
OpenAI 的 Daybreak Red 与 Daybreak Blue 现已在 Amazon Bedrock 中面向符合条件的客户开放
Source
AWS News
Published
2026-08-13T16:12:00Z
Summary
安全团队现可在 Amazon Bedrock 中访问 OpenAI 的 Daybreak Red 和 Daybreak Blue。这两款模型均属于 OpenAI 推出的网络防御计划 Daybreak，该计划旨在为防御方提供受管控的前沿 AI 模型访问权限，助力其开展网络安全工作。 Daybreak Blue 是大多数安全团队在防御性工作流（包括漏洞发现、检测工程和事件响应）中开展工作的起点。Daybreak Red 适用于经授权的高级任务，例如漏洞研究、漏洞利用复现和缓解措施开发。针对这些任务，模型采用更低的拒绝阈值，同时配合更严格的身份验证、监控与访问控制，从而提升调查的速度与深度。这两款模型都基于 Bedrock 的新一代推理引擎运行，并在芯片层级强制执行零操作员访问（ZOA）。您的推理数据不会用于模型训练，这两款模型都不要求您选择与 OpenAI 共享数据。 Daybreak Red（GPT-5.6 Cyber）和 Daybreak Blue（GPT-5.6 Sol）现已在 Amazon Bedrock 中面向以下 AWS 区域 中符合条件的用户开放：美国东部（俄亥俄州）。需先申请获得 OpenAI 的 Daybreak 访问权限 ，之后才能访问这两款模型。如需申请，请联系 OpenAI 或您的 AWS 账户团队以获取资格要求方面的指导。获得批准后，请与您的账户团队合作，在 AWS 上申请访问权限。要了解更多信息，请阅读 博客 。
