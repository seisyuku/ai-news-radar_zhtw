Title
AWS Deadline Cloud 现已支持 EBS 持久卷成本跟踪
Source
AWS News
Published
2026-08-12T16:00:00Z
Summary
AWS Deadline Cloud 现已在 Deadline Cloud Monitor 应用程序的 Usage Explorer 中展示与 Amazon Elastic Block Store（Amazon EBS）持久卷相关的成本。AWS Deadline Cloud 是一项完全托管式服务，可帮助团队在云端运行计算密集型工作负载，适用于视觉效果、动画、产品设计、仿真和游戏开发。 之前，客户已能查看与 Deadline Cloud 相关的计算与许可成本。随着近期持久化 EBS 卷支持功能的发布，客户也需要通过某种方式来查看存储成本。现在，Deadline Cloud 会跟踪每个 EBS 卷从创建到删除期间的成本，且不受任何作业或会话的影响。这些成本在 Usage Explorer 和统计 API 中显示为一种新的持久化卷使用量类型。这些成本将归因于拥有该卷的实例集，从而使客户能够按实例集、场或时间段来汇总支出。这有助于客户发现闲置卷，并决定是调整生存时间还是任其过期。成本跟踪功能会自动启用，无需执行任何操作。 持久化卷成本跟踪功能已在提供 Deadline Cloud 的所有 AWS 区域推出。成本跟踪功能不会产生额外费用。要了解更多信息，请访问 AWS Deadline Cloud 产品页面 或我们的 用户指南 。
