來源摘要（原文）
Amazon S3 表类数据存储服务现在支持服务器访问日志记录，为您提供对表类存储桶的请求的详细记录。现在，您可以跟踪表操作、命名空间管理和数据访问，以支持安全审计、访问分析和成本归因。日志传输不收取额外费用，您只需支付日志文件存储费用。 当您在表类存储桶上启用服务器访问日志记录时，S3 会将该存储桶中所有表和命名空间的请求日志传送到同一账户和区域中的通用存储桶。每条记录使用与通用存储桶的 S3 服务器访问日志相同的空格分隔格式，捕获请求者、操作、表名称、命名空间、响应状态和请求时间。这使您可以重复使用现有的日志分析工作流程，使用您选择的任何查询引擎（例如 Amazon Athena 和 DuckDB）查询 S3 表类数据存储服务日志。 S3 表类数据存储服务的服务器访问日志记录在提供 S3 表类数据存储服务的所有 AWS 区域 可用。您可以使用 AWS 管理控制台、AWS CLI、AWS SDK 或 AWS CloudFormation 将其启用。要了解更多信息，请访问 S3 表类数据存储服务概览页面 和“Amazon S3 User Guide”中 S3 Tables server access logging 。
