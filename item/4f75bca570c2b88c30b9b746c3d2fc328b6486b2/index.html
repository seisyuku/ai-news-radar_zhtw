Title
AWS Advanced Ruby Driver Wrapper 现已全面推出
Source
AWS News
Published
2026-10-05T17:00:00Z
Summary
Amazon Web Services（AWS）Advanced Ruby Driver Wrapper 现已全面推出，可以与 Amazon RDS 和 Amazon Aurora PostgreSQL 和 MySQL 兼容版数据库结合使用。这一高级数据库驱动程序可缩短 RDS 蓝绿切换、Aurora 全局数据库切换和数据库故障转移的时间，从而提高应用程序可用性。此外，它还支持数据库的多种身份验证机制，包括 AWS Secrets Manager 身份验证以及基于令牌的 AWS Identity and Access Management（IAM）身份验证。 AWS Advanced Ruby Driver Wrapper 构建在社区版 pg （PostgreSQL）和 mysql2 （MySQL）驱动程序之上，以提供超出标准数据库连接的增强功能。该封装程序与 Aurora 和 RDS 数据库原生集成，使其能够监控数据库集群状态，并在触发数据库故障转移的意外故障期间，快速连接到新晋的写入节点。此外，该封装程序通过提供的 aws_postgresql 和 aws_mysql2 适配器与 ActiveRecord 无缝集成，因此您无需更改应用程序代码即可启用它。 该驱动程序在 Apache 2.0 许可证下作为开源项目推出。要开始使用，请参阅 GitHub 存储库 中的说明。
