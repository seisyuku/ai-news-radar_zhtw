Amazon DocumentDB 无服务器现可提供高达 35% 的吞吐量提升
收錄來源

發布時間（來源提供）
2026-11-09T16:00:00Z
來源摘要（原文）
随着平台版本 4 的发布，Amazon DocumentDB 无服务器现可提供高达 35% 的吞吐量提升。平台版本代表性能、扩展能力或功能方面的改进，并在集群级别自动管理。 所有新的无服务器集群都在您的 AWS 区域内可用的最新平台版本上启动。您可以通过执行待处理的维护操作 serverless-platform-version-update，将平台版本 3 上的现有集群升级到平台版本 4。这使您能够控制何时应用更新，要么立即应用更新，要么在下一个计划维护时段内应用更新。升级到一个更新的平台版本后，无法降级到上一个版本。 您可以在 AWS 管理控制台中或通过 DescribeDBClusters API 的 ServerlessV2PlatformVersion 字段查看集群的平台版本。有关更多信息，请参阅 Amazon DocumentDB 无服务器扩展能力 和 检查和升级无服务器集群的平台版本 。
