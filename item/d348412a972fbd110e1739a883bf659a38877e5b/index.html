Title
Amazon WorkSpaces Core 托管实例现已支持 ModifyVolume API
Source
AWS News
Published
2026-10-26T18:00:00Z
Summary
Amazon WorkSpaces Core 托管实例现已支持 ModifyVolume API，该 API 支持就地更改卷大小、卷类型、IOPS 或吞吐量，而无需分离卷或重启实例。以前，更改已部署的托管实例的存储容量或性能需要重建该实例。 利用 ModifyVolume，您可以将卷大小增加到最多 16,384 GiB，在支持的 Amazon EBS 卷类型之间切换，调整 gp3、io1 和 io2 卷的 IOPS，以及修改 gp3 卷的吞吐量。该 API 支持用于防止重复更改的幂等性令牌，您可以使用 Amazon EC2 DescribeVolumesModifications 操作跟踪进度。 ModifyVolume 已在提供 Amazon WorkSpaces Core 托管实例的所有 AWS 区域推出。 要开始使用，请直接调用 ModifyVolume，或者待 WorkSpaces Core 合作伙伴解决方案上线后通过该解决方案使用。要了解更多信息，请参阅《WorkSpaces Instances API Reference》中的 ModifyVolume 部分和《Amazon EBS User Guide》中的 Limitations 部分，或访问 WorkSpaces Core 。
