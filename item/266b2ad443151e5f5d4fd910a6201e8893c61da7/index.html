Amazon CloudWatch Logs Insights 现支持在运行查询前估算扫描的字节数
收錄來源
AWS News
發布時間（來源提供）
2026-09-29T08:00:00Z
來源摘要（原文）
Amazon CloudWatch Logs Insights 现在支持您估算查询将在所选日志组和时间范围内扫描的日志数据量（以字节为单位），而无需实际运行该查询。这可以帮助您在运行查询前调整日志组选择、时间范围和筛选条件。 在 CloudWatch 控制台中，当您更改日志组选择、时间范围或查询文本时，估算值会自动显示在查询编辑器中。使用 AWS CLI 或 API 时，请在查询中添加 estimate 命令，以显式请求预估值。使用 estimate 命令的查询不会产生 CloudWatch Logs Insights 查询费用。 estimate 命令已在所有 AWS 商业区域提供。要了解更多信息，请参阅 Amazon CloudWatch Logs 文档 。
