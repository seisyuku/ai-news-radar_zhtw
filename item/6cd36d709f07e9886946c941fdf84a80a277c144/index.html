Amazon Bedrock 现在为 Claude Haiku 5.5 提供加拿大跨区域推理服务
收錄來源

發布時間（來源提供）

來源摘要（原文）
Amazon Bedrock 现在为 Anthropic 的 Claude Haiku 5.5 提供加拿大跨区域推理（CRIS）服务。具有严格数据驻留要求的客户现在可以完全在加拿大境内进行推理处理。加拿大 CRIS 仅在 ca-central-1（加拿大中部）和 ca-west-1（加拿大西部、卡尔加里）之间路由请求。这有助于金融服务、医疗保健、公共部门和其他受监管行业的企业满足联邦和省级数据驻留要求。 加拿大 CRIS 在加拿大客户现有推理选项的基础上新增更多选择。Claude Haiku 5.5 仍然完全支持美国 CRIS 和全球 CRIS。这两种选项均将请求路由至更广泛的 AWS 区域，而全球 CRIS 还能帮助节省成本，因此对于无需将推理处理保留在加拿大境内的工作负载而言，这些选项是理想之选。 加拿大 CRIS 被指定为一种推理配置文件，其模型选择范围有限。此配置文件的未来模型和模型版本可能不会发布。对于必须在加拿大境内进行推理处理的工作负载，我们建议使用加拿大 CRIS。有关更多详细信息，请参阅 Amazon Bedrock User Guide 中的 Inference profiles with limited model selection 。 有关各区域模型可用性的最新信息，请参阅 Amazon Bedrock User Guide 中的 Regional availability 。要开始在 Amazon Bedrock 上使用 Claude 模型，请访问 Amazon Bedrock 控制台。
