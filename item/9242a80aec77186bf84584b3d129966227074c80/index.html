Title
AWS Security Hub 现在支持将资源重要性纳入优先级考量
Source
AWS News
Published
2026-10-14T01:00:00Z
Summary
如今，AWS Security Hub 将资源重要性添加到风险暴露优先级考量中，帮助中央安全团队专注于应对威胁其最重要业务资源的风险。 您可以基于自动化规则设定重要性，例如将特定账户中的所有计算资源标记为“非常重要”。该规则适用于清单中已有的资源以及 Security Hub 发现的新资源。无需任何配置，Security Hub 还可以通过资源标签和资源名称推断出重要性，并对哪个来源决定了重要程度进行记录。重要性会以列的形式显示在资源页面上，用于排序、筛选和分组，还会显示在风险暴露调查发现的影响评估选项卡中。资源重要性已包含在 Security Hub Essentials 中，无需额外付费，且对所有客户始终处于启用状态。 资源重要性已包含在 Security Hub Essentials 中，无需额外付费，也无需另行启用。要了解更多信息，请参阅 AWS Security Hub User Guide 和 AWS Security Hub 产品页面 。 有关已推出 Security Hub 的 AWS 区域的列表，请参阅 AWS 区域表 。
