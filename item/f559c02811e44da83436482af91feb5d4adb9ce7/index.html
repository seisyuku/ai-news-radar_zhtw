來源摘要（原文）
Amazon S3，包括 S3 Tables 和 S3 Vectors，现已在 Vercel Marketplace 和 v0 by Vercel 中提供。开发人员无需离开开发环境即可在几秒钟内创建和连接 S3 资源，通过 Vercel 简化的配置工作流，获得 S3 的耐久性、可扩展性和性能。 数百万客户依赖 S3 提供低成本、高性能的存储来支持 Web 和 AI 应用程序，但此前若要通过 Vercel 配置 S3，必须进入 AWS 管理控制台。现在，S3 直接集成到 Vercel 开发人员体验中，可以实现自动化处理资源预置和连接配置。您可以从 S3 通用存储桶中进行选择来满足几乎所有使用案例要求；对于针对分析工作负载进行了优化的完全托管的 Apache Iceberg 表，您可以选择 S3 Tables；也可以选择 S3 向量，以原生方式大规模存储和查询向量。 通过 Vercel 创建的新 AWS 账户包括 100 美元的服务抵扣金，有效期最长为六个月，可在 Amazon S3、Amazon OpenSearch 无服务器和 AWS Database 服务上使用。现有的 AWS 客户可以将其账户关联以将 S3 用于其 Vercel 项目。 Vercel 上的 Amazon S3 现已在 Vercel 可用的所有 AWS 区域中可用。要开始使用，请阅读 AWS 新闻博客 ， 在 Vercel Marketplace 上访问 AWS ，或启动 v0 by Vercel 。
