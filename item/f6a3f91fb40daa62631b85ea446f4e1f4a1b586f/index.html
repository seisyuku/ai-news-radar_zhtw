Amazon ECR 现在可以跨区域和账户复制映像删除操作
收錄來源
AWS News
發布時間（來源提供）
2026-11-16T22:07:00Z
來源摘要（原文）
Amazon Elastic Container Registry (Amazon ECR) 现在支持将映像删除操作和标签移除操作复制到您的复制目标。以前，ECR 复制功能会将映像复制到目标区域和账户，但不复制删除操作，需要您在每个位置单独管理删除操作。通过复制删除操作，您的目标存储库会自动与源存储库保持一致。 运行多区域或多账户架构的团队不再需要编写脚本或手动跟踪每个目标的映像清理情况。当您直接或通过生命周期策略删除映像或移除源注册表中的标签时，ECR 会将删除操作传播到复制规则中的每个目标。复制的删除操作会发出 EventBridge 事件并记录在 CloudTrail 中，因此您对删除操作的可见性与对映像推送的可见性相同。 复制删除操作的功能现已在所有提供 Amazon ECR 的 AWS 区域推出，无需额外付费。要开始使用，请在 Amazon ECR 控制台或 AWS CLI 中更新您的复制配置。有关更多信息，请参阅 Amazon ECR 用户指南 。
