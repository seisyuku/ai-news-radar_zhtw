Title
AWS 合作伙伴中心代理 MCP 服务器现已支持通过 AWS 登录进行 OAuth
Source
AWS News
Published
2026-08-20T18:02:00Z
Summary
AWS 合作伙伴现在可以通过 AWS 登录进行 OAuth，从他们已使用的工具（例如 Amazon Quick 和 Kiro）访问 AWS 合作伙伴中心代理。合作伙伴可使用其现有的 AWS 身份、登录方法、IAM 权限和监管控制向代理授予访问权限，而无需安装或维护额外的身份验证软件。 以前，AWS 合作伙伴需要使用 SigV4 凭证设置 MCP 代理，才能从其现有工具访问合作伙伴中心代理，或使用 IAM 凭证通过 AWS 管理控制台登录到 AWS 合作伙伴中心。OAuth 可让合作伙伴使用 AWS 登录来向 Amazon Quick 和 Kiro 等工具授予对合作伙伴中心代理的访问权限，从而简化这一过程。合作伙伴可在其现有工具中使用 OAuth 完成协同销售互动、AWS 融资申请和 AWS Marketplace 卖家设置。管理员可使用 IAM 策略、全局条件键、令牌自省和撤销 API、动态客户端注册以及 CloudTrail 审计事件来控制访问权限。 OAuth 支持已通过 AWS 合作伙伴中心代理 MCP 服务器向 AWS 合作伙伴推出，该服务器在美国东部（弗吉尼亚州北部）区域提供。要了解更多信息，请访问 开始使用合作伙伴中心代理 MCP 服务器 和 使用 OAuth 2.0 进行登录 。
