Title
AWS Clean Rooms 现在支持 Databricks 作为数据来源
Source
AWS News
Published
2026-10-20T12:23:00Z
Summary
AWS Clean Rooms 现在支持 Databricks 作为数据来源 ，因此协作成员及其合作伙伴可以安全地分析在 Databricks 中管理的数据，而无需移动或泄露源数据。成员可直接在协作中查询通过 Delta Sharing 共享的 Databricks 表。Databricks 已加入 AWS Glue、Snowflake 和 Amazon Athena 的行列，成为 AWS Clean Rooms 中支持的数据来源。 以前，在 Databricks 中拥有数据的成员必须将其导出或复制到 Amazon S3 中才能在协作中将其用作表，这不仅增加了管道工作，还产生了一份需要治理的额外数据副本。现在，成员可以通过提供工作区 URL、架构和表以及 Delta Sharing 共享来直接注册 Databricks 表，并将其提供给协作。例如，在 Databricks 中管理其客户数据的零售商可以与媒体合作伙伴合作，在 AWS Clean Rooms 中进行广告活动效果衡量，对其 Databricks 数据进行经批准的分析，而无需先构建和维护向 S3 的导出。 AWS Clean Rooms 可以帮助公司及其合作伙伴轻松地分析他们的汇总数据集并进行协作，而无需透露或复制彼此的底层数据。有关提供 AWS Clean Rooms 的 AWS 区域的更多信息，请参阅 AWS 区域 表。要了解有关通过 AWS Clean Rooms 进行协作的更多信息，请访问 AWS Clean Rooms 。
