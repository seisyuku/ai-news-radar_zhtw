AWS Security Hub CSPM 现在支持使用 AWS Organizations 声明性策略进行集中配置
收錄來源
AWS News
發布時間（來源提供）
2026-11-13T08:00:00Z
來源摘要（原文）
AWS Security Hub CSPM 现在支持 AWS Organizations 声明性策略。您可以使用它们在组织的所有账户和区域中启用 Security Hub CSPM，并定义启用哪些安全标准和控制措施。 策略可以宽泛应用于所有账户和区域，也可以定向应用于特定的账户和区域组合。声明性策略有助于让每个账户的配置与其所附加的策略保持一致，从而防止配置漂移。您还可以将它们自动应用于新账户，让每个账户在创建时即具备基准配置。 声明性策略现已成为在组织内部管理 Security Hub CSPM 的推荐方式。这与其他安全服务（如 Amazon GuardDuty、Amazon Inspector 和 AWS Security Hub）让客户管理服务配置的方式一致。它们还提供了更大的灵活性，例如配置特定于区域的设置。在准备好迁移之前，您可以继续使用集中配置。准备好后，请使用 Security Hub CSPM 控制台中的迁移流程。该流程会将您现有的集中配置策略转换为声明性策略，并将其应用于相应的账户和区域。 适用于 Security Hub CSPM 的声明性策略已在所有商业区域、AWS GovCloud（美国）区域和中国区域推出。要开始使用，请参阅 迁移中心配置策略 。要了解更多信息，请参阅《AWS Security Hub CSPM 用户指南》中的 声明性策略 和《AWS Organizations 用户指南》中的 Security Hub CSPM 策略 。要接收有关 Security Hub CSPM 的新功能和控制的通知，请订阅 Security Hub SNS 主题 。您还可以 免费试用 Security Hub CSPM 30 天 ，此服务包含在 AWS 免费套餐中。
