Title
AWS 终端用户消息发送服务新增用于 RCS 注册视频的引导式向导
Source
AWS News
Published
2026-10-16T07:00:00Z
Summary
今天，AWS 终端用户消息发送服务新增一个向导，可以为您的 RCS 智能体注册统筹完成整个视频采集。包括美国在内的多个国家/地区的注册 RCS，要求提交录屏，用于展示您的消息发送服务体验。要进行录制，您必须向测试设备发送一组按特定顺序排列的消息。此前，您需要自行编写这些消息的脚本，极易出错。视频不匹配或不完整也成为了注册 RCS 的一大难点。 现在，该向导会为您完成视频采集的每一个步骤，按正确的顺序发送正确的消息，使您可以一次性录制合规视频并尽快让智能体获得批准。所有需要提交视频的 RCS 注册表单上都有该向导。 要了解更多信息并开始使用，请参阅 AWS 终端用户消息发送服务 用户指南 。
