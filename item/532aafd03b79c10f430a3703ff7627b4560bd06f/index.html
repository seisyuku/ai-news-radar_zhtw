Amazon MWAA 无服务器中提供 Apache Airflow UI
收錄來源

來源摘要（原文）
Amazon MWAA 无服务器为您的工作流程提供原生 Apache Airflow UI。您可以浏览工作流程、检查工作流程运行和任务实例、读取任务日志、查看工作流程的源代码和版本以及启动工作流程运行。该 UI 使用打开它的 IAM 身份所具有的权限，并且仅显示该身份可以读取的内容，因此可以实现只读访问。AWS CloudTrail 会记录该 UI 以您的身份进行的调用。 您可以从 Amazon MWAA 控制台、AWS CLI 或 API 打开 Airflow UI。已经熟悉 Airflow 的团队可以使用他们熟悉的界面来处理其工作流程。 此功能已在提供 Amazon MWAA 无服务器的所有 AWS 区域推出。有关更多信息，请参阅 AWS 区域表 。 要开始使用，请参阅 访问 Airflow UI 。Apache Airflow 是 Apache Software Foundation 的商标。
