Title
Amazon EC2 R8a 实例现已在加拿大（中部）区域推出
Source
AWS News
Published
2026-08-11T22:03:00Z
Summary
即日起，Amazon EC2 R8a 实例已在加拿大（中部）区域推出。此类实例搭载第五代 AMD EPYC 处理器（原代号为 Turin），最高频率达 4.5 GHz，与 R7a 实例相比，不仅性能提升高达 30%，性价比也提升高达 19%。 与 R7a 实例相比，R8a 实例的内存带宽提高了 45%，这使得这些实例非常适合延迟敏感型工作负载。与 Amazon EC2 R7a 实例相比，R8a 实例将 GroovyJVM 的性能提升高达 60%，从而为关键业务应用程序提供更高的请求吞吐量和更短的响应时间。 R8a 实例基于 AWS Nitro System 构建，采用第六代 Nitro 卡，非常适合高性能、内存密集型工作负载，例如 SQL 和 NoSQL 数据库、分布式 Web 级内存缓存、内存数据库、实时大数据分析和电子设计自动化（EDA）应用程序。R8a 实例提供 12 种大小，包括 2 种裸机大小。Amazon EC2 R8a 实例已通过 SAP 认证，与 R7a 实例相比，提供的 SAPS 增加了 38%。 要开始使用，请登录 AWS 管理控制台 。有关新实例的更多信息，请访问 Amazon EC2 R8a 实例页面 。
