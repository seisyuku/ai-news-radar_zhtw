AWS 登录现已支持 OAuth 2.0 令牌交换
收錄來源

發布時間（來源提供）

來源摘要（原文）
AWS 登录现已支持 OAuth 2.0 令牌交换（RFC 8693），使应用程序能够将第三方 OpenID Connect（OIDC）令牌交换为短期的、限定 AWS 服务范围的 OAuth 访问令牌。这样一来，客户便能将第三方应用程序与受支持的 AWS 服务安全集成，而无需共享 AWS 凭证，同时通过 AWS Identity and Access Management（IAM）保持访问控制。 此功能适用于受支持的 使用 AWS 登录的 AWS 服务 ，使客户能够使用现有身份提供商来安全访问 AWS 服务，而无需管理其他凭证。 要了解更多信息 ，请参阅 AWS 登录用户指南 、 AWS MCP 服务器用户指南 和 AWS Glue 发布公告 。
