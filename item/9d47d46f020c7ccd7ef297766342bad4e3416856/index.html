Amazon CloudWatch Omni 现已在更多 AWS 区域推出

來源摘要（原文）
AWS 宣布 Amazon CloudWatch Omni 现已在另外八个 AWS 区域推出。CloudWatch Omni 是一种由 AI 驱动的可观测性体验，以您的团队及其运行的应用程序为核心，帮助您在同一位置观测应用程序与智能体并进行问题排查。它融合了 OpenTelemetry 的互操作性与 CloudWatch 的规模能力及可靠性，贴合您的工作场景：支持单点登录（SSO）的独立 Web 体验，或是本地 IDE 扩展。 借助 CloudWatch Omni，您可以在中央账户中创建空间，以便查看跨 AWS 账户、区域和其他云环境（包括 Azure 和 GCP）的遥测数据。Omni 可以自动发现服务、映射依赖关系并显示黄金指标，依托 AWS DevOps 智能体，您可通过聊天交互、点击操作，或是借助 Agent Toolkit for AWS 调用自有工具，与遥测数据交互，以挖掘信号、构建动态视图和定位根本原因。专门的智能体可观测性体验增加了针对各种框架（包括 LangGraph、CrewAI、OpenAI Agents SDK、Vercel AI SDK 和 Strands）的评估驱动型工作流。 完成本次区域扩展后，除已推出 CloudWatch Omni 的美国东部（弗吉尼亚州北部）、美国西部（俄勒冈州）、欧洲地区（爱尔兰）区域外，该服务现已在以下新增区域推出：加拿大（中部）、亚太地区（孟买）、亚太地区（新加坡）、亚太地区（悉尼）、亚太地区（东京）、欧洲地区（法兰克福）、欧洲地区（伦敦）、南美洲（圣保罗）区域。 要开始使用，请从 CloudWatch 控制台创建您的 Omni 空间，配置 SSO，然后登录。智能体开发者可以安装免费的 适用于 VS Code、Cursor 和 Kiro 的 CloudWatch Omni 扩展 。要了解更多信息，请参阅 Amazon CloudWatch Omni 产品页面 和 文档 。有关定价，请参阅 CloudWatch Omni 定价页面 。
