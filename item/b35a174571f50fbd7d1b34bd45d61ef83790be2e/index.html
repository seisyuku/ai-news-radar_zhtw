Amazon RDS for MySQL 26.10 现已在 Amazon RDS 数据库预览环境中推出
收錄來源

來源摘要（原文）
从今天起， Amazon RDS for MySQL 26.10 已在 Amazon RDS 数据库预览环境 中推出，允许您在 Amazon RDS for MySQL 上评估 MySQL 26.10 的预发布版本。 MySQL 26.10 包括错误修复、安全补丁以及对 READ COMMITTED 工作负载性能和错误日志中清理延迟警告的一些改进。在繁忙的 READ COMMITTED 工作负载下，NUMA 系统的性能可能会受到影响，因为每个关闭的读取-查看都需要一个全局互斥锁。读取-查看对象现在可以重复使用，这消除了关闭时的全局互斥锁。现在，当历史列表长度（HLL）超过 innodb_max_purge_lag 时，以及当清理延迟开始影响 DML 操作时，错误日志会报告警告，这样您就可以在清理积压影响性能之前及时发现它们。要了解更多信息，请参阅 MySQL 26.10 发行说明 。 Amazon RDS 数据库预览环境数据库实例最长保留 60 天，保留期过后将自动删除。在 Preview Environment 中创建的 Amazon RDS 数据库快照只能用于在 Preview Environment 内创建或恢复数据库实例。Amazon RDS 数据库预览环境数据库实例的定价与美国东部（俄亥俄州）区域的 定价 一致。
