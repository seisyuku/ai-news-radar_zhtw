OpenAI GPT-6.1 Terra 现已在 Amazon Bedrock 上正式推出

來源摘要（原文）
今天，AWS 宣布在 Amazon Bedrock 上正式推出 OpenAI GPT-6.1 Terra。GPT-6.1 Terra 扩展了 GPT-6 系列，性能、速度和成本效益之间实现了平衡，可满足日常工作负载的需求。 作为 Terra 系列的最新模型，GPT-6.1 Terra 融合了详细的视觉推理、准确的计算机使用以及相比 GPT-5.6 Terra 更强的事实性和自然写作能力，适用于复杂工作流。在 OpenAI 的 Agents’ Last Exam 评估中，它的得分比 GPT-5.6 Terra 高出 15 个百分点，表现与 GPT-6 Astra 相当，完成任务的速度比 GPT-6 Astra 和 GPT-6.1 Sol 快了三倍以上。GPT-6.1 Terra 提供了均衡的性能，且输入和输出令牌价格比 GPT-6.1 Sol 和 GPT-5.6 Terra 低至少 50%。它支持最多 100 万个输入令牌的上下文窗口，并接受文本和图像输入。Amazon Bedrock 推理引擎提供企业工作负载所需的性能、安全性和规模。 您可以通过 Amazon Bedrock API 直接调用 GPT-6.1 Terra，也可以配置 ChatGPT Work 和 Codex 以在 Amazon Bedrock 上使用该模型。使用它来起草提案、解释技术图纸、调查代码库以及构建跨业务系统运行的智能体。 完善的 AWS 控制措施可帮助您保护工作负载、管理访问权限和审计模型调用活动。 您可以在 Amazon Bedrock 控制台中或通过受支持的 Amazon Bedrock API 以编程方式开始使用。有关受支持的 AWS 区域、端点、API、功能、推理配置文件和定价的信息，请参阅 Amazon Bedrock 文档 。
