Amazon Aurora 和 Amazon RDS 现在支持按需容量预留
收錄來源
AWS News
發布時間（來源提供）
2026-10-21T17:00:00Z
來源摘要（原文）
即日起，您可以在一个或多个可用区中为 Amazon Aurora 和 Amazon RDS 数据库实例预留计算容量，预留时长可按需设置。预留容量有助于确保数据库实例的创建、恢复、扩展计算和启动操作不会因为容量不足而失败。 有些工作负载需要确保特定数据库实例容量在业务关键型事件（如迁移、产品发布、季节性高峰、高可用性部署或灾难恢复）时可用，按需容量预留正是为这类工作负载设计的。您选择数据库实例类别、引擎、可用区和每个可用区的预留容量，RDS 将为您保留该容量。可以在两个或更多可用区中预留容量以支持多可用区部署。要使用预留容量，请在创建、恢复、修改或启动数据库实例时引用该预留。 您可以预留立即可用的容量，无需任何承诺且可以随时取消，也可以安排在未来 5 到 120 天内开始的预留，但需设定最低承诺期限。在预留有效期间内，无论预留中的数据库实例是否在运行，预留容量均按按需费率计费。现有预留数据库实例或数据库节省计划的折扣将自动生效。 按需容量预留已在所有 AWS 商业区域支持 Amazon Aurora 和 Amazon RDS 。要了解有关按需容量预留的更多信息，请访问 Amazon Aurora 和 Amazon RDS 的文档。
