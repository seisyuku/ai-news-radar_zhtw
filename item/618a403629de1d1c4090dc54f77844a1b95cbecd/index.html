Title
Amazon EFS 现已在 AWS GovCloud（美国）区域支持跨账户复制
Source
AWS News
Published
2026-07-29T12:00:00Z
Summary
Amazon EFS 现已在 AWS GovCloud（美国）区域中支持跨账户复制，让客户能够在不同的 AWS 账户之间复制文件系统。EFS 复制让您能够轻松地在您选择的 AWS GovCloud（美国）区域维护文件系统的最新副本。这项功能推出后，使用 EFS 复制功能的客户可以自动将文件数据保存在不同账户中，从而满足业务连续性、多账户灾难恢复和合规性要求。 客户通常使用多个 AWS 账户来帮助隔离和管理业务应用程序和数据，以实现卓越运营、安全性和可靠性。从今天开始，您可以使用 EFS 复制功能将文件系统复制到任何 AWS GovCloud（美国）区域中的另一个账户。这样一来，您无需设置自定义流程来跨账户同步 EFS 数据，从而提高了分布式环境中的弹性和可靠性。 要了解更多信息，请访问 Amazon EFS 文档 ，并使用 Amazon EFS 控制台 、AWS CLI、AWS CloudFormation 和 API 通过几次单击开始配置 EFS 复制。
