Title
Amazon S3 现已支持 FIPS 端点使用 PrivateLink
Source
AWS News
Published
2026-09-03T04:00:00Z
Summary
Amazon S3 现在支持已通过美国联邦信息处理标准（FIPS）140-3 计划验证的端点使用 AWS PrivateLink。 具有安全性和合规性要求的客户可以在连接到 S3 时使用经 FIPS 验证的加密模块，同时将流量保持在其 Virtual Private Cloud（VPC）内。要开始使用，请为 S3 创建新的或编辑现有的接口 VPC 端点，并将其配置为使用 FIPS S3 端点。 AWS PrivateLink 对 FIPS S3 端点的支持现已在 AWS 美国东部（弗吉尼亚州北部）、美国东部（俄亥俄州）、美国西部（北加利福尼亚）、美国西部（俄勒冈州）、加拿大（中部）、加拿大西部（卡尔加里）和 AWS GovCloud（美国）区域提供，不额外收取费用。要了解更多信息，请访问 通过 AWS PrivateLink 访问 AWS 服务 、 FIPS 140-3 合规性 和 S3 文档 。
