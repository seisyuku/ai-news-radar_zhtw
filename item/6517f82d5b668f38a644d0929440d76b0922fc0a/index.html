Title
AWS Security Hub Extended 将供应链安全设为其第 10 个安全类别
Source
AWS News
Published
2026-08-04T19:14:00Z
Summary
AWS Security Hub Extended 计划现将供应链安全设为其第 10 个安全类别，Chainguard 和 Socket 作为精选合作伙伴。随着开发人员大规模采用开源库，安全团队需要确保进入其环境的软件包可信且不含恶意代码。借助此项新增能力，您可在恶意依赖项构建至应用程序之前完成检测与拦截；它与其他所有 Extended 类别一样，支持简化激活流程并采用即用即付定价模式。至此，Extended 计划的精选合作伙伴解决方案已达 23 个。所有解决方案都在单个 AWS 账单上，无需长期承诺。 Security Hub Extended 是 AWS Security Hub 内的一项计划，可帮助您简化跨端点、身份、电子邮件、网络、数据、浏览器、云、AI、安全运营和供应链领域，采购、部署和集成全栈企业安全解决方案的流程。来自所有参与解决方案的安全调查发现均以开放网络安全架构框架（OCSF）格式输出，并自动汇总到 AWS Security Hub 中。借助 Extended 计划，您可以将 AWS 与精选合作伙伴解决方案相结合，快速识别并响应跨边界的风险。 我们将根据客户反馈，持续扩展 Extended 计划。现在，这两种新增的精选合作伙伴解决方案已在提供 Security Hub 的所有 AWS 商业区域推出。要查看受支持的区域的列表，请参阅 AWS 区域表 。 有关定价的更多信息，请访问 AWS Security Hub 定价页面 。要开始使用，请访问 AWS Security Hub 控制台 或 产品页面 。
