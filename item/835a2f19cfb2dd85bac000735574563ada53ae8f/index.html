Amazon MWAA 无服务器现已支持自定义运算符和提供商包运算符

來源摘要（原文）
Amazon MWAA 无服务器现已支持 Apache Airflow 提供商包中的运算符（例如 HTTP、Snowflake 或 dbt），以及您编写的自定义运算符。这可让数据工程师灵活地集成多个系统，并构建专用工作流任务，而无需预置基础设施。 要开始使用，请将提供商包或您自己的运算符添加到代码包中，将其上传到 Amazon S3，并在创建或更新工作流时在工作流定义中引用该运算符。 此功能已在提供 Amazon MWAA 无服务器的所有 AWS 区域推出。有关受支持区域的列表，请参阅 Amazon MWAA 无服务器区域 。要了解更多信息，请参阅《Amazon MWAA 无服务器用户指南》中的 使用 Python、Bash 和自定义运算符运行自定义代码 。
