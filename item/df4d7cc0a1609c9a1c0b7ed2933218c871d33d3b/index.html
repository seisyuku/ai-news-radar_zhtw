Title
Amazon OpenSearch UI 现支持网络访问控制
Source
AWS News
Published
2026-08-06T18:16:00Z
Summary
Amazon OpenSearch Service 现在支持对 OpenSearch UI 应用程序进行网络访问控制。OpenSearch UI 是一项完全托管的 Web 服务，可跨多个 AWS 数据来源实施搜索、分析和统一可观测性。借助网络访问控制功能，您可以使用与 AWS 其他服务相同的 IAM 条件键（aws:SourceVpce、aws:SourceVpc 和 aws:SourceIp），将对 OpenSearch UI 应用程序的访问限制在已获批准的网络范围内，从而帮助您在整个环境中建立一致的数据边界。 您可以在三个层面实施网络限制：针对特定主体的基于身份的策略、用于控制用户通过端点访问哪些应用程序的 VPC 端点策略，以及用于在 AWS 组织内的每个账户中统一实施访问的资源控制策略（RCP）。借助 RCP，您可以在网络外用户通过身份验证之前将其拦截，从而防止企业网络或 VPC 外部的任何人访问登录页面。 网络访问控制功能已在提供 OpenSearch UI 的所有 AWS 区域推出。要了解更多信息，请参阅《Amazon OpenSearch Service 开发人员指南》 中的 限制对 OpenSearch UI 应用程序的网络访问 。有关 Amazon OpenSearch Service 的更多信息，请参阅 Amazon OpenSearch Service 产品页面。
