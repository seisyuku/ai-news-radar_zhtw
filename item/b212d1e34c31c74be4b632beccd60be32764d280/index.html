Title
Amazon WorkSpaces 现已支持嵌套虚拟化
Source
AWS News
Published
2026-08-18T08:00:00Z
Summary
Amazon WorkSpaces 现已支持 Amazon WorkSpaces 个人版和 Amazon WorkSpaces Core 托管捆绑包的嵌套虚拟化。启用嵌套虚拟化后，开发人员可以直接在其 Windows WorkSpaces 上运行 Docker Desktop、Windows Subsystem for Linux（WSL2）以及其他依赖虚拟机监控程序的工具，同时可在 Linux WorkSpaces 上运行基于 KVM 的工作负载、Android 模拟器与嵌套容器，无需配置独立的物理硬件或构建变通环境。 附带许可（公共和自定义）的捆绑包、自带许可（BYOL）捆绑包以及自带协议（BYOP）捆绑包均支持嵌套虚拟化，这些捆绑包在 Windows Server 2019、Windows Server 2022、Windows Server 2025、Windows 11、Ubuntu 22.04、Ubuntu 24.04、Red Hat Enterprise Linux 8、Red Hat Enterprise Linux 9、Rocky Linux 8 或 Rocky Linux 9（采用 DCV 协议）上运行。建议使用 Power（4 个 vCPU）或更高规格的捆绑包。GPU 捆绑包、PCoIP 协议或基于 Windows Server 2016 和 Windows 10 的 Amazon WorkSpaces 不支持嵌套虚拟化。管理员可以通过控制台、API 或 CLI 在单个工作区级别启用或禁用嵌套虚拟化。 您可以通过控制台或 CLI 在 WorkSpaces 上启用嵌套虚拟化来开始使用。有关更多信息，请访问有关 嵌套虚拟化 的 Amazon WorkSpaces 文档。嵌套虚拟化已在提供 Amazon WorkSpaces 的所有 AWS 区域推出，但中国（宁夏）区域和以色列（特拉维夫）区域除外。有关定价信息，请访问 Amazon WorkSpaces 定价页面 。
