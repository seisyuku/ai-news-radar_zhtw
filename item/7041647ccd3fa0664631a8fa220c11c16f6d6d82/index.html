Title
Amazon Time Sync Service 新增对所有商业区域中另外 135 个 EC2 实例类型的微秒级精确时间的支持
Source
AWS News
Published
2026-10-15T17:34:00Z
Summary
Amazon Time Sync Service 新增对所有商业区域中另外 135 个 EC2 实例类型（涵盖 12 个实例系列）的微秒级精确时间的支持。建立在 Amazon 成熟的网络基础设施和 AWS Nitro System 之上，微秒级精确时间和纳秒级精确硬件时间戳直接利用 Nitro System 中运行的参考时钟，使客户能够轻松地对应用程序事件进行排序、衡量单向网络延迟并提高分布式应用程序事务速度。 新支持的系列包括八个第八代系列（C8a、C8i、C8i-flex、C8id、M8i、M8i-flex、R8a 和 X8i）和四个第九代系列（C9g、C9gd、M9g 和 M9gd）。 即日起，客户可以通过创建精确时间置放群组（PTPG）来访问这些额外实例类型的微秒级精确时间，该群组是一种新的置放策略，允许客户启动启用了精确时间协议硬件时钟（PHC）的实例。既需要低网络延迟又需要精确时间的客户，可以将 PTPG 与其集群置放群组（CPG）关联起来，这样他们的低延迟工作负载也能受益于微秒级精确时间。 有关更多信息，请参阅 Amazon Time Sync Service 文档 。
