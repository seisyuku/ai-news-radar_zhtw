Title
Amazon RDS for MySQL 在 Amazon RDS 数据库预览环境中支持 MySQL 9.7
Source
AWS News
Published
2026-07-23T18:05:00Z
Summary
Amazon RDS for MySQL 现已在 Amazon RDS 数据库预览环境 中支持社区版 MySQL 9.7，让您能够在 Amazon RDS for MySQL 上评估最新版本。此预览环境提供了一个沙盒，您可以在其中测试应用程序并在新的 MySQL 9.7 功能正式发布之前深入了解相关内容。 MySQL 9.7 是社区 MySQL 最新的长期支持版本。MySQL 长期支持版本包括错误修复、安全补丁以及新功能。有关此版本的更多详情，请参阅 MySQL 9.7 发行说明 。 Amazon RDS 数据库预览环境数据库实例最长保留 60 天，并在保留期过后自动删除。在预览环境中创建的 Amazon RDS 数据库快照只能用于在预览环境内创建或还原数据库实例。Amazon RDS 数据库预览环境数据库实例的 价格与在美国东部（俄亥俄州）区域创建的生产 RDS 实例相同 。有关更多信息，请参阅 使用数据库预览环境 。
