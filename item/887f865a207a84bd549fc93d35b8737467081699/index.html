Amazon Connect Customer 现在可在联系记录中显示关联案例

來源摘要（原文）
Amazon Connect Customer 现在可在联系记录中包含案例 ID 和参考编号，帮助主管和分析师了解是哪些客户问题导致了联系量上升。案例可跨交互和团队跟踪问题，例如退款申请或账单争议。主管现在可以直接在“联系详细信息”页面上识别与某次交互关联的案例，而无需逐个搜索案例。分析师可以通过 DescribeContact API 和联系事件流获取同样的信息，以衡量每个案例的交互次数。 案例功能已在以下 AWS 区域推出：美国东部（弗吉尼亚州北部）、美国西部（俄勒冈州）、加拿大（中部）、欧洲地区（法兰克福）、欧洲地区（伦敦）、亚太地区（首尔）、亚太地区（新加坡）、亚太地区（悉尼）、亚太地区（东京）和非洲（开普敦）。要了解更多信息并开始使用，请访问案例 网页 和 文档 。
