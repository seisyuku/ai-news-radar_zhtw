來源摘要（原文）
Amazon Relational Database Service （RDS）for PostgreSQL 宣布推出 Amazon RDS 延长支持次要版本 13.23-rds.20260514、12.22-rds.20260514 和 11.22-rds.20260514。 Amazon RDS 延长支持 可在主要版本的标准支持终止日期之后，额外提供最多三年的严重常见漏洞和披露（CVE）及错误修复，让您有更多时间升级到新的主要版本。 您可以使用 Amazon RDS 蓝绿部署 、就地升级或从快照还原来升级数据库。有关执行版本升级的更多信息，请参阅 Amazon RDS for PostgreSQL 用户指南 。 Amazon RDS for PostgreSQL 让您能够在云中轻松设置、运行和扩展 PostgreSQL 部署。在 Amazon RDS 管理控制台 中或使用 AWS 命令行界面（AWS CLI）创建或更新完全托管式 Amazon RDS 数据库。
