來源摘要（原文）
Amazon Textract 现已在亚太地区（东京）和欧洲（苏黎世）区域推出。Amazon Textract 是一项机器学习服务，可以从扫描的文档中自动提取文本、手写字和数据。它不是简单的光学字符识别（OCR），而是可以识别和提取文本以及结构化数据。 在这些区域推出时，Amazon Textract 支持文本检测和文档分析。这包括 DetectDocumentText、AnalyzeDocument、StartDocumentTextDetection、GetDocumentTextDetection、StartDocumentAnalysis 和 GetDocumentAnalysis 操作。目前，这些区域暂不支持 AnalyzeExpense、AnalyzeID 和 AnalyzeLending 操作以及自定义查询（适配器）。 此次发布后，Amazon Textract 已在共 18 个 AWS 区域推出：美国东部（俄亥俄州）、美国东部（弗吉尼亚州北部）、美国西部（北加利福尼亚）、美国西部（俄勒冈州）、亚太地区（孟买）、亚太地区（首尔）、亚太地区（新加坡）、亚太地区（悉尼）、加拿大（中部）、欧洲地区（法兰克福）、欧洲地区（爱尔兰）、欧洲地区（伦敦）、欧洲地区（巴黎）、欧洲（西班牙）、AWS GovCloud（美国东部）和 AWS GovCloud（美国西部），以及新增的亚太地区（东京）和欧洲（苏黎世）。 要了解更多信息，请参阅 Amazon Textract 产品页面 和 Amazon Textract Developer Guide 。有关定价和区域可用性，请参阅 Amazon Textract 定价页面 和 Amazon Textract endpoints and quotas 。
