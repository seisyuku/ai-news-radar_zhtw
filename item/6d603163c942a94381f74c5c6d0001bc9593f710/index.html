Title
Amazon EC2 C9g、C9gd、M9g 和 M9gd 实例现已在更多区域推出
Source
AWS News
Published
2026-10-09T21:00:00Z
Summary
即日起，Amazon Elastic Compute Cloud（Amazon EC2）C9g 和 C9gd 实例在亚太地区（马来西亚、首尔、新加坡）区域推出。Amazon EC2 M9g 和 M9gd 实例在亚太地区（马来西亚）和欧洲（西班牙）区域推出。这些实例由 AWS Graviton5 处理器（第五代定制款 CPU）提供支持，可为运行在 Amazon EC2 上的广泛工作负载提供超高性价比。 与基于 AWS Graviton4 的 C8g、C8gd、M8g 和 M8gd 实例相比， C9g 和 C9gd 实例 以及 M9g 和 M9gd 实例 的计算性能最多可提高 25%。这些实例的数据库性能最高可提升 30%，Web 应用程序性能最高可提升 35%，机器学习性能提升最高可提升 35%。这些实例建立在第六代 AWS Nitro System 之上，是率先采用 Nitro Isolation Engine 的实例。Isolation Engine 利用形式验证提供数学确定性，即客户工作负载彼此之间互相隔离，并且工作负载与 AWS 操作人员之间也互相隔离，开创了经数学验证的云安全性新标准。 C9g 实例是包括高性能计算（HPC）、批处理、游戏、视频编码、科学建模、分布式分析、基于 CPU 的机器学习（ML）推理、实时分析和广告投放等在内的计算密集型工作负载的理想之选。M9g 实例适用于广泛的通用工作负载，包括应用程序服务器、微服务、游戏、缓存和容器。它们还提供智能体人工智能使用案例（例如实时推理、代码生成和多步编排）所需的性能。C9gd 和 M9gd 实例为需要高速、低延迟本地存储来存储暂存空间、临时文件和缓存的工作负载增加了基于 NVMe 的本地 SSD 块级存储。 C9g、C9gd、M9g 和 M9gd 实例可在这些区域通过节省计划、按需实例、竞价型实例、专用实例或专属主机进行购买。 利用 AWS Graviton 提升计算能力 ，立即开始使用 C9g 和 M9g ！
