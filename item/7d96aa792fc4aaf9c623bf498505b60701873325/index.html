Amazon WorkSpaces Applications 推出统一图形映像
收錄來源
AWS News
發布時間（來源提供）
2026-09-29T17:00:00Z
來源摘要（原文）
今天，Amazon WorkSpaces Applications 宣布推出统一图形映像，这是一种单一映像类型，适用于所有受支持的图形实例系列，包括 G4dn、G5、G6 和 G7。此前，每一代图形实例都需要各自专用的映像。现在，客户可以使用一个映像在任意受支持的图形实例系列上创建和管理实例集。 统一图形映像简化了映像管理，并让客户能够更轻松地在新一代 GPU 推出后予以采用。使用统一图形映像创建实例集时，控制台会显示所有兼容的实例类型，因此您可以为工作负载选择合适的价格和性能。基于统一图形映像构建的实例集还可以使用控制台或 UpdateFleet API 在受支持的系列之间切换实例类型，而此前该操作仅限于单个实例系列内的规格。 统一图形映像已在支持 Amazon WorkSpaces Applications 图形实例的所有 AWS 商业区域以及 AWS GovCloud（美国）区域提供。 要开始使用，请通过托管映像更新升级现有图形映像，或从统一基础映像启动映像生成器。要了解更多信息，请访问 Amazon WorkSpaces Applications 文档 。
