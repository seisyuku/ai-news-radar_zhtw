來源摘要（原文）
Bedrock 托管代理（BMA）由 AWS 与 OpenAI 联合开发，基于 OpenAI Agents API 的定制版本构建，该版本专为 AWS 原生环境设计，并与 AWS 资源集成。 现在，您可以构建针对 OpenAI 模型进行优化的代理，这些代理完全在 AWS 内部运行，并使用您现有的身份、权限和治理控制措施。 BMA 负责管理模型如何保存状态、选择和使用工具、执行代码，以及在多个步骤和决策之间协调工作。持久会话会保留消息、工具调用和中间结果，因此您可以稍后返回，提供新信息，并基于已取得的进展继续推进。您可以为特定流程添加可重用的技能，并将代理与工具连接起来，包括通过模型上下文协议（MCP）服务器进行连接。每个代理都使用自己的 IAM 角色运行，支持在执行重要操作前进行人工审批，并通过 AWS CloudTrail 记录受支持的 API 活动。 在预览期间，除代理消耗的基础 AWS 资源外，BMA 不收取额外费用。正式发布后，定价可能会发生变化。 立即通过受支持的 API 开始使用 Amazon Bedrock 托管代理。BMA 现已在美国东部（弗吉尼亚州北部）、美国西部（俄勒冈州）和美国东部（俄亥俄州）推出预览版。有关详细信息，请参阅 Amazon Bedrock 文档 。
