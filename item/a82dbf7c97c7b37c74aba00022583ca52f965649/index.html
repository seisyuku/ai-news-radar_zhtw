AWS Backup 新增对 Amazon Redshift 的还原测试支持
收錄來源

發布時間（來源提供）

來源摘要（原文）
AWS Backup 还原测试现在支持 Amazon Redshift。还原测试可帮助您自动化并定期运行备份的还原测试，以便您确认 Amazon Redshift 备份能否成功还原，并衡量还原所需的时间。 现在，您可以将 Amazon Redshift 与存储、计算和数据库服务中其他支持的 AWS 资源一起纳入还原测试计划。还原测试计划会自动选择恢复点，按计划运行还原操作，并根据恢复时间目标（RTO）衡量还原作业完成时间。这可帮助您评估恢复准备情况，满足相应的法规和合规性要求，以实现灾难恢复和业务连续性。 要开始使用，请创建还原测试计划并按 Amazon 资源名称（ARN）或标签分配您的 Amazon Redshift 资源。选择每项测试是还原到最新的恢复点还是随机还原到符合条件的恢复点。此外，还可以使用还原测试验证功能，在 AWS Backup 删除测试资源之前确认已还原的资源。 此支持已在 AWS Backup 支持还原测试和 Amazon Redshift 的所有 AWS 区域推出。您可以访问 AWS Backup 控制台、AWS 命令行界面（CLI）或 AWS SDK。有关受支持的区域和功能的完整列表，请访问 AWS Backup 文档 。要了解有关还原测试的更多信息，请访问 产品页面 和 定价页面 。
