來源摘要（原文）
Kiro Web 搜索功能使智能体能够实时获取互联网上的最新信息，确保其回答基于最新的搜索结果和网页内容。当问题涉及近期变化或超出模型训练数据范围的主题时，智能体会自动使用 Web 搜索功能。包含 Web 搜索结果的答案附有引用来源。 Kiro 企业管理员可以从 Kiro 控制台的“设置”下关闭其企业的 Web 搜索和 Web 提取功能。团队还可以从单个自定义智能体中移除 Web 工具，或使用基于功能的权限规则屏蔽它们。 如需了解更多详情，请访问 AWS GovCloud（美国）文档 、 监控和跟踪指南 ，或联系您的 AWS 客户团队。要了解有关 Kiro 的更多信息，请参阅 Kiro 产品页面 。
