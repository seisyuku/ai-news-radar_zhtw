來源摘要（原文）
AWS 宣布正式推出 Amazon Bedrock AgentCore CLI 版本 1.0（@aws/agentcore 1.0.0）；该版本经过重新构建，启动速度更快，命令结构更加一致，并支持更多的 AgentCore 资源。CLI 可帮助开发人员从终端创建、开发、部署和操作智能体及支持的资源。 借助版本 1.0，开发人员可以使用项目工作流，也可以直使用执行框架、运行时、记忆、身份、网关和支付功能，而无需先将它们添加到项目中。开发人员可以通过 ID 或 ARN 调用现有资源、打开交互式 Shell、导出执行框架以及使用可搜索菜单、资源选择器和引导式工作流。一致的全局标签可在各项命令中提供区域选择、JSON 输出、调试和版本信息。 可以使用 agentcore 迁移命令将现有项目迁移到 AgentCore 版本 1。 从 npm 安装 AgentCore CLI 版本 1.0，或在 GitHub 上查看源代码。要了解更多信息，请访问 Amazon Bedrock AgentCore 产品页面 、 AgentCore CLI 参考 和 Amazon Bedrock AgentCore 入门 。
