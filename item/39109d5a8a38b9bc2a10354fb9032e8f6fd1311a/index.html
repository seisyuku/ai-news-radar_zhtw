Title
Amazon Location Service 现已在东南亚为 GrabMaps 增加 Search Nearby 支持
Source
AWS News
Published
2026-07-31T14:00:00Z
Summary
Amazon Location Service 现已在亚太地区（新加坡）和亚太地区（马来西亚）这两个 AWS 区域，通过 GrabMaps 数据支持基于邻近性的兴趣点发现。在东南亚创建本地探索、配送和出行应用程序的构建者，可借助经 Grab 平台每日数百万次行程验证的超本地数据，呈现周边相关地点。 SearchNearby 会返回用户所在位置指定半径范围内的地点，并按距离排序。开发人员可以按类别（例如加油站、医院或餐厅）筛选结果，将返回内容限定为应用程序所需数据。这使得配送平台能够找到最近的取货点，打车应用程序能够展示附近的餐饮选择，旅游应用程序则能够定位附近的服务设施。 GrabMaps 提供专为东南亚构建的超本地地图数据。Grab 平台上每日数百万次的行程会持续验证道路网络、地址和兴趣点，并实时捕捉变化。GrabMaps 覆盖新加坡、马来西亚、泰国、越南、印度尼西亚、菲律宾、缅甸和柬埔寨的 500 多座城市，提供详细的后巷、狭窄小街以及摩托车可通行路线数据。 要开始使用，请参阅 Search Nearby 开发人员指南 、 API 参考 和 GrabMaps 概述页面 。
