Amazon EC2 现已发布 ImdsV1Enabled CloudWatch 指标
收錄來源

發布時間（來源提供）

來源摘要（原文）
Amazon EC2 现在支持 ImdsV1Enabled CloudWatch 指标，让客户可以了解自己的哪些 EC2 实例仍启用了实例元数据服务版本 1（IMDSv1）。您可以使用该指标跨账户和区域大规模跟踪 IMDSv2 迁移。 借助 ImdsV1Enabled 指标，您可以配置 CloudWatch 控制面板和警报以跟踪仍允许 IMDSv1 的实例、识别迁移缺口和确定修复优先级，而无需自行构建工具来检查各账户和区域中实例的元数据选项。这为您提供了可靠、持续的信号，用于跟踪和完成 IMDSv2 迁移。 ImdsV1Enabled CloudWatch 指标已在所有 AWS 区域推出，无需额外付费。 要了解更多信息，请参阅 Amazon EC2 用户指南 中的 ImdsV1Enabled CloudWatch 指标。有关分步迁移说明，请参阅 Amazon EC2 用户指南中的“迁移到 IMDSv2” 。
