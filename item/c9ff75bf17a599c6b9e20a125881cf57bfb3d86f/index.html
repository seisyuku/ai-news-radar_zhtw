Title
Amazon RDS for MySQL 宣布延长支持次要版本 5.7.44-rds.20260902 和 8.0.46-rds.20260908
Source
AWS News
Published
2026-09-24T16:00:00Z
Summary
Amazon Relational Database Service (RDS) for MySQL 宣布 Amazon RDS 延长对次要版本 5.7.44-rds.20260902 和 8.0.46-rds.20260908 的支持。 Amazon RDS 延长支持 可在主要版本的标准支持终止日期之后，额外提供最多三年的严重常见漏洞和披露（CVE）及错误修复，让您有更多时间升级到新的主要版本。 您可以使用 Amazon RDS 蓝绿部署 、就地升级或从快照还原来升级数据库。有关执行版本升级的更多信息，请参阅 Amazon RDS for MySQL 用户指南 。您还可以使用 AWS Database Migration Service 从外部 MySQL 源迁移到 MySQL 8.4。有关定价详细信息和区域可用性，请参阅 Amazon RDS for MySQL 。 Amazon RDS for MySQL 让用户能够在云中轻松设置、操作和扩展 MySQL 部署。在 Amazon RDS 管理控制台 中或使用 AWS 命令行界面（AWS CLI）创建或更新完全托管式 Amazon RDS 数据库。
