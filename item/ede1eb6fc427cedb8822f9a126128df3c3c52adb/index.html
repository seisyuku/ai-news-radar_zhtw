AWS WAF AI 流量变现现已支持通过 Stripe 进行法定货币支付

來源摘要（原文）
AWS WAF AI 流量变现现已与 Stripe 集成。发布者、内容所有者和 API 提供商可以收取来自 AI 机器人和智能体的稳定币付款，并以当地货币直接结算到其 Stripe 余额。通过此次发布，客户无需持有稳定币或管理加密钱包即可将智能体访问变现。Stripe 现在可以作为一种新的支付方式与现有的稳定币支付一起使用。 要开始使用，请在 AWS WAF 控制台中通过 Stripe Connect 将您的 Stripe 账户连接到 AWS WAF。您现有的定价和智能体策略无需更改，照常生效。当智能体请求受保护的内容时，AWS WAF 会返回 HTTP 402 响应，其中包含 AWS WAF 接受的有效支付凭证类型。一旦智能体携带有效支付凭证返回并再次发出请求，内容就会不受限制地返回。来自所有支付提供商的收入都会显示在 AWS WAF 控制台收入分析中。 在 AWS WAF Web ACL 与 CloudFront 分配关联的所有边缘站点，Stripe 集成向使用 Amazon CloudFront 的所有 AWS WAF 客户提供且不额外收费。需支付标准 AWS WAF 和 Stripe 处理费用。有关详细信息，请参阅 AWS WAF 定价 。 要开始使用，请访问 AWS WAF 控制台 或浏览 AWS WAF Developer Guide 。
