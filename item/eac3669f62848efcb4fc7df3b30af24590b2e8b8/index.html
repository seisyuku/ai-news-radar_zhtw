EC2 Image Builder 控制台现已与 DevOps 智能体集成来排查问题和创建资源
收錄來源
AWS News
發布時間（來源提供）
2026-11-12T08:00:00Z
來源摘要（原文）
EC2 Image Builder 现已在 Image Builder 控制台中直接与 AWS DevOps 智能体集成，使您能够在控制台聊天面板中对失败的映像管道进行问题排查并创建资源。您可以一次性诊断最多 50 个失败管道，并在同一对话中追问后续问题。您也可以选择通过描述所需资源来创建该资源，智能体会在控制台中填充服务已验证的值。 通过此次集成，诊断失败的管道时不再需要手动检查构建日志、交叉比对错误代码或反复修改配置，从而节省大量时间，也减轻了对专业经验的依赖。该智能体会读取构建日志、工作流步骤、组件和网络配置，然后提供根本原因和修复步骤。对于资源创建，该智能体会先验证配置，然后再将其填入控制台以供您审查和提交。如果您使用自己的智能体进行问题排查或构建，AWS Agent Toolkit 中新增的 EC2 Image Builder 技能同样能为您提供问题排查与资源创建能力。 所有商用区域均提供这一功能。要开始使用，请打开 EC2 Image Builder 控制台，并在控制台面板中使用 DevOps 智能体。有关更多信息，请参阅 EC2 Image Builder 文档 ；有关定价，请参阅 DevOps 智能体定价页面 。
