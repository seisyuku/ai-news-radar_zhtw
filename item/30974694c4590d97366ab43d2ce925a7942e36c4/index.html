AWS Elemental MediaConnect 路由器现在支持端点连接管理
收錄來源
AWS News
發布時間（來源提供）
2026-10-26T08:00:00Z
來源摘要（原文）
AWS Elemental MediaConnect 路由器 现在支持通过新的端点注册表管理连接，该注册表允许您注册 MediaConnect 外部的设备或软件，并将这些端点连接到您的路由器输入和输出。您可以直接与其他 AWS 账户共享注册的端点，无需手动链接路由器输入和输出，也无需在带外协调 IP 地址和加密设置。 跨账户端点共享通过减少所需的计算实例来降低成本，并通过减少网络跃点数来降低延迟。共享通过 AWS Resource Access Manager（AWS RAM）进行管理，连接管理器提供对每个共享连接的可见性和控制权。常见使用案例包括：内容分销商与下游合作伙伴共享直播、广播公司跨组织边界开展协作，以及需要安全的跨账户视频传输的媒体工作流。 MediaConnect 端点注册表已在所有提供 AWS Elemental MediaConnect 路由器的 AWS 区域推出，无需额外付费。有关更多信息，请参阅 AWS Elemental MediaConnect 用户指南 。
