Title
Amazon RDS for PostgreSQL 现在支持后量子 TLS 密钥交换
Source
AWS News
Published
2026-09-24T16:00:00Z
Summary
即日起， Amazon RDS for PostgreSQL 开始支持后量子 TLS（PQ-TLS）密钥交换，为您提供用于加密传输中数据的后量子密码学选项。 RDS for PostgreSQL 18 及更高版本支持修改 ssl_groups 参数。您可以从 RDS for PostgreSQL 允许列表中 选择密码组 ，以符合企业的安全标准。 Amazon RDS for PostgreSQL 让您能够在云中轻松设置、运行和扩展 PostgreSQL 部署。在 Amazon RDS 管理控制台 中或使用 AWS 命令行界面（AWS CLI）创建或更新完全托管式 Amazon RDS 数据库。
