The official Ruby SDK for Model Context Protocol is now a Tier 1 SDK, as defined in our SDK tiering system . Ruby is not alone here, and joins the company of our TypeScript, Python, C#, Go, and Rust SDKs. When an SDK becomes Tier 1-compliant, it means that it reached the top of the three tiers, reserved for SDKs with the highest level of feature support, responsiveness to bugs and security issues, and alignment with MCP ecosystem priorities. If you build MCP servers or clients in Ruby, you can now sleep well knowing that you will get full spec feature support, a 100% conformance pass rate, support for new spec versions by their release date, issue triage within two business days, and critical bug fixes within seven days. This is especially important for developers that are responsible for production-grade services and applications, where being on the bleeding edge of MCP development is critical for the business.
