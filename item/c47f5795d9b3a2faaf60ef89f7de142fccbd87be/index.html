Title
ARC 区域切换功能新增 Amazon RDS Switchover Read Replica 执行块
Source
AWS News
Published
2026-08-20T17:45:00Z
Summary
今天，我们将在 ARC 区域切换功能 中推出 Amazon RDS Switchover Read Replica 执行块 ，该块可自动执行针对在多区域工作负载中运行 Oracle Data Guard 的 Amazon RDS 数据库的恢复编排。 Amazon 应用程序恢复控制器（ARC）区域切换功能 可帮助客户编排多区域应用程序的失效转移流程，以在出现区域故障时实现可控的恢复时间。 要在区域失效转移期间恢复运行 Oracle Data Guard 的 Amazon RDS 数据库，客户需要执行手动步骤来撤消主数据库及其只读副本的角色，或将只读副本提升为主数据库实例。区域切换功能现在可让您使用 RDS Switchover Read Replica 执行块 来自动执行此恢复。同一执行块可自动完成主数据库与只读副本之间的角色切换：在计划的失效转移场景下实现零数据丢失；在恢复速度非常重要的非计划的失效转移场景下，将只读副本提升为主数据库。借助原生的跨账户支持，您可以编排托管在与区域切换计划不同的账户中的 Amazon RDS 实例的恢复过程，从而实现对组织内恢复工作的集中管理。 要开始使用，请参阅 Amazon RDS Switchover Read Replica 执行块 文档。要了解有关 ARC 区域切换功能的更多信息，请访问 应用程序恢复控制器页面 。
