Title
AWS Glue 数据质量自动监测功能现支持分布统计数据用于数据分析
Source
AWS News
Published
2026-07-27T20:23:00Z
Summary
AWS Glue 数据质量自动监测功能现在支持全新的分布分析器，可为您的数据生成频率分布分析。通过在数据质量定义语言（DQDL）中使用这一新的分布分析器，您可以为数值列生成直方图，并为分类列、日期列和布尔列生成值分布图。借助对自定义区间计数量的支持，您可以按照对您的使用案例最重要的粒度来了解数据的形态和模式。 了解数据的分布情况是构建可靠数据管道的基础。分布统计数据可帮助您快速识别数据集中的偏斜、异常值和意外模式，而无需编写自定义代码。该功能直接与您现有的 DQDL 规则集集成，因此您可以在单次评估运行中，将分布分析与当前的数据质量检查一并执行。分布统计数据存储在 Amazon S3 中，以便日后通过 Amazon Athena 之类的服务进行查询，同时也可通过 API 获取，从而轻松地将分布洞察集成到监控工作流和可视化工具（包括 SageMaker 融通式合作开发工作室）中。 AWS Glue 数据质量自动监测功能分布统计数据现已在所有 AWS 商业区域和 AWS GovCloud（美国）区域推出。 要了解有关 Glue 数据质量自动监测功能的更多信息，请参阅 AWS Glue 数据质量自动监测功能文档 。要开始使用分布分析器，请访问 分析器文档 。
