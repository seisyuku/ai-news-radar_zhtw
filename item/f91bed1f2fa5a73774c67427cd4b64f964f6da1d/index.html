Title
Amazon RDS Custom 现已支持 Microsoft SQL Server 的最新累积更新和 GDR 更新
Source
AWS News
Published
2026-10-19T07:30:00Z
Summary
Amazon Relational Database Service（Amazon RDS）Custom for SQL Server 现在支持 Microsoft SQL Server 的最新累积更新（CU）和通用发行版（GDR）更新。此次发布包含对以下版本的支持：SQL Server 2019 CU32+GDR KB5122772 （RDS 版本 15.00.4490.9.v1）和 SQL Server 2022 CU26 + GDR KB5122768 （RDS 版本 16.00.4275.2.v1）。 有关这些更新中包含的改进和修复的更多信息，请参阅 Microsoft 关于 KB5122772 和 KB5122768 的文档。您可以使用 Amazon RDS 管理控制台、AWS SDK 或 CLI 升级 Amazon RDS Custom for SQL Server 实例以应用这些建议的更新。要了解有关升级数据库实例的更多信息，请参阅 Amazon RDS Custom 用户指南 。
