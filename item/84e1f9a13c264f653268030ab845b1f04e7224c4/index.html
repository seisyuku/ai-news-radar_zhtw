Title
AWS Console-to-Code 控制台转代码功能新增 26 项服务并支持跨区域录制
Source
AWS News
Published
2026-08-17T15:00:00Z
Summary
AWS Console-to-Code 控制台转代码功能现已支持另外 26 项 AWS 服务，并引入跨区域和跨浏览器标签页操作录制。本次扩展将支持的服务总数从 6 项增至 32 项，助力开发人员、DevOps 工程师以及云架构师更轻松地将手动控制台工作流转换为可复用的生产就绪型基础设施即代码（IaC）。 ​Console-to-Code 控制台转代码功能还引入了跨区域和跨浏览器标签页操作录制。以前，切换区域或跨浏览器标签页进行操作，会重置或割裂录制的操作列表。现在，操作将整合到单个统一列表中，使用户能够在不丢失上下文的前提下，捕获并自动化复杂的多区域基础设施部署。 ​​​即日起，所有 AWS 商业区域内的客户都可以将 Console-to-Code 控制台转代码功能用于所有 32 项支持的服务和新的跨区域录制功能。 要详细了解如何开始使用 AWS Console-to-Code 控制台转代码功能并查看支持的服务列表，请访问 Amazon Q 开发者版 Console-to-Code 控制台转代码功能文档 。
