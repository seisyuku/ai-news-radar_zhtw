來源摘要（原文）
适用于 macOS 和 Windows 的 AWS Quick 桌面应用程序，以及适用于 iOS 和 Android 的 Quick 移动应用程序，现已在亚太地区（新加坡）区域推出。此次发布建立在 Quick 近期在新加坡区域上线 的基础上。 桌面应用程序可处理您的本地文件，并连接日历、电子邮件及各类业务应用程序。移动应用程序可让您与 Quick 聊天、查看活动源，以及打开控制面板。您的对话、上下文和智能体会在 Web 端、桌面端和移动端之间保持同步，因此您可以在桌面端启动智能体，在手机上查看其进展，并在关闭计算机后让它继续运行。 要开始使用，请从 AWS Quick 下载页面 下载桌面应用程序，或者从 Apple App Store 或 Google Play 下载移动应用程序。要了解更多信息，请参阅《AWS Quick 用户指南》中的 AWS Quick 移动版 ，以及 AWS Quick 产品页面 。
