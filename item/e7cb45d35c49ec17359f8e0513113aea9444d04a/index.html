Title
Amazon Bedrock AgentCore 身份现已提供托管式同意门户
Source
AWS News
Published
2026-09-01T21:29:00Z
Summary
Amazon Bedrock AgentCore 身份 现已提供托管式同意门户，使得在将智能体连接到第三方工具和服务时，无需再构建自定义 OAuth 回调基础设施。 之前，开发人员在使用 AgentCore 网关将智能体连接到 GitHub、Salesforce 和 Slack 等服务时，必须构建、托管和维护自定义 OAuth 回调基础设施才能完成 OAuth 2.0 三方授权（3LO）流程。新的托管式同意门户为智能体开发人员和平台管理员免去了这类无差别的繁重工作。 每个 AgentCore 网关均会获得专属的托管式同意门户，其中包含专用的托管 Web 客户端和凭证提供商列表。平台管理员可在会话开始前与其团队共享门户 URL，从而授权智能体代表他们调用外部工具。终端用户可随时通过自助式界面查看其连接状态，而无需联系管理员。 现在，使用基于 IDE 的智能体客户端（此客户端既无法原生展示 OAuth 同意 URL，也无法处理同意后会话绑定）的开发人员，可以将托管式同意门户用作这些工作流的专用授权界面。 此功能已在提供 Bedrock AgentCore 身份的所有商业区域推出。 要了解更多信息，请访问 Amazon Bedrock AgentCore 身份文档 。
