來源摘要（原文）
即日起， Amazon Aurora PostgreSQL 兼容版 开始支持后量子 TLS（PQ-TLS）密钥交换，为您提供用于加密传输中数据的后量子密码学选项。 Amazon Aurora PostgreSQL 18 及更高版本支持修改 ssl_groups 参数。您可以从 Amazon Aurora PostgreSQL 允许列表中 选择密码组 ，以符合企业的安全标准。 Amazon Aurora 设计具有全球规模的高性能和可用性，与 PostgreSQL 完全兼容。它提供可缩减至零的无服务器计算、支持多区域韧性的 Aurora Global Database、用于提升 I/O 密集型工作负载性价比的 Aurora I/O 优化版，以及内置的安全功能和持续备份。要开始使用，请查看我们的 入门页面 。
