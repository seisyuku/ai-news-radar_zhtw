Title
Amazon S3 Vectors 现已在 AWS European Sovereign Cloud（德国）区域推出
Source
AWS News
Published
2026-08-04T18:15:00Z
Summary
Amazon S3 Vectors 现已在 AWS European Sovereign Cloud（德国）区域推出。Amazon S3 Vectors 是专为人工智能代理、推理、检索增强生成（RAG）和语义搜索打造的向量存储，支持十亿级向量规模。S3 Vectors 旨在提供与 Amazon S3 相同的弹性、持久性和可用性，并提供专用 API，让您无需预置任何基础设施即可存储、访问和查询向量。 有关可以使用 Amazon S3 Vectors 的 AWS 区域的完整列表，请参阅 AWS 区域和端点 。要了解更多信息，请访问 产品 和 文档 页面。
