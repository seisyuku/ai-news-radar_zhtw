Title
用于迁移的 AWS Transform 现已在亚太地区（新加坡）推出
Source
AWS News
Published
2026-10-15T19:24:00Z
Summary
用于迁移的 AWS Transform 现已在亚太地区（新加坡）区域推出。客户进行迁移时，可确保数据驻留于该区域，并降低与本地源基础设施之间的延迟。 AWS Transform 是一项协作式企业 IT 转型服务，由智能体人工智能提供支持，可加速云迁移、应用程序现代化和持续减少技术债务。 借助用于迁移的 AWS Transform，企业 IT 团队可以使用专用智能体实现整个迁移生命周期的自动化，从发现和波次规划到网络转换，以及启动测试实例和割接实例。该服务支持对来自几乎任何来源（包括 VMware、Hyper-V、KVM、裸机和混合环境）的工作负载进行基础设施迁移，将团队、工具和工作流程整合到一个协作式工作台中。 要开始使用，请参阅 AWS Transform 文档 或访问 AWS Transform 产品页面 。
