來源摘要（原文）
具有高达 22.8 TB 基于 NVMe 的本地 SSD 块级存储的 Amazon Elastic Compute Cloud（Amazon EC2）M8id 实例现已在亚太地区（马来西亚）和亚太地区（悉尼）区域推出。M8id 实例非常适合需要平衡计算和内存资源，以及高速、低延迟的本地数据块存储（包括数据日志记录、媒体处理和中等规模数据存储）的工作负载。 与之前的第六代实例相比，Amazon EC2 M8id 实例提供 3 倍的 vCPU、内存和本地存储。与之前的第六代 M6id 实例相比，这些实例的计算性能提升多达 43%，内存带宽增加了 3.3 倍。与之前的第六代实例相比，这些实例处理 I/O 密集型数据库工作负载的性能可提高最多 46%，在 I/O 密集型实时数据分析中，查询速度可提高最多 30%。 此外，客户现在可以使用 EC2 实例带宽权重配置将这些实例的网络和 Amazon EBS 带宽调整 25%，以便更灵活地分配带宽资源，从而更好地优化工作负载。这些实例就 24xlarge、48xlarge、metal-24xl 和 metal-48xl 大小提供 Elastic Fabric Adapter (EFA) 网络。 客户可以通过节省计划、按需型实例和竞价型实例购买这些实例。有关更多信息，请访问 Amazon EC2 M8id 页面。
