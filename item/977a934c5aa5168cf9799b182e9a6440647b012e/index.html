Amazon ElastiCache 无服务器现在支持向量搜索、全文搜索、混合搜索以及聚合搜索
收錄來源
AWS News
發布時間（來源提供）

來源摘要（原文）
适用于 Valkey 的 Amazon ElastiCache 无服务器现在支持向量搜索、全文搜索、混合搜索以及聚合搜索。搜索实时数据的应用程序通常会在延迟与召回率之间面临艰难的权衡，此外，更新内容在可被搜索之前还会存在延迟。借助 ElastiCache 无服务器的搜索功能，应用程序可在延迟低至微秒级的情况下进行数据搜索，向量搜索的召回率高达 99%，同时每天可处理数十亿次查询。更新内容在写入完成后，最快可在微秒级内被检索到。 ElastiCache 无服务器上的搜索功能非常适合对延迟要求高且流量难以预测的应用程序，也适合希望快速入门搜索功能的团队。您可以在单个查询中组合多种搜索类型，根据需要调整召回率，并使用服务器端聚合功能分析结果。开发人员可以为每个智能体、会话或任务提供自己的数据存储以用于内存和上下文检索，这样智能体就可以在不影响生产环境或彼此的情况下进行实验、遭遇失败和重试。每个数据存储在几秒钟内即可准备就绪，无需网络设置即可通过 公共端点 进行访问，并且仅按其使用量计费，且无需管理基础设施。应用程序还可以为产品发现、推荐系统和检索增强生成（RAG）提供支持。 适用于 Valkey 的 ElastiCache 无服务器上的搜索功能在所有商用 AWS 区域、AWS GovCloud（美国）区域可用；适用于 Valkey 的 ElastiCache 版本 9 的搜索功能在 AWS European Sovereign Cloud 区域可用。Valkey 是 Redis 最宽松且供应商中立的开源替代方案，也是 ElastiCache 上推荐使用的引擎。要开始使用，请通过 AWS 管理控制台、AWS SDK 或 AWS CLI 创建新的无服务器缓存或将现有缓存升级到 Valkey 9。要了解更多信息，请参阅 ElastiCache 文档 。有关定价，请参阅 ElastiCache 定价页面 。
