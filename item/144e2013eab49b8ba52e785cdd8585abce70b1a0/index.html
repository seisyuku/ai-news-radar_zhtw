Title
AWS 宣布推出与 Megaport 合作的 AWS 互连 – 最后一英里预览版
Source
AWS News
Published
2026-10-22T12:00:00Z
Summary
AWS 正式推出与 Megaport 合作的 AWS 互连 – 最后一英里预览版，这是一项完全托管式连接服务，客户只需点击几下，即可将其分支机构、数据中心和远程站点连接至 AWS，无需费力进行复杂的网络配置。作为 AWS 与 Megaport 的里程碑式合作，AWS 互连 – 最后一英里将 AWS 云创新与 Megaport 运营的全球最大软件定义网络（SDN）之一相结合，该网络覆盖 31 个国家/地区，拥有 1,200 多个已接入的数据中心。 现在，借助 AWS 管理控制台，客户只需选择他们首选的 AWS 区域、带宽速度、Direct Connect 网关 ID 和合作伙伴订阅用户 ID，即可立即建立与 AWS 的高速私有连接。启动后，AWS 会生成激活密钥，用于完成与 Megaport 的连接预置。本次发布的功能可预配容量并自动化处理复杂的网络配置（包括 BGP 对等互联、VLAN 配置及 ASN 分配），从而简化连接体验。正式发布后，客户还可以通过 AWS 管理控制台将带宽从 1 Gbps 动态扩展到 100 Gbps。该服务专为高可用性而设计，支持零停机维护，并提供 99.99% 的 SLA 保障。 AWS 互连 – 最后一英里现已通过 Megaport 在圣何塞（us-west-1）和弗吉尼亚北部（us-east-1）都市区推出。您可以使用 AWS 管理控制台、命令行界面 (CLI) 或 API 创建预览版互连。合作伙伴还可以通过 GitHub 上发布的开放 API 包轻松采用此功能。有关更多信息，请参阅 AWS 互连 – 最后一英里 文档 和 定价 页面。
