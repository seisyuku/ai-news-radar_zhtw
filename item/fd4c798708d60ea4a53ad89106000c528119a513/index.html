Title
AWS Deadline Cloud 现可在 Deadline Cloud 监控器中跟踪自动下载状态
Source
AWS News
Published
2026-08-21T18:00:00Z
Summary
AWS Deadline Cloud 监控器现可显示从云端运行的作业中自动下载文件的进度、状态和运行状况。Deadline Cloud 是一项完全托管式服务，可帮助团队在云端运行计算密集型工作负载，适用于视觉效果、动画、产品设计、仿真和游戏开发。客户可通过 Deadline Cloud 监控器（DCM）桌面应用程序查看其渲染环境、作业、资源和成本。现在，客户还可以使用该监控器来确认自动配置的作业输出已成功下载到目标驱动器。 通过此次更新，监控器应用程序分别在作业与任务级别新增一个“下载状态”列，其中显示下载进度并确认所有输出文件已保存到您的驱动器上。该列旁会显示一个标识，用于表明状态的时效性。如果文件因任何原因不可用，该应用程序将提供清晰的后续步骤指引。此举无需再手动对驱动器进行验证，帮助团队在下游任务开始前稳妥确认输出是否可用。在大规模渲染管道中，手动检查文件并不现实，该功能在此场景下价值尤为突出。 要了解有关 AWS Deadline Cloud 和 Deadline Cloud 监控器桌面应用程序中新的自动下载状态功能的更多信息，请访问 https://aws.amazon.com/deadline-cloud/。
