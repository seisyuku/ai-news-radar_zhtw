Title
Amazon RDS for PostgreSQL 支持次要版本 18.6、17.11、16.15、15.19 和 14.24
Source
AWS News
Published
2026-08-25T16:00:00Z
Summary
Amazon Relational Database Service（RDS）for PostgreSQL 现已支持最新的次要版本 18.6、17.11、16.15、15.19 和 14.24。我们建议您升级到最新的次要版本，以修复早期 PostgreSQL 版本中的通用漏洞披露（CVE），并利用 PostgreSQL 社区提供的错误修复和改进。 您可以使用自动次要版本升级在计划维护时段内升级数据库。要大规模简化操作，请启用自动次要版本升级，并使用 AWS Organizations 升级部署策略 分阶段编排多次升级，先在低优先级环境中完成验证，然后再升级最重要的环境。您还可以使用 Amazon RDS 蓝绿部署最大限度地缩短次要版本升级的停机时间。有关更多信息，请参阅 升级 RDS for PostgreSQL 数据库引擎 。 Amazon RDS for PostgreSQL 让您能够在云中轻松设置、运行和扩展 PostgreSQL 部署。有关定价详细信息和区域可用性，请参阅 Amazon RDS for PostgreSQL 定价 。在 Amazon RDS 管理控制台 中或使用 AWS 命令行界面（CLI）创建或更新完全托管式 Amazon RDS 数据库。
