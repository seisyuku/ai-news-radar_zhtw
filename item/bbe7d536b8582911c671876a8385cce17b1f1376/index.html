Title
Amazon EVS 现已在更多区域推出
Source
AWS News
Published
2026-07-23T16:24:00Z
Summary
今天，我们宣布 Amazon Elastic VMware Service（Amazon EVS）现已在亚太地区（首尔）、欧洲（苏黎世）和欧洲地区（斯德哥尔摩）区域推出。此次扩展为客户提供了更多选择，可借助 AWS 的规模优势和灵活性在云中运行 VMware 工作负载。 Amazon EVS 支持您在 Amazon 虚拟私有云 (VPC) 内的 EC2 裸机实例上直接运行 VMware Cloud Foundation (VCF)，该服务由 AWS Nitro 提供技术支持。您可以在短短几小时内搭建完整的 VCF 环境，从而实现工作负载快速迁移至 AWS，帮助您淘汰老化基础设施、降低运营风险并满足退出数据中心的紧迫时间要求。此次发布支持所有现有的 Amazon EVS 功能，包括 VCF 9.0 和 9.1 支持 ，以便您利用最新的 VMware 功能（如内存分层）。 新增这些区域的推出之后，通过更接近最终用户、遵守数据驻留或主权要求以及用于增强冗余策略的其他高可用性和弹性选项，降低了 VMware 工作负载的延迟。 要开始使用，请访问 Amazon EVS 产品详情页面 和 用户指南 。
