Title
AWS Marketplace 降低多产品解决方案中专业服务的上架费
Source
AWS News
Published
2026-09-01T18:00:00Z
Summary
现在，AWS Marketplace 对作为符合条件的多产品解决方案一部分购买的专业服务收取 0% 的上架费。此举是在近期将专业服务上架费下调至 0.5% 的基础上进一步推出的。这进一步降低了通过 AWS Marketplace 进行服务交易的任何合作伙伴的成本，同时保留了随之而来的账单优惠。 过去一年中，AWS Marketplace 构建了一套专为发现和购买服务而设计的功能。客户可在智能体模式下通过人工智能驱动的发现功能来找到合适的合作伙伴，通过多产品解决方案在单笔交易中同时采购软件和服务，并按时间与材料等可变支付模式进行支付。多产品解决方案中专业服务 0% 的上架费政策与这些功能相辅相成，进一步降低了合作伙伴通过 AWS Marketplace 销售解决方案的成本。 当多产品解决方案中的专业服务与至少一项其他有效的付费订阅结合时，即可享受 0% 服务费。该优惠适用于新订阅，现有订阅将继续按照原有条款执行。 此政策适用于 AWS Marketplace 运营的所有 AWS 商业区域。 要开始使用，合作伙伴可以查阅 卖家文档 ，并通过 AWS 合作伙伴中心 上架多产品解决方案。客户可直接在 AWS Marketplace 上浏览 多产品解决方案 。
