新聞標題（原文）
AWS 推出对适用于 ML 的 EC2 容量块摊销的支持
收錄來源
AWS News
發布時間（來源提供）
2026-11-06T15:00:00Z
來源摘要（原文）
适用于成本和使用情况报告（CUR）2.0 的 AWS 数据导出以及 AWS Cost Explorer 成本管理服务现在会将适用于 ML 的 Amazon EC2 容量块的预付费用在其每个预留的持续时间内进行摊销。您可以查看在容量块中启动的每个实例的摊销成本，以及未使用容量的摊销成本，从而将预付费用归于使用它的工作负载，并识别未使用的容量。 此前，容量块的预付费用会在购买日期显示为一笔单独费用，难以看出该成本在预留期内如何分摊到使用量上。现在，摊销成本会与您的实例使用量一起显示，因此您可以将 GPU 成本分摊到在预留容量上运行的团队、项目和应用程序。您还可以查看预留中有多大比例未被使用，并为未来的容量块购买做规划。在 CUR 2.0 中，摊销成本显示在 reservation_amortized_upfront_fee_for_billing_period 列和 reservation_effective_cost 列中，reservation_net_effective_cost 则显示享受折扣后的摊销成本。在 Cost Explorer 成本管理服务中，选择摊销成本视图即可查看为预留分摊的容量块成本。 容量块摊销已在除 AWS GovCloud（美国）区域和中国区域之外的所有 AWS 区域推出，无需额外付费。要了解更多信息，请参阅 CUR 2.0 data dictionary 和 exploring your data using Cost Explorer 。
