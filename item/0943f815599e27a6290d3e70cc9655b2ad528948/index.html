AWS Elemental MediaConvert 新增与 AWS Elemental Inference 智能字幕的原生集成
收錄來源

發布時間（來源提供）
2026-11-06T08:00:00Z
來源摘要（原文）
​AWS Elemental MediaConvert 现已集成智能字幕，这是基于 AWS Elemental Inference 和最新语音识别模型构建的 AI 驱动字幕解决方案。此功能将自动字幕生成直接引入视频点播（VOD）转码和打包工作流，无需再使用单独的外部字幕管道。客户现在可以在一个统一的工作流中管理转码和字幕创建。 ​智能字幕可自动将音频转录为字幕，原生支持六种语言，包括英语、法语、德语、意大利语、葡萄牙语和西班牙语。使用 MediaConvert，您可以将输出打包为基于文本的外挂字幕格式或烧录字幕，从而满足各种流式传输或分发需求。为了提高转录质量，您现在可以在 Elemental Inference 中定义自定义词典，以引导模型使用专有名词、品牌名称、技术术语等。智能字幕是对现有附加功能的补充，这些功能包括用于端到端媒体管道的智能裁剪、智能取景以及以可分发格式（例如 HLS 和 DASH）交付的可访问字幕等。 ​智能字幕已在提供 Elemental Inference 的所有 AWS 区域推出，包括美国东部（弗吉尼亚州北部）、美国西部（俄勒冈州）、欧洲地区（爱尔兰）、亚太地区（孟买）和亚太地区（悉尼）。 要了解更多信息，请访问 Smart subtitles with MediaConvert 、 AWS Elemental MediaConvert 和 AWS Elemental Inference smart subtitles 。
