來源摘要（原文）
现在，您可以使用 AWS GovCloud（美国东部、美国西部）区域推出的 Amazon MSK 复制器，在 Amazon MSK 集群之间复制流数据以及将来自外部 Apache Kafka 集群（包括本地集群、AWS 上自行管理的集群或其他云提供商上的集群）的流数据复制到 Amazon MSK 预置集群。 MSK 复制器是 Amazon MSK 的一项功能，可自动在 Kafka 集群之间复制数据，而无需管理自定义复制基础设施或配置开源工具。使用 MSK 复制器，您可以轻松构建具有区域弹性的流式应用程序，提高可用性和业务连续性。MSK 复制器在 Kafka 集群之间提供自动异步复制，无需编写自定义代码、管理基础设施或设置跨区域网络。MSK Replicator 会自动扩展底层资源，这样您就可以按需复制数据，而无需监控或扩展容量。MSK Replicator 还会复制必要的 Kafka 元数据，包括主题配置、访问控制列表 (ACL) 和使用者组偏移。如果某个区域发生意外事件，您可以失效转移到其他 AWS 区域并无缝恢复处理。 您可以通过 Amazon MSK 控制台或 Amazon CLI 开始使用 MSK 复制器。要了解更多信息，请访问 MSK 复制器 文档 、 产品页面 和 定价页面 。
