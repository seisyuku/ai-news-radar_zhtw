Title
Amazon Kinesis Data Streams 现在支持通过热吞吐量来缩减摄取容量
Source
AWS News
Published
2026-07-24T18:55:00Z
Summary
Amazon Kinesis Data Streams 是一项无服务器串流数据服务，可简化任何规模的数据流捕获、处理和存储。按需流可自动提升摄取容量，应对持续上涨的数据摄取用量。启用按需优势模式后，您可通过热吞吐量主动管理流容量，让流能够应对突发的数据流量波动。我们对热吞吐量功能进行了拓展，新增摄取容量缩减能力，让您可完整掌控流写入吞吐量的扩展与缩减操作 要缩减规模，只需为您的按需流设置较低的热吞吐量值即可。流会根据请求的容量或过去一小时内为支持峰值数据摄取用量所需的容量进行调整，以较高者为准。这样可以确保您的流始终为当前流量保留足够的容量，同时释放您不再需要的多余容量。因此，您可以获得最佳的流处理性能和成本效益。 针对所有已启用按需优势模式的按需流，热吞吐量缩减功能免费开放，无额外费用。 有关按需优势模式的更多信息，请参阅《Amazon Kinesis Data Streams 开发人员指南》中的 选择适配的流式传输模式 。要开始使用该功能，请参阅 更新流 。有关定价详情，请参阅 Amazon Kinesis Data Streams 定价 。 该功能现已在支持 Amazon Kinesis Data Streams 按优势模式的所有 AWS 区域推出。
