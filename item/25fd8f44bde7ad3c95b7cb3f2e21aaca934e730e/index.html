Title
AWS 成本异常检测功能支持 Amazon Bedrock 上的第三方模型
Source
AWS News
Published
2026-08-19T17:57:00Z
Summary
AWS 成本异常检测功能 现在可以监控在 Amazon Bedrock 上运行的第三方基础模型的支出，例如 Anthropic Claude 及其他由提供商托管的模型。成本异常检测功能使用机器学习来检测异常支出并发送提醒，此次发布将覆盖范围扩大到在 Amazon Bedrock 上使用的第三方模型。运行生产级生成式人工智能工作负载的团队，现在可以自动检测其 Amazon Bedrock 模型支出以及其余 AWS 成本的异常情况。 通过此次发布，成本异常检测功能会通过 AWS 托管服务监控器自动评估您的第三方 Amazon Bedrock 模型成本，您无需进行任何设置。当某个模型的支出发生意外变化时，您会收到提醒，并获得按成本影响程度排序的根本原因分析，该分析涵盖 AWS 服务、账户、区域和使用类型等维度，从而使您能够像处理任何其他 AWS 支出一样，快速了解生成式人工智能成本变化并采取相应措施。 此功能已在除 AWS GovCloud 和中国区域外的所有 AWS 商业区域推出。 要了解更多信息，请参阅《AWS 账单与成本管理用户指南》中的 使用 AWS 成本异常检测功能检测异常支出 。
