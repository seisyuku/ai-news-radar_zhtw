Amazon Redshift 现已支持跨区域查询数据湖
收錄來源
AWS News
發布時間（來源提供）
2026-10-01T18:41:00Z
來源摘要（原文）
Amazon Redshift 现在支持查询位于不同 AWS 区域的 Amazon S3 数据湖表。利用增强型 VPC 路由，Amazon S3 和 Amazon Redshift 之间的数据湖查询流量将停留在您自己的 VPC 内。 这两项功能均由集成数据湖查询引擎提供支持，该引擎直接在 RG 预置集群和无服务器集群的计算资源上运行。这些功能面向拥有全球分布式数据的企业和需要严格控制数据传输方式的安全敏感型客户。 借助跨区域支持，您可以使用 Amazon Redshift 直接查询其他区域的 S3 数据，无需先复制。这样一来，您可以更轻松地进行全球分析、整合不同区域的报告以及查询出于驻留要求必须保留在特定区域的数据。跨区域查询会产生标准数据传输费用。查询引擎在集群的计算资源上运行，因此当您使用增强型 VPC 路由时，在 Amazon S3 和 Amazon Redshift 之间传输的数据将完全流经您的 VPC，而不是公共网络。金融服务、医疗保健和政府等受监管行业可以使用此功能，因为它能够将数据湖查询保持在网络边界内，从而满足合规性要求。 这两项功能均可与集成数据湖查询引擎配合使用，已在提供 RG 预置集群和无服务器集群的所有区域推出。要了解更多信息，请参阅 Amazon Redshift 文档 中的 使用增强型 VPC 路由 查询数据湖 表 。
