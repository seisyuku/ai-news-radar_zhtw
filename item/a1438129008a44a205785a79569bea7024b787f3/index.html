Title
AWS Deadline Cloud 现已在作业模板中支持表达式
Source
AWS News
Published
2026-09-29T21:55:00Z
Summary
AWS Deadline Cloud 现已在作业模板中支持灵活的表达式和丰富的参数类型，为客户提供了一种更简洁、更强大的方式，将该服务融入现有的生产管道。Deadline Cloud 是一项完全托管式服务，可帮助团队在云端运行计算密集型工作负载，适用于视觉效果、动画、产品设计、仿真和游戏开发。 客户现在可以直接在作业模板中表达管道逻辑。这包括算术、条件、字符串和路径操作以及列表推导等表达式，所有这些全部采用熟悉的 Python 风格语法。客户可以利用该功能将帧范围拆分为每个任务对应的帧，根据场景名称推导输出路径，或直接在作业模板中切换可选标志，从而更轻松地实现定制化管道操作的自动化。新的布尔型、列表型和帧范围参数类型与管道现有的工作描述方式相一致。例如，勾选复选框时可添加 --gpu 标志及其对应的主机要求；而摄像机列表可作为某个步骤的任务范围。表达式在提交时会进行类型检查，且其求值结果是确定性的，这意味着作业执行每次都会以可预测的方式运行。 这些功能来自 Open Job Description 的新 EXPR 扩展，这是 Deadline Cloud 用于作业模板的开放规范，已在所有支持 AWS Deadline Cloud 的 AWS 区域提供。 要开始使用，请访问 Deadline Cloud 开发人员指南 。
