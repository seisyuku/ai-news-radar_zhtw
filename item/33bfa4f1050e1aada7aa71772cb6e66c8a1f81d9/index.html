Title
AWS Client VPN 现已支持 CLI、管理控制能力和更快的连接
Source
AWS News
Published
2026-08-13T20:49:00Z
Summary
AWS Client VPN 推出重新构建的 AWS Client VPN 6.0.x 版本，该版本提供命令行界面（CLI）支持、企业管理控制能力和更快的连接建立速度等新功能，使您能够更轻松地实现 VPN 连接自动化，并在企业范围内集中管理设备。 AWS VPN Client CLI 提供与 GUI 完全相同的功能。现在，您可以通过脚本实现 VPN 连接，并将其集成到自动化工作流与基础设施即代码部署中。以前，要将 VPN 连接集成到自动化环境中，需要使用第三方工具或人工介入。此功能支持后台 CLI 操作，消除了这一限制。以前，您必须在组织内所有用户之间分发 VPN 配置文件，而该操作可由任何不具备相应权限的用户管理。现在，借助 AWS 客户端上的管理控制能力，您可以将配置文件的范围限定为特定用户来集中实施 VPN 策略，管理对设备上的所有用户可用的全局配置文件，并在整个组织内实施已批准的 VPN 配置。 该客户端已通过 OpenVPN3 重新构建，可在所有受支持的操作系统上更快地建立连接。您可以同时使用 GUI 和 CLI，因为两者可并行运行，而且 VPN 连接独立于任一界面持续生效。重新构建的客户端 v6.0 及更高版本仍可与现有 AWS Client VPN 端点完全向后兼容，因此无需更改端点。今天，更新后的 AWS Client VPN 适用于 Windows（x64/ARM）、macOS（x64/ARM）和 Linux（x64）。除了 AWS Client VPN 的标准费用外，无额外费用。 下载适用于 macOS 、 Windows 和 Linux 的最新客户端版本 6.0.x 以开始使用。 要了解有关 Client VPN 的更多信息，请访问 AWS Client VPN 产品页面或参阅 文档 。
