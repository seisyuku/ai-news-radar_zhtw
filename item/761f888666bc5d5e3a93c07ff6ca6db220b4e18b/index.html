Title
AWS 韧性监测中心现已提供推荐的韧性测试
Source
AWS News
Published
2026-08-03T19:02:58Z
Summary
AWS 韧性监测中心现已提供推荐的韧性测试，帮助平台工程团队和站点可靠性团队验证其服务在已知故障场景下的响应和恢复能力。 韧性监测中心根据您服务的架构、配置和韧性策略提供预先配置好的测试。它使用 AWS 故障注入服务（FIS）注入受控故障，然后评估您的服务能否在您定义的恢复目标内恢复。通过 AWS 推荐的韧性测试，团队可以验证针对可用区受损、区域受损和依赖项故障等场景的准备情况。每项测试都会自动将服务中的资源作为目标，注入所需故障，根据警报评估和恢复目标生成通过或失败结果，然后生成详细的测试报告。 新一代 AWS 韧性监测中心的推荐测试功能已在以下 AWS 区域推出：美国东部（弗吉尼亚州北部）、美国东部（俄亥俄州）、美国西部（俄勒冈州）、加拿大（中部）、欧洲地区（爱尔兰）、欧洲地区（伦敦）、欧洲地区（法兰克福）、欧洲地区（巴黎）、欧洲地区（斯德哥尔摩）、亚太地区（孟买）、亚太地区（新加坡）、亚太地区（悉尼）、亚太地区（东京）、亚太地区（首尔）和南美洲（圣保罗）。 要开始使用，请访问 AWS 管理控制台 。要了解有关推荐韧性测试的更多信息，请参阅新一代 AWS 韧性监测中心 的产品页面。
