Title
AWS Capabilities by Region 现在提供针对单个功能的可用性通知，并支持高级筛选条件
Source
AWS News
Published
2026-10-05T17:57:00Z
Summary
今天，AWS 宣布在 AWS 构建者中心的 AWS Capabilities by Region 中推出功能级可用性通知和高级筛选条件。构建者现在可以针对他们感兴趣的 AWS 区域，为 AWS 服务或 AWS 服务的单个功能设置可用性通知，并接收应用程序内通知和每周电子邮件摘要，内容涵盖自构建者启用可用性通知以来变为可用的所有功能。为服务设置可用性通知会涵盖该服务中的每项功能，“所有区域”选项会涵盖每个区域，包括未来推出的 AWS 区域。 除了功能级可用性通知所带来的灵活性之外，构建者现在还可以按可用性状态筛选 API 操作和 CloudFormation 资源，从而只查看所选 AWS 区域中可用的内容，或只查看不可用的内容。构建者还可以选择如何比较 AWS 区域：显示所有功能，仅显示在每个选定区域中具有相同可用性状态的功能，或仅显示在选定 AWS 区域之间可用性不同的功能。比较中涵盖超过 19,000 个 API 操作和超过 5,000 种 CloudFormation 资源类型，这些筛选条件让构建者只需进行几次选择，即可从完整列表定位到两个 AWS 区域之间的具体差异。这些筛选条件可与搜索和现有的显示首选项一起使用。
