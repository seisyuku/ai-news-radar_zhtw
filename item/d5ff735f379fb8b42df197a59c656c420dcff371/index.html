Title
Amazon EC2 M6in 和 M6idn 实例现已在更多区域推出
Source
AWS News
Published
2026-07-21T20:00:00Z
Summary
即日起，Amazon Elastic Compute Cloud（Amazon EC2）M6in 和 M6idn 实例将在 AWS 亚太地区（海得拉巴）和南美洲（圣保罗）区域推出。这些第六代网络优化型实例由第三代 Intel Xeon 可扩展处理器提供支持，基于 AWS Nitro System 构建，可提供高达 200 Gbps 的网络带宽，与第五代实例相比，提供高出 2 倍的网络带宽。 客户可以使用 M6in 和 M6idn 实例来扩展网络密集型工作负载的性能和吞吐量，例如高性能文件系统、分布式 Web 级内存缓存、缓存实例集、实时大数据分析以及 5G 用户平面功能等电信应用程序。 M6in 和 M6idn 实例提供了 10 种不同的实例大小（包括裸机大小），可提供多达 128 个 vCPU 和 512GiB 内存。它们可以提供高达 100Gbps 的 Amazon Elastic Block Store (EBS) 带宽和高达 400K 的 IOPS。32xlarge 和裸机大小的 M6in 和 M6idn 实例提供 Elastic Fabric Adapter (EFA) 联网支持。M6idn 实例提供高达 7.6TB 的高速、低延迟实例存储。 通过本次区域扩展，M6in 和 M6idn 实例现已在以下 AWS 区域 推出：美国东部（俄亥俄州、弗吉尼亚州北部）、美国西部（北加利福尼亚、俄勒冈州）、欧洲地区（爱尔兰、法兰克福、西班牙、斯德哥尔摩、苏黎世、伦敦）、亚太地区（海得拉巴、孟买、新加坡、东京、悉尼、首尔）、南美洲（圣保罗）、加拿大（中部）和 AWS GovCloud（美国西部）。客户可以通过 Savings Plan、按需和 Spot 实例购买新实例。要了解更多信息，请参阅 M6in 和 M6idn 实例页面 。
