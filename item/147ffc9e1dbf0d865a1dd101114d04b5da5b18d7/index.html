Title
Amazon RDS for Oracle 现在支持 Oracle Application Express（APEX）版本 26.1
Source
AWS News
Published
2026-08-14T15:00:00Z
Summary
Amazon Relational Database Service（Amazon RDS）for Oracle 现在支持 Oracle Application Express（APEX）版本 26.1。Amazon RDS for Oracle 是一项托管式数据库服务，让您能够轻松地在云中设置、操作和扩展 Oracle Database 部署。Oracle APEX 是一个低代码开发平台，它让开发人员能够构建具备现代用户界面的可扩展、安全的企业级应用程序。要了解关于 Oracle APEX 26.1 最新功能的更多信息，请参阅 Oracle 的 APEX 26.1 文档 。 有关支持的 Oracle APEX 版本以及如何为 RDS for Oracle 数据库添加或修改 Oracle APEX 选项的更多详细信息，请参阅 Amazon RDS for Oracle APEX 文档 。 Oracle APEX 26.1 现已在提供 Amazon RDS for Oracle 的所有 AWS 区域推出。有关区域可用性，请参阅 Amazon RDS for Oracle 定价 。
