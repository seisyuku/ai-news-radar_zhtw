Title
Amazon Cognito 现已在 Agent Toolkit for AWS 中作为技能提供
Source
AWS News
Published
2026-08-07T18:00:48Z
Summary
Amazon Cognito 现已作为一项核心技能（aws-auth）在 Agent Toolkit for AWS 中提供。使用该工具包的人工智能编程代理现在可以遵循最佳实践工作流来设置、配置、保护 Amazon Cognito 并排查其问题，从而帮助开发人员更快地为用户、人工智能代理和微服务实现安全的登录流程。 Amazon Cognito（aws-auth）技能涵盖用户池和应用程序客户端配置、托管登录和 OAuth 2.0 流程、令牌管理、JWT 授权器、通行密钥/WebAuthn 注册、威胁防护、Lambda 触发器连接以及身份池。与 AWS MCP 服务器 配合使用时，代理将通过基于 IAM 的护栏和 CloudTrail 审计日志记录执行 AWS CLI 命令。该技能也可通过 AWS CLI 独立运行。 Amazon Cognito（aws-auth）技能作为 Agent Toolkit for AWS 的一部分提供。要开始使用，请参阅 GitHub 上的 Amazon Cognito aws-auth 技能 ，或浏览 Agent Toolkit 快速入门指南 。有关 Amazon Cognito 的更多信息，请参阅 Amazon Cognito 开发人员指南 。
