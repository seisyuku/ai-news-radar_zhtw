Title
AWS Marketplace 新增 AI 洞察功能，帮助买家在购买前了解定价
Source
AWS News
Published
2026-08-05T17:00:00Z
Summary
现在，您可以在购买产品之前了解产品的定价机制。AI 洞察功能位于 AWS Marketplace 产品列表的“定价”部分，以通俗易懂的语言解释每种产品的定价方式：定价单位对应什么、随着使用量增加账单如何变化、多个定价维度如何合并为一项总成本，以及哪些内容包含在内、哪些不包含在内。过去，要解答这些问题，您需要访问多个网站并自行拼凑定价细节。现在，相关信息已直接显示在产品列表中，您无需切换标签页即可评估定价并继续购买流程。 AI 洞察会注明来源，以便您了解解释的依据。该功能综合了卖家在 AWS Marketplace 产品列表中公布的定价，以及卖家公开网站上的其他定价相关信息。 AI 洞察功能已于今日在大部分具备外部定价相关信息的产品列表中上线。所有提供 AWS Marketplace 的 AWS 商业区域均提供该功能。要查看该功能，请在 AWS Marketplace 网站上打开任意产品列表，滚动至定价部分。卖家可随时查看自己产品列表中的显示内容，并通过“AWS Marketplace 卖家指南”中 AI 洞察 页面链接的“联系我们”表单申请修改。
