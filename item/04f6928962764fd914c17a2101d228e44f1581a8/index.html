AWS Security Hub 现已支持将调查发现以 CSV 或 JSON 格式导出到 S3

來源摘要（原文）
AWS Security Hub 宣布支持将调查发现以 CSV 或 JSON（OCSF）格式导出到 Amazon S3。对于需要在控制台之外使用调查发现（例如针对合规性报告或审计取证等使用案例）的安全团队，现在可以直接从 Security Hub 控制台的各个调查发现页面（包括“威胁”、“暴露”、“漏洞”、“状况管理”、“敏感数据”及“所有调查发现”页面）导出相关文件，无需自行构建和维护提取管道。 通过此次发布，您可以从正在查看的调查发现页面按需导出，由 Security Hub 将结果导出到您账户中的 S3 存储桶。如果您希望在电子表格中查看或共享调查发现，可以选择 CSV 格式；如果您需要符合开放网络安全架构框架（OCSF）标准的调查发现，可以选择 JSON 格式。 调查发现导出功能已在提供 AWS Security Hub 的所有 AWS 区域推出。要了解更多信息，请访问 AWS Security Hub User Guide，网址为 https://docs.aws.amazon.com/securityhub/latest/userguide/securityhub-v2-findings-export.html 。
