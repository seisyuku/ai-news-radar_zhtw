新聞標題（原文）
Amazon RDS for Oracle 不再要求对 JVM、Spatial、Locator 和 OLAP 选项进行自动次要版本升级
收錄來源
AWS News
發布時間（來源提供）
2026-10-30T17:00:00Z
來源摘要（原文）
Amazon Relational Database Service（Amazon RDS）for Oracle 现支持您在使用 JVM、Spatial、Locator 或 OLAP 选项的新的和现有的数据库实例上关闭自动次要版本升级。以前，这些选项需要启用自动次要版本升级。 此次变更后，您可以利用这些选项，自行决定何时对数据库实例应用次要版本升级。如果您关闭自动次要版本升级，我们建议您定期应用新的次要版本，以便您的数据库实例保持最新的 Oracle 安全修复。要保持次要版本自动升级处于开启状态，同时仍控制环境的升级顺序，您可以使用 AWS Organizations 升级部署策略 。 此变更已在提供 Amazon RDS for Oracle 的 所有 AWS 商业区域和 AWS GovCloud（美国）区域 推出。要了解有关 Amazon RDS for Oracle 中可用选项的更多信息，请参阅 Amazon RDS User Guide 中的 Adding options to Oracle DB instances 。
