來源摘要（原文）
Amazon S3 表类数据存储服务现在支持在 AWS 账户中为每个 AWS 区域创建多达 100 个表存储桶，而之前只能创建 10 个。这样一来，您可以在 AWS 账户中为每个 AWS 区域创建多达 100 万个表。表存储桶限额提升后，您可以为每个数据集、工作负载或团队创建单独的表存储桶，并对每个数据集、工作负载或团队应用表存储桶级别的设置（例如加密、访问策略和复制）。默认情况下，更高的配额适用于所有账户，不收取额外费用。 S3 表类数据存储服务提供了首款内置 Apache Iceberg 支持的云对象存储，也是大规模存储表格数据的最简单方法。S3 表类数据存储服务可进行持续的表维护，即使您的数据湖不断扩展和演变，它也能随着时间的推移自动优化查询效率和存储成本。 更高的默认配额已在提供 S3 表类数据存储服务的所有 AWS 区域推出。如果您需要超过默认数量的配额，则可以通过 AWS Support 请求提升配额。要了解更多信息，请访问 S3 表类数据存储服务概述页面 、 用户指南 和 配额文档 。
