Title
AWS Conﬁg 现支持 15 个新资源类型
Source
AWS News
Published
2026-08-03T15:00:00Z
Summary
AWS Conﬁg 现已支持 15 种新增的 AWS 资源类型，涵盖的关键服务包括 Amazon Bedrock、Amazon OpenSearch 无服务器和 Amazon SageMaker。此次扩展为您的 AWS 环境提供了更大的覆盖范围，使您能够更有效地发现、评测、审计和修复更广泛的资源。 此次发布后，如果您为所有资源类型启用了记录功能，则 AWS Config 将自动跟踪这些新增资源。新支持的资源类型也可在 Config 规则和 Config 聚合器中找到。 您现在可以使用 AWS Conﬁg 在所有提供资源的 AWS 区域 监控以下新增的受支持资源类型： 资源类型： AWS::AppSync::DomainName AWS::OpenSearchServerless::AccessPolicy AWS::Bedrock::AutomatedReasoningPolicy AWS::OpenSearchServerless::LifecyclePolicy AWS::Bedrock::AutomatedReasoningPolicyVersion AWS::SageMaker::ImageVersion AWS::Bedrock::Blueprint AWS::SageMaker::InferenceComponent AWS::Bedrock::DataAutomationProject AWS::SageMaker::PartnerApp AWS::BedrockAgentCore::ApiKeyCredentialProvider AWS::SageMaker::Project AWS::Connect::UserHierarchyGroup AWS::SageMaker::Space AWS::Glue::Trigger
