Title
Amazon Bedrock 将 Claude 模型的区域内支持扩展至英国（伦敦）
Source
AWS News
Published
2026-09-30T17:00:00Z
Summary
我们很高兴地宣布在英国（伦敦）区域针对 Amazon Bedrock 上 Anthropic 的 Claude Opus 5.5 和 Claude Sonnet 5 推出区域内支持。需要在英国境内处理数据的客户（包括金融服务、医疗保健和公共部门的客户）现在可以大规模使用这些模型，同时将推理保留在本地进行。 在英国，Amazon Bedrock 支持 Claude Opus 5.5 和 Claude Sonnet 5，并在伦敦（eu-west-2）区域的 bedrock-runtime 端点上提供区域内推理。Amazon Bedrock 在您发起调用的区域内处理推理请求和数据，处理过程绝不会离开该区域。 有关各区域模型可用性的最新信息，请参阅 Amazon Bedrock User Guide 中的 Regional availability by models 。要开始在 Amazon Bedrock 上使用 Claude 模型，请访问 Amazon Bedrock 控制台。
