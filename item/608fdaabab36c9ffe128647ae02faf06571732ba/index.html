Title
Amazon Keyspaces（Apache Cassandra 兼容）现已在另外 11 个区域正式推出
Source
AWS News
Published
2026-09-16T16:00:00Z
Summary
Amazon Keyspaces（Apache Cassandra 兼容） 现已在另外 11 个区域正式推出，使这些区域的客户能够构建与 Cassandra 兼容的应用程序，在降低延迟的同时，确保数据留存于相应区域内，满足数据驻留要求。 Amazon Keyspaces（Apache Cassandra 兼容）是一种可扩展、高度可用、托管的 Apache Cassandra 兼容数据库服务。Amazon Keyspaces 是无服务器的，因此您只需为所使用的资源付费，即可构建每秒可处理数千个请求的应用程序，且吞吐量和存储空间几乎不受限制。 要查找新的可用区域列表，请参阅以下资源： 按区域探索 AWS 功能 。
