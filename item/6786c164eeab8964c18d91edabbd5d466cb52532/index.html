Amazon Simple Email Service 现已在六个新 AWS 区域推出

來源摘要（原文）
Amazon Simple Email Service（Amazon SES） 现已在亚太地区（新西兰、墨尔本、台北、泰国）、墨西哥（中部）、欧洲（西班牙）推出。客户现在可以在这些新增区域使用 Amazon SES 来发送电子邮件，以及在需要时帮助管理数据要求。 Amazon SES 是一种可扩展、经济高效且灵活的基于云的电子邮件服务，旨在帮助数字营销人员和应用程序开发人员从任何应用程序内发送营销、通知和事务处理电子邮件。要了解有关 Amazon SES 的更多信息，请访问此 页面 。 此次发布之后，Amazon SES 已在全球 35 个 AWS 区域推出：美国东部（弗吉尼亚州北部、俄亥俄州）、美国西部（北加利福尼亚、俄勒冈州）、AWS GovCloud（美国西部、美国东部）、亚太地区（大阪、孟买、海得拉巴、悉尼、新加坡、首尔、东京、雅加达、马来西亚、新西兰、墨尔本、台北、泰国）、加拿大（中部、卡尔加里）、欧洲地区（爱尔兰、法兰克福、伦敦、巴黎、斯德哥尔摩、米兰、苏黎世、西班牙）、中东（巴林、阿联酋）、以色列（特拉维夫）、南美洲（圣保罗）、墨西哥（中部）和非洲（开普敦）。 有关所有 Amazon SES 区域端点的完整列表，请参阅 AWS General Reference 中的 AWS Service Endpoints 。
