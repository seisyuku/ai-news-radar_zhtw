來源摘要（原文）
今天，我们宣布正式推出 Web Answer on Amazon Bedrock AgentCore。Web Answer 是一种托管式工具，只需一次调用即可针对自然语言问题返回经过综合、有依据且附带引用的答案。智能体构建者可以将其附加到智能体并获得基于最新网络资源生成的完整答案，而无需自行构建和维护搜索、检索、综合和引用管道。 Web Answer 基于 6 月推出的 Web Search on Amazon Bedrock AgentCore 构建，将能力从“查找网页内容”拓展至“返回完整答案”，而这种能力正是客户一直期待的。借助 Web Answer，您的智能体发送一个问题，即可通过一次工具调用收到带有引用的综合答案。Web Answer 的工作方式类似智能体：它会自行规划搜索、并行运行多项搜索，并判断何时已收集到足够的信息来给出答案。您始终掌控边界，可通过域白名单、域黑名单和发布日期过滤器限定它的查找范围。它可作为目标附加到 AgentCore 网关，通过 MCP 调用，以及使用 IAM 进行身份验证，且没有数据传出。 Web Answer 已在美国东部（弗吉尼亚州北部）区域推出，按工具调用次数计费。 要详细了解 Web Answer on Amazon Bedrock AgentCore，请参阅 Web Answer 文档 页面 和 Web Answer 的 网站 。有关区域可用性，请参阅 AWS 区域 表 。
