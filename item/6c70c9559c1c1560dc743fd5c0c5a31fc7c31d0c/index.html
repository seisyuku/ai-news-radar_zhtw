Title
AWS DataSync 增强模式新增了 HDFS、Azure Blob 和对象存储位置，并支持 Hyper-V 代理
Source
AWS News
Published
2026-07-28T10:00:00Z
Summary
AWS DataSync 增强模式现在支持通过 Hadoop Distributed File Systems（HDFS）、Microsoft Azure Blob Storage 和自管理对象存储进行基于代理的数据传输。此外，增强模式代理现在可以部署在 Microsoft Hyper-V 上。借助 DataSync 代理，客户可以利用增强模式提供的并行传输能力、无限制文件数量支持以及详细指标，在这些位置之间传输数据。 增强模式 HDFS 支持包括用于实现高可用性的多种 NameNode 配置以及采用 Kerberos 身份验证的透明数据加密（TDE），使受监管行业的企业能够在不牺牲可用性的前提下，安全地迁移 PB 级加密的 Hadoop 数据。 此功能现已在提供 AWS DataSync 的所有 AWS 区域推出。要开始使用，请访问 AWS DataSync 控制台 。有关更多信息，请参阅 AWS DataSync 文档 。
