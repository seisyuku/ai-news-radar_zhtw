Title
Amazon WorkSpaces 简化了智能体对企业云桌面的安全访问，降低基础设施的运营和管理负担
Source
AWS News
Published
2026-10-20T17:00:00Z
Summary
适用于智能体的 WorkSpaces 现已将身份验证和桌面连接作为托管式模型上下文协议（MCP）服务的一部分进行处理，因此您可以将智能体连接到受治理的云桌面，无需编写自定义代码。这样使得 WorkSpaces 可以轻松与任何支持 MCP 的客户端配合使用。 以前，将智能体连接到桌面需要您管理会话前需求以及手动生成、调用和轮换流式 URL，这使得每次会话到期时都会增加复杂性。现在，您可以通过 OAuth 2.0 使用现有 AWS 凭证创建会话，由该服务处理连接生命周期。您只需配置一次要使用的桌面堆栈，您的智能体就会定位到对应桌面，无需查看或处理底层流式连接。您还可以查询会话状态以查看智能体连接到哪个桌面堆栈、实例集和会话，并生成用于实时观测智能体的链接。这使您能够查看和审计智能体正在进行的工作，从而掌握智能体的操作内容和位置。 为了助力智能体使用多个应用程序，智能体现已可通过目录 MCP 工具来发现和启动应用程序，无需在菜单中导航。借助这些新工具，智能体可以列出可用的应用程序，在运行时启动一个或多个应用程序，并在它们之间切换，从而将开始菜单和任务栏导航替换为程序化、确定性路径，从而提高准确率并降低 token 消耗成本。 适用于智能体的 WorkSpaces 在治理员工队伍的同一网络隔离和合规边界内运行智能体会话，继承企业已配置的 VPC 控制、数据丢失防护策略和会话级安全态势。该服务现在还在另外四个 AWS 区域推出：南美洲（圣保罗）、欧洲地区（米兰）、欧洲（西班牙）和亚太地区（马来西亚）。 要开始在 WorkSpaces 上运行智能体，请访问： https://docs.aws.amazon.com/appstream2/latest/developerguide/agent-access.html 。
