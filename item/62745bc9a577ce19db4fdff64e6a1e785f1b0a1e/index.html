Title
AWS 宣布推出可连接到 Oracle 云基础设施的 AWS 互连 – 多云正式发布版
Source
AWS News
Published
2026-07-29T15:00:00Z
Summary
AWS 宣布推出可连接到 Oracle 云基础设施（OCI）的 AWS 互连 – 多云正式发布版。 随着越来越多的应用程序迁移到云端，客户一直在采用多云策略。他们这样做的原因有很多，包括互操作性要求、自由选择最适合自身需求的技术，以及能够更轻松、更快速地在任何环境中构建和部署应用程序。以前，当跨多个云服务提供商（CSP）互连工作负载时，客户必须采取“自己动手”的多云方法，这导致了大规模构建，管理全球多层网络也变得非常复杂。AWS 互连 – 多云是同类产品中首个专门构建的产品，也是多个云产品相互连接和通信的一种新方式，使客户能够快速为其他云提供商预置弹性且可扩展的私有连接。 今年 5 月，OCI 推出了 AWS 互连公开预览版，并成为最新一家采用为该服务提供支持的 开放规范 的 CSP。今天推出正式发布版后，AWS 客户现在可以依靠同样一致、简单的体验，将他们在 OCI 和 Google Cloud 上的工作负载相互连接。Microsoft Azure 将于 2026 年晚些时候推出该服务。 可连接到 OCI 的 AWS 互连 – 多云已在 us-east-1（弗吉尼亚州北部）AWS 区域推出。您可以使用 AWS 管理控制台、命令行界面（CLI）或 API 创建互连。有关更多信息，请参阅 AWS 互连 – 多云文档 。
