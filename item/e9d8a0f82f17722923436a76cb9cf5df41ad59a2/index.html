控制台中的 Amazon Q 开发者版现已更名为 AWS 助手
收錄來源

發布時間（來源提供）

來源摘要（原文）
AWS 管理控制台和控制台移动应用程序中的 Amazon Q 开发者版现已更名为 AWS 助手。以前，客户通过这些界面与 Amazon Q 开发者版交互。现在，AWS 助手提供了同样的个性化、账户感知型指导和操作，其名称还能直观地体现产品功能。 AWS 助手简化了客户在 AWS 上进行构建、运营和优化的方式。AWS 助手目前免费提供。现有的 Amazon Q 开发者版专业套餐订阅用户将在 AWS 助手下自动保留其专业套餐功能。 AWS 助手在全球范围内可用。要了解更多信息，请访问 aws.amazon.com/products/assistant/ 。
