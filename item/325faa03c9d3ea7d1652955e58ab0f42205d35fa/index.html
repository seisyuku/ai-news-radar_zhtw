Title
AWS 终端用户消息发送服务现已支持 WhatsApp 中的动态流程
Source
AWS News
Published
2026-09-14T07:00:00Z
Summary
AWS 终端用户消息发送服务现已支持 WhatsApp 动态流程，您可以将 WhatsApp 对话转化为丰富的交互式体验，终端用户无需离开 WhatsApp 即可完成操作。 无需将终端用户引导至网站或独立表单来完成交互式体验，您可以直接在聊天中引导他们完成预约、销售线索生成、注册、问卷调查或交易。客户可以使用 Meta 提供的入门模板开始构建流程，该模板内置了文本输入框、日期选择器、下拉菜单和按钮等常见构建基块；也可以从零开始自定义流程。利用动态流程，每个屏幕均能实时调用您自己的 HTTPS 端点，因此您可以展示实时可用性，并为终端用户个性化定制流程中的每个步骤。 您可以通过控制台或 API 全程在 AWS 最终用户社交消息中构建和管理流程。使用 JSON 架构定义流程，然后使用消息模板传送流程，在客户所在之处触达他们。 WhatsApp 流程已在提供最终用户社交消息服务的所有区域推出。要开始使用，请参阅 用户指南 。
