AWS Key Management Service 现已支持用于后量子密钥封装的 ML-KEM

來源摘要（原文）
AWS Key Management Service（KMS）现已支持基于模块格基的密钥封装机制（ML-KEM），这是 NIST FIPS 203 下的一项后量子密码学标准，可使两方建立共享密钥。 NIST 设计 ML-KEM 是为了在其战略性加密路线图中取代经典密钥建立方案（如 DH/ECDH 密钥协商和基于 RSA 的密钥传输）（请参阅 NIST IR 8547 ）。 ML-KEM 可解决这些经典方案面临的“先收集，后解密”威胁，即攻击者今天记录密钥建立交换，待算力足够强大的量子计算机可用后再恢复共享密钥。 KMS 支持 NIST FIPS 203 中定义的全部三个 ML-KEM 密钥规范：ML-KEM-512、ML-KEM-768 和 ML-KEM-1024。Encapsulate API 使用公钥生成随机的 32 字节共享密钥及其加密文字形式。Decapsulate API 使用相应的私钥从加密文字恢复共享密钥。KMS 在通过了 FIPS 140-3 第 3 级验证的硬件安全模块（HSM）中保护 ML-KEM 密钥对的私钥。您可以使用 GetPublicKey API 导出公钥并将其分发给合作伙伴、客户端应用程序或外部系统，以便使用 AWS-LC、OpenSSL 或 Bouncy Castle 等加密库在本地执行封装操作。 ML-KEM 现已在提供 KMS 的所有 AWS 区域推出，但中东（阿联酋）、中东（巴林）和中国区域除外。有关更多信息，请参阅《AWS KMS Developer Guide》中的 Key spec reference 部分。
