Title
AWS Elemental MediaTailor 新增可配置的广告超时和并发控制，以提升广告填充率并加快启动速度
Source
AWS News
Published
2026-07-27T16:09:00Z
Summary
AWS Elemental MediaTailor 现在支持您直接控制广告决策服务器（ADS）的超时设置。此前，更改这些设置需要联系 AWS Support。现在，您可以配置单个 HTTP 广告请求超时、直播、点播和直播广告预取的广告个性化总时间预算，并可启用并行的 ADS 请求。 这些设置使您能够针对具体工作流优化广告投放性能。例如，您可以增加直播活动的个性化时间预算以提高广告填充率，或在点播工作流中启用并行 ADS 请求，以缩短整体响应时间，从而加快视频启动速度。新的预取特定超时设置让您能够对直播广告检索进行更精细的控制。 您可以通过 AWS Elemental MediaTailor 控制台、AWS CLI 或 AWS SDK，在播放配置中使用新的 AdsPersonalizationTimeouts 和 AdsPersonalizationConcurrency 参数来配置这些设置。 该功能已在所有提供 AWS Elemental MediaTailor 的 AWS 区域推出。 要了解有关配置 ADS 请求超时、个性化时间预算和并发的更多信息，请参阅“AWS Elemental MediaTailor 用户指南”中的 高级设置 部分。
