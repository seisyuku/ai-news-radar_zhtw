Title
Amazon CloudWatch 管道新增了 GeoIP、RDS 和 XML 处理器
Source
AWS News
Published
2026-08-19T20:13:00Z
Summary
Amazon CloudWatch 管道现已新增三个处理器，可用于在摄取日志数据时对其进行解析和富化：Amazon RDS 日志解析器、XML 解析器和 GeoIP 富化处理器。CloudWatch 管道是一项完全托管的服务，可以摄取、转换遥测数据并将其路由到 CloudWatch，无需管理基础设施。 日志源生成的数据通常无法直接查询，需对该数据进行二次处理。RDS Aurora 日志以原生引擎格式传入，应用程序日志内嵌 XML 内容，而 IP 地址则缺少位置上下文信息。这三个新处理器可解决上述问题。Amazon RDS 处理器将 Aurora 审计和错误日志解析为结构化字段；XML 解析器将包含 XML 字符串的字段转换为 JSON 格式；GeoIP 处理器使用城市、国家/地区和坐标等地理位置上下文信息来富化任意 IP 地址字段。例如，您可以将 Aurora 审计日志解析为结构化字段以进行合规性报告。您可以在单独的管道中，从 Windows 事件日志提取 XML 有效载荷并将其转换为 JSON 格式，同时将其源 IP 解析为城市和国家/地区信息以进行安全分析。您可以单独使用或在一个管道中组合使用这些处理器。 这些处理器已在正式发布 CloudWatch 管道的所有 AWS 区域推出，无需任何额外费用。CloudWatch Logs 摄取和存储费率将适用。您可以使用 AWS 管理控制台、AWS CLI 或 AWS SDK 向管道添加这些处理器。要开始使用，请参阅 Amazon CloudWatch 管道文档 。
