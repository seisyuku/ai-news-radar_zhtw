Title
Amazon EC2 I8ge 实例现已在另外几个 AWS 区域正式推出
Source
AWS News
Published
2026-07-23T17:00:00Z
Summary
Amazon Web Services（AWS）宣布在 AWS 欧洲地区（伦敦）和加拿大（中部）区域推出 Amazon EC2 I8ge 实例。I8ge 实例由 AWS Graviton4 处理器提供支持，与上一代基于 Graviton2 的存储优化型 Amazon EC2 实例相比，其计算性能提升高达 60%。I8ge 实例采用第三代 AWS Nitro SSD，即本地 NVMe 存储，与上一代 Amazon EC2 Im4gn 实例相比，每 TB 的实时存储性能提升高达 55%。与 Im4gn 实例相比，I8ge 实例将存储 I/O 延迟降低多达 60%，将存储 I/O 延迟变化性降低多达 75%。 I8ge 实例是存储优化型实例，提供高达 120TB 的本地 NVMe 存储。对于在访问大型数据集时需要实现快速本地存储、高随机读/写性能和持续低延迟的工作负载，这是理想的选择。这些多功能实例共提供 11 种不同的大小，其中包括 2 种裸机大小，可灵活地满足客户的计算需求。它们为 Amazon Elastic Block Store (EBS) 提供高达 180Gbps 的网络性能带宽和 60Gbps 的专用带宽，确保在最严苛的应用场景下实现快速高效的数据传输。 要开始您的 Graviton 之旅，请访问 使用 AWS Graviton 提升您的计算能力 页面。要开始使用，请参阅 AWS 管理控制台 、 AWS 命令行界面 (AWS CLI) 和 AWS SDK 。要了解更多信息，请访问 I8ge 实例页面 。
