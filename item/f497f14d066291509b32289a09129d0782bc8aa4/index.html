Title
Amazon OpenSearch Ingestion 现已在 AWS GovCloud（美国）区域推出
Source
AWS News
Published
2026-08-19T17:54:00Z
Summary
即日起，客户可以在 AWS GovCloud（美国东部）和 AWS GovCloud（美国西部）区域，使用 Amazon OpenSearch Ingestion 将数据摄取到 Amazon OpenSearch Service 托管集群或无服务器集合中。 Amazon OpenSearch Ingestion 是一个完全托管式数据摄取层，让您可以摄取和处理数据，然后在 Amazon OpenSearch 托管的集群或无服务器集合中为这些数据编制索引。Amazon OpenSearch Ingestion 提供无代码体验，可以筛选、转换和编辑数据以及将数据路由到 Amazon OpenSearch Service 中。Amazon OpenSearch Ingestion 可自动预置和扩展底层资源，以满足工作负载不断变动的需求。 通过此次发布，Amazon OpenSearch Ingestion 现已在 19 个 AWS 区域全面推出：美国东部（俄亥俄州）、美国东部（弗吉尼亚州北部）、美国西部（俄勒冈州）、美国西部（北加利福尼亚）、欧洲地区（爱尔兰）、欧洲地区（伦敦）、欧洲地区（法兰克福）、欧洲地区（西班牙）、欧洲地区（巴黎）、亚太地区（东京）、亚太地区（悉尼）、亚太地区（新加坡）、亚太地区（孟买）、亚太地区（首尔）、加拿大（中部）、南美洲（圣保罗）、欧洲地区（斯德哥尔摩）、GovCloud（美国东部）和 GovCloud（美国西部）。 要了解更多信息，请参阅 Amazon OpenSearch Ingestion 网页和 Amazon OpenSearch Ingestion 开发人员指南 。
