Title
Amazon EMR 7.14 现已推出
Source
AWS News
Published
2026-09-22T08:00:00Z
Summary
Amazon EMR 7.14 现已推出，在 Amazon EMR on EC2、Amazon EMR on EKS 和 Amazon EMR Serverless 上提供多项新功能，同时升级了其他应用程序的版本。此版本还将 Apache Spark 升级到 3.5.8 版，并将 Apache Iceberg 升级到 1.10.1 版。 Apache Iceberg 实体化视图现已在包含更新和删除操作的表上能够更快地刷新，它利用变更数据捕获来仅读取受变更影响的数据文件。在 Amazon EMR on EKS 上，集群现已支持 Spark Connect 端点，以通过基于令牌的身份验证进行交互式 Spark 会话，并能够在 IPv6 Amazon EKS 集群上运行工作负载。在 Amazon EMR Serverless 上，Spark 作业的存储空间上限从 200 GiB 增至 1 TiB，为随机数据提供更大存储空间。 Amazon EMR 7.14 现已在提供 Amazon EMR 的所有 AWS 区域推出。 要了解更多信息，请访问 Amazon EMR 7.14 发布指南 ，或从 Amazon EMR 控制台 创建集群以开始使用。
