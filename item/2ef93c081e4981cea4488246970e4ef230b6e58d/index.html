Title
AWS 终端用户消息发送服务现已提供端到端托管式 OTP 验证
Source
AWS News
Published
2026-10-16T07:00:00Z
Summary
今天，AWS 终端用户消息发送服务宣布在通知功能中推出端到端托管式一次性密码（OTP）验证。您可在五分钟内获得一套可用的 OTP 解决方案（包括 AWS 电话号码与验证码核验），无需设置电话号码、向运营商注册，也不用管理消息的传送方式。之前，您需要自行生成一次性密码并交由通知发送，同时需要构建和维护验证码的生成、存储与失效逻辑。现在，通知会生成验证码、传送验证码并验证收件人输入的验证码，您可直接上线完整验证流程，省去全部相关开发工作。验证码可通过短信、语音以及新增的 WhatsApp 渠道发送。 您只需在通知验证码配置中设置一次规则：验证码类型、长度、有效期、收件人可尝试的次数，以及各渠道对应的模板。此后，一次调用即可将验证码发送给您所选渠道上的收件人，另一次调用则用于验证其输入的验证码。 通知功能现已在提供 AWS 终端用户消息发送服务的所有商业 AWS 区域推出。 要了解更多信息并开始使用，请参阅 AWS 终端用户消息发送服务 用户指南 。
