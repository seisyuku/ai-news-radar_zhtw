新聞標題（原文）
AWS Transfer Family 现支持在 Web 应用程序中下载多个文件和文件夹
收錄來源
AWS News
發布時間（來源提供）
2026-09-29T08:00:00Z
來源摘要（原文）
AWS Transfer Family 现在允许 Web 应用程序用户一次性下载多个文件和文件夹。最终用户可以任意选择文件和文件夹的组合，并通过一次操作将其一并下载。下载内容以 zip 压缩包形式提供，解压后将保留原始的文件夹结构。 您只需在某个位置选择文件和文件夹，然后从操作菜单中选择“下载”即可开始。此前，最终用户一次只能下载一个文件，且完全无法下载文件夹。Web 应用程序会显示待下载的文件及实时进度，并针对每个文件显示成功或失败的状态。 多文件下载功能已在 Google Chrome、Mozilla Firefox 以及基于 Chromium 的浏览器（如 Microsoft Edge）中提供。Safari 目前尚不支持此功能，最终用户在 Safari 中仍需逐个下载文件。该功能已在提供 Transfer Family Web 应用程序的所有 AWS 区域推出。如需了解更多信息，请访问 Transfer Family Web 应用程序用户指南 。
