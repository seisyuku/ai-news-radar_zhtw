Title
AWS Glue 零 ETL 现可捕获 Salesforce 归档记录
Source
AWS News
Published
2026-09-15T08:00:00Z
Summary
适用于 Salesforce 的 AWS Glue 零 ETL 集成现已支持在目标表中捕获归档记录，为您提供完整的 Salesforce 数据副本，以供分析和报告使用。系统会通过 isArchived 字段准确识别并反映归档记录，因此您的分析数据始终与 Salesforce 源数据保持完全同步。对于 Salesforce 会自动归档的高容量实体（如 Events、Tasks 和 Activities），此功能尤为重要，它使您能够在分析数据存储中全面了解这些数据。 此功能适用于您的零 ETL 集成，无需任何操作。新集成自创建之日起即会自动捕获归档记录。对于现有集成，AWS Glue 会自动回填归档记录状态，无需重新同步、重新配置或更改架构。在为您准确填充 isArchived 字段的同时，您的现有管道将继续不间断地运行。 此功能已在支持适用于 Salesforce 的 AWS Glue 零 ETL 集成的所有 AWS 商业区域和 AWS GovCloud（美国）区域推出。 要开始使用，请通过 AWS Glue 控制台 、CLI 或 SDK 创建或继续使用适用于 Salesforce 的 AWS Glue 零 ETL 集成。要了解更多信息，请参阅 AWS Glue 零 ETL 文档 。
