Title
AWS Security Hub MCP 应用程序支持将风险调查发现整合到 AI 辅助工作流（预览版）
Source
AWS News
Published
2026-07-27T17:00:00Z
Summary
AWS 宣布推出 AWS Security Hub MCP 应用程序的预览版，这是一个本地模型上下文协议（MCP）服务器，可将您的 Security Hub 风险调查发现直接导入 Claude Desktop。 该功能可减少上下文切换和手动分类，从而帮助加快您的安全调查进程，让您无需离开 AI 辅助工作流即可了解风险并采取相应措施。 借助 Security Hub MCP 应用，您可以通过自然语言调查安全态势：查看主要风险调查发现、深入分析调查发现的攻击路径和扩展网络路径、检查相关联的调查发现及受影响的资源配置，并获取修复建议。每次工具调用都会返回两部分内容：文本摘要，供您的人工智能代理进行推理；交互式可视化图表，供您在同一对话中进行验证。MCP 服务器使用您现有的 AWS 凭证在您的机器上本地运行，且所有工具均为只读模式，不会对您的环境进行任何更改。 Security Hub MCP 应用程序面向 Security Hub 客户免费提供。该功能已在所有支持 Security Hub 的 AWS 商业区域推出预览版。 要了解更多信息，请参阅 AWS Security Hub 用户指南 和 AWS Security Hub 产品页面 。有关完整区域列表，请参阅 AWS 区域性服务列表 。
