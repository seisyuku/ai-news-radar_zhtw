來源摘要（原文）
除 AWS GovCloud（美国东部）之外，AWS CodeConnections 现在还在 AWS GovCloud（美国西部）区域推出。CodeConnections 可让您将 AWS 服务（例如 AWS CodePipeline 和 AWS CodeBuild）连接到由第三方提供商（例如 Bitbucket）托管的源代码存储库。 此次发布之后，在 AWS GovCloud（美国西部）运行工作负载的客户可以在其管道所在的区域中建立与源代码存储库的连接。例如，团队可以配置一个连接，让对其存储库的提交自动在 AWS CodePipeline 中启动发布，而无需为每个集成管理提供商凭证。 要了解更多信息，请参阅 AWS CodeConnections User Guide 和 AWS GovCloud User Guide 。要开始使用，请访问 AWS GovCloud（美国）控制台。
