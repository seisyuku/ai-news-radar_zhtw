Title
AWS Organizations 现已支持在服务配额中查看账户数量上限配额
Source
AWS News
Published
2026-08-03T18:54:00Z
Summary
AWS Organizations 客户现在可以直接通过 AWS 服务配额查看其账户数量上限配额及使用情况，而无需依赖 AWS Support 或 AWS 账户团队来确定当前账户限制。 现在，客户可以监控其当前账户配额的使用情况，并在达到上限之前申请提升配额，从而能够主动、轻松地规划账户增长。他们可以通过登录管理账户并访问服务配额控制台，或调用服务配额 GetServiceQuota API 来查看该配额。 配额查看功能现已在美国东部（弗吉尼亚州北部）推出。要了解更多信息，请参阅 AWS 服务配额文档中的 查看服务配额 。有关 AWS Organizations 配额和服务限制的更多信息，请参阅 AWS Organizations 文档 。
