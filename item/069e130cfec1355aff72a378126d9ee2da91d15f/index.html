Title
AWS Lambda 现在支持 Amazon Linux 2023 上的 Java 8、11 和 17
Source
AWS News
Published
2026-07-31T14:00:00Z
Summary
AWS Lambda 现在支持 Amazon Linux 2023（AL2023）上的 Java 8、Java 11 和 Java 17 运行时，可作为托管运行时和容器基础映像使用。这些新的运行时使在 Java 8、11 或 17 上运行 Lambda 函数的客户能够从 Amazon Linux 2（AL2）迁移到 AL2023，而无需同时进行 Java 版本升级。 Java 8、11 和 17 的现有 Lambda 运行时在 AL2 上运行，而 AL2 已于 2026 年 6 月 30 日到期。为了保持支持范围和 SLA 资格，客户必须将其函数迁移到基于 AL2023 的运行时。AWS 建议客户升级到 AL2023 上的 Java 21 或 Java 25 作为首选迁移路径。这些运行时提供了最新的语言功能和性能改进。对于尚未准备好升级 Java 版本的客户，AL2023 上的新 Java 8、11 和 17 运行时提供了另一条前进路径。此外，Java 8、11 和 17 当前基于 AL2 的 Lambda 运行时仍受支持，并将继续接收关键和部分重要安全问题的补丁，直至 2027 年 6 月 30 日，这使客户在 AL2 生命周期结束后有整整一年的时间来完成迁移。 AL2023 上的 Java 8、11 和 17 运行时已在提供 Lambda 的所有 AWS 区域推出，包括 AWS GovCloud（美国）区域和中国区域。 要了解有关 Lambda 中 AL2023 支持的更多信息，请参阅我们的 博客文章 。对于已准备好升级到 Java 21 或 Java 25 的客户，您可以使用 AWS Transform 自定义 来协助其迁移。要了解有关 Lambda 运行时的更多信息，请参阅 Lambda 运行时文档 。
