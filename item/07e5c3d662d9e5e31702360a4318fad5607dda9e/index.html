Title
AWS IAM Identity Center 现已支持跨区域可信身份传播
Source
AWS News
Published
2026-10-26T08:00:00Z
Summary
可信身份传播会将用户的身份随其请求一并传递，因此 AWS 服务可以根据用户的身份及其底层组关联来授予权限，并记录该用户的访问以供审计。借助跨区域支持，这种身份上下文现在可以传播到在不同 AWS 区域运行的 AWS 服务，让您在跨 AWS 区域进行架构设计和部署时具有更大的灵活性。 客户通常会出于多种原因跨 AWS 区域分配工作负载，包括将计算与所查询的数据分开，在容量可用的情况下运行工作负载，或者用于灾难恢复和全球规模。以前，可信身份传播要求访问用户身份的所有 AWS 服务位于同一 AWS 区域。要访问另一个 AWS 区域中的服务，客户必须通过无法区分单个用户的宽泛 IAM 角色授予访问权限，或者将其所有服务整合到单个 AWS 区域中。使用跨区域可信身份传播，用户的身份会随着请求自动在 AWS 区域之间传输，因此您可以根据用户的身份及其底层组关联来授予访问权限，并审计谁访问了哪些资源，同时对每个用户保留精细访问控制。 跨区域可信身份传播现已在提供 IAM Identity Center 的所有 AWS 区域推出，不额外收费。有关提供 IAM Identity Center 的区域的列表，请参阅 按区域探索 AWS 功能 。 有关更多信息，请参阅《IAM Identity Center User Guide》中的 Trusted identity propagation 部分。
