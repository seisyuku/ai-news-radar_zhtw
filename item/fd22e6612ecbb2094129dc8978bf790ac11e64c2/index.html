Title
Amazon SES 点击跟踪现在支持为移动应用程序深度链接自定义 URL 路径
Source
AWS News
Published
2026-08-14T07:00:00Z
Summary
Amazon Simple Email Service（SES） 现新增 ses:custom-path HTML 属性，可更轻松地支持移动深度链接。当您将该属性添加到 <a> 标签时，SES 会将您的路径段传递到跟踪 URL 中，从而使移动操作系统能够将其与您应用程序的通用链接（iOS）或应用程序链接（Android）配置进行匹配。这样，您就可以在不关闭互动跟踪功能的情况下使用移动深度链接。 该功能已在提供 Amazon SES 的所有 AWS 区域推出。要使用这项功能，您需要一个用于点击跟踪的自定义重定向域，并在该域上托管 Apple App Site Association（AASA）或 Digital Asset Links 验证文件。然后，在 HTML 电子邮件的链接中添加 ses:custom-path 属性即可。 要了解更多信息，请参阅《Amazon SES 开发人员指南》中的 配置自定义域以处理打开和点击跟踪 以及 Amazon SES 电子邮件发送指标常见问题 。
