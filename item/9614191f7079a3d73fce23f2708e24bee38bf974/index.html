Title
Amazon EKS 现已支持高级 Kubernetes 控制面板配置参数
Source
AWS News
Published
2026-08-12T18:00:00Z
Summary
Amazon Elastic Kubernetes Service（Amazon EKS） 现已支持为 Kubernetes 控制面板组件（包括调度器、控制器管理器和 API 服务器）配置参数。您可以调整容器组（pod）放置策略以提高资源利用率，调整水平容器组自动扩缩对需求变化的响应速度，设置资源生命周期参数（例如事件保留期限）等。 除了默认值之外，集群管理员现在可以更精细地控制 Kubernetes 控制面板参数。例如，您可以将调度器的节点资源适配策略参数设置为 MostAllocated ，这会将容器组打包到已得到充分利用的节点上，助您在更少的节点上运行相同的工作负载。默认的 LeastAllocated 策略会将容器组分配给各个节点，在余量比密度更重要的场景中，可保留该策略。 您可以在提供 Amazon EKS 的任何 AWS 区域中配置 Kubernetes 控制面板参数。有关可配置参数的完整列表以及更多信息，请参阅 Amazon EKS 用户指南 中的“控制面板配置”。
