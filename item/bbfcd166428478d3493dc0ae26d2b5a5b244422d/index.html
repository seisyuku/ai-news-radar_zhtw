Title
AWS Glue Data Catalog 现已支持适用于 Apache Iceberg V3 的表优化、统计数据和爬网程序
Source
AWS News
Published
2026-10-01T08:00:00Z
Summary
AWS Glue Data Catalog 现在支持适用于 Apache Iceberg 版本 3（V3）表的表优化、统计数据和爬网程序。借助这些新功能，您可以自动维护 V3 表、对其进行优化以提高查询性能，并在 Amazon S3 中发现它们。 通过表优化，您可以使用 binpack、sort 或 z-order 策略压缩 V3 表来提高查询性能，并删除过期快照和孤立文件来降低存储成本。这些优化支持 V3 数据类型，包括变体、地理空间和纳秒级精度时间戳。您还可以为 V3 表生成不同值数量（NDV）统计数据，分析引擎使用这些统计数据来高效地规划查询。此外，您可以使用 Glue 爬网程序来发现存储在 Amazon S3 中的 V3 表并将其注册到 Glue Data Catalog 中，从而使其可供任何兼容 V3 的引擎查询。 这些功能适用于 Iceberg V3 表，已在提供 Glue Data Catalog 表优化、统计数据和爬网程序的所有 AWS 区域推出。要了解更多信息，请参阅 Glue 开发人员指南中的 Glue 优化 、 Glue 统计数据 和 Glue 爬网程序 。
