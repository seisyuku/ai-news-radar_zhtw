Title
来自 xAI 的 Grok 4.3 现已在 AWS GovCloud（美国西部）的 Amazon Bedrock 上推出
Source
AWS News
Published
2026-07-30T13:00:00Z
Summary
xAI 的 Grok 4.3 模型现已在 AWS GovCloud（美国西部）的 Amazon Bedrock 上推出。通过此次发布，xAI 加入 Amazon Bedrock，成为 AWS GovCloud（美国西部）的模型提供商，在您构建涉及推理、代理式和企业工作流程的生成式人工智能应用程序时，可为您提供更多选择。 Grok 4.3 是一款推理优先模型，支持可配置的推理力度（无、低、中、高）。它还具备强大的工具使用和指令遵循能力，可用于构建可靠的代理，并具备令牌效率优势，有助于在大规模推理场景下保持较高的成本效益。Grok 4.3 特别适合客户支持、Web 开发、判例法研究和财务文档问答等企业工作负载，并且能够在对话式人工智能、搜索、聊天和多轮工作流中提供一致的高质量结果。Grok 4.3 在 Mantle 上运行，这是 Amazon Bedrock 中的一款高性价比的新型推理引擎，支持工具调用、结构化输出和响应流式传输。 有关支持的区域列表，请参阅 Grok 4.3 的 区域可用性 。要开始使用，请访问我们文档中的 Grok 4.3 模型详细信息页面 。
