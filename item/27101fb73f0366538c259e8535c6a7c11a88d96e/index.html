Title
AWS 弹性灾难恢复现可保留 Linux 服务器的 UEFI 启动模式
Source
AWS News
Published
2026-08-10T13:00:00Z
Summary
AWS 弹性灾难恢复（AWS DRS）现可在恢复使用 UEFI 固件启动的 Linux 源服务器时保留其 UEFI 启动模式。此前，DRS 以传统 BIOS 模式启动这些 Linux 服务器，这可能需要在恢复后进行额外配置。现在，恢复后的 Linux 实例将以与源服务器相同的 UEFI 启动模式启动。这意味着恢复后的实例与源环境更加一致，因此，依赖 UEFI 启动行为的应用程序将完全按照您的预期恢复，无需执行任何额外的恢复后操作步骤。启动模式会自动保留，无需进行任何配置。 此功能已在提供 AWS DRS 的所有 AWS 区域推出，无需额外费用。要了解更多信息，请参阅 AWS 弹性灾难恢复用户指南 。
