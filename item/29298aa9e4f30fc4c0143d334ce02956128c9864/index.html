Title
Amazon RDS for MariaDB 现已支持 MariaDB 12.3
Source
AWS News
Published
2026-08-11T08:54:00Z
Summary
即日起，Amazon RDS for MariaDB 支持 MariaDB 主要版本 12.3，这是 MariaDB 社区发布的最新长期支持版本。此版本支持 MariaDB 12.3.2 次要版本。 MariaDB 12.3 实现了与 Oracle TO_DATE() 函数的兼容，减少了将应用程序从 Oracle 迁移到 MariaDB 时需修改的代码量。它新增一个 IS JSON 谓词，可让您在数据库而非应用程序代码中原生验证 JSON 文档。查询优化器现在能够更高效地处理可重排序的 LEFT JOIN 语句，以及针对 RANGE 分区的有序扫描，从而在无需更改应用程序的前提下，提升这些查询的性能。有关更多详细信息，请参阅 MariaDB 12.3 发行说明 和 RDS MariaDB 发行说明 。 您可以使用 Amazon RDS 蓝绿部署 、就地升级或从快照还原来升级数据库。参阅 Amazon RDS 用户指南 ，了解有关执行主要版本升级的更多信息。您还可以使用 AWS Database Migration Service ，从外部 MariaDB 源迁移到 RDS for MariaDB 12.3。 Amazon RDS for MariaDB 可让您轻松地在云中设置、操作和扩展 MariaDB 部署。有关定价详细信息和区域可用性，请参阅 Amazon RDS for MariaDB 。在 Amazon RDS 管理控制台 中创建或更新完全托管式 Amazon RDS for MariaDB 数据库。
