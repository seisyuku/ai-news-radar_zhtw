來源摘要（原文）
AWS 宣布推出适用于 Amazon WorkSpaces 个人版的全新 Linux 捆绑包，其中包括 Rocky Linux 10、Red Hat Enterprise Linux 10 和 Ubuntu 26.04 LTS。借助这些捆绑包，您可以在最新的企业版 Linux 操作系统上启动 WorkSpaces，并使用仅这些版本附带的新版软件包。这些新捆绑包采用现代 Wayland 显示技术，可让您使用最新的 Linux 桌面功能。新的操作系统选择不仅提升了安全性，而且延长了各个分发版的支持生命周期。 基于 Rocky Linux 8 和 9、Red Hat Enterprise Linux 8 和 9 以及 Ubuntu 22.04 LTS 和 24.04 LTS 的 WorkSpaces 捆绑包仍可继续使用，而新捆绑包可让您按自己的时间表采用最新版本。您现有的 WorkSpaces 可继续运行，没有任何变化。在应用程序和工作流准备就绪后，您可以将用户迁移到新的操作系统。 要开始使用，请在创建新的 Linux WorkSpace 时，选择托管式 Rocky Linux 10、Red Hat Enterprise Linux 10 或 Ubuntu 26.04 LTS 捆绑包。这些捆绑包以 Standard、Performance、Power 和 PowerPro 规格提供，已在提供 Amazon WorkSpaces 的所有 AWS 区域推出。有关受支持的操作系统的完整列表，请参阅 Bundles and images for WorkSpaces Personal 。有关定价信息，请访问 Amazon WorkSpaces 定价页面 。
