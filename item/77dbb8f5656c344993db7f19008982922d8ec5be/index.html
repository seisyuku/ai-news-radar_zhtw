Title
Microsoft Expands Copilot Model Library: SpaceXAI Grok Officially Launched in Word, Excel, and PowerPoint
Source
AIBASE
Published
2026-09-14T01:58:34Z
Summary
Microsoft announced the introduction of SpaceXAI's Grok model into Microsoft 365 Copilot, which is now available in Word, Excel, and PPT. It is currently offered as a limited preview under the Frontier project to specific customers for evaluating office task efficiency. This move continues Microsoft's strategy of reducing reliance on a single provider like OpenAI, following the integration of models such as Anthropic Claude, further promoting a multi-model supply approach.
