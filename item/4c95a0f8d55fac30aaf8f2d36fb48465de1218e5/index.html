Title
AWS Transfer Family 现可自动批准将 SFTP 连接器配额增加至 1000 个
Source
AWS News
Published
2026-09-30T08:00:00Z
Summary
AWS Transfer Family 现在可以自动批准将每个 AWS 区域中每个 AWS 账户的 SFTP 连接器配额增加至最多 1000 个请求。随着文件传输需求的增长，您可以添加更多连接器，无需等待人工审批。 默认配额仍为每个 AWS 账户在每个 AWS 区域内 100 个 SFTP 连接器，您仍需通过 AWS 服务配额控制台申请增加配额。此前，所有配额增加请求都需要人工审批。自动审批适用于使用服务托管型或 Amazon VPC Lattice 出口的连接器。如果您需要超过 1000 个连接器，请在服务配额控制台中提交增加配额的申请。 该功能已在所有提供 Transfer Family SFTP 连接器的 AWS 区域推出。要了解更多信息，请访问 AWS Transfer Family SFTP 连接器文档 。
