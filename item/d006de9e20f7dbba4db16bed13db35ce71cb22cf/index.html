來源摘要（原文）
今天，AWS 推出了 TorchNeuron 的公开测试版，这是面向 AWS Trainium 的开源原生 PyTorch 后端。Trainium 是一个 AI 芯片组合，旨在为深度学习 AI 训练和推理工作负载提供高性能和成本效益。TorchNeuron 让 AI 科学家和研究人员能够在 Trainium 上原生使用 PyTorch 进行试验和构建模型。 有了 TorchNeuron，开发人员只需切换到 .to('neuron') 即可在 Trainium 上启用 PyTorch 代码，同时保持 PyTorch 与即时执行、torch.compile 和标准 PyTorch API 的完全兼容。此外，TorchNeuron 与 Neuron Kernel 接口（NKI）集成，可为 Trainium 硬件提供自定义运算符和性能优化。 TorchNeuron 可通过适用于 Amazon EC2 Trainium2 实例和 Amazon EC2 Trainium3 实例的 TorchNeuron GitHub 存储库 以开源形式获得。 要了解有关 TorchNeuron 和 AWS Trainium 加速器的更多信息，请访问 AWS Neuron 页面 。
