新聞標題（原文）
AWS Backup 现已支持用于 Amazon EKS 还原的资源修改器
收錄來源
AWS News
發布時間（來源提供）
2026-11-12T08:00:00Z
來源摘要（原文）
今天，AWS Backup 宣布在还原 Amazon Elastic Kubernetes Service（Amazon EKS）备份时支持资源修改器。利用资源修改器，您可以在还原过程中转换 Kubernetes 资源，以便让还原后的集群适配目标环境。 当您还原已跨账户或 AWS 区域复制的 EKS 备份时，还原后的集群可能带有与源环境相关的引用，例如 IAM 角色、数据库端点和 Amazon ECR 注册表 URI。以前，每次还原后，您都必须手动查找和更新这些引用，这既耗时又容易出错。利用资源修改器，您只需通过 YAML 文件定义一次转换规则，AWS Backup 便会在还原过程中自动应用该规则，从而提升跨账户与跨区域灾难恢复工作流的可靠性。 AWS Backup 对 Amazon EKS 备份资源修改器的支持，已在所有 AWS 商业区域和 AWS GovCloud（美国）区域推出。要开始使用，请参阅 AWS Backup 文档 和 发布博客 。
