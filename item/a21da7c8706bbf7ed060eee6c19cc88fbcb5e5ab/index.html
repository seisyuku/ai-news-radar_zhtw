Title
Amazon EC2 I8g 实例现已在 AWS 欧洲地区（巴黎）、亚太地区（雅加达）区域推出
Source
AWS News
Published
2026-08-04T16:00:00Z
Summary
AWS 宣布在以下 AWS 区域全面推出 Amazon EC2 存储优化型 I8g 实例：欧洲地区（巴黎）和亚太地区（雅加达）。 I8g 实例由 AWS Graviton4 处理器提供支持，可为存储密集型工作负载提供 Amazon EC2 中最佳的计算性能。I8g 实例使用第三代 AWS Nitro SSD，即本地 NVMe 存储，与 I4g 实例相比，每 TB 的实时存储性能提升高达 65%，同时存储 I/O 延迟降低高达 50%，存储 I/O 延迟可变性降低高达 60%。这些实例基于 AWS Nitro System 构建，该系统将 CPU 虚拟化、存储和联网功能卸载到专用硬件和软件，从而增强工作负载的性能和安全性。 Amazon EC2 I8g 实例专为需要快速数据访问和存储实时延迟的 I/O 密集型工作负载而设计。这些实例在处理事务型、实时、分布式数据库方面表现出色，包括 MySQL、PostgreSQL、HBase 以及如 Aerospike、MongoDB、ClickHouse 和 Apache Druid 等 NoSQL 解决方案。它们还针对实时分析平台（如 Apache Spark）、数据湖仓以及用于训练的 AI LLM 预处理进行了优化。I8g 实例有十一种不同的大小可供选择，包括两种裸机大小，内存为 1.5 TiB，本地实例存储容量为 45 TB。它们提供高达 100Gbps 的网络性能带宽和 60Gbps 的 Amazon Elastic Block Store (EBS) 专用带宽。 要了解更多信息，请访问 Amazon EC2 I8g 实例 。 要开始您的 Graviton 之旅，请访问 使用 AWS Graviton 提升您的计算能力 页面。要开始使用，请参阅 AWS 管理控制台 、 AWS 命令行界面 (AWS CLI) 和 AWS SDK 。
