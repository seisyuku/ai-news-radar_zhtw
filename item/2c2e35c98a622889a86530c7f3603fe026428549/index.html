Title
Amazon Aurora DSQL 现已支持 Amazon CloudWatch 数据库洞察
Source
AWS News
Published
2026-08-20T16:00:00Z
Summary
Amazon Aurora DSQL 现已新增一项 Amazon CloudWatch 数据库洞察指标，可提供单条语句、集群级别的性能监控详情。Aurora DSQL 数据库洞察可捕获所有活跃集群会话的采样等待状态和标准化 SQL 语句。您可以使用该指标诊断集群的性能问题，并识别资源消耗最高的查询。 借助 Aurora DSQL 数据库洞察指标，可使用 Amazon CloudWatch 数据库洞察、Amazon CloudWatch PromQL 和 Aurora DSQL 系统诊断 AI 技能来分析集群性能。该指标（每隔 1 分钟捕获一次）默认可用，不额外收费。 此功能已在提供 Aurora DSQL 的所有 AWS 区域 推出。要了解有关 Aurora DSQL 数据库洞察的更多信息，请阅读 博客 与 开始使用 。要了解有关 CloudWatch 数据库洞察的更多信息，请参阅 定价 和 文档 。
