Amazon GameLift Servers 为容器实例集新增 CPU 突发能力

來源摘要（原文）
Amazon GameLift Servers 现在为容器实例集提供 CPU 突发能力，使游戏开发人员在运行时能够更灵活地分配和使用计算资源。此前，容器实例集依赖于固定的 CPU 值，该值既能控制容器部署密度，又设定了严格的运行时上限。这种双重限制迫使开发人员在高效的资源利用率和为游戏服务器工作负载保留性能余量之间做出选择。 游戏服务器的工作负载本质上具有突发性：在比赛的大部分时间里，CPU 需求保持在较低水平，但在物理计算、人工智能处理或碰撞检测过程中会急剧增加。借助 CPU 突发能力，开发人员现在可以根据常规的 CPU 需求部署容器，同时仍允许游戏服务器进程在需求高峰时段突发使用实例中闲置的可用 CPU。此功能需选择性启用，并按容器组定义进行配置。它支持高密度部署而不损耗峰值性能，且包含在标准容器实例集定价中，不收取任何额外费用。 Amazon GameLift Servers 容器实例集的 CPU 突发能力现已在支持容器实例集的所有 AWS 区域推出，不包括中国区域。 要了解有关 Amazon GameLift Servers 容器实例集的 CPU 突发能力的更多信息，请参阅 Amazon GameLift Servers 开发人员指南 或浏览 Amazon GameLift Servers 产品页面 。
