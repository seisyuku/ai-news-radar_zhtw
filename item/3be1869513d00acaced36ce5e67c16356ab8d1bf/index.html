Title
AWS DataSync 增强模式现在支持 Amazon EFS 和适用于 Lustre 的 Amazon FSx
Source
AWS News
Published
2026-07-28T10:00:00Z
Summary
AWS DataSync 增强模式现在支持将 Amazon EFS 和适用于 Lustre 的 Amazon FSx 作为源位置或目标位置。 AWS DataSync 是一项安全的高速文件传输服务，可简化通过网络移动数据的过程。增强模式可并行处理数据，消除文件数量限制，并提供详细的传输指标。此前，想要将数据移入或移出 EFS 或适用于 Lustre 的 FSx 的客户只能使用基本模式。现在，客户可以在这些位置使用增强模式，从而简化大规模迁移、代理式人工智能和机器学习训练、高性能计算、基因组学处理和媒体渲染的工作流程。 此功能现已在提供 AWS DataSync 的所有 AWS 区域 推出。要开始使用，请访问 AWS DataSync 控制台 。有关更多信息，请参阅 AWS DataSync 文档 。
