AWS Control Tower AFT 现已支持仅计划的自定义运行
收錄來源

發布時間（來源提供）
2026-10-05T19:31:00Z
來源摘要（原文）
AWS Control Tower Account Factory for Terraform（AFT）现已支持仅计划的自定义运行，这使管理员能够在将 Terraform 更改应用到其管理的账户之前预览这些更改。 AFT 是一个开源的 Terraform 模块，可自动完成 AWS Control Tower 环境中的账户预置和自定义配置。此前，调用自定义配置总会触发完整的 Terraform 应用，且无法预览更改，这使得在广泛部署之前难以验证预期结果或发现意外的配置偏差。借助仅计划的运行，管理员现在可以针对全局和账户自定义配置触发 Terraform 计划，而无需应用任何更改。该功能支持发布前验证和偏差检测，并可集成到 CI/CD 审查工作流程中。仅计划的运行兼容所有支持 AFT 的 Terraform 发行版，包括开源版本、Terraform Cloud 和 Terraform Enterprise。 该功能已在支持 AWS Control Tower Account Factory for Terraform 的所有 AWS 区域推出。要开始使用，请参阅 AFT 文档 和 AFT 1.22.0 发行说明 ，了解配置详细信息。有关更多信息，请参阅 AWS Control Tower 用户指南 。
