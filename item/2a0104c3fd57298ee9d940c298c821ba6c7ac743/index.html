Title
Amazon Bedrock 将 IAM 主体成本分配功能扩展至 bedrock-mantle 端点
Source
AWS News
Published
2026-08-11T20:25:00Z
Summary
Amazon Bedrock 是一项完全托管的服务，提供对领先人工智能公司高性能基础模型的安全企业级访问，使您能够构建和扩展生成式人工智能应用程序。Amazon Bedrock 现已支持针对通过 bedrock-mantle 端点发出的模型推理请求，按 AWS Identity and Access Management（IAM）主体（包括 IAM 用户和角色）进行成本分配。这扩展了此前在 bedrock-runtime 端点上可用的功能，助力客户将推理成本分摊到用户、团队、项目和应用程序上。 客户可以为 IAM 用户和角色添加“团队”、“项目”或“成本中心”等属性标签，并将其激活为成本分配标签；随后，便可在 AWS Cost Explorer 成本管理服务中按标签分析 bedrock-mantle 推理成本，或在 AWS 成本和使用情况报告 2.0（CUR 2.0）的行项目级别进行深入分析。要开始使用，请在 AWS 账单与成本管理控制台中激活 IAM 主体标签。然后，在 Cost Explorer 成本管理服务中按标签对成本进行筛选或分组，或创建一个 CUR 2.0 数据导出并选择“包含调用者身份（IAM 主体）分配数据”。 此功能已在提供 bedrock-mantle 端点的所有 AWS 区域推出。要了解更多信息，请参阅 使用 IAM 主体进行成本分配 和 Amazon Bedrock 中的 IAM 主体归因 。
