AWS Batch 现在支持向 Amazon CloudWatch 发布作业指标

來源摘要（原文）
AWS Batch 现在支持向 Amazon CloudWatch 发布作业指标，为批处理工作负载提供原生可观测性。AWS Batch 在整个作业生命周期中都会发布指标，让您能够了解作业队列运行状况、失败率和作业持续时间。 AWS Batch 自动将作业状态转换和持续时间指标发布到 Amazon CloudWatch 中的 AWS/BATCH 命名空间，维度为 JobQueueName。状态转换指标用于追踪有多少作业进入了给定状态，例如已提交、正在运行、成功或失败。持续时间指标用于追踪作业在各状态之间停留的时间，例如从提交到可运行状态所需的时间，或总执行时间。您可以在 AWS Batch 控制台、Amazon CloudWatch 控制台中或通过 AWS CLI 和 AWS SDK 查看这些指标。 AWS Batch CloudWatch 指标现已在提供 AWS Batch 的所有 AWS 区域 发布。有关更多信息，请参阅 AWS Batch 用户指南 中的 CloudWatch Metrics（指标）页面。
