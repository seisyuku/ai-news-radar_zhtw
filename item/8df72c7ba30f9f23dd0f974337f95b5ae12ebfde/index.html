Title
适用于 .NET 的 AWS Lambda Durable Execution SDK 现已正式推出
Source
AWS News
Published
2026-07-23T18:00:00Z
Summary
今天，AWS 宣布适用于 .NET 的 AWS Lambda Durable Execution SDK 正式推出，该 SDK 使 C# 开发人员能够利用 Lambda 耐用函数构建具有弹性的长期运行工作流程。借助此 SDK，开发人员可以直接在应用程序中创建多步骤应用程序，例如付款处理管道、人工智能代理编排以及人机协同审批，而无需实施自定义进度跟踪或集成外部编排服务。 Lambda 耐用函数扩展了 Lambda 的事件驱动编程模型，引入了可自动设置进度检查点的操作，并且在等待外部事件时可将执行暂停长达一年。适用于 .NET 的 AWS Lambda Durable Execution SDK 为使用 Lambda 耐用函数进行构建提供了 C# 原生般的开发体验。它包含进度跟踪步骤、用于人机协同和代理协同工作流程的回调集成、用于可靠函数链的持久化调用，以及用于高效暂停的等待功能。此 SDK 将从 NuGet 安装到您目前使用的.NET 工具链中。此 SDK 中的 本地测试模拟器 使开发人员能够在将其部署到生产环境之前进行本地构建和调试。 要开始使用，请参阅 Lambda 耐用函数开发人员指南 ，以及 NuGet 上适用于 .NET 的 AWS Lambda Durable Execution SDK 。有关区域可用性和定价的详细信息，请参阅 AWS 区域性服务列表 和 AWS Lambda 定价 。
