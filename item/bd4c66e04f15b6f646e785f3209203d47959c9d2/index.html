Amazon Connect Customer Global Resiliency 现已支持跨关联 AWS 区域的持续聊天
收錄來源
AWS News
發布時間（來源提供）
2026-10-23T17:00:00Z
來源摘要（原文）
Amazon Connect Customer Global Resiliency 现在为客户提供了一种机制，可以实现跨关联 AWS 区域的长时间持续聊天体验。利用此功能，最终用户可以恢复以前的对话，同时跨 AWS 区域保留完整上下文、元数据和聊天记录，无需最终用户重复信息，同时让座席能够通过访问各个 AWS 区域的完整对话历史记录来提供个性化的服务。 例如，最终用户可以在美国东部（弗吉尼亚州北部）区域发起一次聊天，然后在关联的美国西部（俄勒冈州）区域恢复该聊天，继续与具有完整对话历史记录和聊天附件的座席进行同一对话。要采用此功能，请启用 全局路由 。 此功能已在支持 Amazon Connect Customer Global Resiliency 的所有 AWS 区域推出。要了解更多信息，请访问 Amazon Connect Customer 管理员指南 。
