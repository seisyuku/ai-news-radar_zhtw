來源摘要（原文）
作为一款用于构建生产级生成式人工智能应用程序和代理的平台，Amazon Bedrock 现已向 AWS GovCloud（美国）区域内符合条件的客户提供 Claude Mythos 5.2。Claude Mythos 5.2 是 Anthropic 迄今为止最先进的人工智能模型，适用于网络安全、软件编码和复杂推理任务使用案例。该模型可识别软件中复杂的安全漏洞，并演示其可利用性。它还能理解大型代码库，并在人工指导更少的情况下交付可操作的调查发现，性能高于以前的人工智能模型。这使安全团队能够加快执行网络安全防御工作，发现并修复全球最重要软件中的安全漏洞，并在威胁出现之前将其解决。Claude Mythos 5.2 是 Anthropic 首款具备强大网络安全功能的人工智能模型，已在 AWS GovCloud（美国）区域推出。 Claude Mythos 5.2 可通过 Amazon Bedrock 提供给 AWS GovCloud（美国）区域内符合条件的客户。访问权限仅限于允许列表中的企业；要开始使用，请访问 Anthropic 的网络验证计划 。
