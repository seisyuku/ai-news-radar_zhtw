Title
AWS Direct Connect 当前支持在虚拟接口上提供 BGP 路由可见性
Source
AWS News
Published
2026-07-30T20:21:00Z
Summary
AWS Direct Connect 现在提供边界网关协议（BGP）路由可见性，使您能够查看在 AWS 与您的本地路由器之间，跨私有、中转和公有虚拟接口（VIF）交换的路由。现在，您可以查看 AWS 从您的路由器接受了哪些路由、AWS 向您的路由器通告了哪些路由，以及这些路由的 AS 路径和 BGP 团体属性值。这种可见性有助于网络管理员排查路由问题、验证路由传播情况，以及监控其混合网络连接。 借助此功能，您可以直接在 Direct Connect 控制台中或通过编程方式使用 ListVirtualInterfaceRoutes API 操作，查看已接受的路由（AWS 从您的路由器接收的路由）和已通告的路由（AWS 发送给您的路由器的路由）。所有路由都会显示其前缀、地址族、AS 路径、团体属性值和安装时间戳，以便您全面了解路由拓扑。您可以按前缀、AS 路径、团体属性或地址族来筛选路由，从而快速识别特定路由行为。在管理复杂的多区域架构、验证 BGP 策略配置或诊断异常流量模式时，此功能尤为有用。 此功能已在所有 AWS 商业区域以及 AWS 中国区域（北京，由光环新网运营；宁夏，由西云数据运营）推出。 要了解有关 BGP 路由可见性的更多信息，请参阅 AWS Direct Connect 文档 ，或通过 Direct Connect 控制台 访问该功能。
