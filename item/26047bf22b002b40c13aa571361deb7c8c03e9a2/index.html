Title
Amazon MSK Connect 现已支持暂停和恢复连接器
Source
AWS News
Published
2026-10-22T15:00:00Z
Summary
Amazon MSK Connect （Amazon Managed Streaming for Apache Kafka Connect）现已支持暂停和恢复连接器，允许您临时暂停连接器处理记录，稍后再恢复。如果您需要在维护源数据库或目标端期间停止数据流，或者在调查上游或下游问题时暂停处理，此功能很有用。 Amazon MSK Connect 是一项完全托管的服务，允许您使用 Amazon MSK （Managed Streaming for Apache Kafka）部署、监控和扩展 Apache Kafka Connect 连接器。以前，若要暂停连接器，只能删除并重新创建连接器。该操作破坏性较强，会带来额外风险和运维开销。通过此次发布，您可以暂停正在运行的连接器，并在准备就绪时恢复其运行 – 暂停后的连接器会保留其配置、容量设置和已提交的偏移量，恢复运行时，其任务将从上次提交的偏移量处继续处理。 此功能已在提供 Amazon MSK Connect 的所有 AWS 区域推出，通过 Amazon MSK 控制台、AWS CLI、AWS SDK 和 AWS CDK 即可访问，无需额外付费。要了解更多信息，请参阅 Amazon MSK Connect 文档 。要开始使用，请访问 Amazon MSK 控制台 。
