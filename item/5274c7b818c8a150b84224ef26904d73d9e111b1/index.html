AWS 网络负载均衡器现已在 AWS 菲尼克斯本地区域推出
收錄來源

來源摘要（原文）
AWS 网络负载均衡器现已在菲尼克斯本地区域（us-west-2-phx-2a）推出。AWS Local Zones 是 AWS 基础设施部署的一种形式，可将 AWS 计算、存储、数据库和其他精选服务放置在更靠近目前不存在 AWS 区域的大量人口聚居的位置，或者靠近行业和 IT 中心的位置。 通过此次发布，您可以直接在菲尼克斯本地区域创建 AWS 网络负载均衡器。此前，如果您的目标在菲尼克斯本地区域运行，您必须将负载均衡器放在父区域的可用区中，因此连接及其流量必须往返父区域。这增加了延迟，并将流量路由到应用程序运行区域之外。现在，连接路由对目标保持本地状态，为菲尼克斯都会区的最终用户提供更短、更一致的延迟，并将流量保持在本地区域内。对于延迟敏感型工作负载（如为该区域用户提供服务的实时游戏、媒体流和实时金融应用程序），这一点尤其有用。 要了解有关网络负载均衡器的更多信息，请访问 文档 。有关 AWS Local Zones 的更多信息，请访问 AWS Local Zones 网站 。 位置网页 列出了可用和已宣布的本地区域。您可以在 AWS Global View 控制台的 Local Zones 选项卡中启用 AWS Local Zones，也可以使用 ModifyAvailabilityZoneGroup API 启用该功能。
