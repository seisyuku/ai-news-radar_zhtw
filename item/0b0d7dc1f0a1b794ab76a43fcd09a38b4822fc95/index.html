Title
AWS Clean Rooms 支持自定义分析规则中的最小聚合阈值
Source
AWS News
Published
2026-08-13T12:00:00Z
Summary
AWS Clean Rooms 现已支持 自定义分析规则类型中的最小聚合阈值 。最小聚合阈值可防止查询返回有关个体或小规模群体的结果，从而保护个体数据主体的隐私。本次发布后，组织可以对自定义 SQL 查询强制实施最小聚合阈值，确保查询输出的每一行至少代表指定数量的不同值（例如用户 ID）。参与协作的数据提供方可指定身份列以及对查询输出强制执行的最小身份计数；也可以选择为特定列设置更高的阈值。 以前，要对自定义 SQL 强制实施最小聚合阈值，数据提供方必须依赖预先批准的分析模板，并在查询运行前执行人工代码审查。现在，数据提供方可以使用自定义分析规则类型，为自定义 SQL 配置最小聚合阈值，而无需使用预结构化查询或手动审批流程。此外，数据提供方可以指定哪些列可跨数据集进行筛选或关联。例如，发布者与广告主在媒体规划使用案例中开展协作时，可允许对其数据执行临时查询；而包含不到 1000 名普通用户的小型农村邮编区域，将自动从结果中过滤掉，从而保护用户隐私。 AWS Clean Rooms 可以帮助公司及其合作伙伴轻松地分析他们的汇总数据集并进行协作，而无需透露或复制彼此的底层数据。有关提供 AWS Clean Rooms 的 AWS 区域的更多信息，请参阅 AWS 区域 表。要了解有关通过 AWS Clean Rooms 进行协作的更多信息，请访问 AWS Clean Rooms 。
