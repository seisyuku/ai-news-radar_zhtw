Title
AWS DevOps 智能体新增对双向 Slack 通信的支持
Source
AWS News
Published
2026-09-11T15:00:00Z
Summary
现在，借助 AWS DevOps 智能体，工程师可以直接在 Slack 中跨 AWS、多云和本地环境管理生产运维，并完成完整的调查生命周期。以前，值班工程师和 DevOps 团队在处理高危事件时，会遇到工作流割裂问题，迫使他们在通信平台与调查平台之间来回切换上下文。本次更新将这两个平台整合为一个统一位置，即事件响应发生的地方。 现在，工程团队只需在任何已连接的 Slack 私有频道中 @ AWS DevOps 智能体，即可启动并引导调查。所有调查活动（包括团队提供的上下文、智能体调查发现和建议的操作）都记录在一个线程中。提出有关 AWS 资源、系统指标、警报状态、部署历史记录和事件模式的问题，从而减轻关键时刻的认知负担，并显著提升生产运维效率。 此功能已在 当前支持 AWS DevOps 智能体的所有 AWS 商业区域推出。 要开始使用，请参阅 用户指南 。请在 发布历史记录 页面上查看所有最新的 AWS DevOps 智能体功能。
