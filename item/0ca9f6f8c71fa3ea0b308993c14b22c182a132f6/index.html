來源摘要（原文）
Amazon DCV 2026.0 现已发布，新增了对 RHEL 10、Rocky Linux 10、CentOS 10 和 Ubuntu 26.04 的支持，同时推出了新的 macOS 客户端，并更新了 Windows 和 Linux 客户端。Amazon DCV 是一种高性能的远程显示协议，支持客户安全地访问跨 Windows、Linux 和 macOS 平台的远程桌面和应用程序会话。 Amazon DCV 2026.0 包括以下关键功能和改进： 支持 RHEL 10、Rocky Linux 10、CentOS 10 和 Ubuntu 26.04，且 Linux 主机和会话均在现代 Wayland 显示服务器上运行 支持游戏手柄的新版 macOS 客户端，以及更新后的 Windows 和 Linux 客户端 Windows 主机上的 URL 重定向功能，使在远程会话中打开的已配置链接能在客户端设备的本地浏览器中启动 Windows 上的偏好设置重定向功能，使远程会话能够访问客户端的打印机设置 性能优化，包括在 Linux 和 macOS 客户端上支持 H.264 帧切片以及基于切片的多线程解码，以降低延迟 支持 Amazon EC2 上的新 macOS 服务器版本 如需进一步了解 Amazon DCV 2026.0 中的新功能和增强功能，请参阅 发行说明 或访问 Amazon DCV 网页 ，了解更多信息并开始使用。
