Title
AWS Transform 现已纳入 FedRAMP C 类认证范围
Source
AWS News
Published
2026-08-28T19:45:00Z
Summary
AWS Transform 现已纳入美国东部（俄亥俄州）区域的 FedRAMP C 类认证范围（以前属于中等基准范围）。现在，您可以使用 AWS Transform 构建应用程序，并运行满足 FedRAMP C 类合规要求的工作负载。 联邦风险与授权管理计划 (FedRAMP) 是一项美国政府层面的计划，它提供一种标准方法来对云产品和云服务进行安全性评估、授权以及持续监控。 AWS Transform 是一项代理式迁移与现代化服务，旨在将企业转型周期从数年压缩至数月。它能够处理从大规模迁移基础设施到持续减少技术债务的所有工作，且无需担心通常会导致此类项目陷入停滞的手动交接和上下文丢失问题。 要了解有关 FedRAMP 的更多信息，请参阅 AWS 合规范围内服务页面 。要了解有关 AWS Transform 的更多信息，请访问 网页 和 文档 。
