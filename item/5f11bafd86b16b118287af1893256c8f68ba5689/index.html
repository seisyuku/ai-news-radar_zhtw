Title
适用于 InfluxDB 的 Amazon Timestream 现支持备份和还原
Source
AWS News
Published
2026-08-07T19:21:00Z
Summary
适用于 InfluxDB 的 Amazon Timestream 现支持您创建和管理自己的备份，并按需还原数据。您可以触发一次性按需备份，根据您选择的频率和保留期安排自动定期备份，并将备份还原到新资源或替换现有资源。该功能适用于 InfluxDB 2 和 InfluxDB 3 两种引擎，可通过 AWS 管理控制台、AWS CLI 以及适用于 InfluxDB 的 Timestream API 使用。 借助此功能，您可以掌控自己的数据保护策略。在进行高风险的迁移或配置更改之前，您可以进行按需备份。此外，您还可以为每个资源定义多达四项自动备份配置，采用每小时、每天、每周、每月或自定义时间表，每项配置均可设置独立的保留期。首次备份将捕获数据库的完整副本，后续备份为增量备份，这可减小持续备份对性能的影响。还原备份时，您可以创建一个继承源配置的新资源，或替换现有资源。如果源资源使用客户自主管理型密钥（KMS），其备份将使用相同的密钥。 客户驱动的备份和还原功能已在提供适用于 InfluxDB 的 Amazon Timestream 的所有 AWS 区域 推出。要开始使用，请打开 Amazon Timestream 控制台。有关更多信息，请参阅 适用于 InfluxDB 的 Amazon Timestream 文档 和 定价页面 。
