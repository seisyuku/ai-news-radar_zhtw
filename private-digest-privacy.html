AI News Radar Daily｜隱私權說明

工具說明 · 隱私權說明 · 使用說明

存取哪些資料

程式使用 Google Drive／Docs API 保存日報原始 Markdown 與 metadata、可讀原稿、校稿副本，並讀取私人設定。只要求 drive.file，不要求讀取全部 Drive、Gmail、聯絡人或個人帳號資料。API 可回傳檔案名稱、ID、內容、連結及權限資料；程式用於保存、讀回與確認本人存取。

資料用途與位置

文件內容只用於維護者的日報生成、閱讀、校稿及設定。檔案保存於本人私人 Google Drive；GitHub Actions 暫時處理產物，工作收尾清除本次暫存資料。不將私人稿件或輸入放進公開儲存庫、公開 artifact 或執行摘要。若工作被強制終止，收尾可能無法執行，暫存仍依執行環境回收。

授權憑證

一次性授權在維護者的 Mac 執行。憑證保存在本機 Downloads 私人檔案與 GitHub 加密 Secrets，用於取得短期 Google access token；不寫入程式碼或公開日誌。

哪些服務參與

Google 提供授權、Drive 儲存與 Docs 編輯；GitHub Actions 執行已設定的工作。維護者若主動使用 ChatGPT 的 Drive 連線讀寫文件，該次內容也會進入其使用的 ChatGPT 環境，依現有帳號及服務設定處理。此日報保存程式沒有呼叫 Gemini 或其他 LLM 生成服務。

分享與撤銷

程式不將私人日報公開分享、不自動發布或出售 Google 文件內容。維護者可在 Google 帳號的第三方存取設定撤銷授權，並在 Drive 刪除文件；撤銷授權不會自行刪除既有文件。程式沒有自動清理私人歷史稿件的排程。

聯絡與更新

此工具由 AI News Radar 專案維護者自用維護。可透過專案 GitHub Issues 提出一般問題，請勿提交憑證、私人文件內容或私人連結。用途或資料處理方式改變時，應同步更新本說明。
