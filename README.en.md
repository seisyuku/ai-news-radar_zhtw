## What this project provides

The site aggregates official AI-company announcements and industry reporting,
then promotes six types of business events into the primary signal view:

| Category | Coverage |
| --- | --- |
| Earnings | Revenue, financial milestones, and IPO activity |
| Market structure | Market-share shifts, acquisitions, and antitrust action |
| Security | Material vulnerabilities and security incidents |
| Pricing | Pricing, plans, and commercial offer changes |
| Benchmarks | Model evaluations and leaderboard changes |
| Model releases | Major proprietary and open model releases |

The broader list includes relevant product releases, research, and industry
reporting. Every item links to its original source.

## What this project does not target

- Programming tutorials, prompt tips, or tool walkthroughs
- General social-media discussions and opinion threads
- Individual developers' implementation notes

The editorial question is “what material event happened in the AI industry?”,
not “how do I use AI to write code?”.

## Source governance

Sources are separated into official first-party channels, international
business and technology media, Taiwan media, independent benchmark providers,
watchlist sources, and comparison-only digests. The source badge shown on the
site reflects that tier. See [Source Coverage](docs/SOURCE_COVERAGE.md) for the
current source policy and [Operations](docs/OPERATIONS.md) for deployment and
monitoring procedures.

## How it runs

The project is a static site generated by GitHub Actions. The scheduled job
fetches sources, filters for AI relevance, identifies business events, converts
Chinese text to Taiwan Traditional Chinese, and publishes static JSON and web
assets. The public site needs no application server or database.

Local verification:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-dev.txt
python -m py_compile scripts/update_news.py
python -m pytest -q
python scripts/update_news.py --output-dir data --window-hours 24 --rss-opml feeds/follow.opml
python -m http.server 8080
```

Never commit `feeds/follow.opml`, API keys, tokens, cookies, or `.env` values.
Use `feeds/follow.example.opml` as the public template.
